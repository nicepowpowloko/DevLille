1. Vue d'ensemble

Pour développer des applications web avec PHP et MySQL, chaque apprenant a besoin d'un environnement de développement local sur son ordinateur. Cet environnement simule un vrai serveur web.

1.1 Ce dont on a besoin

Les outils nécessaires pour tous les OS
Apache : Serveur web local qui fait tourner les fichiers PHP (simule internet)
MySQL : Moteur de base de donnees qui stocke les donnees
PHP : Langage de programmation cote serveur
phpMyAdmin : Interface graphique pour gerer MySQL (creer des BDD, des tables, etc.)

1.2 Quel outil selon l'OS

Windows

Outil : Laragon

Site : laragon.org

Difficulte : Tres simple

Gratuit : Oui

Looping : Fonctionne nativement

Mac

Outil : MAMP

Site : mamp.info

Difficulte : Simple

Gratuit : Oui (version de base)

Looping : Non disponible

Linux

Outil : XAMPP

Site : apachefriends.org

Difficulte : Simple

Gratuit : Oui

Looping : Non disponible

Pour Looping (modélisation Merise) : Looping fonctionne uniquement sur Windows. Les apprenants Mac et Linux peuvent utiliser les PC Windows de la salle pour les séances de modélisation, ou utiliser les alternatives gratuites détaillées en section 5.

2. Windows - Laragon

Windows - Installation de Laragon

2.1 Télécharger Laragon

1Aller sur le site officiel

Ouvrir le navigateur et aller sur : laragon.org/download

Choisir Laragon Full (inclut Apache, MySQL, PHP, phpMyAdmin, Git, Node.js)

2Installer Laragon

Double-cliquer sur le fichier .exe téléchargé

Suivre l'assistant d'installation (tout laisser par défaut)

Laragon s'installe dans C:\laragon\

3Lancer Laragon

Double-cliquer sur l'icône Laragon sur le Bureau

Cliquer sur "Démarrer tout" (Start All)

Apache et MySQL doivent passer au vert

4Vérifier l'installation

Ouvrir le navigateur → aller sur http://localhost

La page d'accueil Laragon doit s'afficher

2.2 Accéder à phpMyAdmin

URL : http://localhost/phpmyadmin
Utilisateur : root
Mot de passe : (vide, ne rien saisir)

3. Mac - MAMP

Mac - Installation de MAMP

3.1 Télécharger MAMP

1Aller sur le site officiel

Ouvrir le navigateur et aller sur : mamp.info/fr

Cliquer sur "Télécharger MAMP"

Choisir la version MAMP (gratuit), pas MAMP PRO (payant)

2Installer MAMP

Ouvrir le fichier .pkg téléchargé

Suivre l'assistant d'installation

MAMP s'installe dans /Applications/MAMP/

3Lancer MAMP

Ouvrir MAMP depuis le dossier Applications

Cliquer sur "Start Servers"

Les deux indicateurs (Apache et MySQL) doivent passer au vert

La page d'accueil MAMP s'ouvre automatiquement dans le navigateur

4Vérifier l'installation

Ouvrir le navigateur → aller sur http://localhost:8888

La page d'accueil MAMP doit s'afficher

Difference importante avec Laragon : MAMP utilise le port 8888 par defaut au lieu du port 80. Toutes les URLs doivent inclure :8888.

3.2 Accéder à phpMyAdmin

URL : http://localhost:8888/phpmyadmin
Utilisateur : root
Mot de passe : root (different de Laragon !)

3.3 Changer le port (optionnel)

Pour utiliser le port 80 (comme Laragon) et simplifier les URLs :

  1. Ouvrir MAMP → Cliquer sur "Préférences"
  2. Onglet "Ports"
  3. Cliquer sur "Mettre les ports Apache et MySQL à 80 et 3306"
  4. Cliquer "OK" et redémarrer les serveurs

3.4 Informations importantes

Information Valeur par défaut Après changement port

URL phpMyAdminhttp://localhost:8888/phpmyadminhttp://localhost/phpmyadmin
Dossier des projets/Applications/MAMP/htdocs/
Utilisateur MySQLroot
Mot de passe MySQLroot
Port MySQL88893306

4. Linux - XAMPP

Linux - Installation de XAMPP

4.1 Télécharger XAMPP

1Aller sur le site officiel

Ouvrir le navigateur et aller sur : apachefriends.org/fr/download.html

Télécharger la version Linux (fichier .run)

Choisir la version compatible avec PHP 8.x

2Rendre le fichier exécutable

Ouvrir un terminal dans le dossier de téléchargement :

# Rendre le fichier exécutable
chmod +x xampp-linux-x64-8.x.x-installer.run

# Lancer l'installation
sudo ./xampp-linux-x64-8.x.x-installer.run

3Suivre l'installateur graphique

Un assistant graphique s'ouvre

Tout laisser par défaut et cliquer "Next" jusqu'à la fin

XAMPP s'installe dans /opt/lampp/

4Démarrer XAMPP

# Démarrer tous les services
sudo /opt/lampp/lampp start

# Démarrer uniquement Apache
sudo /opt/lampp/lampp startapache

# Démarrer uniquement MySQL
sudo /opt/lampp/lampp startmysql

# Arrêter tous les services
sudo /opt/lampp/lampp stop

# Vérifier le statut
sudo /opt/lampp/lampp status

5Lancer l'interface graphique XAMPP (optionnel)

# Ouvrir le panneau de contrôle graphique
sudo /opt/lampp/manager-linux-x64.run

6Vérifier l'installation

Ouvrir le navigateur → aller sur http://localhost

La page d'accueil XAMPP doit s'afficher

4.2 Alternative : Installation manuelle (Ubuntu / Debian)

Si XAMPP pose des problèmes, voici l'installation directe via les paquets système :

# Mettre à jour les paquets
sudo apt update && sudo apt upgrade

# Installer Apache
sudo apt install apache2

# Installer MySQL
sudo apt install mysql-server

# Installer PHP et l'extension MySQL
sudo apt install php php-mysql php-mbstring php-xml php-curl

# Installer phpMyAdmin
sudo apt install phpmyadmin

# Démarrer les services
sudo systemctl start apache2
sudo systemctl start mysql

# Activer au démarrage automatique
sudo systemctl enable apache2
sudo systemctl enable mysql

Sécuriser MySQL après installation

# Lancer le script de sécurisation
sudo mysql_secure_installation

# Puis se connecter à MySQL
sudo mysql -u root -p

# Créer un utilisateur pour phpMyAdmin
CREATE USER 'dev'@'localhost' IDENTIFIED BY 'motdepasse';
GRANT ALL PRIVILEGES ON *.* TO 'dev'@'localhost';
FLUSH PRIVILEGES;

4.3 Accéder à phpMyAdmin

URL : http://localhost/phpmyadmin
Utilisateur XAMPP : root / mot de passe vide
Utilisateur installation manuelle : dev / ton mot de passe

5. Looping et ses Alternatives

Looping est le logiciel de modélisation Merise utilisé en cours. Il fonctionne uniquement sur Windows. Voici les solutions pour chaque OS.

5.1 Windows - Looping natif

Windows - Looping fonctionne nativement

1Télécharger Looping

Site officiel : looping-mcd.fr

Télécharger le fichier .zip et décompresser

Double-cliquer sur Looping.exe (pas d'installation requise)

Looping fonctionne directement. Aucune configuration necessaire.

5.2 Mac - Alternatives à Looping

Mac - Alternatives gratuites à Looping

Option A : draw.io (recommandée - gratuit, en ligne)

Utiliser draw.io pour les MCD

Site : app.diagrams.net

  • Fonctionne dans le navigateur, aucune installation
  • Contient des formes pour les entités et associations Merise
  • Export en PDF, PNG, XML
  • Sauvegarde dans Google Drive ou localement

Pour les formes Merise dans draw.io :

  1. Ouvrir draw.io → Nouveau diagramme
  2. Menu "Extras" → "Modifier le diagramme"
  3. Ou utiliser les rectangles pour les entités et les losanges pour les associations

Option B : MySQL Workbench (gratuit - génère le SQL)

Utiliser MySQL Workbench

Site : mysql.com/products/workbench

  • Disponible sur Mac, Windows et Linux
  • Création de diagrammes EER (Entité-Relation)
  • Génération automatique du SQL
  • Connexion directe à MySQL pour exécuter le SQL

Option C : Looping via CrossOver (payant ~60€)

Faire tourner Looping sur Mac avec CrossOver

Site : codeweavers.com

  • CrossOver permet de faire tourner des .exe Windows sur Mac
  • Installer CrossOver → Installer Looping.exe dedans
  • Fonctionne dans la plupart des cas

5.3 Linux - Alternatives à Looping

Linux - Alternatives gratuites à Looping

Option A : draw.io (recommandée - gratuit, en ligne)

Même chose que Mac

Site : app.diagrams.net

Fonctionne dans le navigateur sur tous les systèmes.

Option B : MySQL Workbench (gratuit)

Installer MySQL Workbench sur Linux

# Ubuntu/Debian
sudo apt install mysql-workbench

# Ou télécharger depuis le site officiel
# mysql.com/products/workbench

Option C : Looping via Wine (gratuit)

Faire tourner Looping sur Linux avec Wine

# Installer Wine
sudo apt install wine

# Lancer Looping avec Wine
wine /chemin/vers/Looping.exe

Wine est gratuit et permet de faire tourner Looping sous Linux avec des résultats corrects.

7. Dépannage courant

7.1 Problèmes Windows - Laragon

Erreurs courantes Windows
Apache ne démarre pas : Le port 80 est déjà utilisé. Vérifier si Skype, IIS ou un autre serveur tourne. Aller dans Laragon → Préférences → changer le port Apache vers 8080.
MySQL ne démarre pas : Le port 3306 est déjà utilisé. Vérifier si une autre version de MySQL est installée. Redémarrer l'ordinateur puis relancer Laragon.
phpMyAdmin inaccessible : Vérifier que Apache est bien démarré (vert). Essayer http://localhost:80/phpmyadmin.

7.2 Problèmes Mac - MAMP

Erreurs courantes Mac
Erreur de connexion PHP : Verifier que le mot de passe est bien "root" (et non vide). Verifier que le port est 8889 (pas 3306).
Page blanche ou erreur 403 : Les fichiers du projet ne sont pas dans /Applications/MAMP/htdocs/. Deplacer le dossier au bon endroit.
MAMP ne s'ouvre pas : Aller dans Securite et confidentialite → Autoriser les applications de sources inconnues → Relancer MAMP.

7.3 Problèmes Linux - XAMPP

Erreurs courantes Linux
Permission refusée sur htdocs : Changer les permissions : sudo chmod -R 777 /opt/lampp/htdocs/
Apache ne démarre pas : Apache système déjà actif : sudo systemctl stop apache2 puis sudo /opt/lampp/lampp startapache
phpMyAdmin : accès refusé : Configurer un mot de passe MySQL : sudo /opt/lampp/bin/mysql -u root puis ALTER USER 'root'@'localhost' IDENTIFIED BY '';

8. Exercice de Vérification

Chaque apprenant doit réaliser ces étapes pour vérifier que son environnement est correctement installé.

Exercice : Vérifier son installation

Etape 1 : Démarrer les serveurs

  • Windows Laragon → "Démarrer tout" → Apache et MySQL verts
  • Mac MAMP → "Start Servers" → indicateurs verts
  • Linux Terminal → sudo /opt/lampp/lampp start

Etape 2 : Vérifier Apache

  • Windows + Linux → ouvrir http://localhost
  • Mac → ouvrir http://localhost:8888
  • La page d'accueil doit s'afficher

Etape 3 : Vérifier phpMyAdmin

  • Windows + Linux → http://localhost/phpmyadmin → login root / (vide)
  • Mac → http://localhost:8888/phpmyadmin → login root / root
  • L'interface phpMyAdmin doit s'afficher

Etape 4 : Créer une base de test

  • Dans phpMyAdmin → "Nouvelle base de données"
  • Nommer la base test_installation
  • Choisir utf8mb4_general_ci
  • Cliquer "Créer"

Etape 5 : Créer un fichier PHP de test

  • Windows → créer C:\laragon\www\test\index.php
  • Mac → créer /Applications/MAMP/htdocs/test/index.php
  • Linux → créer /opt/lampp/htdocs/test/index.php
<?php
// Fichier de test - à adapter selon l'OS

// Windows / Linux
$password = '';

// Mac MAMP
// $password = 'root';

try {
    $pdo = new PDO(
        'mysql:host=localhost;dbname=test_installation;charset=utf8mb4',
        'root',
        $password
    );
    echo '<h1 style="color:green">Connexion MySQL reussie !</h1>';
    echo '<p>Environnement de developpement fonctionnel.</p>';
} catch (PDOException $e) {
    echo '<h1 style="color:red">Erreur de connexion</h1>';
    echo '<p>' . $e->getMessage() . '</p>';
}
?>

Etape 6 : Ouvrir le fichier dans le navigateur

  • Windows + Linux → http://localhost/test
  • Mac → http://localhost:8888/test
  • La page doit afficher "Connexion MySQL réussie !" en vert
