1.1 — Mettre à jour son CV

Transformer son parcours de formation en arguments pour un recruteur

💡
Pourquoi c'est prioritaire ?

Le CV est la première chose qu'un recruteur regarde — souvent en moins de 30 secondes. Un CV technique bien structuré compense le manque d'expérience.

👨‍💻
Prénom NOM
Développeur Web et Web Mobile · DWWM
📍 Amiens / Lille ✉️ email@domaine.fr 💼 Disponible dès le [DATE] 🔗 github.com/monprofil
HTML5/CSS3 JavaScript ES6+ React PHP 8 MySQL REST API Git / GitHub Docker VS Code Travail en équipe Agilité

✅ Ce qu'il faut mettre

  • ✓ Titre précis : "Développeur Web Full-Stack · Certifié DWWM"
  • ✓ Stack technique complète avec niveaux honnêtes
  • ✓ Projets réalisés en formation (titre, techno, lien)
  • ✓ Alternance / stage avec missions détaillées
  • ✓ Lien vers GitHub et/ou portfolio
  • ✓ Date de disponibilité explicite

❌ Ce qu'il faut éviter

  • ✕ "Maîtrise parfaite de React" si vous débutez
  • ✕ Photo trop informelle ou absente (domaine tech = ok sans)
  • ✕ CV de 3 pages — 1 page max pour un junior
  • ✕ Compétences en "barres de progression" (non mesurables)
  • ✕ Adresse e-mail non professionnelle
  • ✕ Objectif générique copié-collé
📌
Formulation des projets (méthode STAR adaptée)

→ Contexte : type de projet, durée, équipe
→ Technologies : stack utilisée
→ Réalisation : ce que vous avez codé
→ Résultat : ce que ça démontre (autonomie, méthode, qualité)

1.2 — Optimiser son profil LinkedIn

LinkedIn est le canal n°1 de sourcing en IT — les recruteurs tech y sont très actifs

📸 Photo & bannière

  • ✓ Photo professionnelle, fond neutre
  • ✓ Bannière custom (Canva) avec vos techno
  • ✓ Titre accrocheur en-dessous du nom

✍️ Résumé "À propos"

  • ✓ 3-5 lignes max, ton humain
  • ✓ Ce que vous savez faire
  • ✓ Ce que vous cherchez
  • ✓ Appel à l'action (contact)

⚙️ Paramètres clés

  • ✓ URL personnalisée (/in/prenomnom)
  • ✓ "Open to work" activé
  • ✓ Compétences validées par des pairs

💬 Exemple de titre LinkedIn percutant

Développeur Web Full-Stack · React / PHP / MySQL · Certifié DWWM · Disponible dès [mois]

Pourquoi ça fonctionne ?

Les mots-clés techniques sont directement recherchés par les ATS et les recruteurs. Le titre fait office de mini CV en un coup d'œil.

1.3 — Construire son portfolio

Un portfolio en ligne est votre vitrine — il remplace 10 diplômes pour un dev junior

⚠️
Un portfolio avec des bugs, c'est pire que pas de portfolio

Testez sur mobile, Chrome et Firefox. Corrigez les coquilles. Un recruteur tech clique sur votre portfolio pour voir ce que vous valez — soyez irréprochable.

📦 Ce qu'il doit contenir

  • ✓ 3 à 5 projets max, bien choisis
  • ✓ Capture d'écran + lien live + lien GitHub
  • ✓ Stack utilisée par projet
  • ✓ Courte description : contexte, défis, solutions
  • ✓ Formulaire de contact fonctionnel
  • ✓ Design sobre et responsive

🛠️ Solutions techniques

  • → GitHub Pages — gratuit, pour les sites statiques
  • → Vercel / Netlify — idéal pour React
  • → Hostinger — PHP + MySQL possible
  • → Nom de domaine — prénom-nom.fr (~10€/an)
  • → Évitez les constructeurs no-code — faites-le vous-même !
🐙

1.4 — GitHub : votre vitrine technique

Beaucoup de recruteurs tech regardent votre GitHub avant même votre CV

📋 README de profil

Créez un dépôt votre-username/votre-username avec un README.md affiché sur votre profil.

  • ✓ Qui vous êtes, ce que vous cherchez
  • ✓ Stack maîtrisée (badges shields.io)
  • ✓ Projets mis en avant (pinned repos)
  • ✓ Stats GitHub (github-readme-stats)

🔁 Bonnes pratiques commits

  • ✓ Messages clairs : "feat:", "fix:", "docs:"
  • ✓ Commits réguliers — montrent votre activité
  • ✓ README par projet : installation, usage, stack
  • ✓ .gitignore soigné — pas de fichiers sensibles
  • ✕ Pas de code "WIP abandonné" sans branche
🚀
Le "green graph" parle pour vous

Un historique de contributions régulier montre que vous codez activement. Contribuez à des projets open source, participez à des challenges (Frontend Mentor, Codewars) ou améliorez vos projets existants.

2.2 — Définir ses objectifs professionnels

Clarifier sa cible pour mieux viser — pas de stratégie sans objectif clair

🎯 Quel poste viser ?

  • → Développeur Front-End (HTML/CSS/JS/React)
  • → Développeur Back-End (PHP/Node.js/SQL)
  • → Développeur Full-Stack (les deux)
  • → Intégrateur Web (maquette → code)
  • → Développeur WordPress (niche fréquente en agence)
💡

En tant que junior, visez un poste "Full-Stack" si vous êtes en agence, "Front" ou "Back" si vous visez un éditeur ou une startup produit.

🏢 Quel type de structure ?

  • ✓ Agence web — variété de projets, apprentissage rapide
  • ✓ Startup — autonomie, full-stack souvent requis
  • ✓ ESN / SSII — missions en clientèle, évolution rapide
  • ✓ PME / ETI — poste interne, stabilité
  • ✓ Freelance — après 2-3 ans d'expérience minimum

📍 Critères de recherche à définir

📌 Localisation

  • ✓ Zone géographique max
  • ✓ Télétravail partiel ou total ?
  • ✓ Mobilité possible ?

💶 Salaire

  • ✓ Junior HdF : 24 000–30 000 €/an
  • ✓ Ne pas brader ses compétences
  • ✓ Négocier les avantages aussi

🌱 Évolution

  • ✓ Formation continue possible ?
  • ✓ Mentorat en interne ?
  • ✓ Stack moderne ?

2.3 — Plan d'actions sur 90 jours

Une feuille de route concrète pour les 3 premiers mois post-certification

Semaine 1–2 · Jour 1 à 14

🧹 Bilan & mise à jour des profils

Finaliser CV, LinkedIn, GitHub, portfolio. Définir sa cible (poste, secteur, zone géo). Créer une boîte mail dédiée à la recherche. Configurer les alertes emploi (APEC, Welcome to the Jungle, Indeed).

Semaine 3–4 · Jour 15 à 28

🚀 Lancement de la recherche active

Envoyer 5 à 10 candidatures ciblées par semaine. Personnaliser chaque lettre de motivation. Prendre contact avec France Travail, missions locales, l'APEC. Activer son réseau (anciens stagiaires, tuteurs entreprise, formateurs).

Semaine 5–8 · Jour 29 à 56

🎯 Entretiens & montée en compétences

Préparer les entretiens techniques (LeetCode easy, révisions stack). S'entraîner à pitcher son parcours en 2 minutes. Continuer un projet perso pour montrer l'évolution. Rejoindre des meetups dev locaux (Hauts-de-France Tech, Humanitix Lille).

Semaine 9–12 · Jour 57 à 90

📈 Bilan et ajustement

Analyser les retours (silence radio ? reformuler la cible). Élargir la zone de recherche si nécessaire. Solliciter un coaching emploi via France Travail ou l'APEC. Envisager une mission freelance ou un CDD pour gagner de l'expérience.

3.1 — Organismes pour l'emploi

Les structures institutionnelles qui peuvent vous aider dans votre insertion

🏛️
France Travail (ex-Pôle Emploi)
Inscription obligatoire si vous êtes en recherche d'emploi. Accès aux offres, accompagnement personnalisé, droits au chômage si éligible, formations complémentaires financées.
Accompagnement ARE (indemnités) Formations
🎓
APEC (Cadres & Bac+2 minimum)
Réseau spécialisé cadres et techniciens qualifiés. Offres d'emploi, accompagnement bilan de compétences, ateliers CV/entretien, coaching. Accessible aux jeunes diplômés.
Offres ciblées IT Coaching Réseau
🌱
Mission Locale (moins de 26 ans)
Accompagnement global des jeunes : emploi, logement, mobilité, santé. Dispositifs financiers (PACEA, Garantie Jeunes). Partenaires locaux en Hauts-de-France.
-26 ans Aides financières Accompagnement global
🔧
Cap Emploi (si RQTH)
Pour les personnes en situation de handicap reconnue. Accompagnement spécialisé, aménagements de poste, partenariat avec AGEFIPH. Démarche confidentielle possible.
RQTH AGEFIPH Aménagements
🏢
Real Conseil — Suivi post-formation
Votre organisme de formation assure un suivi à 6 et 12 mois après la certification. N'hésitez pas à solliciter votre formateur pour une relecture de CV, une mise en relation ou une orientation.
Suivi alumni Réseau formateurs Recommandations

3.2 — Réseaux & communautés tech

Le réseau est votre premier outil de recrutement — 30-40% des postes ne sont jamais publiés

🖥️ Plateformes de recherche d'emploi

  • ✓ Welcome to the Jungle — culture d'entreprise mise en avant
  • ✓ LinkedIn Jobs — candidature directe, réseau actif
  • ✓ Indeed — volume important, bonne couverture HdF
  • ✓ APEC.fr — postes qualifiés tech
  • ✓ Talent.io — profil inverti, les entreprises viennent à vous
  • ✓ Malt — pour les premières missions freelance

🤝 Communautés locales & nationales

  • → Dev Lille — meetups mensuels dev Nord
  • → La French Tech Hauts-de-France
  • → Slack Developers France
  • → Discord JS, React FR, PHP FR
  • → OpenSourcers Amiens
  • → Alumni DWWM / Real Conseil (votre promo)
🤝
La candidature spontanée fonctionne

Identifiez 10 entreprises locales qui vous inspirent. Envoyez un email personnalisé au DT ou CTO directement (trouvez-les sur LinkedIn). C'est plus efficace que postuler à 50 offres en masse.

Quiz de validation

Vérifiez vos acquis sur ce module insertion professionnelle

Question 1 / 6
Quelle est la longueur recommandée pour un CV de développeur junior ?
A 2 à 3 pages pour tout détailler
B 1 page maximum, l'essentiel bien mis en valeur
C Peu importe la longueur si le contenu est bon
D Une infographie visuelle avec des jauges de niveau
✅ Exact ! 1 page est la norme pour un profil junior. Au-delà, les recruteurs ne lisent plus.
❌ Non. Pour un junior, 1 page maximum est la règle. Allez à l'essentiel : stack, projets, expériences.
Question 2 / 6
Sur LinkedIn, où placer les mots-clés techniques pour être trouvé par les recruteurs ?
A Uniquement dans la section "Expériences"
B Dans les commentaires de ses propres posts
C Dans le titre, le résumé "À propos" et la section "Compétences"
D Seulement dans la bannière image
✅ Parfait ! Ces 3 zones sont indexées par l'algorithme LinkedIn — titre, "À propos" et compétences.
❌ Non. Les mots-clés doivent figurer dans le titre (sous le nom), le résumé "À propos" ET la section compétences.
Question 3 / 6
Combien de projets faut-il idéalement présenter dans son portfolio ?
A Le plus possible — montrez tout ce que vous avez fait
B 3 à 5 projets bien documentés et fonctionnels
C 1 seul projet très abouti suffit
D Aucun si vous avez une belle page d'accueil
✅ Correct ! 3 à 5 projets ciblés valent mieux que 20 projets non documentés. La qualité prime.
❌ Non. 3 à 5 projets bien documentés est l'idéal. Trop de projets dilue l'attention. Trop peu limite la preuve.
Question 4 / 6
Quel organisme contacter en priorité si vous avez moins de 26 ans et cherchez un accompagnement global (emploi, logement, mobilité) ?
A La Mission Locale
B L'APEC
C Cap Emploi
D La Chambre de Commerce
✅ La Mission Locale est spécialisée dans l'accompagnement global des moins de 26 ans.
❌ Non. La Mission Locale est l'organisme dédié aux moins de 26 ans pour un accompagnement complet.
Question 5 / 6
Dans le "plan 90 jours", quelle est la priorité des 2 premières semaines ?
A Envoyer un maximum de candidatures dès le premier jour
B Attendre les offres qui correspondent exactement à ses compétences
C Finaliser son bilan et mettre à jour tous ses profils (CV, LinkedIn, GitHub)
D Contacter directement les entreprises par téléphone
✅ Exact ! Les 2 premières semaines servent à poser les fondations : profils, cible, outils de suivi.
❌ Non. Postuler sans profils à jour est contre-productif. Semaines 1-2 = bilan + mise à jour de tous les profils.
Question 6 / 6
Pourquoi la candidature spontanée est-elle recommandée ?
A Elle est obligatoire pour s'inscrire à France Travail
B Elle garantit une réponse plus rapide
C Elle évite de passer par les plateformes d'emploi
D 30-40% des postes ne sont jamais publiés — le réseau et le contact direct y donnent accès
✅ Exact ! Le "marché caché" de l'emploi représente une part significative des recrutements en IT.
❌ Non. La candidature spontanée permet d'accéder aux postes non publiés (30-40% du marché réel).
