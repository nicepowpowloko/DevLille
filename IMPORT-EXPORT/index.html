Import / Export
Header, Footer & Architecture

Découper une page HTML en composants réutilisables, et organiser ses fichiers proprement.

export / import Header · Footer Architecture
Étape 1

Le problème — tout dans un seul fichier

Sur un site de 5 pages, le Header et le Footer sont identiques partout. Sans modules, tu copies-colles le même HTML 5 fois. Dès que tu modifies un lien du menu, tu dois modifier 5 fichiers.

Sans modules
index.html
  ← header complet
  ← contenu
  ← footer complet

about.html
  ← header copié-collé
  ← contenu
  ← footer copié-collé

Modifier = changer 5 fichiers
Avec modules
components/
  header.js ← 1 seule fois
  footer.js ← 1 seule fois

index.js
  ← import Header
  ← import Footer

Modifier = changer 1 fichier
Étape 2

L'architecture des dossiers

Voici l'organisation recommandée. Chaque fichier a un seul rôle.

mon-projet/ ├── components/ ← composants réutilisables │ ├── header.js ← génère le <header> │ └── footer.js ← génère le <footer> │ ├── pages/ ← une page = un fichier │ ├── home.js │ ├── about.js │ └── contact.js │ ├── styles/ │ ├── main.css ← styles globaux │ └── components.css ← styles header/footer │ ├── index.html ← point d'entrée unique └── main.js ← orchestre tout
Règle d'or : 1 composant = 1 fichier. Le dossier components/ ne contient que des fonctions qui retournent du HTML. Les pages dans pages/ assemblent ces composants.
Étape 3

Créer le Header et le Footer

Chaque composant est une fonction qui retourne une chaîne HTML. On l'exporte pour pouvoir l'importer ailleurs.

composants
// components/header.js

export function createHeader() {
    return `
    <header class="site-header">
        <div class="logo">MonSite</div>
        <nav>
            <a href="/">Accueil</a>
            <a href="/about">À propos</a>
            <a href="/contact">Contact</a>
        </nav>
    </header>
    `;
}

// Variante : header avec paramètre (page active)
export function createHeaderWithActive(pageActive) {
    const links = [
        { href: '/',        label: 'Accueil'  },
        { href: '/about',   label: 'À propos' },
        { href: '/contact', label: 'Contact'  },
    ];

    const nav = links.map(link => `
        <a href="${link.href}" class="${link.href === pageActive ? 'active' : ''}">
            ${link.label}
        </a>`).join('');

    return `<header class="site-header"><nav>${nav}</nav></header>`;
}
// components/footer.js

export function createFooter() {
    const annee = new Date().getFullYear(); // année dynamique !

    return `
    <footer class="site-footer">
        <p>© ${annee} MonSite — Tous droits réservés</p>
        <ul>
            <li><a href="/mentions">Mentions légales</a></li>
            <li><a href="/cgv">CGV</a></li>
        </ul>
    </footer>
    `;
}
Étape 4

Importer et injecter dans la page

On importe les composants dans main.js et on les injecte dans le DOM avec innerHTML.

main.js
import { createHeader } from './components/header.js';
import { createFooter } from './components/footer.js';

// Injecter dans le DOM
document.getElementById('header').innerHTML = createHeader();
document.getElementById('footer').innerHTML = createFooter();

// Ou en passant la page active :
import { createHeaderWithActive } from './components/header.js';
document.getElementById('header').innerHTML = createHeaderWithActive('/');
index.html — structure minimaliste
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="styles/main.css">
    <title>Mon Site</title>
</head>
<body>

    <!-- Conteneurs vides, remplis par JS -->
    <div id="header"></div>

    <main id="app">
        <!-- contenu de la page -->
    </main>

    <div id="footer"></div>

    <!-- type="module" obligatoire pour les import/export -->
    <script type="module" src="main.js"></script>

</body>
</html>
Important : type="module" est obligatoire dans la balise <script> pour utiliser import/export. Sans ça, le navigateur ne comprend pas les modules ES.
Étape 5

Gérer plusieurs pages

Chaque page a son propre fichier JS qui importe les composants communs et ajoute son propre contenu.

pages/about.js
import { createHeader } from '../components/header.js';
import { createFooter } from '../components/footer.js';

// Composants communs
document.getElementById('header').innerHTML = createHeader();
document.getElementById('footer').innerHTML = createFooter();

// Contenu spécifique à la page About
document.getElementById('app').innerHTML = `
    <section class="about">
        <h1>À propos</h1>
        <p>Notre histoire…</p>
    </section>
`;
Résultat dans le navigateur pour about.html : ┌─────────────────────────────────────────────┐ │ createHeader() ← components/header.js │ ├─────────────────────────────────────────────┤ │ │ │ Contenu About ← pages/about.js │ │ │ ├─────────────────────────────────────────────┤ │ createFooter() ← components/footer.js │ └─────────────────────────────────────────────┘
Étape 6 — Bonus

Simplifier les imports avec un index.js

Quand le dossier components/ grandit, on crée un index.js qui regroupe tous les exports. Ça évite des lignes d'import à rallonge.

components/index.js — barrel file
// On re-exporte tout depuis un seul endroit
export { createHeader, createHeaderWithActive } from './header.js';
export { createFooter }                          from './footer.js';
export { createNav }                             from './nav.js';
export { createCard }                            from './card.js';
Avant / Après
// Avant — un import par fichier
import { createHeader } from './components/header.js';
import { createFooter } from './components/footer.js';
import { createNav }    from './components/nav.js';
import { createCard }   from './components/card.js';

// Après — tout depuis l'index
import { createHeader, createFooter, createNav, createCard }
    from './components/index.js';
