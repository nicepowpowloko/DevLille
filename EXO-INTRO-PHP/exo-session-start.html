EXO-01 Bienvenue avec session session_start() + $_SESSION

Crée un fichier exo01.php. Au tout début du fichier, démarre la session avec session_start().
Si la variable de session $_SESSION['nom'] n’existe pas, initialise-la avec ton prénom.
Affiche ensuite : « Bonjour [prénom] ! » et le nombre de visites de la page (compteur de session).

Objectifs

  • Appeler session_start() en tout premier
  • Utiliser isset() pour vérifier une variable de session
  • Créer et incrémenter un compteur de visites
Solution
<?php
session_start();

if (!isset($_SESSION['nom'])) {
    $_SESSION['nom'] = "Alex";
}

if (!isset($_SESSION['visites'])) {
    $_SESSION['visites'] = 0;
}
$_SESSION['visites']++;

echo "Bonjour " . $_SESSION['nom'] . " !<br>";
echo "Vous avez visité cette page " . $_SESSION['visites'] . " fois.";
?>
session_start() $_SESSION isset() compteur
EXO-02 Préférence de couleur session + formulaire

Crée deux fichiers : exo02.php (formulaire) et traitement.php.
Dans le formulaire, propose un choix de couleur de fond (rouge, bleu, vert). Envoie en POST vers traitement.php.
Dans traitement.php, démarre la session et stocke la couleur choisie dans $_SESSION['couleur'], puis redirige vers exo02.php.
Dans exo02.php, applique la couleur de fond enregistrée en session (sinon couleur par défaut).

Objectifs

  • Stocker une valeur venant d’un formulaire dans une session
  • Utiliser la session pour persister un choix utilisateur
  • header("Location: ...") après traitement
Solution (traitement.php)
<?php
session_start();
if (isset($_POST['couleur'])) {
    $_SESSION['couleur'] = $_POST['couleur'];
}
header("Location: exo02.php");
exit;
?>
session_start() $_SESSION['clé'] = valeur header Location
EXO-03 Compteur de visites global session + unset

Crée un fichier exo03.php. Affiche le nombre total de visites sur le site (toutes pages confondues).
Ajoute un lien « Réinitialiser le compteur » qui supprime la variable de session correspondante avec unset().

Objectifs

  • Compteur persistant sur plusieurs pages
  • Supprimer une variable de session avec unset($_SESSION['clé'])
Solution
<?php
session_start();

if (!isset($_SESSION['total_visites'])) {
    $_SESSION['total_visites'] = 0;
}
$_SESSION['total_visites']++;

echo "Nombre total de visites sur le site : " . $_SESSION['total_visites'];

if (isset($_GET['reset'])) {
    unset($_SESSION['total_visites']);
    header("Location: exo03.php");
    exit;
}
?>
<a href="exo03.php?reset=1">Réinitialiser le compteur</a>
unset($_SESSION[...]) $_GET pour action
Intermédiaire
Objectif : Gérer plusieurs variables de session, destruction partielle ou totale.
EXO-04 Panier simple tableau dans $_SESSION

Crée un fichier panier.php. Initialise un tableau $_SESSION['panier'] si nécessaire.
Ajoute 3 produits (via des liens GET ou un formulaire). Affiche le contenu du panier et le nombre d’articles.
Ajoute un bouton « Vider le panier » qui supprime uniquement la clé panier.

Objectifs

  • Stocker un tableau dans une session
  • array_push() ou $_SESSION['panier'][] = ...
  • count() sur un tableau de session
Solution (extrait)
<?php
session_start();
if (!isset($_SESSION['panier'])) {
    $_SESSION['panier'] = [];
}

if (isset($_GET['add'])) {
    array_push($_SESSION['panier'], $_GET['add']);
}

echo "Articles dans le panier : " . count($_SESSION['panier']);
foreach ($_SESSION['panier'] as $item) {
    echo "<li>" . $item . "</li>";
}

if (isset($_GET['vider'])) {
    $_SESSION['panier'] = [];
}
?>
tableau dans $_SESSION array_push() vider une clé
EXO-05 Login / Logout simple session + déconnexion

Simule un login : un formulaire avec username et mot de passe fixe (ex: admin / 1234).
Si les identifiants sont corrects, stocke $_SESSION['user'] = $username; et affiche un espace membre.
Ajoute un lien « Déconnexion » qui détruit la session ou uniquement la variable user.

Objectifs

  • Vérifier l’authentification via session
  • session_destroy() ou unset($_SESSION['user'])
  • Protection d’une page avec if (!isset($_SESSION['user']))
Solution (extrait login)
<?php
session_start();
if (isset($_POST['username'])) {
    if ($_POST['username'] === 'admin' && $_POST['password'] === '1234') {
        $_SESSION['user'] = $_POST['username'];
    }
}

if (isset($_GET['logout'])) {
    unset($_SESSION['user']);
    session_destroy();
}
?>
Difficile
Objectif : Combiner sessions avec logique plus avancée (panier complet, timeout, etc.).
