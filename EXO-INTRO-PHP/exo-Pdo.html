EXO-01 Connexion PDO a la base new PDO / DSN / try-catch / PDOException

Cree un fichier connexion.php dans htdocs/. Connecte-toi a la base catalogue_shop avec PDO en utilisant un bloc try/catch. Si la connexion reussit, affiche "Connexion OK !". Si elle echoue, affiche le message d'erreur. Configure PDO pour lancer des exceptions et retourner les resultats en tableaux associatifs.

Objectifs

  • Construire le DSN (Data Source Name) : mysql:host=localhost;port=8889;dbname=...
  • Instancier PDO avec new PDO($dsn, $user, $pass)
  • Capturer les erreurs avec try { } catch (PDOException $e) { }
  • Configurer avec PDO::ATTR_ERRMODE et PDO::ATTR_DEFAULT_FETCH_MODE
Solution
<?php
$dsn = 'mysql:host=localhost;port=8889;dbname=catalogue_shop;charset=utf8mb4';
$user = 'root';
$pass = 'root';

try {
    $pdo = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]);
    echo 'Connexion OK !';
} catch (PDOException $e) {
    die('Erreur de connexion : ' . $e->getMessage());
}
new PDO($dsn, $u, $p) DSN mysql: try / catch PDOException ATTR_ERRMODE FETCH_ASSOC
EXO-02 Lire tous les produits avec query() query() / fetchAll() / foreach

Cree un fichier liste.php. Inclus la connexion PDO puis utilise query() pour selectionner tous les produits de la table produits. Recupere tous les resultats avec fetchAll() et affiche chaque produit dans une boucle foreach avec le nom, le prix et le stock.

Objectifs

  • Executer une requete simple : $pdo->query('SELECT ...')
  • Recuperer tous les resultats : $stmt->fetchAll()
  • Parcourir les resultats avec foreach ($produits as $p)
  • Acceder aux colonnes : $p['nom'], $p['prix']
Solution
<?php
require_once 'connexion.php';

$stmt = $pdo->query('SELECT * FROM produits ORDER BY nom');
$produits = $stmt->fetchAll();

foreach ($produits as $p) {
    echo htmlspecialchars($p['nom']) . ' — ' . number_format($p['prix'], 2, ',', ' ') . ' EUR\n';
}
echo count($produits) . ' produits trouves';

EXO-03 Lire un seul produit avec fetch() fetch() / un seul enregistrement

Cree un fichier detail.php. Recois l'id du produit via l'URL (?id=1). Utilise query() pour selectionner le produit correspondant. Recupere le resultat avec fetch() (une seule ligne). Affiche les details complets. Si le produit n'existe pas, affiche "Produit introuvable.".

Objectifs

  • Recuperer un parametre GET : $_GET['id']
  • Difference entre fetch() (1 ligne) et fetchAll() (toutes)
  • Verifier si le resultat existe : if ($produit)
  • Caster en entier pour eviter les injections : (int) $_GET['id']
Solution
<?php
require_once 'connexion.php';
$id = (int) ($_GET['id'] ?? 0);
$stmt = $pdo->query("SELECT * FROM produits WHERE id = {$id}");
$produit = $stmt->fetch();

if ($produit) {
    echo "Nom : " . htmlspecialchars($produit['nom']) . "\n";
    echo "Prix : " . $produit['prix'] . " EUR\n";
    echo "Stock : " . $produit['stock'] . "\n";
} else {
    echo 'Produit introuvable.';
}
fetch() fetchAll() (int) cast $_GET['id'] if ($result)

EXO-04 Requete preparee — SELECT securise prepare() / execute() / marqueurs :nom

Reprends detail.php et remplace le query() par une requete preparee avec prepare() et execute(). Utilise un marqueur nomme :id. C'est la bonne pratique pour toute requete recevant des donnees externes. Ajoute aussi une recherche par nom avec LIKE et un marqueur :terme.

Objectifs

  • Preparer la requete : $stmt = $pdo->prepare('SELECT ... WHERE id = :id')
  • Executer avec les valeurs : $stmt->execute(['id' => $id])
  • Difference entre marqueurs nommes :nom et positionnels ?
  • Comprendre pourquoi c'est plus sur que la concatenation directe
Solution
<?php
require_once 'connexion.php';

// Marqueur nomme :id
$id = (int) ($_GET['id'] ?? 0);
$stmt = $pdo->prepare('SELECT * FROM produits WHERE id = :id');
$stmt->execute([':id' => $id]);
$produit = $stmt->fetch();

// Recherche LIKE
$terme = '%' . trim($_GET['q'] ?? '') . '%';
$stmt = $pdo->prepare('SELECT * FROM produits WHERE nom LIKE :terme');

EXO-05 INSERT avec PDO prepare() / execute() / lastInsertId()

Cree un fichier ajouter.php avec un formulaire (nom, prix, stock, categorie_id). Quand le formulaire est soumis, valide les donnees puis insere le nouveau produit dans la table produits avec une requete preparee. Recupere l'id du produit insere avec lastInsertId() et redirige vers le detail du produit.

Objectifs

  • Preparer un INSERT : INSERT INTO produits (nom, prix) VALUES (:nom, :prix)
  • Passer tous les marqueurs dans execute()
  • Recuperer l'id auto-genere : $pdo->lastInsertId()
  • Rediriger apres insertion : header("Location: detail.php?id=$id")
Solution
<?php
require_once 'connexion.php';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nom = trim($_POST['nom'] ?? '');
    $prix = (float) ($_POST['prix'] ?? 0);
    $stock = (int)   ($_POST['stock'] ?? 0);
    $categorie_id = (int)   ($_POST['categorie_id'] ?? 0);

    $stmt = $pdo->prepare(
        'INSERT INTO produits (nom, prix, stock, categorie_id) VALUES (:nom, :prix, :stock, :categorie_id)'
    );
    $stmt->execute([
        ':nom'          => $nom,
        ':prix'         => $prix,
        ':stock'        => $stock,
        ':categorie_id' => $categorie_id,
    ]);
    $new_id = $pdo->lastInsertId();
    header("Location: detail.php?id={$new_id}");
    exit();
}
?>

EXO-06 UPDATE et DELETE avec PDO UPDATE / DELETE / rowCount()

Cree un fichier modifier.php. Recois l'id via GET, charge le produit existant, affiche un formulaire pre-rempli. Quand soumis, execute un UPDATE. Ajoute aussi une action "supprimer" via GET (?action=supprimer&id=X) qui execute un DELETE et redirige vers la liste. Utilise rowCount() pour verifier combien de lignes ont ete affectees.

Objectifs

  • UPDATE prepare : UPDATE produits SET nom=:nom WHERE id=:id
  • DELETE prepare : DELETE FROM produits WHERE id=:id
  • Compter les lignes affectees : $stmt->rowCount()
  • Repopuler le formulaire avec les valeurs actuelles du produit
Solution
<?php
require_once 'connexion.php';
$id = (int) ($_GET['id'] ?? 0);

// Supprimer
if (isset($_GET['action']) && $_GET['action'] === 'supprimer') {
    $stmt = $pdo->prepare('DELETE FROM produits WHERE id = :id');
    $stmt->execute([':id' => $id]);
    header('Location: liste.php'); exit();
}

// UPDATE
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $stmt = $pdo->prepare('UPDATE produits SET nom=:nom, prix=:prix, stock=:stock WHERE id=:id');
    $stmt->execute([':nom'=>trim($_POST['nom']), ':prix'=>(float)$_POST['prix'], ':stock'=>(int)$_POST['stock'], ':id'=>$id]);
    header('Location: liste.php'); exit();
}

// Charger le produit pour pre-remplir
$stmt = $pdo->prepare('SELECT * FROM produits WHERE id = :id');
$stmt->execute([':id' => $id]);
$produit = $stmt->fetch();
?>

EXO-07 SELECT avec JOIN via PDO prepare() / JOIN / fetchAll / FETCH_ASSOC

Cree un fichier catalogue.php. Ecris une requete preparee qui fait un JOIN entre produits et categories. Ajoute un filtre optionnel par categorie passe en GET (?categorie_id=1). Si le parametre est present, utilise un marqueur :categorie_id. Sinon execute la requete sans filtre. Affiche les resultats avec le nom de la categorie.

Objectifs

  • JOIN via PDO : requete preparee avec plusieurs tables
  • Requete conditionnelle : construire la requete SQL selon les parametres
  • Passer ou non un parametre a execute() selon le contexte
  • Afficher les colonnes de plusieurs tables : $p['categorie_nom']
Solution
<?php
require_once 'connexion.php';
$categorie_id = (int) ($_GET['categorie_id'] ?? 0);

$sql = 'SELECT p.*, c.nom AS categorie_nom FROM produits p JOIN categories c ON p.categorie_id = c.id';

if ($categorie_id) {
    $sql .= ' WHERE p.categorie_id = :categorie_id';
    $stmt = $pdo->prepare($sql);
    $stmt->execute([':categorie_id' => $categorie_id]);
} else {
    $stmt = $pdo->query($sql);
}

$produits = $stmt->fetchAll();
foreach ($produits as $p) {
    echo htmlspecialchars($p['nom']) . ' [' . htmlspecialchars($p['categorie_nom']) . ']\n';
}
JOIN via PDO requete conditionnelle $p['categorie_nom'] query() vs prepare()
EXO-08 Transactions PDO beginTransaction / commit / rollBack

Cree un fichier transaction.php. Simule un achat : quand un utilisateur achete un produit, il faut 1) diminuer le stock du produit et 2) inserer une ligne dans la table commandes. Ces deux operations doivent reussir ensemble ou echouer ensemble. Utilise une transaction PDO pour garantir l'integrite des donnees.

Objectifs

  • Demarrer une transaction : $pdo->beginTransaction()
  • Valider les changements : $pdo->commit()
  • Annuler en cas d'erreur : $pdo->rollBack()
  • Comprendre l'atomicite : tout ou rien
Solution
<?php
require_once 'connexion.php';
$produit_id = 1; $utilisateur_id = 1; $quantite = 2;

try {
    $pdo->beginTransaction();

    $stmt = $pdo->prepare('SELECT stock FROM produits WHERE id = :id');
    $stmt->execute([':id' => $produit_id]);
    $stock = $stmt->fetchColumn();
    if ($stock < $quantite) throw new Exception('Stock insuffisant');

    $stmt = $pdo->prepare('UPDATE produits SET stock = stock - :qte WHERE id = :id');
    $stmt->execute([':qte' => $quantite, ':id' => $produit_id]);

    $stmt = $pdo->prepare('INSERT INTO commandes (utilisateur_id, produit_id, quantite) VALUES (:u, :p, :q)');
    $stmt->execute([':u'=>$utilisateur_id, ':p'=>$produit_id, ':q'=>$quantite]);

    $pdo->commit();
    echo 'Achat reussi !';
} catch (Exception $e) {
    $pdo->rollBack();
    echo 'Erreur : ' . $e->getMessage();
}

EXO-09 Classe Database reutilisable Singleton / connexion unique / require_once Bonus

Exercice bonus. Cree un fichier Database.php qui encapsule la connexion PDO dans une classe avec le pattern Singleton : une seule instance de PDO pour toute l'application. La methode statique getInstance() retourne toujours la meme connexion. Utilise-la dans liste.php et detail.php avec Database::getInstance().

Objectifs

  • Comprendre le pattern Singleton : une seule instance partagee
  • Creer une propriete statique private static $instance
  • Methode statique public static function getInstance()
  • Utilisation : $pdo = Database::getInstance()
Solution
<?php
class Database {
    private static $instance = null;
    private function __construct() {}

    public static function getInstance(): PDO {
        if (self::$instance === null) {
            try {
                self::$instance = new PDO(
                    'mysql:host=localhost;port=8889;dbname=catalogue_shop;charset=utf8mb4',
                    'root', 'root',
                    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION, PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC]
                );
            } catch (PDOException $e) {
                die('Connexion impossible : ' . $e->getMessage());
            }
        }
        return self::$instance;
    }
}

// Dans liste.php / detail.php :
require_once 'Database.php';
$pdo = Database::getInstance();
$produits = $pdo->query('SELECT * FROM produits')->fetchAll();
