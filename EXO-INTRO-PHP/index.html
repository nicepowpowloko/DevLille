exo03.php PHP

$prix_ttc = 49.90;

EXO-09 Générateur de mot de passe str_split / shuffle / implode Bonus

Exercice bonus. Génère un mot de passe aléatoire de 12 caractères contenant minuscules, majuscules, chiffres et caractères spéciaux. La difficulté ici est de comprendre comment transformer une chaîne en tableau de caractères, mélanger ce tableau, en prendre une partie et le reconstruire en chaîne.

Objectifs

  • Transformer une chaîne en tableau avec str_split()
  • Fusionner des tableaux avec array_merge()
  • Mélanger un tableau avec shuffle()
  • Extraire une portion avec array_slice()
  • Reconstruire une chaîne avec implode()
exo09.php PHP 
<?php
$minuscules = str_split('abcdefghijklmnopqrstuvwxyz');
$majuscules = str_split('ABCDEFGHIJKLMNOPQRSTUVWXYZ');
$chiffres   = str_split('0123456789');
$speciaux   = str_split('!@#$%&*?');

// 1. Fusionne tous les tableaux en un seul
// 2. Mélange aléatoirement
// 3. Garde seulement les 12 premiers
// 4. Reconstitue la chaîne
// 5. Affiche le mot de passe et sa longueur

Résultat attendu (aléatoire à chaque exécution)

Mot de passe : K7!mZqP#2xRt
Longueur     : 12 caractères
Solution
<?php
$minuscules = str_split('abcdefghijklmnopqrstuvwxyz');
$majuscules = str_split('ABCDEFGHIJKLMNOPQRSTUVWXYZ');
$chiffres   = str_split('0123456789');
$speciaux   = str_split('!@#$%&*?');

$tous = array_merge($minuscules, $majuscules, $chiffres, $speciaux);
shuffle($tous);
$mdp = implode('', array_slice($tous, 0, 12));

echo "Mot de passe : {$mdp}\n";
echo "Longueur     : " . strlen($mdp) . " caractères\n";
