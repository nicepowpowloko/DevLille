EXO-01 Mon premier formulaire POST $_POST / isset

Crée un fichier exo01.php. Ce fichier contient à la fois le formulaire HTML et le traitement PHP. Le formulaire demande un prénom et un message. Quand il est soumis, affiche au-dessus du formulaire : "Bonjour [prénom], tu as écrit : [message]". Tant que le formulaire n'a pas été soumis, n'affiche rien.

Objectifs

  • Créer un formulaire HTML avec method="POST" et action=""
  • Récupérer les données avec $_POST['nom_du_champ']
  • Tester la soumission avec isset($_POST['submit'])
  • Comprendre que PHP et HTML cohabitent dans le même fichier
Solution
<?php
$resultat = '';

if (isset($_POST['submit'])) {
    $prenom  = $_POST['prenom']  ?? '';
    $message = $_POST['message'] ?? '';
    $resultat = "Bonjour {$prenom}, tu as écrit : {$message}";
}
?>
<!DOCTYPE html>
<html lang="fr">
<body>
  <?php if ($resultat) echo "<p>{$resultat}</p>"; ?>

  <form method="POST" action="">
    <input type="text" name="prenom" placeholder="Ton prénom">
    <textarea name="message" placeholder="Ton message"></textarea>
    <button type="submit" name="submit">Envoyer</button>
  </form>
</body>
</html>

EXO-02 Vérifier les champs vides empty / trim / messages d'erreur

Crée un fichier exo02.php avec un formulaire de connexion (champs email et mot de passe). Quand il est soumis, vérifie que les deux champs sont remplis avec empty(). Si un champ est vide, affiche un message d'erreur en rouge. Si les deux sont remplis, affiche "Connexion réussie !" en vert. Utilise trim() pour supprimer les espaces avant de tester.

Objectifs

  • Utiliser trim() pour nettoyer la saisie
  • Utiliser empty() pour tester si un champ est vide
  • Stocker les erreurs dans un tableau $erreurs[]
  • Afficher les erreurs conditionnellement
Solution
<?php
$erreurs = [];
$succes  = false;

if (isset($_POST['submit'])) {
    $email = trim($_POST['email'] ?? '');
    $mdp   = trim($_POST['mdp']   ?? '');

    if (empty($email)) $erreurs[] = "L'email est obligatoire.";
    if (empty($mdp))   $erreurs[] = "Le mot de passe est obligatoire.";
    if (empty($erreurs)) $succes = true;
}
?>
<!DOCTYPE html><html lang="fr"><body>

<?php if ($succes): ?>
  <p style="color:green">Connexion réussie !</p>
<?php elseif (!empty($erreurs)): ?>
  <?php foreach ($erreurs as $e): ?>
    <p style="color:red"> <?= htmlspecialchars($e) ?></p>
  <?php endforeach; ?>
<?php endif; ?>

<form method="POST" action="">
  <input type="email" name="email" placeholder="Email">
  <input type="password" name="mdp" placeholder="Mot de passe">
  <button type="submit" name="submit">Connexion</button>
</form>
</body></html>

EXO-04 Validation d'email et de longueur filter_var / strlen / FILTER_VALIDATE_EMAIL

Crée un fichier exo04.php avec un formulaire d'inscription simple : champs nom (min 2 caractères, max 50), email (format valide) et âge (nombre entier entre 18 et 99). Utilise filter_var() pour valider l'email et l'entier. Affiche les erreurs au-dessus du formulaire et repopule les champs avec les valeurs saisies.

Objectifs

  • Valider un email avec filter_var($email, FILTER_VALIDATE_EMAIL)
  • Valider un entier avec filter_var($age, FILTER_VALIDATE_INT)
  • Vérifier la longueur avec strlen()
  • Repopuler les champs : value="<?= htmlspecialchars($nom) ?>"
Solution
<?php
$erreurs = [];
$succes  = false;
$nom = $email = $age = '';

if (isset($_POST['submit'])) {
    $nom   = trim($_POST['nom']   ?? '');
    $email = trim($_POST['email'] ?? '');
    $age   = trim($_POST['age']   ?? '');

    if (strlen($nom) < 2 || strlen($nom) > 50)
        $erreurs[] = "Le nom doit contenir entre 2 et 50 caractères.";

    if (!filter_var($email, FILTER_VALIDATE_EMAIL))
        $erreurs[] = "L'email n'est pas valide.";

    $opts = ['options' => ['min_range' => 18, 'max_range' => 99]];
    if (!filter_var($age, FILTER_VALIDATE_INT, $opts))
        $erreurs[] = "L'âge doit être un entier entre 18 et 99.";

    if (empty($erreurs)) $succes = true;
}
?>
<!DOCTYPE html><html lang="fr"><body>
  <?php if ($succes): ?>
    <p style="color:green">Inscription réussie !</p>
  <?php endif; ?>
  <?php foreach ($erreurs as $e): ?>
    <p style="color:red"> <?= htmlspecialchars($e) ?></p>
  <?php endforeach; ?>
  <form method="POST" action="">
    <input type="text"  name="nom"   value="<?= htmlspecialchars($nom) ?>">
    <input type="email" name="email" value="<?= htmlspecialchars($email) ?>">
    <input type="number" name="age"  value="<?= htmlspecialchars($age) ?>">
    <button type="submit" name="submit">S'inscrire</button>
  </form>
</body></html>
filter_var() FILTER_VALIDATE_EMAIL FILTER_VALIDATE_INT min_range / max_range strlen() repopulation champs
EXO-05 Formulaire d'ajout de produit validation complète / htmlspecialchars / header()

Crée deux fichiers : ajouter.php (le formulaire) et liste.php (affichage de la liste). Le formulaire contient les champs nom, prix (nombre décimal positif) et stock (entier ≥ 0). Après validation réussie, stocke le produit dans $_SESSION et redirige vers liste.php avec header().

Objectifs

  • Valider un flottant positif avec filter_var($v, FILTER_VALIDATE_FLOAT)
  • Démarrer une session avec session_start()
  • Stocker dans $_SESSION['produits'][]
  • Rediriger avec header('Location: liste.php') + exit()
Solution — ajouter.php
<?php
session_start();
$erreurs = [];
$nom = $prix = $stock = '';

if (isset($_POST['submit'])) {
    $nom   = trim($_POST['nom']   ?? '');
    $prix  = trim($_POST['prix']  ?? '');
    $stock = trim($_POST['stock'] ?? '');

    if (empty($nom))
        $erreurs[] = "Le nom est obligatoire.";

    $prixF = filter_var($prix, FILTER_VALIDATE_FLOAT);
    if ($prixF === false || $prixF <= 0)
        $erreurs[] = "Le prix doit être un nombre positif.";

    $opts  = ['options' => ['min_range' => 0]];
    $stockI = filter_var($stock, FILTER_VALIDATE_INT, $opts);
    if ($stockI === false)
        $erreurs[] = "Le stock doit être un entier >= 0.";

    if (empty($erreurs)) {
        $_SESSION['produits'][] = [
            'nom'   => htmlspecialchars($nom),
            'prix'  => $prixF,
            'stock' => $stockI,
        ];
        header('Location: liste.php');
        exit();
    }
}
?>
session_start() $_SESSION FILTER_VALIDATE_FLOAT header() + exit() repopulation
EXO-06 Confirmation de mot de passe comparaison / regex / password_hash

Crée un fichier exo06.php avec un formulaire d'inscription demandant un email, un mot de passe et une confirmation. Valide que les deux mots de passe sont identiques, que le mot de passe fait au moins 8 caractères et contient au moins un chiffre (utilise preg_match()). Si tout est valide, affiche le hash du mot de passe avec password_hash().

Objectifs

  • Comparer deux champs avec ===
  • Vérifier la longueur avec strlen()
  • Utiliser une regex avec preg_match('/[0-9]/', $mdp)
  • Hasher un mot de passe avec password_hash($mdp, PASSWORD_DEFAULT)
Solution
<?php
$erreurs = [];
$succes  = '';
$email = $mdp = $confirm = '';

if (isset($_POST['submit'])) {
    $email   = trim($_POST['email']   ?? '');
    $mdp     = $_POST['mdp']     ?? '';
    $confirm = $_POST['confirm'] ?? '';

    if (!filter_var($email, FILTER_VALIDATE_EMAIL))
        $erreurs[] = "L'email n'est pas valide.";

    if (strlen($mdp) < 8)
        $erreurs[] = "Le mot de passe doit contenir au moins 8 caractères.";

    if (!preg_match('/[0-9]/', $mdp))
        $erreurs[] = "Le mot de passe doit contenir au moins un chiffre.";

    if ($mdp !== $confirm)
        $erreurs[] = "Les mots de passe ne correspondent pas.";

    if (empty($erreurs)) {
        $hash   = password_hash($mdp, PASSWORD_DEFAULT);
        $succes = "✅ Compte créé ! Hash : {$hash}";
    }
}
?>
<!DOCTYPE html><html lang="fr"><body>
  <?php if ($succes) echo "<p>{$succes}</p>"; ?>
  <?php foreach ($erreurs as $e): ?>
    <p style="color:red"> <?= htmlspecialchars($e) ?></p>
  <?php endforeach; ?>
  <form method="POST" action="">
    <input type="email"    name="email"   value="<?= htmlspecialchars($email) ?>">
    <input type="password" name="mdp">
    <input type="password" name="confirm">
    <button type="submit" name="submit">Créer le compte</button>
  </form>
</body></html>

EXO-07 Formulaire de contact complet validation multi-champs / pattern PRG / session flash

Crée deux fichiers : contact.php et merci.php. Le formulaire contient nom, email, sujet (select parmi 3 options), et message (min 20 caractères). Applique le pattern PRG (Post Redirect Get) : après validation réussie, stocke les données dans $_SESSION et redirige vers merci.php qui les affiche puis les supprime de la session.

Objectifs

  • Valider un <select> avec in_array()
  • Implémenter le pattern PRG complet
  • Utiliser un message "flash" en session (affiché une seule fois)
  • Nettoyer les données de session après affichage avec unset()
Solution — contact.php
<?php
session_start();
$erreurs        = [];
$sujets_valides = ['question', 'probleme', 'suggestion'];
$nom = $email = $sujet = $message = '';

if (isset($_POST['submit'])) {
    $nom     = trim($_POST['nom']     ?? '');
    $email   = trim($_POST['email']   ?? '');
    $sujet   = $_POST['sujet']   ?? '';
    $message = trim($_POST['message'] ?? '');

    $l = strlen($nom);
    if ($l < 2 || $l > 80)
        $erreurs[] = "Le nom doit faire entre 2 et 80 caractères.";

    if (!filter_var($email, FILTER_VALIDATE_EMAIL))
        $erreurs[] = "L'email n'est pas valide.";

    if (!in_array($sujet, $sujets_valides))
        $erreurs[] = "Le sujet sélectionné est invalide.";

    if (strlen($message) < 20)
        $erreurs[] = "Le message doit contenir au moins 20 caractères.";

    if (empty($erreurs)) {
        $_SESSION['contact'] = [
            'nom'     => htmlspecialchars($nom),
            'email'   => htmlspecialchars($email),
            'sujet'   => htmlspecialchars($sujet),
            'message' => htmlspecialchars($message),
        ];
        header('Location: merci.php');
        exit();
    }
}
?>
in_array() pattern PRG $_SESSION flash unset() select validation
EXO-08 Mini CRUD formulaire ajout / modification / suppression via formulaires

Crée un fichier crud.php qui gère une liste de tâches en session. Trois formulaires dans la même page : un pour ajouter une tâche (POST), un pour marquer comme faite (POST avec un champ caché id), et un lien pour supprimer (GET avec ?action=supprimer&id=X). Recharge la page après chaque action avec header().

Objectifs

  • Utiliser <input type="hidden"> pour passer un ID
  • Gérer plusieurs actions POST sur une même page
  • Gérer une action GET ($_GET['action'])
  • Modifier un élément de session par son index
Solution — crud.php
<?php
session_start();
if (!isset($_SESSION['taches'])) $_SESSION['taches'] = [];

// AJOUTER
if (isset($_POST['ajouter'])) {
    $titre = trim($_POST['titre'] ?? '');
    if (!empty($titre)) {
        $_SESSION['taches'][] = ['titre' => htmlspecialchars($titre), 'faite' => false];
        header('Location: crud.php'); exit();
    }
}

// MARQUER COMME FAITE
if (isset($_POST['terminer'])) {
    $id = (int) ($_POST['id'] ?? -1);
    if (isset($_SESSION['taches'][$id]))
        $_SESSION['taches'][$id]['faite'] = true;
    header('Location: crud.php'); exit();
}

// SUPPRIMER
if (isset($_GET['action']) && $_GET['action'] === 'supprimer') {
    $id = (int) ($_GET['id'] ?? -1);
    unset($_SESSION['taches'][$id]);
    $_SESSION['taches'] = array_values($_SESSION['taches']); // réindexe
    header('Location: crud.php'); exit();
}
?>
<!DOCTYPE html><html lang="fr"><body>
  <form method="POST" action="">
    <input type="text" name="titre" placeholder="Nouvelle tâche">
    <button type="submit" name="ajouter">Ajouter</button>
  </form>
  <?php foreach ($_SESSION['taches'] as $i => $t): ?>
    <p>
      <?= $t['faite'] ? '✅' : '⏳' ?>
      <?= $t['titre'] ?>
      <form method="POST" style="display:inline">
        <input type="hidden" name="id" value="<?= $i ?>">
        <button type="submit" name="terminer">✓ Fait</button>
      </form>
      <a href="?action=supprimer&id=<?= $i ?>">🗑</a>
    </p>
  <?php endforeach; ?>
</body></html>

EXO-09 Formulaire avec protection XSS htmlspecialchars / strip_tags / filter_input Bonus

Exercice bonus. Crée un fichier exo09.php avec un formulaire de commentaire. Teste de saisir <script>alert('XSS')</script> dans un champ. Utilise htmlspecialchars() pour afficher le commentaire sans exécuter le script. Utilise strip_tags() pour supprimer toutes les balises. Utilise filter_input() pour récupérer les données directement filtrées. Compare les trois approches et affiche chaque résultat.

Objectifs

  • Comprendre la faille XSS avec un exemple concret
  • Utiliser htmlspecialchars($val, ENT_QUOTES, 'UTF-8')
  • Utiliser strip_tags($val) pour supprimer le HTML
  • Utiliser filter_input(INPUT_POST, 'champ', FILTER_SANITIZE_SPECIAL_CHARS)
Solution
<?php
$brut = $safe1 = $safe2 = $safe3 = '';

if (isset($_POST['submit'])) {
    $brut  = $_POST['commentaire'] ?? '';
    $safe1 = htmlspecialchars($brut, ENT_QUOTES, 'UTF-8');
    $safe2 = strip_tags($brut);
    $safe3 = filter_input(INPUT_POST, 'commentaire', FILTER_SANITIZE_SPECIAL_CHARS);
}
?>
<!DOCTYPE html><html lang="fr"><body>
  <?php if ($brut): ?>
    <p><strong>Valeur brute</strong> (DANGEREUX) :
      <?= $brut ?></p>
    <p><strong>htmlspecialchars</strong> :
      <?= $safe1 ?></p>
    <p><strong>strip_tags</strong> :
      <?= htmlspecialchars($safe2) ?></p>
    <p><strong>filter_input</strong> :
      <?= $safe3 ?></p>
  <?php endif; ?>
  <form method="POST" action="">
    <textarea name="commentaire" rows="3"
      placeholder="Teste : <script>alert('XSS')</script>"></textarea>
    <button type="submit" name="submit">Envoyer</button>
  </form>
</body></html>
