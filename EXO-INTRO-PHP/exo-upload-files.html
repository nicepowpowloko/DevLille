EXO-01Premier upload$_FILES + move_uploaded_file

Crée un formulaire avec un champ file nommé "photo". Dans upload.php, déplace le fichier dans un dossier uploads/ en gardant le nom original.

Solution
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_FILES['photo'])) {
    $file = $_FILES['photo'];
    if ($file['error'] === 0) {
        $uploadDir = 'uploads/';
        if (!is_dir($uploadDir)) mkdir($uploadDir, 0755, true);
        $dest = $uploadDir . $file['name'];
        if (move_uploaded_file($file['tmp_name'], $dest)) {
            echo "Upload réussi !";
        }
    }
}

EXO-04Validation taille et typeValidation

Limite la taille à 5 Mo et n’accepte que les images (jpg, png, gif). Vérifie le type MIME réel avec finfo.

Solution
<?php
$file = $_FILES['photo'];
$maxSize = 5 * 1024 * 1024;

if ($file['size'] > $maxSize) die("Fichier trop volumineux (max 5 Mo)");

$allowed = ['image/jpeg', 'image/png', 'image/gif'];
if (!in_array($file['type'], $allowed)) die("Type non autorisé");

// Vérification réelle du type
$finfo = finfo_open(FILEINFO_MIME_TYPE);
$realType = finfo_file($finfo, $file['tmp_name']);
finfo_close($finfo);

if (!in_array($realType, $allowed)) die("Type de fichier invalide");
EXO-05Nom de fichier sécuriséuniqid + extension

Génère un nom unique pour éviter les collisions et les attaques par nom de fichier.

Solution
<?php
$extension = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
$newName = uniqid('file_', true) . '.' . $extension;

$uploadDir = 'uploads/';
$destination = $uploadDir . $newName;

if (move_uploaded_file($file['tmp_name'], $destination)) {
    echo "Fichier enregistré sous : " . $newName;
}
EXO-06Gestion complète des erreursswitch error

Crée une fonction qui retourne un message clair selon le code d’erreur de $_FILES.

Solution
<?php
function getUploadErrorMessage($errorCode) {
    switch ($errorCode) {
        case UPLOAD_ERR_INI_SIZE:
            return "Le fichier dépasse la taille maximale autorisée par PHP.";
        case UPLOAD_ERR_FORM_SIZE:
            return "Le fichier dépasse la taille maximale du formulaire.";
        case UPLOAD_ERR_PARTIAL:
            return "Le fichier n'a été que partiellement uploadé.";
        case UPLOAD_ERR_NO_FILE:
            return "Aucun fichier n'a été envoyé.";
        default:
            return "Erreur inconnue lors de l'upload.";
    }
}

EXO-07Upload multiplename="files[]"

Permets d’uploader plusieurs fichiers en une seule fois. Traite chaque fichier individuellement.

Solution
<?php
// Formulaire : <input type="file" name="files[]" multiple>

foreach ($_FILES['files']['name'] as $key => $name) {
    if ($_FILES['files']['error'][$key] === 0) {
        $tmp = $_FILES['files']['tmp_name'][$key];
        $newName = uniqid('multi_', true) . '.' . strtolower(pathinfo($name, PATHINFO_EXTENSION));
        move_uploaded_file($tmp, 'uploads/' . $newName);
    }
}
