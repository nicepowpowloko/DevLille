EXO-01 Bulletin de notes if / elseif / else

Crée un fichier exo01.php. Déclare une variable $note avec une valeur entre 0 et 20. Affiche la mention correspondante selon le barème suivant : 18-20 → Très Bien, 14-17 → Bien, 10-13 → Passable, 0-9 → Insuffisant. Teste avec plusieurs valeurs différentes.

Objectifs

  • Utiliser if, elseif et else
  • Utiliser les opérateurs de comparaison >= et <=
  • Enchaîner plusieurs conditions
Solution
<?php
$note = 15;

if ($note >= 18) {
    $mention = "Très Bien";
} elseif ($note >= 14) {
    $mention = "Bien";
} elseif ($note >= 10) {
    $mention = "Passable";
} else {
    $mention = "Insuffisant";
}

echo "Note : {$note}/20 — Mention : {$mention}";
if elseif else opérateurs >= <=

Crée un fichier exo02.php. Déclare une variable $nombre et affiche sa table de multiplication de 1 à 10 grâce à une boucle for. Chaque ligne doit afficher le calcul complet avec le résultat.

Objectifs

  • Écrire une boucle for avec initialisation, condition et incrément

Solution
<?php

}

EXO-04 Jours de la semaine switch / array

Crée un fichier exo04.php. Déclare une variable $jour avec un numéro de 1 à 7. Utilise un switch pour afficher le nom du jour et si c'est un jour de week-end ou de semaine. Teste aussi avec une valeur invalide (ex: 9).

Objectifs

  • Écrire un switch avec case et break
  • Utiliser default pour gérer les cas non prévus
  • Regrouper plusieurs case pour une même action
Solution
<?php
$jour = 6;

switch ($jour) {
    case 1:
        echo "Jour n°{$jour} : Lundi — Semaine\n";
        break;
    case 2:
        echo "Jour n°{$jour} : Mardi — Semaine\n";
        break;
    case 3:
        echo "Jour n°{$jour} : Mercredi — Semaine\n";
        break;
    case 4:
        echo "Jour n°{$jour} : Jeudi — Semaine\n";
        break;
    case 5:
        echo "Jour n°{$jour} : Vendredi — Semaine\n";
        break;
    case 6:
        echo "Jour n°{$jour} : Samedi — Week-end \n";
        break;
    case 7:
        echo "Jour n°{$jour} : Dimanche — Week-end \n";
        break;
    default:
        echo "Numéro de jour invalide (doit être entre 1 et 7)\n";
}

EXO-05 Stock de produits foreach / if / tableau associatif

Crée un fichier exo05.php. Tu as un tableau de produits (tableaux associatifs avec nom, prix et stock). Parcours-le avec foreach et affiche chaque produit avec son statut : stock > 10 → "En stock", 1 à 10 → "Stock faible ", 0 → "Rupture ". Affiche aussi le total des articles en stock à la fin.

Objectifs

  • Parcourir un tableau de tableaux associatifs
  • Imbriquer un if/elseif/else dans un foreach
  • Accumuler une somme dans une variable
  • Accéder aux clés d'un tableau associatif
Solution
<?php
$produits = [
    ['nom' => 'Clavier',  'prix' => 49.90,  'stock' => 15],
    ['nom' => 'Souris',   'prix' => 29.90,  'stock' => 4],
    ['nom' => 'Écran',    'prix' => 299.00, 'stock' => 0],
    ['nom' => 'Casque',   'prix' => 89.90,  'stock' => 22],
];
$total_stock = 0;

foreach ($produits as $p) {
    if ($p['stock'] > 10) {
        $statut = "En stock";
    } elseif ($p['stock'] > 0) {
        $statut = "Stock faible ";
    } else {
        $statut = "Rupture ";
    }

    echo str_pad($p['nom'], 9)
       . number_format($p['prix'], 2, ',', ' ')
       . " € — {$statut} ({$p['stock']})\n";

    $total_stock += $p['stock'];
}

echo "Total en stock : {$total_stock} articles";
foreach if / elseif / else tableau associatif $total += $val str_pad()
EXO-06 Compte à rebours while / if

Crée un fichier exo06.php. Utilise une boucle while pour faire un compte à rebours de 10 à 0. À chaque tour, si le nombre est pair affiche-le en majuscules "PAIR", s'il est impair affiche "impair". Quand tu atteins 0 affiche "Décollage ! 🚀".

Objectifs

  • Utiliser une boucle while avec une condition de sortie
  • Utiliser l'opérateur modulo % pour tester pair/impair
  • Décrémenter une variable $i--
  • Imbriquer un if dans le while
Solution
<?php
$i = 10;

while ($i >= 0) {
    if ($i == 0) {
        echo "0  → Décollage ! \n";
    } elseif ($i % 2 == 0) {
        echo "{$i}  → PAIR\n";
    } else {
        echo "{$i}  → impair\n";
    }
    $i--;
}

EXO-07 Analyse de ventes foreach / if / accumulation

Crée un fichier exo07.php. Tu as un tableau de ventes mensuelles. Parcours-le et calcule : le total des ventes, la meilleure vente, la moins bonne vente, la moyenne, et affiche le mois correspondant à chaque extrême. Affiche enfin si chaque mois est au-dessus ou en-dessous de la moyenne.

Objectifs

  • Parcourir un tableau associatif avec foreach ($t as $k => $v)
  • Trouver un max/min en comparant au fur et à mesure
  • Calculer une moyenne après la boucle
  • Faire un deuxième passage pour comparer à la moyenne
Solution
<?php
$ventes = [
    'Janvier' => 12500, 'Février' => 9800,
    'Mars'    => 15200, 'Avril'   => 11300,
    'Mai'     => 18900, 'Juin'    => 14700,
];

$total      = 0;
$max        = null;
$min        = null;
$mois_max   = '';
$mois_min   = '';

foreach ($ventes as $mois => $montant) {
    $total += $montant;
    if ($max === null || $montant > $max) {
        $max = $montant; $mois_max = $mois;
    }
    if ($min === null || $montant < $min) {
        $min = $montant; $mois_min = $mois;
    }
}
$moyenne = $total / count($ventes);

echo "=== ANALYSE DES VENTES ===\n";
echo "Total    : " . number_format($total, 0, ',', ' ') . " €\n";
echo "Moyenne  : " . number_format($moyenne, 0, ',', ' ') . " €\n";
echo "Meilleur : {$mois_max} (" . number_format($max, 0, ',', ' ') . " €)\n";
echo "Moins bon: {$mois_min} (" . number_format($min, 0, ',', ' ') . " €)\n\n";

foreach ($ventes as $mois => $montant) {
    $statut = $montant >= $moyenne ? "au-dessus" : "sous la moyenne";
    echo str_pad($mois, 9) . ": "
       . str_pad(number_format($montant, 0, ',', ' '), 8, ' ', STR_PAD_LEFT)
       . " € — {$statut}\n";
}
foreach $k => $v max / min dynamiques accumulation += count() double boucle
EXO-08 Gestion d'une liste de tâches array / foreach / in_array / array_search

Crée un fichier exo08.php. Gère une liste de tâches avec un tableau associatif où la clé est le nom de la tâche et la valeur est true (faite) ou false (en cours). Affiche la liste complète avec le statut de chaque tâche, le nombre de tâches faites, et vérifie si une tâche spécifique existe dans la liste avec array_key_exists().

Objectifs

  • Parcourir un tableau associatif avec foreach ($t as $k => $v)
  • Compter les éléments selon une condition
  • Utiliser array_key_exists()
  • Utiliser array_filter() pour filtrer
Solution
<?php
$taches = [
    'Créer la base de données'  => true,
    'Concevoir les maquettes'   => true,
    'Coder le back-end'         => false,
    'Intégrer le front-end'     => false,
    'Rédiger la documentation' => false,
];

$faites = 0;

foreach ($taches as $nom => $faite) {
    $icone = $faite ? '' : '';
    echo "{$icone} {$nom}\n";
    if ($faite) $faites++;
}

$total = count($taches);
echo "\nProgression : {$faites} / {$total} tâches terminées\n";

$recherche = 'Coder le back-end';
$existe    = array_key_exists($recherche, $taches) ? 'OUI' : 'NON';
echo "'{$recherche}' existe dans la liste : {$existe}\n";

EXO-09 Tri de tableau & recherche sort / usort / in_array Bonus

Exercice bonus. Tu as un tableau de joueurs avec un nom et un score. Utilise usort() pour trier les joueurs du meilleur au moins bon score. Affiche le classement avec le rang, le nom et le score. Cherche ensuite si un joueur spécifique est dans le top 3 avec une boucle for et affiche son rang s'il est trouvé.

Objectifs

  • Utiliser usort() avec une fonction de comparaison
  • Afficher un classement numéroté avec foreach
  • Rechercher dans un tableau trié avec for
  • Utiliser break pour sortir d'une boucle dès qu'on a trouvé
Solution
<?php
$joueurs = [
    ['nom' => 'Alice',  'score' => 4200],
    ['nom' => 'Bob',    'score' => 7800],
    ['nom' => 'Clara',  'score' => 6100],
    ['nom' => 'David',  'score' => 9500],
    ['nom' => 'Eva',    'score' => 3300],
];

// Tri décroissant par score
usort($joueurs, fn($a, $b) => $b['score'] - $a['score']);

echo "=== CLASSEMENT ===\n";
$rang = 1;
foreach ($joueurs as $j) {
    echo "#{$rang}  "
       . str_pad($j['nom'], 8)
       . " — "
       . number_format($j['score'], 0, ',', ' ')
       . " pts\n";
    $rang++;
}

// Recherche Clara
$recherche = 'Clara';
for ($i = 0; $i < count($joueurs); $i++) {
    if ($joueurs[$i]['nom'] === $recherche) {
        echo "\n{$recherche} est classée #" . ($i + 1) . "\n";
        break;
    }
}
usort() fn() comparaison for avec index break str_pad()
