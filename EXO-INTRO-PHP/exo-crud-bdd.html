EXO-01 Connexion PDO + afficher les produits new PDO · query() · fetchAll() · foreach

Cree un fichier connexion.php avec la connexion PDO, puis un fichier liste.php qui inclut la connexion et affiche tous les produits de la table produits dans un tableau HTML. Chaque ligne doit afficher : id, nom, prix et stock.

Objectifs

  • Creer la connexion PDO avec try/catch et ATTR_ERRMODE_EXCEPTION
  • Inclure la connexion dans liste.php avec require_once
  • Executer : $stmt = $pdo->query('SELECT * FROM produits ORDER BY nom')
  • Recuperer tout : $produits = $stmt->fetchAll()
  • Afficher dans un <table> HTML avec foreach
Solution — connexion.php
<?php
$dsn  = 'mysql:host=localhost;port=8889;dbname=catalogue_shop;charset=utf8mb4';
$user = 'root'; $pass = 'root';
try {
    $pdo = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]);
} catch (PDOException $e) {
    die('Connexion impossible : ' . $e->getMessage());
}
Solution — liste.php
<?php
require_once 'connexion.php';
$produits = $pdo->query('SELECT * FROM produits ORDER BY nom')->fetchAll();
?>
<!DOCTYPE html><html lang="fr"><body>
<h1>Liste des produits</h1>
<p><?= count($produits) ?> produits affiches</p>
<table border="1">
  <tr><th>ID</th><th>Nom</th><th>Prix</th><th>Stock</th></tr>
  <?php foreach ($produits as $p): ?>
  <tr>
    <td><?= $p['id'] ?></td>
    <td><?= htmlspecialchars($p['nom']) ?></td>
    <td><?= number_format($p['prix'], 2, ',', ' ') ?> €</td>
    <td><?= $p['stock'] ?></td>
  </tr>
  <?php endforeach; ?>
</table>
</body></html>

EXO-02 Ajouter un produit (CREATE) INSERT INTO · prepare() · execute() · lastInsertId()

Cree un fichier ajouter.php avec un formulaire HTML (nom, prix, stock, categorie_id). Quand le formulaire est soumis, insere le nouveau produit dans la base avec une requete preparee. Recupere l'id genere avec lastInsertId() et redirige vers liste.php avec un message flash.

Objectifs

  • Detecter la soumission : $_SERVER['REQUEST_METHOD'] === 'POST'
  • Valider les champs : non vide, prix > 0, stock >= 0
  • Preparer l'INSERT : $pdo->prepare('INSERT INTO produits (nom, prix, stock) VALUES (:nom, :prix, :stock)')
  • Executer avec les valeurs : $stmt->execute([...])
  • Recuperer l'id insere : $pdo->lastInsertId()
  • Stocker un message flash en session et rediriger : header('Location: liste.php')
Solution
<?php
require_once 'connexion.php'; session_start();
$erreurs = []; $nom = $prix = $stock = $cat_id = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nom = trim($_POST['nom'] ?? '');
    $prix = (float)($_POST['prix'] ?? 0);
    $stock = (int)($_POST['stock'] ?? 0);
    $cat_id = (int)($_POST['categorie_id'] ?? 0);
    if(empty($nom)) $erreurs[] = 'Le nom est obligatoire.';
    if($prix <= 0) $erreurs[] = 'Le prix doit etre positif.';
    if($stock < 0) $erreurs[] = 'Le stock ne peut pas etre negatif.';
    if(empty($erreurs)) {
        $stmt = $pdo->prepare('INSERT INTO produits (nom, prix, stock, categorie_id) VALUES (:nom, :prix, :stock, :cat)');
        $stmt->execute([':nom'=>htmlspecialchars($nom), ':prix'=>$prix, ':stock'=>$stock, ':cat'=>$cat_id]);
        $new_id = $pdo->lastInsertId();
        $_SESSION['flash'] = "Produit #" . $new_id . " ajoute !";
        header('Location: liste.php'); exit();
    }
}
?>
<!DOCTYPE html><html lang="fr"><body>
<?php foreach($erreurs as $e): ?><p style="color:red"> <?= htmlspecialchars($e) ?></p><?php endforeach; ?>
<form method="POST">
  <input type="text"   name="nom"          value="<?= htmlspecialchars($nom) ?>" placeholder="Nom">
  <input type="number" name="prix"         value="<?= $prix ?>" step="0.01" placeholder="Prix">
  <input type="number" name="stock"        value="<?= $stock ?>" placeholder="Stock">
  <input type="number" name="categorie_id" value="<?= $cat_id ?>" placeholder="ID categorie">
  <button type="submit">Ajouter</button>
</form>
</body></html>

EXO-03 Afficher le detail d'un produit (READ) fetch() · WHERE id = :id · htmlspecialchars()

Cree un fichier detail.php qui recoit l'id du produit via l'URL (?id=1). Utilise une requete preparee pour charger ce produit depuis la BDD. Affiche tous ses details. Si l'id n'existe pas, affiche "Produit introuvable" et un lien retour. Ajoute aussi les liens "Modifier" et "Supprimer".

Objectifs

  • Recuperer et securiser l'id : $id = (int) ($_GET['id'] ?? 0);
  • Requete preparee : $pdo->prepare('SELECT * FROM produits WHERE id = :id')
  • Recuperer une seule ligne : $stmt->fetch()
  • Verifier que le produit existe : if (!$produit)
  • Afficher les donnees en securisant avec htmlspecialchars()
Solution
<?php
require_once 'connexion.php';
$id = (int)($_GET['id'] ?? 0);
$stmt = $pdo->prepare('SELECT p.*, c.nom AS categorie_nom FROM produits p LEFT JOIN categories c ON p.categorie_id = c.id WHERE p.id = :id');
$stmt->execute([':id' => $id]);
$produit = $stmt->fetch();
if (!$produit) { echo '<p>Produit introuvable.</p><a href="liste.php">Retour</a>'; exit(); }
?>
<h1><?= htmlspecialchars($produit['nom']) ?></h1>
<p>Prix : <?= number_format($produit['prix'], 2, ',', ' ') ?> €</p>
<p>Stock : <?= $produit['stock'] ?></p>
<p>Categorie : <?= htmlspecialchars($produit['categorie_nom'] ?? 'Non definie') ?></p>
<a href="modifier.php?id=<?= $produit['id'] ?>">Modifier</a> | 
<a href="supprimer.php?id=<?= $produit['id'] ?>" onclick="return confirm('Supprimer ?')">Supprimer</a>
(int) cast securite prepare() + execute() fetch() if (!$produit) htmlspecialchars() LEFT JOIN dans la requete

EXO-04 Modifier un produit (UPDATE) prepare() UPDATE · formulaire pre-rempli · rowCount()

Cree un fichier modifier.php. Il charge le produit depuis la BDD (pre-remplissage du formulaire) et execute un UPDATE quand le formulaire est soumis. Valide les donnees, execute la requete preparee, affiche le nombre de lignes modifiees avec rowCount() et redirige vers detail.php.

Objectifs

  • Charger le produit existant pour pre-remplir le formulaire
  • Gerer deux scenarios dans le meme fichier : GET (affichage) et POST (traitement)
  • UPDATE prepare : UPDATE produits SET nom=:nom, prix=:prix WHERE id=:id
  • Verifier le nombre de lignes modifiees : $stmt->rowCount()
  • Rediriger vers le detail apres succes
Solution
<?php
require_once 'connexion.php'; session_start();
$id = (int)($_GET['id'] ?? $_POST['id'] ?? 0);
if($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nom = trim($_POST['nom'] ?? '');
    $prix = (float)($_POST['prix'] ?? 0);
    $stock = (int)($_POST['stock'] ?? 0);
    $stmt = $pdo->prepare('UPDATE produits SET nom=:nom, prix=:prix, stock=:stock WHERE id=:id');
    $stmt->execute([':nom'=>htmlspecialchars($nom), ':prix'=>$prix, ':stock'=>$stock, ':id'=>$id]);
    $_SESSION['flash'] = $stmt->rowCount() . ' ligne(s) modifiee(s).';
    header("Location: detail.php?id={$id}"); exit();
}
$stmt = $pdo->prepare('SELECT * FROM produits WHERE id = :id');
$stmt->execute([':id' => $id]);
$produit = $stmt->fetch();
if(!$produit) { header('Location: liste.php'); exit(); }
?>
<form method="POST">
  <input type="hidden" name="id" value="<?= $id ?>">
  <input type="text"   name="nom"   value="<?= htmlspecialchars($produit['nom']) ?>">
  <input type="number" name="prix"  value="<?= $produit['prix'] ?>" step="0.01">
  <input type="number" name="stock" value="<?= $produit['stock'] ?>">
  <button type="submit">Enregistrer</button>
</form>

EXO-05 Supprimer un produit (DELETE) DELETE · confirm() · flash session · PRG

Cree un fichier supprimer.php. Il affiche une page de confirmation avec les details du produit a supprimer. Quand l'utilisateur confirme (formulaire POST), execute un DELETE prepare. Stocke un message flash en session et redirige vers liste.php. Applique le pattern PRG pour eviter la double soumission.

Objectifs

  • Afficher une page de confirmation avant de supprimer
  • DELETE prepare : DELETE FROM produits WHERE id = :id
  • Pattern PRG : POST -> stocker flash -> Redirect -> GET affiche flash
  • Supprimer le flash apres affichage : unset($_SESSION['flash'])
  • Verifier avec rowCount() si la suppression a eu lieu
Solution
<?php
require_once 'connexion.php'; session_start();
$id = (int)($_GET['id'] ?? $_POST['id'] ?? 0);
$stmt = $pdo->prepare('SELECT * FROM produits WHERE id = :id');
$stmt->execute([':id'=>$id]);
$produit = $stmt->fetch();
if(!$produit) { header('Location: liste.php'); exit(); }
if($_SERVER['REQUEST_METHOD'] === 'POST') {
    $stmt = $pdo->prepare('DELETE FROM produits WHERE id = :id');
    $stmt->execute([':id'=>$id]);
    if($stmt->rowCount() > 0) $_SESSION['flash'] = "Produit supprime.";
    header('Location: liste.php'); exit();
}
?>
<h2>Supprimer <?= htmlspecialchars($produit['nom']) ?> ?</h2>
<form method="POST"><input type="hidden" name="id" value="<?= $id ?>">
  <button type="submit">Oui, supprimer</button> <a href="liste.php">Annuler</a>
</form>

EXO-07 CRUD complet en un seul fichier switch action · POST · GET · flash · PRG

Cree un fichier crud.php qui gere toutes les actions CRUD dans un seul fichier. L'action est determinee par $_GET['action'] (liste, ajouter, modifier, supprimer) ou $_POST['action']. Utilise un switch pour router vers la bonne logique. Chaque action POST redirige apres execution (pattern PRG).

Objectifs

  • Router les actions avec switch ($action)
  • Lire l'action : $action = $_GET['action'] ?? $_POST['action'] ?? 'liste'
  • Toutes les actions POST redirigent apres execution
  • La vue est rendue apres le switch (separation logique/affichage)
  • Un seul require_once connexion.php pour tout le fichier
Solution
<?php
require_once 'connexion.php'; session_start();
$action = $_GET['action'] ?? $_POST['action'] ?? 'liste';
$id = (int)($_GET['id'] ?? $_POST['id'] ?? 0);

if($_SERVER['REQUEST_METHOD'] === 'POST') {
    switch($action) {
        case 'creer':
            $s = $pdo->prepare('INSERT INTO produits (nom, prix, stock) VALUES (:n, :p, :s)');
            $s->execute([':n'=>trim($_POST['nom']), ':p'=>(float)$_POST['prix'], ':s'=>(int)$_POST['stock']]);
            $_SESSION['flash'] = 'Produit cree !'; header('Location: crud.php'); exit();
        case 'modifier':
            $s = $pdo->prepare('UPDATE produits SET nom=:n, prix=:p, stock=:s WHERE id=:id');
            $s->execute([':n'=>trim($_POST['nom']), ':p'=>(float)$_POST['prix'], ':s'=>(int)$_POST['stock'], ':id'=>$id]);
            $_SESSION['flash'] = 'Produit modifie !'; header('Location: crud.php'); exit();
        case 'supprimer':
            $s = $pdo->prepare('DELETE FROM produits WHERE id=:id');
            $s->execute([':id'=>$id]);
            $_SESSION['flash'] = 'Supprime !'; header('Location: crud.php'); exit();
    }
}
/* switch($action) pour charger les donnees de vue */
switch($action) $_GET['action'] routage CRUD pattern PRG flash session un fichier unique
EXO-08 Pagination des resultats LIMIT · OFFSET · COUNT(*) · pages

Ajoute la pagination a liste.php. Affiche 5 produits par page. Calcule le nombre total de pages avec COUNT(*). Affiche les liens de navigation (Precedent / Suivant / numeros de page). La page courante vient de $_GET['page'] avec comme valeur par defaut 1.

Objectifs

  • Compter le total : $total = $pdo->query('SELECT COUNT(*) FROM produits')->fetchColumn();
  • Calculer : $nb_pages = ceil($total / $par_page)
  • Securiser la page courante : $page = max(1, min((int)($_GET['page'] ?? 1), $nb_pages))
  • Calculer l'offset : $offset = ($page - 1) * $par_page
  • Requete avec pagination : SELECT * FROM produits ORDER BY nom LIMIT :limit OFFSET :offset
  • Afficher les liens de navigation avec boucle for
Solution
<?php
require_once 'connexion.php';
$par_page = 5;
$total = (int)$pdo->query('SELECT COUNT(*) FROM produits')->fetchColumn();
$nb_pages = (int)ceil($total/$par_page);
$page = max(1, min((int)($_GET['page'] ?? 1), $nb_pages));
$offset = ($page-1) * $par_page;
$stmt = $pdo->prepare('SELECT * FROM produits ORDER BY nom LIMIT :lim OFFSET :off');
$stmt->bindValue(':lim', $par_page, PDO::PARAM_INT);
$stmt->bindValue(':off', $offset,   PDO::PARAM_INT);
$stmt->execute(); $produits = $stmt->fetchAll();
?>
/* Afficher le tableau + la navigation pagination */

EXO-09 CRUD avec transactions et upload image beginTransaction · commit · rollBack · $_FILES Bonus

Exercice bonus. Ameliore le formulaire d'ajout de produit pour qu'il accepte une image (upload de fichier). Utilise une transaction PDO pour garantir que l'INSERT dans produits et la copie du fichier reussissent ensemble ou echouent ensemble. Si l'image est invalide, rollback et aucun produit n'est insere.

Objectifs

  • Valider l'upload : type MIME, taille max, extension autorisee
  • Generer un nom unique : uniqid() . '.' . $extension
  • Utiliser une transaction : $pdo->beginTransaction()
  • En cas d'erreur : $pdo->rollBack() + supprimer le fichier copie
  • En cas de succes : $pdo->commit()
  • Stocker le nom du fichier dans la colonne image de la table
Solution
<?php
require_once 'connexion.php'; session_start();
if($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nom = trim($_POST['nom'] ?? '');
    $prix = (float)($_POST['prix'] ?? 0);
    $stock = (int)($_POST['stock'] ?? 0);
    $erreurs = [];
    $types_ok = ['image/jpeg', 'image/png', 'image/webp'];
    if($_FILES['image']['error'] !== UPLOAD_ERR_OK) $erreurs[] = 'Image manquante.';
    if(!in_array($_FILES['image']['type'], $types_ok)) $erreurs[] = 'Type non autorise.';
    if($_FILES['image']['size'] > 2*1024*1024) $erreurs[] = 'Max 2 Mo.';
    if(empty($erreurs)) {
        $ext = strtolower(pathinfo($_FILES['image']['name'], PATHINFO_EXTENSION));
        $nom_fichier = uniqid() . '.' . $ext;
        $dest = 'images/' . $nom_fichier;
        $pdo->beginTransaction();
        try {
            $stmt = $pdo->prepare('INSERT INTO produits (nom, prix, stock, image) VALUES (:nom, :prix, :stock, :img)');
            $stmt->execute([':nom'=>$nom, ':prix'=>$prix, ':stock'=>$stock, ':img'=>$nom_fichier]);
            if(!move_uploaded_file($_FILES['image']['tmp_name'], $dest)) throw new Exception('Echec copie');
            $pdo->commit();
            $_SESSION['flash'] = 'Produit ajoute !'; header('Location: liste.php'); exit();
        } catch(Exception $e) {
            $pdo->rollBack(); $erreurs[] = 'Erreur : ' . $e->getMessage();
        }
    }
}
?>
<form method="POST" enctype="multipart/form-data">
  <input type="text"   name="nom"   placeholder="Nom">
  <input type="number" name="prix"  step="0.01">
  <input type="number" name="stock">
  <input type="file"   name="image" accept="image/*">
  <button type="submit">Ajouter</button>
</form>
