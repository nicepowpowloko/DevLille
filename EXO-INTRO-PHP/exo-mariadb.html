EXO-01 Gerer les bases de donnees SHOW DATABASES · CREATE · DROP · USE

Dans le terminal ou phpMyAdmin, connecte-toi a MariaDB avec root. Liste toutes les bases existantes, cree une nouvelle base formation_test en UTF-8, selectionne-la, affiche la version du serveur, puis supprime cette base.

Objectifs

  • Lister les bases : SHOW DATABASES;
  • Creer avec le bon encodage : CREATE DATABASE formation_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  • Selectionner : USE formation_test; et verifier : SELECT DATABASE();
  • Infos serveur : SELECT VERSION(), USER(), NOW();
  • Supprimer proprement : DROP DATABASE IF EXISTS formation_test;
Solution
SHOW DATABASES;
CREATE DATABASE formation_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE formation_test;
SELECT DATABASE();
SELECT VERSION(), USER(), NOW();
DROP DATABASE IF EXISTS formation_test;
SHOW DATABASES CREATE DATABASE CHARACTER SET utf8mb4 USE SELECT DATABASE() DROP DATABASE IF EXISTS
EXO-02 Creer et gerer des utilisateurs CREATE USER · ALTER USER · DROP USER · mysql.user

Cree un utilisateur dev_user avec le mot de passe DevPass2025! accessible uniquement depuis localhost. Verifie son existence dans la table systeme mysql.user, change son mot de passe, puis supprime-le proprement.

Objectifs

  • Creer un utilisateur : CREATE USER 'dev_user'@'localhost' IDENTIFIED BY 'DevPass2025!';
  • Lister tous les utilisateurs : SELECT user, host FROM mysql.user ORDER BY user;
  • Modifier le mot de passe : ALTER USER 'dev_user'@'localhost' IDENTIFIED BY 'NouveauMdp!';
  • Supprimer : DROP USER IF EXISTS 'dev_user'@'localhost';
  • Comprendre le format user@host : host controle depuis ou la connexion est autorisee
Solution
CREATE USER 'dev_user'@'localhost' IDENTIFIED BY 'DevPass2025!';
SELECT user, host, password_expired FROM mysql.user WHERE user = 'dev_user';
ALTER USER 'dev_user'@'localhost' IDENTIFIED BY 'NouveauMdp2025!';
SELECT user, host FROM mysql.user ORDER BY user;
DROP USER IF EXISTS 'dev_user'@'localhost';
CREATE USER user@localhost IDENTIFIED BY mysql.user ALTER USER DROP USER IF EXISTS

EXO-04 Sauvegarder avec mysqldump mysqldump · backup · restore · compression

Depuis le terminal, utilise mysqldump (fourni avec MAMP) pour sauvegarder la base catalogue_shop. Exporte la structure seule, les donnees seules, puis l'ensemble complet. Restaure ensuite le backup dans une nouvelle base catalogue_restore.

Objectifs

  • Localiser mysqldump sur MAMP Mac : /Applications/MAMP/Library/bin/mysqldump
  • Export complet : mysqldump -u root -p -P 8889 catalogue_shop > backup.sql
  • Structure seule : mysqldump --no-data catalogue_shop > structure.sql
  • Donnees seules : mysqldump --no-create-info catalogue_shop > data.sql
  • Restaurer : mysql -u root -p -P 8889 catalogue_restore < backup.sql
Solution
# Export complet
mysqldump -u root -proot -P 8889 catalogue_shop > ~/Desktop/backup_complet.sql
# Structure seule
mysqldump -u root -proot -P 8889 --no-data catalogue_shop > ~/Desktop/structure.sql
# Donnees seules
mysqldump -u root -proot -P 8889 --no-create-info catalogue_shop > ~/Desktop/data.sql
# Export compresse
mysqldump -u root -proot -P 8889 catalogue_shop | gzip > ~/Desktop/backup.sql.gz

# Restauration
mysql -u root -proot -P 8889 -e "CREATE DATABASE catalogue_restore CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -proot -P 8889 catalogue_restore < ~/Desktop/backup_complet.sql
mysql -u root -proot -P 8889 catalogue_restore -e "SHOW TABLES;"
mysqldump --no-data --no-create-info --databases gzip compression mysql < backup.sql restauration

EXO-06 Creer et utiliser des VUES CREATE VIEW · DROP VIEW · SHOW FULL TABLES

Une vue est une requete sauvegardee qu'on utilise comme une table. Cree une vue v_catalogue qui joint produits et categories et ne garde que les produits en stock. Cree aussi une vue v_stats_categories avec le nombre de produits et le prix moyen par categorie.

Objectifs

  • Creer une vue : CREATE VIEW v_catalogue AS SELECT ...;
  • Interroger comme une table : SELECT * FROM v_catalogue WHERE categorie = 'Electronique';
  • Lister les vues : SHOW FULL TABLES WHERE Table_type = 'VIEW';
  • Voir la definition : SHOW CREATE VIEW v_catalogue;
  • Supprimer : DROP VIEW IF EXISTS v_catalogue;
Solution
CREATE VIEW v_catalogue AS
SELECT p.id, p.nom, p.prix, p.stock, c.nom AS categorie
FROM produits p JOIN categories c ON p.categorie_id = c.id
WHERE p.stock > 0;

SELECT * FROM v_catalogue ORDER BY prix ASC;

CREATE VIEW v_stats_categories AS
SELECT c.nom, COUNT(p.id) AS nb_produits, ROUND(AVG(p.prix),2) AS prix_moyen, SUM(p.stock) AS stock_total
FROM categories c LEFT JOIN produits p ON c.id = p.categorie_id
GROUP BY c.id, c.nom;

SHOW FULL TABLES WHERE Table_type = 'VIEW';
DROP VIEW IF EXISTS v_catalogue;
CREATE VIEW AS SELECT * FROM vue LEFT JOIN dans une vue SHOW FULL TABLES WHERE Table_type DROP VIEW IF EXISTS

EXO-08 Procedure stockee et Trigger CREATE PROCEDURE · CALL · CREATE TRIGGER · OLD · NEW

Cree une procedure stockee sp_ajouter_produit qui verifie que le prix est positif avant d'inserer. Cree aussi un trigger tr_log_prix qui enregistre automatiquement dans une table logs_prix chaque modification de prix.

Objectifs

  • Changer le delimiteur : DELIMITER $$ pour ecrire des blocs multi-lignes
  • Creer une procedure : CREATE PROCEDURE nom(IN param TYPE) BEGIN ... END
  • Lever une erreur : SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '...';
  • Appeler : CALL sp_ajouter_produit('Webcam', 59.90, 20, 1);
  • Trigger AFTER UPDATE : acceder aux valeurs avec OLD.prix et NEW.prix
Solution
CREATE TABLE IF NOT EXISTS logs_prix (id INT AUTO_INCREMENT PRIMARY KEY, produit_id INT, ancien_prix DECIMAL(10,2), nouveau_prix DECIMAL(10,2), modifie_le DATETIME DEFAULT CURRENT_TIMESTAMP);

DELIMITER $$
CREATE PROCEDURE sp_ajouter_produit(IN p_nom VARCHAR(150), IN p_prix DECIMAL(10,2), IN p_stock INT, IN p_cat_id INT)
BEGIN
  IF p_prix <= 0 THEN
    SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Le prix doit etre positif';
  END IF;
  INSERT INTO produits (nom, prix, stock, categorie_id) VALUES (p_nom, p_prix, p_stock, p_cat_id);
END $$
DELIMITER ;

DELIMITER $$
CREATE TRIGGER tr_log_prix AFTER UPDATE ON produits FOR EACH ROW
BEGIN
  IF OLD.prix <> NEW.prix THEN
    INSERT INTO logs_prix (produit_id, ancien_prix, nouveau_prix) VALUES (NEW.id, OLD.prix, NEW.prix);
  END IF;
END $$
DELIMITER ;

CALL sp_ajouter_produit('Webcam HD', 59.90, 20, 1);
UPDATE produits SET prix = 699.00 WHERE id = 1;
SELECT * FROM logs_prix;
DELIMITER $$ CREATE PROCEDURE IN param TYPE IF ... THEN ... END IF SIGNAL SQLSTATE 45000 CALL CREATE TRIGGER AFTER UPDATE OLD.col / NEW.col
EXO-09 Script backup automatise + cron bash · mysqldump · gzip · rotation · crontab Bonus

Exercice bonus. Cree un script bash backup_mariadb.sh qui sauvegarde automatiquement la base, compresse le fichier, garde seulement les 7 derniers backups (rotation automatique) et enregistre chaque operation dans un fichier de log. Planifie ensuite ce script avec crontab pour qu'il s'execute chaque nuit a 2h.

Objectifs

  • Script bash avec variables : chemin mysqldump, credentials, dossier backup
  • Nommer avec la date : $(date +%Y%m%d_%H%M%S)
  • Compression gzip : mysqldump ... | gzip > backup.sql.gz
  • Verifier le succes : if [ $? -eq 0 ]; then ... fi
  • Rotation automatique : ls -t *.sql.gz | tail -n +8 | xargs rm -f
  • Planification : crontab -e puis 0 2 * * * /chemin/backup.sh
Solution
#!/bin/bash
DB_USER="root"; DB_PASS="root"; DB_PORT="8889"; DB_NAME="catalogue_shop"
BACKUP_DIR="$HOME/Desktop/backups_mariadb"
LOG_FILE="$BACKUP_DIR/backup.log"
MYSQLDUMP="/Applications/MAMP/Library/bin/mysqldump"

mkdir -p "$BACKUP_DIR"
DATE=$(date +%Y%m%d_%H%M%S)
FILENAME="$BACKUP_DIR/${DB_NAME}_${DATE}.sql.gz"

echo "[$(date)] Debut..." >> "$LOG_FILE"
$MYSQLDUMP -u $DB_USER -p$DB_PASS -P $DB_PORT --single-transaction --routines --triggers $DB_NAME | gzip > "$FILENAME"

if [ $? -eq 0 ]; then
  SIZE=$(du -sh "$FILENAME" | cut -f1)
  echo "[$(date)] OK — $FILENAME ($SIZE)" >> "$LOG_FILE"
else
  echo "[$(date)] ERREUR !" >> "$LOG_FILE"; exit 1
fi

ls -t "$BACKUP_DIR"/*.sql.gz 2>/dev/null | tail -n +$((RETENTION + 1)) | xargs rm -f
echo "[$(date)] Rotation OK" >> "$LOG_FILE"
# Planifier : crontab -e  ->  0 2 * * * /bin/bash /chemin/backup_mariadb.sh
bash script mysqldump --single-transaction gzip compression $(date +%Y%m%d) if [ $? -eq 0 ] ls -t tail -n xargs rm crontab -e 0 2 * * *
