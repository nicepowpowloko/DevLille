EXO-01Créer le fichier JSONInitialisation

Crée data.json avec un tableau vide [].
Dans index.php, lis le fichier et affiche un message si aucun produit.

Solution
<?php
$file = 'data.json';
if (!file_exists($file)) {
    file_put_contents($file, '[]');
}
$data = json_decode(file_get_contents($file), true);

if (empty($data)) {
    echo "Aucun produit pour le moment.";
}
EXO-02Ajouter un produit (Create)Formulaire POST

Crée un formulaire (nom, prix) qui envoie vers create.php. Ajoute le produit avec un ID auto-incrémenté.

Solution
<?php
// create.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $file = 'data.json';
    $data = json_decode(file_get_contents($file), true) ?? [];

    $new = [
        'id'   => count($data) + 1,
        'nom'  => trim($_POST['nom']),
        'prix' => (float)$_POST['prix']
    ];

    $data[] = $new;
    file_put_contents($file, json_encode($data, JSON_PRETTY_PRINT));

    header('Location: index.php');
}

EXO-04Modifier un produit (Update)edit.php

Crée edit.php qui charge le produit par ID, affiche un formulaire pré-rempli et met à jour le JSON.

Solution
<?php
// edit.php
$id = (int)$_GET['id'];
$file = 'data.json';
$data = json_decode(file_get_contents($file), true) ?? [];

$index = array_search($id, array_column($data, 'id'));

if ($index !== false) {
    $product = &$data[$index];

    if ($_SERVER['REQUEST_METHOD'] === 'POST') {
        $product['nom'] = trim($_POST['nom']);
        $product['prix'] = (float)$_POST['prix'];
        file_put_contents($file, json_encode($data, JSON_PRETTY_PRINT));
        header('Location: index.php');
        exit;
    }
}
?>
<form method="POST">
    Nom: <input type="text" name="nom" value=""><br>
    Prix: <input type="number" name="prix" value="" step="0.01"><br>
    <button type="submit">Enregistrer les modifications</button>
</form>
EXO-05Supprimer un produit (Delete)delete.php

Crée delete.php qui supprime un produit par ID et redirige vers la liste.

Solution
<?php
// delete.php
$id = (int)$_GET['id'];
$file = 'data.json';
$data = json_decode(file_get_contents($file), true) ?? [];

$data = array_filter($data, fn($p) => $p['id'] !== $id);
$data = array_values($data); // réindexer

file_put_contents($file, json_encode($data, JSON_PRETTY_PRINT));

header('Location: index.php');
EXO-06Rechercher un produitFiltrage

Ajoute un champ de recherche par nom dans index.php et filtre les résultats affichés.

Solution
<?php
// Dans index.php
$search = $_GET['search'] ?? '';
$data = json_decode(file_get_contents('data.json'), true) ?? [];

if ($search) {
    $data = array_filter($data, fn($p) => stripos($p['nom'], $search) !== false);
}

EXO-07Fonctions CRUD centraliséesfunctions.php

Crée un fichier functions.php avec les fonctions : getAll(), add(), update(), delete().

Solution
<?php
// functions.php
function getAllProducts() {
    $file = 'data.json';
    if (!file_exists($file)) return [];
    return json_decode(file_get_contents($file), true) ?? [];
}

function saveProducts($data) {
    file_put_contents('data.json', json_encode($data, JSON_PRETTY_PRINT));
}

function addProduct($nom, $prix) {
    $data = getAllProducts();
    $data[] = ['id' => count($data)+1, 'nom' => trim($nom), 'prix' => (float)$prix];
    saveProducts($data);
}
EXO-08Sécurité basiqueValidation + Sanitize

Valide que le nom n’est pas vide et que le prix est un nombre positif. Utilise htmlspecialchars() à l’affichage.

Solution
<?php
// Exemple de validation dans create.php ou edit.php
$nom = trim($_POST['nom'] ?? '');
$prix = (float)($_POST['prix'] ?? 0);

if (empty($nom) || $prix <= 0) {
    die("Erreur : nom obligatoire et prix > 0");
}
EXO-09CRUD complet avec messages flash (Bonus)Flash messages

Ajoute des messages flash (succès / erreur) après chaque action et redirige vers la liste.

Solution
<?php
// Après une action réussie
session_start();
$_SESSION['flash'] = ['type' => 'success', 'message' => 'Produit ajouté avec succès !'];
header('Location: index.php');

// Dans index.php
if (isset($_SESSION['flash'])) {
    echo "<div style='color:green'>" . htmlspecialchars($_SESSION['flash']['message']) . "</div>";
    unset($_SESSION['flash']);
}
