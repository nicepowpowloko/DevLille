localStorage en JavaScript

Qu'est-ce que le localStorage ?

Le localStorage est un espace de stockage dans le navigateur qui permet de sauvegarder des données de manière permanente.

C'est comme une petite base de données locale dans le navigateur de l'utilisateur.

L'utilisateur ajoute des données
↓
localStorage les sauvegarde
↓
La page se recharge
↓
Les données sont TOUJOURS LÀ !

Comparaison : Avec et Sans localStorage

SANS localStorage

  • Les données sont dans des variables JavaScript
  • Elles existent uniquement en mémoire
  • Quand on recharge la page → TOUT DISPARAÎT
  • Les données sont perdues à jamais

AVEC localStorage

  • Les données sont sauvegardées dans le navigateur
  • Elles persistent même après fermeture
  • Quand on recharge la page → TOUT RESTE
  • Les données sont conservées indéfiniment

Les 4 opérations du localStorage

Opération Méthode Rôle
Sauvegarder localStorage.setItem(clé, valeur) Enregistrer des données
Récupérer localStorage.getItem(clé) Lire des données sauvegardées
Supprimer localStorage.removeItem(clé) Effacer une donnée spécifique
Tout effacer localStorage.clear() Supprimer TOUTES les données

Sauvegarder des données simples

1Sauvegarder une chaîne de caractères

// Syntaxe : localStorage.setItem(clé, valeur) localStorage.setItem("prenom", "Thomas"); localStorage.setItem("age", "30"); localStorage.setItem("ville", "Paris"); console.log("Données sauvegardées !");
Explication :
• setItem() prend 2 paramètres : une clé et une valeur
• La clé = le nom de la donnée (comme le nom d'une variable)
• La valeur = le contenu à sauvegarder
• Les données restent même après fermeture du navigateur !

Récupérer des données

2Lire les données sauvegardées

// Syntaxe : localStorage.getItem(clé) let prenom = localStorage.getItem("prenom"); let age = localStorage.getItem("age"); let ville = localStorage.getItem("ville"); console.log(prenom); // Affiche : Thomas console.log(age); // Affiche : 30 console.log(ville); // Affiche : Paris
ATTENTION :
Si la clé n'existe pas, getItem() retourne null.
Il faut toujours vérifier avant d'utiliser !
// Vérifier si une donnée existe let prenom = localStorage.getItem("prenom"); if (prenom !== null) { console.log("Bonjour " + prenom); } else { console.log("Aucun prénom sauvegardé"); }

Sauvegarder des tableaux et objets avec JSON

PROBLÈME :
localStorage ne peut sauvegarder QUE des chaînes de caractères !
Pour les tableaux et objets, il faut les convertir en JSON.
Processus de conversion
Objet JavaScript
{ nom: "Alice", age: 25 }
↓ JSON.stringify()
Chaîne JSON
'{"nom":"Alice","age":25}'
↓ localStorage.setItem()
Sauvegardé dans localStorage
↓ localStorage.getItem()
Chaîne JSON récupérée
'{"nom":"Alice","age":25}'
↓ JSON.parse()
Objet JavaScript reconstitué
{ nom: "Alice", age: 25 }

Exemple complet : Sauvegarder un tableau

// // SAUVEGARDER un tableau // let mesCours = [ { lecon: "JavaScript", heure: "09h00" }, { lecon: "PHP", heure: "14h00" }, { lecon: "HTML/CSS", heure: "16h30" } ]; // Convertir en JSON (chaîne de caractères) let coursJSON = JSON.stringify(mesCours); // Sauvegarder dans localStorage localStorage.setItem("cours", coursJSON); console.log(" Cours sauvegardés !");
// // RÉCUPÉRER le tableau // // Récupérer la chaîne JSON let coursJSON = localStorage.getItem("cours"); // Vérifier que des données existent if (coursJSON !== null) { //Convertir le JSON en tableau JavaScript let mesCours = JSON.parse(coursJSON); //Utiliser le tableau console.log(mesCours); console.log("Premier cours : " + mesCours[0].lecon); } else { console.log("Aucun cours sauvegardé"); }

Exemple complet : Application de gestion de cours

// // CONSTRUCTEUR // function Cours(lecon, heure, salle) { this.lecon = lecon; this.heure = heure; this.salle = salle; } // // FONCTION : Sauvegarder tous les cours // function sauvegarderCours(tableauCours) { // Convertir en JSON let coursJSON = JSON.stringify(tableauCours); // Sauvegarder localStorage.setItem("mesCours", coursJSON); console.log("Cours sauvegardés !"); } // // FONCTION : Charger les cours sauvegardés // function chargerCours() { // Récupérer les données let coursJSON = localStorage.getItem("mesCours"); // Si des cours existent if (coursJSON !== null) { // Convertir en tableau JavaScript let coursData = JSON.parse(coursJSON); // Recréer les objets Cours let coursReconstruits = coursData.map(function(data) { return new Cours(data.lecon, data.heure, data.salle); }); return coursReconstruits; } else { // Retourner un tableau vide return []; } } // // UTILISATION // // Au chargement de la page : charger les cours let tousLesCours = chargerCours(); // Ajouter un nouveau cours let nouveauCours = new Cours("JavaScript", "09h00", "A101"); tousLesCours.push(nouveauCours); // Sauvegarder après chaque modification sauvegarderCours(tousLesCours);

Supprimer des données

Supprimer une donnée spécifique

// Supprimer la clé "prenom" localStorage.removeItem("prenom"); console.log("Prénom supprimé");

Tout supprimer

// Supprimer TOUTES les données du localStorage localStorage.clear(); console.log("Tout le localStorage est vide");

Récapitulatif des méthodes

Méthode Syntaxe Exemple
Sauvegarder setItem(clé, valeur) localStorage.setItem("nom", "Alice")
Récupérer getItem(clé) let nom = localStorage.getItem("nom")
Supprimer removeItem(clé) localStorage.removeItem("nom")
Tout effacer clear() localStorage.clear()
Convertir en JSON JSON.stringify(objet) JSON.stringify(mesCours)
Reconvertir JSON.parse(chaîne) JSON.parse(coursJSON)

Points importants à retenir

1localStorage ne sauvegarde QUE des chaînes de caractères

Pour les objets/tableaux, utilisez JSON.stringify() et JSON.parse()

2Toujours vérifier si une donnée existe avant de l'utiliser

Utilisez if (donnée !== null)

3Les données persistent indéfiniment

Même après fermeture du navigateur ou redémarrage de l'ordinateur

4Limite de stockage : environ 5-10 MB

Suffisant pour la plupart des applications web

5Les données sont spécifiques à un domaine

chaque site web a son propre localStorage

Exercice pratique

Créer une liste de tâches persistante

Objectifs :

  • Créer un constructeur Tache(nom, fait)
  • Permettre d'ajouter des tâches
  • Sauvegarder dans localStorage après chaque ajout
  • Charger les tâches au démarrage
  • Permettre de marquer une tâche comme "terminée"
  • Les tâches doivent persister après rechargement
