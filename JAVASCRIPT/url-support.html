De la théorie à la pratique : maîtrisez URLSearchParams et ses 12 méthodes pour créer des applications réactives et maintenables.

1. Anatomie détaillée d'une URL foundation
https://shop.app/produits/liste.html?id=42&mode=edit&lang=fr&promo=ete2025#section-avis
?
Délimiteur
Marque le début des paramètres
&
Séparateur
Entre chaque paire clé=valeur
=
Assignation
Lie la clé à sa valeur
#
Fragment
Ancre (non lue par URLSearchParams)

Rappel : window.location.search capture uniquement la partie après le ? jusqu'au # (exclu). Le fragment est géré par window.location.hash.

2. API URLSearchParams 12 méthodes

Toutes les méthodes de l'objet URLSearchParams :

  • .get(clé) Retourne la première valeur (ou null)
  • .getAll(clé) Tableau de toutes les valeurs (pour ?tag=js&tag=css)
  • .has(clé) true/false si la clé existe
  • .set(clé, valeur) Modifie ou ajoute une paire
  • .append(clé, valeur) Ajoute une valeur supplémentaire
  • .delete(clé) Supprime toutes les occurrences
  • .keys() / .values() / .entries() Itérateurs
  • .forEach(callback) Parcours simple
  • .sort() Trie les paires par clé
  • .toString() Reconstruit la query string
// EXEMPLE COMPLET
// 1. Récupération de la chaîne (ex: "?produit=42&couleur=rouge&couleur=bleu&promo=true")
const queryString = window.location.search;

// 2. Instanciation
const params = new URLSearchParams(queryString);

// 3. Extraction sécurisée
const productId = params.get('produit') ?? 'default-123'; // utilise || ou ??
const hasPromo = params.has('promo'); // true
const couleurs = params.getAll('couleur'); // ['rouge','bleu']

// 4. Modification (utile pour changer l'URL sans recharger)
params.set('page', '2');
params.append('tag', 'nouveau');
params.delete('couleur');
// Nouvelle query : "produit=42&promo=true&page=2&tag=nouveau"
const newUrl = `${window.location.pathname}?${params.toString()}`;
// window.history.pushState({}, '', newUrl); → met à jour l'URL sans recharger

Gestion des erreurs

  • • get() peut retourner null → toujours prévoir une valeur par défaut
  • • Attention aux espaces : ?name=John+Doe → décodé automatiquement
  • • decodeURIComponent() si besoin manuel

Sécurité

  • • Ne jamais faire confiance aux données URL pour des actions critiques (ex: admin=1)
  • • Valider côté serveur également
  • • Échapper l'affichage HTML (risque XSS)

URLSearchParams vs Objet

  • • Object.fromEntries(params) convertit en objet simple
  • • Attention : écrase les clés multiples
  • • [...params] donne tableau de paires
