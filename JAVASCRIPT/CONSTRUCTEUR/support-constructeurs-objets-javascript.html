Introduction aux Constructeurs

Pourquoi utiliser des constructeurs ?

Imaginons que vous devez créer plusieurs objets similaires, par exemple des voitures :

// SANS constructeur : beaucoup de répétition ! const voiture1 = { marque: "Peugeot", modele: "308", annee: 2022, demarrer: function() { console.log("Vroum vroum"); } }; const voiture2 = { marque: "Renault", modele: "Clio", annee: 2021, demarrer: function() { console.log("Vroum vroum"); } }; const voiture3 = { marque: "Citroën", modele: "C3", annee: 2023, demarrer: function() { console.log("Vroum vroum"); } }; // Répétitif, fastidieux, et source d'erreurs !

AVEC un constructeur : simple et efficace !

// Créer un "moule" pour fabriquer des voitures function Voiture(marque, modele, annee) { this.marque = marque; this.modele = modele; this.annee = annee; this.demarrer = function() { console.log("Vroum vroum"); }; } // Créer des instances facilement const voiture1 = new Voiture("Peugeot", "308", 2022); const voiture2 = new Voiture("Renault", "Clio", 2021); const voiture3 = new Voiture("Citroën", "C3", 2023); // Beaucoup plus simple et maintenable !

Qu'est-ce qu'un constructeur ?

Un constructeur est une fonction spéciale qui sert de "moule" ou "blueprint" pour créer plusieurs objets avec la même structure.

Analogie de l'usine

Imaginez une usine de voitures :

  • Le constructeur = les plans de fabrication
  • L'instance = une voiture produite
  • Le mot-clé new = le processus de fabrication

Les différentes façons de créer des objets

Méthode Syntaxe Utilisation
Objet littéral const obj = { } Objet unique, simple
Fonction constructeur function Obj() { } Créer plusieurs objets similaires
Classes ES6 class Obj { } Syntaxe moderne (recommandée)
Object.create() Object.create(proto) Héritage prototypal avancé

Les Fonctions Constructeurs

Syntaxe de base

// Convention : nom en PascalCase (première lettre en majuscule) function Personne(nom, prenom, age) { // "this" fait référence au nouvel objet en cours de création this.nom = nom; this.prenom = prenom; this.age = age; // Méthode this.sePresenter = function() { return `Bonjour, je suis ${this.prenom} ${this.nom}, j'ai ${this.age} ans`; }; } // Créer des instances avec le mot-clé "new" const personne1 = new Personne("Dupont", "Marie", 25); const personne2 = new Personne("Martin", "Lucas", 30); console.log(personne1.sePresenter()); // "Bonjour, je suis Marie Dupont, j'ai 25 ans" console.log(personne2.sePresenter()); // "Bonjour, je suis Lucas Martin, j'ai 30 ans"

Que se passe-t-il avec le mot-clé "new" ?

Les 4 étapes de "new"

Quand vous écrivez new Personne("Dupont", "Marie", 25), JavaScript fait automatiquement 4 choses :

  1. Création : Crée un nouvel objet vide {}
  2. Liaison : Lie cet objet au prototype du constructeur
  3. Exécution : Exécute la fonction constructeur avec this pointant vers le nouvel objet
  4. Retour : Retourne automatiquement le nouvel objet

Visualisation du processus "new"

1. new Personne()
Création d'un objet vide
→
2. Liaison prototype
obj.__proto__ = Personne.prototype
→
3. Exécution
this.nom = "Dupont"
this.prenom = "Marie"
→
4. Retour
return obj

Exemple détaillé : Compte bancaire

Constructeur de compte bancaire

// Fonction constructeur pour créer des comptes bancaires function CompteBancaire(titulaire, soldeInitial) { // Propriétés d'instance this.titulaire = titulaire; this.solde = soldeInitial || 0; // Valeur par défaut : 0 this.numeroCompte = Math.floor(Math.random() * 1000000); // Méthode : déposer de l'argent this.deposer = function(montant) { if (montant > 0) { this.solde += montant; console.log(`Dépôt de ${montant}€. Nouveau solde : ${this.solde}€`); } else { console.log(" Le montant doit être positif"); } }; // Méthode : retirer de l'argent this.retirer = function(montant) { if (montant > 0 && montant <= this.solde) { this.solde -= montant; console.log(` Retrait de ${montant}€. Nouveau solde : ${this.solde}€`); } else if (montant > this.solde) { console.log(" Solde insuffisant"); } else { console.log(" Le montant doit être positif"); } }; // Méthode : afficher les informations this.afficher = function() { console.log(`\n Compte n°${this.numeroCompte}`); console.log(` Titulaire : ${this.titulaire}`); console.log(` Solde : ${this.solde}€`); }; } // Création de comptes const compteMarie = new CompteBancaire("Marie Dupont", 1000); const compteLucas = new CompteBancaire("Lucas Martin", 500); // Utilisation compteMarie.deposer(500); // Dépôt de 500€. Nouveau solde : 1500€ compteMarie.retirer(300); // Retrait de 300€. Nouveau solde : 1200€ compteMarie.afficher(); // Affiche les infos compteLucas.deposer(200); // Dépôt de 200€. Nouveau solde : 700€ compteLucas.afficher(); // Affiche les infos

Vérifier le type d'un objet

const compte = new CompteBancaire("Marie", 1000); // Vérifier si un objet est une instance d'un constructeur console.log(compte instanceof CompteBancaire); // true console.log(compte instanceof Object); // true (tous les objets héritent d'Object) // Vérifier le constructeur console.log(compte.constructor === CompteBancaire); // true // Vérifier le type console.log(typeof compte); // "object"

Propriétés statiques vs propriétés d'instance

Propriétés d'instance

Propres à chaque objet créé

function Voiture(marque) { // Propriété d'instance this.marque = marque; } const v1 = new Voiture("Peugeot"); const v2 = new Voiture("Renault"); console.log(v1.marque); // "Peugeot" console.log(v2.marque); // "Renault" // Chaque instance a sa propre valeur

Propriétés statiques

Appartiennent au constructeur lui-même

function Voiture(marque) { this.marque = marque; } // Propriété statique Voiture.nombreVoitures = 0; const v1 = new Voiture("Peugeot"); Voiture.nombreVoitures++; const v2 = new Voiture("Renault"); Voiture.nombreVoitures++; console.log(Voiture.nombreVoitures); // 2 (partagée par tous)

Erreur courante : Oublier "new"

function Personne(nom) { this.nom = nom; } // SANS new : "this" pointe vers window (ou undefined en mode strict) const personne1 = Personne("Marie"); console.log(personne1); // undefined console.log(window.nom); // "Marie" (pollution globale !) // AVEC new : fonctionne correctement const personne2 = new Personne("Lucas"); console.log(personne2); // { nom: "Lucas" } console.log(personne2.nom); // "Lucas"

Le Prototype en JavaScript

Qu'est-ce que le prototype ?

Le prototype est un objet partagé par toutes les instances créées par un constructeur. C'est comme une "bibliothèque commune" de méthodes et propriétés.

Analogie

Imaginez un immeuble :

  • Chaque appartement (instance) a ses propres meubles (propriétés)
  • Mais tous partagent la même salle de gym au sous-sol (prototype)

Problème avec les méthodes dans le constructeur

Inefficace : méthodes dans le constructeur

function Personne(nom, prenom) { this.nom = nom; this.prenom = prenom; // PROBLÈME : cette fonction est recréée pour CHAQUE instance this.sePresenter = function() { return `Je suis ${this.prenom} ${this.nom}`; }; } const p1 = new Personne("Dupont", "Marie"); const p2 = new Personne("Martin", "Lucas"); // Chaque instance a sa PROPRE copie de la méthode console.log(p1.sePresenter === p2.sePresenter); // false // Gaspillage de mémoire si vous créez 1000 personnes !

Efficace : méthodes dans le prototype

function Personne(nom, prenom) { this.nom = nom; this.prenom = prenom; } // Ajouter la méthode au prototype (partagée par toutes les instances) Personne.prototype.sePresenter = function() { return `Je suis ${this.prenom} ${this.nom}`; }; const p1 = new Personne("Dupont", "Marie"); const p2 = new Personne("Martin", "Lucas"); // Les deux instances partagent la MÊME méthode console.log(p1.sePresenter === p2.sePresenter); // true // Économie de mémoire même avec 1000 personnes !

La chaîne de prototypes

Comment JavaScript recherche une propriété

1. personne1
{ nom: "Dupont", prenom: "Marie" }
↓ si propriété non trouvée
2. Personne.prototype
{ sePresenter: function() {...} }
↓ si propriété non trouvée
3. Object.prototype
{ toString: function() {...}, ... }
↓ si propriété non trouvée
4. null
undefined

Constructeur de produits avec prototype

// Constructeur function Produit(nom, prix, quantite) { // Propriétés d'instance (propres à chaque objet) this.nom = nom; this.prix = prix; this.quantite = quantite || 0; } // Méthodes dans le prototype (partagées par tous) Produit.prototype.calculerTotal = function() { return this.prix * this.quantite; }; Produit.prototype.ajouterStock = function(quantite) { this.quantite += quantite; console.log(`${quantite} ${this.nom}(s) ajouté(s). Stock : ${this.quantite}`); }; Produit.prototype.retirerStock = function(quantite) { if (quantite <= this.quantite) { this.quantite -= quantite; console.log(` ${quantite} ${this.nom}(s) retiré(s). Stock : ${this.quantite}`); return true; } else { console.log(` Stock insuffisant. Stock actuel : ${this.quantite}`); return false; } }; Produit.prototype.afficher = function() { console.log(`\n ${this.nom}`); console.log(` Prix : ${this.prix}€`); console.log(` Stock : ${this.quantite}`); console.log(` Valeur totale : ${this.calculerTotal()}€`); }; // Propriété statique (compteur de produits) Produit.nombreProduits = 0; // Modifier le constructeur pour compter les produits const OriginalProduit = Produit; Produit = function(nom, prix, quantite) { OriginalProduit.call(this, nom, prix, quantite); Produit.nombreProduits++; }; Produit.prototype = OriginalProduit.prototype; // Utilisation const ordinateur = new Produit("Ordinateur", 899, 10); const souris = new Produit("Souris", 25, 50); ordinateur.afficher(); ordinateur.ajouterStock(5); ordinateur.retirerStock(3); ordinateur.afficher(); console.log(`\nNombre total de produits créés : ${Produit.nombreProduits}`);

Ajouter/Modifier le prototype dynamiquement

function Animal(nom) { this.nom = nom; } // Créer une instance const chat = new Animal("Minou"); // Ajouter une méthode au prototype APRÈS la création Animal.prototype.parler = function() { console.log(`${this.nom} fait un bruit`); }; // L'instance existante hérite automatiquement de la nouvelle méthode ! chat.parler(); // "Minou fait un bruit" // Créer une nouvelle instance const chien = new Animal("Rex"); chien.parler(); // "Rex fait un bruit"

Vérifier les propriétés

function Personne(nom) { this.nom = nom; } Personne.prototype.espece = "Humain"; const marie = new Personne("Marie"); // Vérifier si une propriété existe (dans l'objet OU le prototype) console.log("nom" in marie); // true (dans l'objet) console.log("espece" in marie); // true (dans le prototype) // Vérifier si une propriété est directement dans l'objet console.log(marie.hasOwnProperty("nom")); // true console.log(marie.hasOwnProperty("espece")); // false (dans le prototype) // Lister les propriétés propres à l'objet console.log(Object.keys(marie)); // ["nom"] // Lister TOUTES les propriétés (y compris le prototype) for (let prop in marie) { console.log(prop); // "nom", "espece" }

Attention : Remplacer le prototype

function Animal(nom) { this.nom = nom; } Animal.prototype.parler = function() { console.log("Bruit générique"); }; const chat = new Animal("Minou"); // Remplacer COMPLÈTEMENT le prototype Animal.prototype = { manger: function() { console.log("Miam"); } }; // L'ancienne instance garde l'ancien prototype chat.parler(); // Fonctionne : "Bruit générique" chat.manger(); // Erreur : chat.manger is not a function // Seules les NOUVELLES instances auront le nouveau prototype const chien = new Animal("Rex"); chien.manger(); // Fonctionne : "Miam" chien.parler(); // Erreur : chien.parler is not a function

🎓 Les Classes ES6 (Syntaxe Moderne)

Introduction aux classes

Les classes ES6 (introduites en 2015) sont une syntaxe plus claire et moderne pour créer des constructeurs d'objets. Sous le capot, elles fonctionnent exactement comme les fonctions constructeurs avec prototypes.

À savoir

Les classes JavaScript ne sont que du "sucre syntaxique" (syntactic sugar) sur les fonctions constructeurs. Elles rendent le code plus lisible mais ne changent pas le fonctionnement interne.

Syntaxe de base

// Définir une classe class Personne { // Le constructeur est appelé automatiquement avec "new" constructor(nom, prenom, age) { this.nom = nom; this.prenom = prenom; this.age = age; } // Méthode (automatiquement ajoutée au prototype) sePresenter() { return `Bonjour, je suis ${this.prenom} ${this.nom}, j'ai ${this.age} ans`; } // Autre méthode vieillir() { this.age++; console.log(`Anniversaire ! J'ai maintenant ${this.age} ans`); } } // Créer des instances (identique aux fonctions constructeurs) const marie = new Personne("Dupont", "Marie", 25); const lucas = new Personne("Martin", "Lucas", 30); console.log(marie.sePresenter()); // "Bonjour, je suis Marie Dupont, j'ai 25 ans" marie.vieillir(); // "Anniversaire ! J'ai maintenant 26 ans"

Comparaison : Fonction constructeur vs Classe

Fonction Constructeur (ancienne syntaxe)

function Voiture(marque, modele) { this.marque = marque; this.modele = modele; } Voiture.prototype.demarrer = function() { console.log("Vroum !"); }; Voiture.prototype.info = function() { return `${this.marque} ${this.modele}`; }; const voiture = new Voiture("Peugeot", "308");

Classe ES6 (syntaxe moderne)

class Voiture { constructor(marque, modele) { this.marque = marque; this.modele = modele; } demarrer() { console.log("Vroum !"); } info() { return `${this.marque} ${this.modele}`; } } const voiture = new Voiture("Peugeot", "308");

Getters et Setters

Les classes permettent de définir facilement des getters et setters pour contrôler l'accès aux propriétés.

class CompteBancaire { constructor(titulaire, soldeInitial) { this.titulaire = titulaire; this._solde = soldeInitial; // Convention : _ pour propriété privée } // Getter : permet de lire une valeur comme une propriété get solde() { return this._solde; } // Setter : permet de modifier une valeur avec validation set solde(montant) { if (montant < 0) { console.log(" Le solde ne peut pas être négatif"); return; } this._solde = montant; } // Getter calculé get soldeFormate() { return `${this._solde.toFixed(2)} €`; } } const compte = new CompteBancaire("Marie", 1000); // Utiliser le getter (pas de parenthèses) console.log(compte.solde); // 1000 console.log(compte.soldeFormate); // "1000.00 €" // Utiliser le setter compte.solde = 1500; // OK console.log(compte.solde); // 1500 compte.solde = -500; // Le solde ne peut pas être négatif console.log(compte.solde); // 1500 (inchangé)

Méthodes statiques

Les méthodes statiques appartiennent à la classe elle-même, pas aux instances.

class Calculatrice { // Méthode statique (appelée sur la classe, pas sur une instance) static additionner(a, b) { return a + b; } static soustraire(a, b) { return a - b; } static multiplier(a, b) { return a * b; } static diviser(a, b) { if (b === 0) { return "Erreur : division par zéro"; } return a / b; } } // Appeler les méthodes statiques directement sur la classe console.log(Calculatrice.additionner(5, 3)); // 8 console.log(Calculatrice.multiplier(4, 7)); // 28 // On ne peut PAS appeler sur une instance const calc = new Calculatrice(); // calc.additionner(5, 3); // Erreur : calc.additionner is not a function

Propriétés statiques

class Voiture { // Propriété statique (ES2022) static nombreVoitures = 0; constructor(marque, modele) { this.marque = marque; this.modele = modele; Voiture.nombreVoitures++; // Incrémenter à chaque création } static afficherTotal() { console.log(`Total de voitures créées : ${Voiture.nombreVoitures}`); } } const v1 = new Voiture("Peugeot", "308"); const v2 = new Voiture("Renault", "Clio"); const v3 = new Voiture("Citroën", "C3"); Voiture.afficherTotal(); // "Total de voitures créées : 3"

Champs privés (ES2022)

JavaScript supporte maintenant de vraies propriétés privées avec le préfixe #.

class CompteBancaire { // Champs privés (préfixe #) #solde; #pin; constructor(titulaire, soldeInitial, pin) { this.titulaire = titulaire; // Public this.#solde = soldeInitial; // Privé this.#pin = pin; // Privé } // Méthode publique pour accéder au solde consulterSolde(pinSaisi) { if (pinSaisi === this.#pin) { return this.#solde; } else { return " Code PIN incorrect"; } } // Méthode privée #verifierPin(pin) { return pin === this.#pin; } retirer(montant, pin) { if (!this.#verifierPin(pin)) { return " Code PIN incorrect"; } if (montant <= this.#solde) { this.#solde -= montant; return ` Retrait de ${montant}€ effectué`; } else { return " Solde insuffisant"; } } } const compte = new CompteBancaire("Marie", 1000, "1234"); console.log(compte.titulaire); // "Marie" (public) // console.log(compte.#solde); // Erreur : champ privé console.log(compte.consulterSolde("1234")); // 1000 (avec bon PIN) console.log(compte.consulterSolde("0000")); // " Code PIN incorrect"

class Produit { // Propriété statique static nombreProduits = 0; static tva = 0.20; // Champ privé #prixHT; constructor(nom, prixHT, stock = 0) { this.nom = nom; this.#prixHT = prixHT; this.stock = stock; this.id = ++Produit.nombreProduits; } // Getter pour le prix HT get prixHT() { return this.#prixHT; } // Setter avec validation set prixHT(prix) { if (prix < 0) { console.log(" Le prix ne peut pas être négatif"); return; } this.#prixHT = prix; } // Getter calculé : prix TTC get prixTTC() { return this.#prixHT * (1 + Produit.tva); } // Getter calculé : valeur du stock get valeurStock() { return this.#prixHT * this.stock; } // Méthode d'instance ajouterStock(quantite) { this.stock += quantite; console.log(` ${quantite} ${this.nom}(s) ajouté(s). Stock : ${this.stock}`); } retirerStock(quantite) { if (quantite <= this.stock) { this.stock -= quantite; console.log(` ${quantite} ${this.nom}(s) retiré(s). L'Héritage en JavaScript

Qu'est-ce que l'héritage ?

L'héritage permet de créer une classe "enfant" qui hérite des propriétés et méthodes d'une classe "parent".

Analogie de l'arbre généalogique

  • Classe parent : Animal (peut manger, dormir)
  • Classe enfant : Chien (hérite de manger/dormir + peut aboyer)

Héritage avec les classes (extends et super)

// Classe parent (ou superclasse) class Animal { constructor(nom, age) { this.nom = nom; this.age = age; } manger() { console.log(`${this.nom} mange`); } dormir() { console.log(`${this.nom} dort`); } sePresenter() { console.log(`Je suis ${this.nom}, j'ai ${this.age} ans`); } } // Classe enfant (ou sous-classe) hérite de Animal class Chien extends Animal { constructor(nom, age, race) { // super() appelle le constructeur du parent super(nom, age); // OBLIGATOIRE avant d'utiliser "this" // Propriété spécifique aux chiens this.race = race; } // Méthode spécifique aux chiens aboyer() { console.log(`${this.nom} aboie : Woof woof !`); } // Surcharge (override) : remplacer une méthode du parent sePresenter() { // Appeler la méthode du parent avec super super.sePresenter(); console.log(`Je suis un chien de race ${this.race}`); } } // Utilisation const rex = new Chien("Rex", 5, "Berger Allemand"); // Méthodes héritées du parent rex.manger(); // "Rex mange" rex.dormir(); // "Rex dort" // Méthode propre au chien rex.aboyer(); // "Rex aboie : Woof woof !" // Méthode surchargée rex.sePresenter(); // "Je suis Rex, j'ai 5 ans" // "Je suis un chien de race Berger Allemand"

Hiérarchie à plusieurs niveaux

// Niveau 1 : Classe de base class Vehicule { constructor(marque, annee) { this.marque = marque; this.annee = annee; } demarrer() { console.log(`Le véhicule ${this.marque} démarre`); } } // Niveau 2 : Hérite de Vehicule class Voiture extends Vehicule { constructor(marque, annee, portes) { super(marque, annee); this.portes = portes; } klaxonner() { console.log("Beep beep !"); } } // Niveau 3 : Hérite de Voiture class VoitureElectrique extends Voiture { constructor(marque, annee, portes, autonomie) { super(marque, annee, portes); this.autonomie = autonomie; } recharger() { console.log(`Recharge de la ${this.marque}. Autonomie : ${this.autonomie} km`); } // Surcharge demarrer() { console.log(`La ${this.marque} électrique démarre silencieusement`); } } const tesla = new VoitureElectrique("Tesla Model 3", 2023, 4, 500); // Méthodes héritées de tous les niveaux tesla.demarrer(); // Méthode surchargée tesla.klaxonner(); // De Voiture tesla.recharger(); // Propre à VoitureElectrique

Vérifier l'héritage

class Animal {} class Chien extends Animal {} const rex = new Chien(); // instanceof vérifie toute la chaîne d'héritage console.log(rex instanceof Chien); // true console.log(rex instanceof Animal); // true console.log(rex instanceof Object); // true (tout hérite d'Object) // Vérifier le prototype console.log(Object.getPrototypeOf(rex) === Chien.prototype); // true console.log(Chien.prototype instanceof Animal); // true

Règles importantes pour l'héritage

  1. Dans le constructeur d'une classe enfant, super() DOIT être appelé AVANT d'utiliser this
  2. Une classe ne peut hériter que d'UNE seule classe parent (pas d'héritage multiple)
  3. Utilisez super.methode() pour appeler une méthode du parent
  4. Les méthodes statiques sont aussi héritées

Comparaisons et Bonnes Pratiques

Objet littéral vs Constructeur vs Classe

Critère Objet littéral Fonction Constructeur Classe ES6
Syntaxe const obj = {} function Obj() {} class Obj {}
Usage Objet unique Plusieurs instances Plusieurs instances
Héritage Difficile Prototype extends/super
Lisibilité Très simple Moyenne Excellente
this Simple Complexe Simple
Compatibilité Tous navigateurs Tous navigateurs ES6+ (2015)

Quand utiliser chaque approche ?

Utilisez un objet littéral quand :

  • Vous avez besoin d'UN SEUL objet
  • L'objet est simple et ne nécessite pas de méthodes complexes
  • Exemple : configuration, constantes
const config = { apiUrl: "https://api.example.com", timeout: 5000, retries: 3 };

Utilisez une classe quand :

  • Vous devez créer PLUSIEURS objets similaires
  • Vous voulez de l'héritage
  • Vous développez en JavaScript moderne (ES6+)
  • Exemple : utilisateurs, produits, animaux
class Utilisateur { constructor(nom, email) { this.nom = nom; this.email = email; } envoyerEmail() { // ... } }

Bonnes pratiques

Conventions de nommage

  • Classes/Constructeurs : PascalCase (première lettre majuscule) → Personne, CompteBancaire
  • Instances : camelCase → personne, monCompte
  • Méthodes : camelCase → sePresenter(), calculerTotal()
  • Propriétés privées : préfixe _ ou # → _solde, #pin

Recommandations générales

  1. Privilégiez les classes ES6 pour les nouveaux projets (syntaxe plus claire)
  2. Mettez les méthodes dans le prototype (ou utilisez les classes qui le font automatiquement)
  3. Utilisez des getters/setters pour contrôler l'accès aux propriétés sensibles
  4. Documentez vos classes avec des commentaires JSDoc
  5. Validez les données dans le constructeur
  6. Ne pas abuser de l'héritage : préférez la composition quand c'est possible

Composition vs Héritage

La composition (avoir des objets à l'intérieur d'autres objets) est souvent préférable à l'héritage profond.

Héritage profond (éviter)

class Animal {} class Mammifere extends Animal {} class Carnivore extends Mammifere {} class Felin extends Carnivore {} class Chat extends Felin {} // Hiérarchie trop profonde, // difficile à maintenir

Composition (préférer)

class Animal { constructor() { this.comportement = new Comportement(); this.alimentation = new Alimentation(); } } class Comportement { courir() {} sauter() {} } class Alimentation { manger(nourriture) {} } // Plus flexible et maintenable
