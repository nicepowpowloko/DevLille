Module 1: Variables et Types de Données

Concepts Clés

Les variables sont des conteneurs qui stockent des données. En JavaScript, on peut déclarer des variables avec var, let, ou const.

1. Déclaration de Variables

var (ancienne méthode, à éviter)

Exemple avec var:
var nom = "Thomas";
var age = 30;
console.log(nom); // Affiche: Thomas
console.log(age); // Affiche: 30

let (moderne, valeur modifiable)

Exemple avec let:
let prenom = "Marie";
prenom = "Sophie"; // On peut modifier
console.log(prenom); // Affiche: Sophie

const (moderne, valeur constante)

Exemple avec const:
const PI = 3.14159;
// PI = 3.14; Erreur! On ne peut pas modifier une constante
console.log(PI); // Affiche: 3.14159

2. Types de Données Primitifs

Type Description Exemple
String Chaîne de caractères (texte) "Bonjour", 'Hello'
Number Nombres (entiers ou décimaux) 42, 3.14, -17
Boolean Valeur vraie ou fausse true, false
Undefined Variable déclarée mais non assignée let x;
Null Absence intentionnelle de valeur let x = null;
Démonstration des types:
// String
let message = "Bienvenue en JavaScript!";
let citation = 'JavaScript est génial';

// Number
let age = 25;
let prix = 19.99;
let temperature = -5;

// Boolean
let estConnecte = true;
let aUnCompte = false;

// Undefined
let nonDefini;
console.log(nonDefini); // undefined

// Null
let vide = null;

3. Vérifier le Type d'une Variable

Utilisation de typeof:
let nom = "Alice";
let age = 30;
let estActif = true;

console.log(typeof nom);      // "string"
console.log(typeof age);      // "number"
console.log(typeof estActif); // "boolean"

Module 2: Opérateurs

Concepts Clés

Les opérateurs permettent d'effectuer des opérations sur les variables et les valeurs. JavaScript propose plusieurs types d'opérateurs.

1. Opérateurs Arithmétiques

Opérateur Description Exemple Résultat
+ Addition 5 + 3 8
- Soustraction 10 - 4 6
* Multiplication 6 * 7 42
/ Division 20 / 4 5
% Modulo (reste) 10 % 3 1
** Puissance 2 ** 3 8
Exemples d'opérations arithmétiques:
let a = 10;
let b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.333...
console.log(a % b);  // 1 (reste de 10 divisé par 3)
console.log(a ** b); // 1000 (10 puissance 3)

2. Opérateurs d'Assignation

Opérateur Équivalent Exemple
= Assignation simple x = 5
+= x = x + y x += 3
-= x = x - y x -= 2
*= x = x * y x *= 4
/= x = x / y x /= 2
Utilisation des opérateurs d'assignation:
let score = 100;

score += 50;  // score = score + 50 → 150
score -= 20;  // score = score - 20 → 130
score *= 2;   // score = score * 2  → 260
score /= 4;   // score = score / 4  → 65

console.log(score); // 65

3. Opérateurs de Comparaison

Opérateur Description Exemple Résultat
== Égalité (valeur) 5 == "5" true
=== Égalité stricte (valeur + type) 5 === "5" false
!= Différent (valeur) 5 != "5" false
!== Différent strict 5 !== "5" true
> Supérieur à 10 > 5 true
< Inférieur à 3 < 8 true
>= Supérieur ou égal 5 >= 5 true
<= Inférieur ou égal 4 <= 3 false
Comparaisons en action:
let age = 18;

console.log(age == 18);   // true
console.log(age == "18"); // true (compare seulement la valeur)
console.log(age === "18");// false (compare valeur ET type)
console.log(age > 15);    // true
console.log(age < 20);    // true
console.log(age >= 18);   // true
Bonne pratique: Utilisez toujours === et !== au lieu de == et != pour éviter les comportements inattendus.

4. Opérateurs Logiques

Opérateur Description Exemple Résultat
&& ET logique (AND) true && false false
|| OU logique (OR) true || false true
! NON logique (NOT) !true false
Opérateurs logiques en pratique:
let age = 25;
let aPermis = true;

// ET (&&) - Les deux conditions doivent être vraies
let peutConduire = (age >= 18) && aPermis;
console.log(peutConduire); // true

// OU (||) - Au moins une condition doit être vraie
let peutEntrer = (age >= 18) || (aPermis === false);
console.log(peutEntrer); // true

// NON (!) - Inverse la valeur
let estMineur = !(age >= 18);
console.log(estMineur); // false

5. Opérateurs d'Incrémentation/Décrémentation

++ et --:
let compteur = 0;

compteur++;  // Incrémente de 1 → compteur = 1
compteur++;  // Incrémente de 1 → compteur = 2
compteur--;  // Décrémente de 1 → compteur = 1

console.log(compteur); // 1

// Différence entre pré et post incrémentation
let x = 5;
let y = x++;  // y = 5, puis x = 6 (post-incrémentation)
let z = ++x;  // x = 7, puis z = 7 (pré-incrémentation)

Module 3: Structures Conditionnelles

Concepts Clés

Les structures conditionnelles permettent d'exécuter du code selon certaines conditions. Elles sont essentielles pour créer une logique de programme.

1. La Structure if

Syntaxe de base:
let age = 20;

if (age >= 18) {
    console.log("Vous êtes majeur");
}

// Si la condition est vraie, le code entre {} s'exécute
// Sinon, il est ignoré

2. if...else

Avec une alternative:
let temperature = 15;

if (temperature > 25) {
    console.log("Il fait chaud ");
} else {
    console.log("Il fait frais ");
}

// Résultat: "Il fait frais "

3. if...else if...else

Conditions multiples:
let note = 15;

if (note >= 16) {
    console.log("Très bien!");
} else if (note >= 14) {
    console.log("Bien");
} else if (note >= 12) {
    console.log("Assez bien");
} else if (note >= 10) {
    console.log("Passable");
} else {
    console.log("Insuffisant");
}

// Résultat: "Bien"

4. Conditions avec Opérateurs Logiques

Combiner plusieurs conditions:
let age = 25;
let aPermis = true;

// ET (&&) - Les deux doivent être vraies
if (age >= 18 && aPermis) {
    console.log("Vous pouvez conduire");
}

// OU (||) - Au moins une doit être vraie
let estWeekend = true;
let estVacances = false;

if (estWeekend || estVacances) {
    console.log("Pas de travail aujourd'hui!");
}

// NON (!) - Inverse la condition
let estConnecte = false;

if (!estConnecte) {
    console.log("Veuillez vous connecter");
}

5. L'Opérateur Ternaire

Condition en une ligne:
// Syntaxe: condition ? valeurSiVrai : valeurSiFaux

let age = 20;
let statut = (age >= 18) ? "majeur" : "mineur";
console.log(statut); // "majeur"

// Équivalent avec if/else:
let statut2;
if (age >= 18) {
    statut2 = "majeur";
} else {
    statut2 = "mineur";
}

6. Switch Statement

Pour tester plusieurs valeurs spécifiques:
let jour = "lundi";

switch (jour) {
    case "lundi":
        console.log("Début de semaine");
        break;
    case "mercredi":
        console.log("Milieu de semaine");
        break;
    case "vendredi":
        console.log("Bientôt le weekend!");
        break;
    case "samedi":
    case "dimanche":
        console.log("Weekend! ");
        break;
    default:
        console.log("Jour normal");
}

// Résultat: "Début de semaine"
Important: N'oubliez pas le break dans les case du switch, sinon le code continuera à s'exécuter dans les cases suivants!

8. Valeurs Truthy et Falsy

En JavaScript, certaines valeurs sont considérées comme "fausses" (falsy) dans un contexte booléen:

  • false
  • 0
  • "" (chaîne vide)
  • null
  • undefined
  • NaN

Toutes les autres valeurs sont "vraies" (truthy).

Utilisation des valeurs truthy/falsy:
let nom = "";

if (nom) {
    console.log("Bonjour " + nom);
} else {
    console.log("Nom non défini"); // Ce code s'exécute
}

let age = 0;

if (age) {
    console.log("Âge: " + age);
} else {
    console.log("Âge invalide"); // Ce code s'exécute
}
Exercices Pratiques
  1. Créez un programme qui vérifie si un nombre est positif, négatif ou nul
  2. Écrivez un système qui donne des réductions selon l'âge (enfant, adulte, senior)
  3. Créez un vérificateur de mot de passe avec plusieurs conditions (longueur, caractères spéciaux, etc.)
  4. Utilisez switch pour créer un menu de restaurant selon le jour
  5. Combinez plusieurs conditions avec && et || pour un système d'accès
Bonne pratique: Utilisez des noms de variables explicites pour vos conditions. if (estMajeur && aPermis) est plus lisible que if (x && y).

Module 4: Boucles (Loops)

Concepts Clés

Les boucles permettent de répéter du code plusieurs fois. Elles sont essentielles pour traiter des collections de données ou répéter des actions.

1. La Boucle for

Syntaxe et utilisation:
// Syntaxe: for (initialisation; condition; incrémentation)

for (let i = 0; i < 5; i++) {
    console.log("Itération numéro: " + i);
}

/* Affiche:
Itération numéro: 0
Itération numéro: 1
Itération numéro: 2
Itération numéro: 3
Itération numéro: 4
*/

// Compter de 1 à 10
for (let i = 1; i <= 10; i++) {
    console.log(i);
}

// Compter à l'envers
for (let i = 10; i >= 0; i--) {
    console.log("Décompte: " + i);
}

2. La Boucle while

Répéter tant qu'une condition est vraie:
let compteur = 0;

while (compteur < 5) {
    console.log("Compteur: " + compteur);
    compteur++;
}

/* Affiche:
Compteur: 0
Compteur: 1
Compteur: 2
Compteur: 3
Compteur: 4
*/

// Exemple pratique
let essais = 0;
let motDePasse = "";

while (motDePasse !== "secret" && essais < 3) {
    console.log("Essai numéro " + (essais + 1));
    essais++;
}

3. La Boucle do...while

Exécuter au moins une fois:
let nombre = 0;

do {
    console.log("Nombre: " + nombre);
    nombre++;
} while (nombre < 3);

/* Affiche:
Nombre: 0
Nombre: 1
Nombre: 2
*/

// Différence avec while: do...while s'exécute AU MOINS UNE FOIS
let x = 10;

do {
    console.log("Ceci s'affiche!"); // S'affiche une fois
} while (x < 5);

while (x < 5) {
    console.log("Ceci ne s'affiche pas"); //  Ne s'affiche jamais
}

4. break et continue

Contrôler le flux des boucles:
// break - Arrête complètement la boucle
for (let i = 0; i < 10; i++) {
    if (i === 5) {
        break; // Sort de la boucle
    }
    console.log(i); // Affiche: 0, 1, 2, 3, 4
}

// continue - Passe à l'itération suivante
for (let i = 0; i < 10; i++) {
    if (i % 2 === 0) {
        continue; // Saute les nombres pairs
    }
    console.log(i); // Affiche: 1, 3, 5, 7, 9
}

// Exemple pratique
for (let i = 1; i <= 20; i++) {
    // Sauter les nombres divisibles par 3
    if (i % 3 === 0) {
        continue;
    }
    // Arrêter à 15
    if (i > 15) {
        break;
    }
    console.log(i);
}

5. Boucles Imbriquées

Une boucle dans une autre boucle:
// Table de multiplication
for (let i = 1; i <= 5; i++) {
    for (let j = 1; j <= 5; j++) {
        console.log(`${i} × ${j} = ${i * j}`);
    }
    console.log("---");
}

// Créer un motif
for (let ligne = 1; ligne <= 5; ligne++) {
    let motif = "";
    for (let etoile = 1; etoile <= ligne; etoile++) {
        motif += "★ ";
    }
    console.log(motif);
}

/* Affiche:
★ 
★ ★ 
★ ★ ★ 
★ ★ ★ ★ 
★ ★ ★ ★ ★ 
*/

6. for...of (Parcourir des Arrays)

Boucle moderne pour les tableaux:
let fruits = ["Pomme", "Banane", "Orange", "Fraise"];

// Parcourir chaque élément
for (let fruit of fruits) {
    console.log("J'aime les " + fruit + "s");
}

/* Affiche:
J'aime les Pommes
J'aime les Bananes
J'aime les Oranges
J'aime les Fraises
*/

// Avec les strings
let mot = "JavaScript";
for (let lettre of mot) {
    console.log(lettre);
}

8. Choisir la Bonne Boucle

Boucle Quand l'utiliser
for Quand vous connaissez le nombre d'itérations
while Quand vous ne connaissez pas le nombre d'itérations à l'avance
do...while Quand vous devez exécuter le code au moins une fois
for...of Pour parcourir des arrays ou des strings
Exercices Pratiques
  1. Créez une boucle qui affiche les nombres de 1 à 100
  2. Affichez uniquement les multiples de 5 entre 1 et 50
  3. Créez une table de multiplication complète (de 1 à 10)
  4. Faites un compte à rebours de 10 à 0
  5. Créez un motif de triangle avec des astérisques (5 lignes)
  6. Trouvez la somme des nombres de 1 à 100 avec une boucle
  7. Parcourez un tableau de prénoms et affichez chacun
Attention aux boucles infinies! Assurez-vous que votre condition de boucle puisse devenir fausse, sinon votre programme se bloquera.
Bonne pratique: Utilisez des noms de variables significatifs comme i pour index, ligne, colonne, etc. Cela rend votre code plus lisible.

Module 5: Fonctions

Concepts Clés

Les fonctions sont des blocs de code réutilisables qui effectuent une tâche spécifique. Elles permettent d'organiser et de structurer votre code.

1. Déclarer une Fonction

Syntaxe de base:
// Déclaration de fonction
function direBonjour() {
    console.log("Bonjour!");
}

// Appel de la fonction
direBonjour(); // Affiche: Bonjour!

// Fonction avec paramètres
function saluer(nom) {
    console.log("Bonjour " + nom + "!");
}

saluer("Thomas"); // Affiche: Bonjour Thomas!
saluer("Marie");  // Affiche: Bonjour Marie!

2. Paramètres et Arguments

Passer des valeurs aux fonctions:
// Fonction avec plusieurs paramètres
function additionner(a, b) {
    let resultat = a + b;
    console.log(resultat);
}

additionner(5, 3);  // Affiche: 8
additionner(10, 20); // Affiche: 30

// Paramètres par défaut (ES6)
function saluerAvecTitre(nom, titre = "M.") {
    console.log(`Bonjour ${titre} ${nom}`);
}

saluerAvecTitre("Dupont");          // Bonjour M. Dupont
saluerAvecTitre("Martin", "Mme");   // Bonjour Mme Martin

3. Return - Retourner des Valeurs

Récupérer le résultat d'une fonction:
function multiplier(a, b) {
    return a * b;
}

let resultat = multiplier(4, 5);
console.log(resultat); // 20

// Utiliser directement le résultat
console.log(multiplier(3, 7)); // 21

// Fonction de calcul complexe
function calculerAire(longueur, largeur) {
    let aire = longueur * largeur;
    return aire;
}

let aireSalon = calculerAire(5, 4);
console.log("L'aire est: " + aireSalon + " m²");
Important: Le code après return ne s'exécute jamais. return termine immédiatement la fonction.

4. Fonctions Expressions

Assigner une fonction à une variable:
// Expression de fonction
const soustraire = function(a, b) {
    return a - b;
};

console.log(soustraire(10, 3)); // 7

// Différence: le hoisting
//  Fonctionne (déclaration de fonction)
direBonjour();
function direBonjour() {
    console.log("Bonjour!");
}

//  Erreur (expression de fonction)
// direAuRevoir(); // Erreur!
const direAuRevoir = function() {
    console.log("Au revoir!");
};

5. Arrow Functions (ES6)

Syntaxe moderne et concise:
// Syntaxe traditionnelle
const addition = function(a, b) {
    return a + b;
};

// Arrow function équivalente
const additionFlecha = (a, b) => {
    return a + b;
};

// Encore plus concis (return implicite)
const additionCourt = (a, b) => a + b;

console.log(additionCourt(5, 3)); // 8

// Un seul paramètre (parenthèses optionnelles)
const double = x => x * 2;
console.log(double(5)); // 10

// Sans paramètre
const direBonjour = () => console.log("Bonjour!");
direBonjour();

6. Scope (Portée) des Variables

Variables locales vs globales:
// Variable globale
let nomGlobal = "Thomas";

function afficherNom() {
    // Variable locale
    let nomLocal = "Marie";
    console.log(nomGlobal); //  Accessible
    console.log(nomLocal);  //  Accessible
}

afficherNom();
console.log(nomGlobal); //  Accessible
// console.log(nomLocal); //  Erreur! n'existe pas ici

// Block scope avec let et const
if (true) {
    let x = 10;
    const y = 20;
    var z = 30;
}

// console.log(x); //  Erreur
// console.log(y); //  Erreur
console.log(z);    //  30 (var n'a pas de block scope!)

Module 6: Tableaux (Arrays)

Concepts Clés

Les tableaux (arrays) sont des structures de données qui permettent de stocker plusieurs valeurs dans une seule variable.

1. Créer des Tableaux

Différentes façons de créer un array:
// Méthode littérale (recommandée)
let fruits = ["Pomme", "Banane", "Orange"];

// Tableau vide
let vide = [];

// Accéder aux éléments
console.log(fruits[0]); // "Pomme"
console.log(fruits.length); // 3

2. Méthodes Essentielles

Méthode Description Exemple
push() Ajoute à la fin arr.push("Nouveau")
pop() Enlève le dernier arr.pop()
map() Transforme chaque élément arr.map(x => x * 2)
filter() Filtre les éléments arr.filter(x => x > 5)
reduce() Réduit à une valeur arr.reduce((a,b) => a+b)
Manipulation complète:
let nombres = [1, 2, 3, 4, 5];

// map - transformer
let doubles = nombres.map(n => n * 2);
// [2, 4, 6, 8, 10]

// filter - filtrer
let pairs = nombres.filter(n => n % 2 === 0);
// [2, 4]

// reduce - réduire
let somme = nombres.reduce((acc, n) => acc + n, 0);
// 15

// find - trouver
let premierGrand = nombres.find(n => n > 3);
// 4

Module 7: Objets

Concepts Clés

Les objets permettent de regrouper des données et des fonctionnalités. Ils utilisent des paires clé-valeur.

1. Créer des Objets

Syntaxe de base:
// Objet littéral
let personne = {
    nom: "Dupont",
    prenom: "Marie",
    age: 30,
    ville: "Paris"
};

// Accéder aux propriétés
console.log(personne.nom);        // "Dupont"
console.log(personne["prenom"]);  // "Marie"

// Modifier
personne.age = 31;

// Ajouter
personne.email = "marie@email.com";

2. Méthodes d'Objet

Fonctions dans les objets:
let voiture = {
    marque: "Toyota",
    modele: "Corolla",
    annee: 2020,
    
    // Méthode
    demarrer: function() {
        console.log("La voiture démarre!");
    },
    
    // Syntaxe ES6
    klaxonner() {
        console.log("Beep beep!");
    },
    
    // Utiliser 'this'
    afficherInfo() {
        console.log(this.marque + " " + this.modele);
    }
};

voiture.demarrer();      // "La voiture démarre!"
voiture.afficherInfo();  // "Toyota Corolla"

3. Parcourir un Objet

Boucles sur les objets:
let etudiant = {
    nom: "Martin",
    age: 22,
    note: 15
};

// for...in
for (let cle in etudiant) {
    console.log(cle + ": " + etudiant[cle]);
}

// Object.keys()
let cles = Object.keys(etudiant);
console.log(cles); // ["nom", "age", "note"]

// Object.values()
let valeurs = Object.values(etudiant);
console.log(valeurs); // ["Martin", 22, 15]

// Object.entries()
let entrees = Object.entries(etudiant);
console.log(entrees);
// [["nom", "Martin"], ["age", 22], ["note", 15]]

4. Destructuration (ES6)

Extraire des propriétés:
let personne = {
    nom: "Dubois",
    age: 28,
    ville: "Lyon"
};

// Destructuration
let {nom, age, ville} = personne;
console.log(nom);   // "Dubois"
console.log(age);   // 28
console.log(ville); // "Lyon"

// Avec renommage
let {nom: nomPersonne, age: agePersonne} = personne;
console.log(nomPersonne); // "Dubois"

Le DOM (Document Object Model) représente la structure HTML d'une page. JavaScript peut modifier le DOM pour créer des pages interactives.

Méthodes de sélection:

Changer texte et HTML:

📚 Concepts Clés

Les événements permettent de réagir aux actions de l'utilisateur (clics, saisie clavier, mouvements de souris, etc.).

Écouter les événements:

});

function gererClic() {
    console.log("Clic géré!");

bouton.addEventListener("click", gererClic);

Événement Description Usage
click Clic de souris Boutons, liens
dblclick Double-clic Actions spéciales
mouseover Souris sur l'élément Tooltips, hover
keydown Touche pressée Saisie clavier
submit Soumission formulaire Validation
change Changement de valeur Inputs, selects

3. L'Objet Event

Informations sur l'événement:
bouton.addEventListener("click", function(event) {
    console.log(event.type);       // "click"
    console.log(event.target);     // L'élément cliqué

    console.log(event.clientY);    // Position Y de la souris
});

// Empêcher le comportement par défaut
lien.addEventListener("click", function(e) {

});

div.addEventListener("click", function(e) {

});

Module 10: JavaScript Asynchrone

📚 Concepts Clés

Le JavaScript asynchrone permet d'exécuter du code sans bloquer le reste du programme. Essentiel pour les appels API, les timers, etc.

1. setTimeout et setInterval

Délais et intervalles:
// setTimeout - Exécute une fois après un délai
setTimeout(function() {
    console.log("Exécuté après 2 secondes");
}, 2000);

// Avec arrow function
setTimeout(() => {
    console.log("Hello!");
}, 1000);

// setInterval - Répète à intervalles réguliers
let compteur = 0;
let interval = setInterval(() => {
    compteur++;
    console.log(compteur);
    
    if (compteur === 5) {
        clearInterval(interval); // Arrête l'intervalle
    }
}, 1000);

// clearTimeout - Annule un setTimeout
let timer = setTimeout(() => console.log("Jamais exécuté"), 5000);
clearTimeout(timer);

2. Callbacks

Fonctions de rappel:
// Callback simple
function faireQuelqueChose(callback) {
    console.log("Début...");
    setTimeout(() => {
        callback();
    }, 1000);
}

faireQuelqueChose(function() {
    console.log("Terminé!");
});

// Callback avec paramètres
function chargerDonnees(url, callback) {
    setTimeout(() => {
        let donnees = {id: 1, nom: "Test"};
        callback(donnees);
    }, 1000);
}

chargerDonnees("api/users", function(data) {
    console.log(data);
});

3. Promises (Promesses)

Gestion moderne de l'asynchrone:
// Créer une Promise
let maPromesse = new Promise((resolve, reject) => {
    let succes = true;
    
    setTimeout(() => {
        if (succes) {
            resolve("Succès!");
        } else {
            reject("Erreur!");
        }
    }, 1000);
});

// Utiliser une Promise
maPromesse
    .then(resultat => {
        console.log(resultat); // "Succès!"
    })
    .catch(erreur => {
        console.error(erreur);
    });

// Chaînage de Promises
fetch("https://api.example.com/data")
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error));

4. Async/Await (ES2017)

Syntaxe moderne et lisible:
// Fonction async
async function chargerDonnees() {
    try {
        let response = await fetch("https://api.example.com/users");
        let data = await response.json();
        console.log(data);
        return data;
    } catch (error) {
        console.error("Erreur:", error);
    }
}

// Appel
chargerDonnees();

// Exemple avec plusieurs appels
async function chargerTout() {
    try {
        let users = await fetch("/api/users").then(r => r.json());
        let posts = await fetch("/api/posts").then(r => r.json());
        
        console.log("Users:", users);
        console.log("Posts:", posts);
    } catch (error) {
        console.error(error);
    }
}

// Promise.all - Attendre plusieurs promises
async function chargerParallele() {
    try {
        let [users, posts] = await Promise.all([
            fetch("/api/users").then(r => r.json()),
            fetch("/api/posts").then(r => r.json())
        ]);
        
        console.log(users, posts);
    } catch (error) {
        console.error(error);
    }
}

Module 12: Gestion des Erreurs

📚 Concepts Clés

La gestion des erreurs permet de gérer les problèmes sans faire planter l'application.

1. Try...Catch

Capturer les erreurs:
// Syntaxe de base
try {
    // Code qui peut causer une erreur
    let resultat = riskyFunction();
    console.log(resultat);
} catch (error) {
    // Gérer l'erreur
    console.error("Une erreur est survenue:", error.message);
} finally {
    // Toujours exécuté
    console.log("Nettoyage...");
}

// Exemple concret
try {
    let data = JSON.parse('{"nom": "Test"}');
    console.log(data.nom);
} catch (error) {
    console.error("JSON invalide:", error);
}

2. Throw - Lancer des Erreurs

Créer ses propres erreurs:
function diviser(a, b) {
    if (b === 0) {
        throw new Error("Division par zéro impossible!");
    }
    return a / b;
}

try {
    let resultat = diviser(10, 0);
    console.log(resultat);
} catch (error) {
    console.error("Erreur:", error.message);
}

// Types d'erreurs
throw new Error("Erreur générique");
throw new TypeError("Mauvais type");
throw new RangeError("Hors limites");
throw new ReferenceError("Variable inexistante");

3. Async Error Handling

Erreurs avec async/await:
async function chargerDonnees() {
    try {
        let response = await fetch("https://api.example.com/data");
        
        if (!response.ok) {
            throw new Error(`HTTP Error: ${response.status}`);
        }
        
        let data = await response.json();
        return data;
        
    } catch (error) {
        console.error("Erreur de chargement:", error.message);
        // Gérer l'erreur (afficher message, réessayer, etc.)
        return null;
    }
}

// Avec Promise
fetch("https://api.example.com/data")
    .then(response => {
        if (!response.ok) throw new Error("Erreur HTTP");
        return response.json();
    })
    .then(data => console.log(data))
    .catch(error => console.error(error));

Module 13: Classes ES6+

Concepts Clés

Les classes ES6+ offrent une syntaxe moderne pour la programmation orientée objet en JavaScript.

1. Créer une Classe

Syntaxe de base:
class Personne {
    // Constructeur
    constructor(nom, age) {
        this.nom = nom;
        this.age = age;
    }
    
    // Méthode
    sePresenter() {
        console.log(`Je suis ${this.nom}, j'ai ${this.age} ans`);

        this.age++;
    }
}

// Créer une instance
let marie = new Personne("Marie", 30);
marie.sePresenter(); // "Je suis Marie, j'ai 30 ans"
marie.vieillir();
console.log(marie.age); // 31

2. Héritage

Étendre une classe:
class Animal {
    constructor(nom) {
        this.nom = nom;
    }
    
    parler() {
        console.log(`${this.nom} fait du bruit`);
    }
}

class Chien extends Animal {
    constructor(nom, race) {
        super(nom); // Appelle le constructeur parent
        this.race = race;
    }
    
    parler() {
        console.log(`${this.nom} aboie: Woof!`);
    }
    
    courir() {
        console.log(`${this.nom} court vite`);
    }
}

let rex = new Chien("Rex", "Labrador");
rex.parler();  // "Rex aboie: Woof!"
rex.courir();  // "Rex court vite"

3. Getters et Setters

Propriétés calculées:
class Rectangle {
    constructor(largeur, hauteur) {
        this.largeur = largeur;
        this.hauteur = hauteur;
    }
    
    // Getter
    get aire() {
        return this.largeur * this.hauteur;
    }
    
    // Setter
    set dimensions({largeur, hauteur}) {
        this.largeur = largeur;
        this.hauteur = hauteur;
    }
    
    // Getter
    get perimetre() {
        return 2 * (this.largeur + this.hauteur);
    }
}

let rect = new Rectangle(10, 5);
console.log(rect.aire);      // 50
console.log(rect.perimetre); // 30

rect.dimensions = {largeur: 20, hauteur: 10};
console.log(rect.aire);      // 200

Module 14: Fonctionnalités ES6+ Avancées

Concepts Clés

ES6+ apporte de nombreuses fonctionnalités modernes qui simplifient le code JavaScript.

1. Destructuration

Arrays et objets:
// Destructuration d'array
let nombres = [1, 2, 3, 4, 5];
let [premier, deuxieme, ...reste] = nombres;
console.log(premier);  // 1
console.log(deuxieme); // 2
console.log(reste);    // [3, 4, 5]

// Destructuration d'objet
let personne = {
    nom: "Dupont",
    age: 30,
    ville: "Paris"
};
let {nom, age, ville} = personne;
console.log(nom);  // "Dupont"

// Avec renommage
let {nom: nomPersonne, age: agePersonne} = personne;

// Valeurs par défaut
let {nom, pays = "France"} = personne;
console.log(pays); // "France"

2. Spread Operator (...)

Étendre des arrays/objets:
// Avec arrays
let arr1 = [1, 2, 3];
let arr2 = [4, 5, 6];
let fusion = [...arr1, ...arr2];
console.log(fusion); // [1, 2, 3, 4, 5, 6]

// Copier un array
let copie = [...arr1];

// Avec objets
let obj1 = {a: 1, b: 2};
let obj2 = {c: 3, d: 4};
let fusionObj = {...obj1, ...obj2};
console.log(fusionObj); // {a: 1, b: 2, c: 3, d: 4}

// Modifier en copiant
let personne = {nom: "Marie", age: 30};
let nouvellePersonne = {...personne, age: 31};

3. Template Literals

Strings avancés:
let nom = "Thomas";
let age = 32;

// Interpolation
let message = `Bonjour, je suis ${nom} et j'ai ${age} ans`;

// Multi-lignes
let texte = `
    Ceci est un texte
    sur plusieurs lignes
    très facilement
`;

// Expressions
let prix = 100;
let total = `Le total avec TVA est: ${prix * 1.2}€`;

// Tagged templates
function tag(strings, ...values) {
    console.log(strings);
    console.log(values);
}
tag`Hello ${nom}, tu as ${age} ans`;

4. Optional Chaining (?.)

Accès sécurisé aux propriétés:
let user = {
    nom: "Marie",
    adresse: {
        ville: "Paris"
    }
};

// Sans optional chaining (risque d'erreur)
// let code = user.adresse.codePostal.numero; // Erreur!

// Avec optional chaining
let code = user.adresse?.codePostal?.numero;
console.log(code); // undefined (pas d'erreur)

// Avec méthodes
let resultat = user.getInfo?.();

// Avec arrays
let premier = users?.[0]?.nom;

5. Nullish Coalescing (??)

Valeur par défaut:
// ?? retourne la valeur de droite si gauche est null/undefined
let nom = null;
let nomDefaut = nom ?? "Anonyme";
console.log(nomDefaut); // "Anonyme"

// Différence avec ||
let count = 0;
let resultat1 = count || 10;  // 10 (car 0 est falsy)
let resultat2 = count ?? 10;  // 0 (car 0 n'est pas null/undefined)

// Chaînage
let valeur = null;
let result = valeur ?? "défaut 1" ?? "défaut 2";
console.log(result); // "défaut 1"

6. Map et Set

Nouvelles structures de données:
// Map - Clés/valeurs
let map = new Map();
map.set("nom", "Marie");
map.set("age", 30);
map.set(1, "un");

console.log(map.get("nom")); // "Marie"
console.log(map.size);       // 3
map.delete("age");
console.log(map.has("age")); // false

// Itération
for (let [cle, valeur] of map) {
    console.log(`${cle}: ${valeur}`);
}

// Set - Valeurs uniques
let set = new Set([1, 2, 3, 3, 4]);
console.log(set); // Set {1, 2, 3, 4}

set.add(5);
set.delete(2);
console.log(set.has(3)); // true

// Convertir en array
let arr = [...set];

Module 15: Modules JavaScript

Concepts Clés

Les modules permettent d'organiser le code en fichiers séparés et réutilisables.

1. Export et Import

Export nommé:
// fichier: math.js
export const PI = 3.14159;

export function addition(a, b) {
    return a + b;
}

export function multiplication(a, b) {
    return a * b;
}

// fichier: main.js
import { PI, addition, multiplication } from './math.js';

console.log(PI);              // 3.14159
console.log(addition(5, 3));  // 8

2. Export Default

Export par défaut:
// fichier: Personne.js
export default class Personne {
    constructor(nom, age) {
        this.nom = nom;
        this.age = age;
    }
    
    sePresenter() {
        return `Je suis ${this.nom}`;
    }
}

// fichier: main.js
import Personne from './Personne.js';

let marie = new Personne("Marie", 30);
console.log(marie.sePresenter());

3. Import/Export Mixte

Combiner les deux:
// fichier: utils.js
export const VERSION = "1.0.0";

export function log(message) {
    console.log(`[LOG] ${message}`);
}

export default class Logger {
    constructor(prefix) {
        this.prefix = prefix;
    }
    
    log(message) {
        console.log(`[${this.prefix}] ${message}`);
    }
}

// fichier: main.js
import Logger, { VERSION, log } from './utils.js';

console.log(VERSION);
log("Hello");

let logger = new Logger("APP");
logger.log("Démarrage");

4. Import tout

Importer un module entier:
// fichier: math.js
export const PI = 3.14159;
export function addition(a, b) { return a + b; }
export function multiplication(a, b) { return a * b; }

// fichier: main.js
import * as Math from './math.js';

console.log(Math.PI);
console.log(Math.addition(5, 3));
console.log(Math.multiplication(4, 2));
