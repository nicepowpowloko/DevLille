Partie A : Commande simple

Objectif : Calculer le prix d'une commande à l'unité (sans formule). Le client choisit la taille de son pop-corn et de sa boisson, et peut ajouter des extras (bonbons, nachos, etc.).

Concepts utilisés : Switch pour les tailles, if/else pour les extras (boolean), addition progressive avec l'opérateur +=

Partie B : Avec formules

Objectif : Gérer les formules (Solo, Duo, Famille) qui ont des prix spéciaux. Le client peut ensuite ajouter des extras à sa formule.

Concepts utilisés : If/else pour vérifier quelle formule est choisie, combinaison avec les extras, switch pour les formules

Partie C : Avec promotion

Objectif : Appliquer automatiquement les promotions selon le montant total de la commande. Si le total dépasse certains seuils, une réduction s'applique.

Concepts utilisés : Conditions imbriquées pour les promotions, calcul de pourcentage, opérateur de comparaison (>)
