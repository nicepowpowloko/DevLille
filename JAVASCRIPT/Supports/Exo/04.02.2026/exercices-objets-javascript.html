Rappels Théoriques

Qu'est-ce qu'un objet en JavaScript ?

Un objet est une structure de données qui permet de stocker plusieurs valeurs sous forme de paires clé-valeur. C'est l'un des types de données les plus importants en JavaScript.

Analogie

Imaginez un objet comme une fiche d'identité :

  • Nom : Dupont
  • Prénom : Marie
  • Âge : 25
  • Ville : Lille

Chaque information (nom, prénom, etc.) est une propriété de l'objet "personne".

Syntaxe de base

// Création d'un objet littéral const personne = { nom: "Dupont", prenom: "Marie", age: 25, ville: "Lille" }; // Accès aux propriétés console.log(personne.nom); // "Dupont" (notation pointée) console.log(personne["prenom"]); // "Marie" (notation entre crochets)

Méthodes d'un objet

Un objet peut contenir des fonctions appelées méthodes.

const personne = { nom: "Dupont", prenom: "Marie", age: 25, // Méthode : fonction dans un objet sePresenter: function() { return `Bonjour, je m'appelle ${this.prenom} ${this.nom}`; }, // Syntaxe moderne (ES6) vieillir() { this.age++; } }; console.log(personne.sePresenter()); // "Bonjour, je m'appelle Marie Dupont" personne.vieillir(); console.log(personne.age); // 26

Le mot-clé "this"

Important !

Dans une méthode d'objet, this fait référence à l'objet lui-même.

Manipulation des objets

const voiture = { marque: "Peugeot", modele: "308" }; // Ajouter une propriété voiture.annee = 2023; voiture["couleur"] = "rouge"; // Modifier une propriété voiture.marque = "Renault"; // Supprimer une propriété delete voiture.modele; // Vérifier l'existence d'une propriété console.log("marque" in voiture); // true console.log(voiture.hasOwnProperty("annee")); // true

Méthodes utiles pour les objets

Méthode Description Exemple
Object.keys() Retourne un tableau des clés Object.keys(personne) → ["nom", "prenom", "age"]
Object.values() Retourne un tableau des valeurs Object.values(personne) → ["Dupont", "Marie", 25]
Object.entries() Retourne un tableau de paires [clé, valeur] Object.entries(personne) → [["nom", "Dupont"], ...]
Object.assign() Copie les propriétés d'un objet vers un autre Object.assign({}, personne)

Parcourir un objet

const personne = { nom: "Dupont", prenom: "Marie", age: 25 }; // Boucle for...in for (let propriete in personne) { console.log(`${propriete}: ${personne[propriete]}`); } // Affiche : // nom: Dupont // prenom: Marie // age: 25 // Avec Object.keys() Object.keys(personne).forEach(cle => { console.log(`${cle}: ${personne[cle]}`); }); // Avec Object.entries() Object.entries(personne).forEach(([cle, valeur]) => { console.log(`${cle}: ${valeur}`); });
