Système de Filtres en JavaScript · Du concept à la pratique

Pourquoi des filtres ?

Les filtres permettent aux utilisateurs de naviguer dans de grandes collections de données (produits, articles, utilisateurs) en affinant les résultats selon leurs critères.

Filtrage côté client

Idéal pour des données statiques ou modérées. Réactif, sans rechargement de page, avec une expérience utilisateur fluide.

Les 3 piliers

1. Collecter les critères · 2. Filtrer les données · 3. Rafraîchir l'affichage

L'algorithme de filtrage expliqué

// LOGIQUE DE FILTRAGE PAS À PAS

// 1. Données sources (notre catalogue)
const produits = [
  { id: 1, nom: "Laptop Pro", categorie: "informatique", prix: 1200, stock: 5, note: 4.5 },
  { id: 2, nom: "Souris sans fil", categorie: "accessoires", prix: 30, stock: 50, note: 4.2 },
  // ...
];

// 2. État des filtres (ce que l'utilisateur a choisi)
const filtresActifs = {
  categorie: "informatique",
  prixMin: 500,
  prixMax: 2000,
  enStock: true,
  noteMin: 4
};

// 3. Fonction de filtrage (le cœur du système)
function filtrerProduits(produits, filtres) {
  return produits.filter(produit => {
    // On teste CHAQUE condition
    const correspondCategorie = !filtres.categorie || produit.categorie === filtres.categorie;
    const correspondPrix = produit.prix >= (filtres.prixMin || 0) && produit.prix <= (filtres.prixMax || Infinity);
    const correspondStock = !filtres.enStock || produit.stock > 0;
    const correspondNote = produit.note >= (filtres.noteMin || 0);

    // Toutes les conditions doivent être vraies (ET logique)
    return correspondCategorie && correspondPrix && correspondStock && correspondNote;
  });
}

// 4. Utilisation
const resultats = filtrerProduits(produits, filtresActifs);
// Résultat : tous les produits qui satisfont TOUS les critères

Principe fondamental : On utilise .filter() pour créer un nouveau tableau avec uniquement les éléments qui passent tous les tests.

Les techniques de filtrage avancées

1

Filter()

Méthode native JS qui crée un nouveau tableau avec les éléments satisfaisant une condition

2

ET/OU logique

Combinaison de conditions : && pour ET, || pour OU dans les fonctions de filtrage

3

Valeurs par défaut

Gérer les filtres vides avec || ou ?? pour ne pas bloquer l'affichage

4

Performance

Pour de grands tableaux, pensez à indexer ou utiliser Web Workers

Filtre simple (une condition)

produits.filter(p => p.categorie === "informatique");

Filtre multiple (ET)

produits.filter(p =>
  p.categorie === "informatique" &&
  p.prix < 1000 &&
  p.stock > 0
);

Filtre avec OR

produits.filter(p =>
  p.categorie === "informatique" ||
  p.categorie === "accessoires"
);

Combinaison complexe

produits.filter(p =>
  (p.categorie === "audio" && p.prix < 200) ||
  (p.note > 4.5 && p.stock > 0)
);

Bonnes pratiques pour des filtres professionnels

1. Immutabilité

Ne modifiez jamais les données originales. Utilisez .filter() qui retourne un nouveau tableau.

2. Debouncing

Pour les filtres en temps réel (input), attendez que l'utilisateur arrête de taper avant de filtrer.

3. URL sync

Synchronisez les filtres avec l'URL pour permettre le partage et le retour en arrière.

4. Feedback visuel

Indiquez toujours combien de résultats sont trouvés et quels filtres sont actifs.

5. Gestion des erreurs

Prévoyez un message "Aucun résultat" et des valeurs par défaut pour les filtres vides.

6. Performance

Pour +5000 items, envisagez la virtualisation ou le filtrage côté serveur.
