C'est quoi SVG Path Editor ?

Un outil en ligne gratuit pour créer et modifier des paths SVG visuellement. Au lieu de taper des coordonnées à la main, tu cliques et fais glisser des points sur un canvas.

// Le problème sans cet outil

Écrire un path SVG à la main c'est difficile :

d="M 150 20 Q 200 60 170 80 Q 140 100 120 90 Q 80 70 90 40 Z"

Tu ne sais pas ce que ça donne sans l'afficher. Modifier un point = recalculer toutes les coordonnées. C'est long et source d'erreurs.

// La solution avec SVG Path Editor

Tu vois ta forme en temps réel pendant que tu la dessines

Tu glisses les points avec la souris au lieu de taper des chiffres

Le code d="..." est généré automatiquement

Tu copies le path et tu le colles dans ton HTML

workflow.md
1

Ouvrir l'outil

Va sur yqnn.github.io/svg-path-editor dans ton navigateur

2

Dessiner ta forme

Clique sur le canvas pour placer des points, ajuste les courbes en tirant les poignées

3

Copier le path

Le champ en haut contient ton d="..." — tu le copies directement

4

Coller dans ton SVG

Dans ton HTML : <path d="TON_PATH" fill="#ff6aaa"/>

L'interface de l'outil

L'outil est divisé en 4 zones principales. Comprendre chaque zone te permet de travailler efficacement.

// Les 4 zones de l'interface

① Barre d'outils
Zoom +/−, Convertir en absolu/relatif, options d'affichage (grille, règles, points de contrôle)
② Champ Path
La valeur d="..." du path — modifiable directement au clavier. Se met à jour en temps réel quand tu bouges les points.
③ Canvas de dessin
Zone principale — clique pour ajouter des points, glisse pour déplacer. Les points violets = absolu, orange = relatif.
④ Liste des commandes
Chaque point du path apparaît ici sous forme de ligne. Clique sur ... pour modifier, supprimer, ou convertir une commande.
Astuce — Coordonnées absolues vs relatives

Couleur violette = coordonnées absolues (position exacte dans le SVG). Couleur orange = coordonnées relatives (position par rapport au point précédent). Les deux donnent le même résultat visuellement — c'est juste une question de lisibilité du code.

Astuce — Grille d'aide

Active la grille avec le bouton Grid dans la barre d'outils pour aligner tes points plus facilement.

Premiers pas — Dessiner une forme

Suis ces étapes sur l'outil ouvert dans un autre onglet pour dessiner ta première forme.

dessiner-triangle.md
1

Effacer le path existant

Dans le champ d="..." en haut, sélectionne tout et supprime. Le canvas devient vide.

2

Placer le premier point (M)

Clique une fois sur le canvas. Un point violet apparaît — c'est le point de départ M (Move to).

3

Tracer des lignes (L)

Clique à d'autres endroits pour tracer des lignes droites. Chaque clic ajoute une commande L (Line to).

4

Fermer la forme (Z)

Dans la liste des commandes, clique sur ... du dernier point → Insert after → choisis Z pour fermer le path.

5

Copier et utiliser

Sélectionne le contenu du champ d="...", copie, et colle dans ton HTML comme valeur du d.

transformer-en-courbe.md

Pour transformer une ligne droite en courbe :

→

Sélectionne un point L dans la liste

Clique sur ... à droite → Convert to → choisis Q (courbe quadratique) ou C (cubique)

→

Ajuster la courbe

Des poignées de contrôle apparaissent sur le canvas — tire-les pour modifier la courbure de la ligne.

Les commandes disponibles

Chaque lettre dans un path correspond à une commande. Voici ce que chacune fait dans l'outil.

commandes-path.md
Cmd Nom Ce que ça fait
M / m M Move to Déplace le stylo sans tracer — point de départ obligatoire
L / l L Line to Trace une ligne droite jusqu'au point
H / h H Horizontal Ligne horizontale — ne prend qu'une coordonnée X
V / v V Vertical Ligne verticale — ne prend qu'une coordonnée Y
Q / q Q Quadratic Courbe avec 1 point de contrôle — courbe douce simple
C / c C Cubic Courbe avec 2 points de contrôle — courbe très précise
S / s S Smooth cubic Courbe cubique qui continue la courbe précédente en douceur
T / t T Smooth quad Courbe quadratique qui continue la courbe précédente
A / a A Arc Arc de cercle ou d'ellipse — pour les arrondis parfaits
Z / z Z Close path Ferme le chemin en revenant au point de départ
Majuscule vs minuscule

L 100 50 = va aux coordonnées absolues (100, 50) dans le SVG. l 100 50 = avance de 100px à droite et 50px en bas par rapport à la position actuelle. Pour débuter, utilise les majuscules — c'est plus intuitif.

Le plus utile au quotidien

Pour 90% des formes tu auras besoin de : M pour commencer, L pour les droites, Q pour les courbes douces, et Z pour fermer. Le reste c'est pour les cas spéciaux.

Raccourcis clavier

L'outil supporte des raccourcis clavier pour aller beaucoup plus vite. Une fois mémorisés, tu n'as plus besoin du menu ....

raccourcis.md

Quand un point est sélectionné sur le canvas :

MInsérer une commande Move après
LInsérer une ligne droite après
QInsérer une courbe quadratique après
CInsérer une courbe cubique après
HInsérer une ligne horizontale après
VInsérer une ligne verticale après
AInsérer un arc après
ZInsérer une fermeture de path après

Pour convertir le point sélectionné (au lieu d'insérer après) :

⇧LConvertir le point en ligne droite
⇧QConvertir en courbe quadratique
⇧CConvertir en courbe cubique
⇧HConvertir en horizontale

Navigation et zoom :

scrollZoom avant / arrière
clicSélectionner / désélectionner un point
dragDéplacer un point ou une poignée
DelSupprimer le point sélectionné

Exercice pratique

Mets en pratique ce que tu as appris ! Voici 3 exercices progressifs à faire directement dans l'outil.

Exercice 1 — La goutte d'eau

  1. Ouvre le Path Editor dans un nouvel onglet
  2. Place un point en haut au centre M 100 10
  3. Trace une courbe vers le bas à gauche avec Q
  4. Trace une courbe vers le bas à droite avec Q
  5. Ferme avec Z
  6. Copie le path et colle dans un <path> avec fill="#00b4d8"

🎯 Exercice 2 — L'étoile

  1. Crée 5 points alternés : un haut, un bas, un haut, un bas, un haut en cercle
  2. Utilise uniquement des commandes L
  3. Ferme avec Z
  4. Essaie de convertir certaines lignes en courbes Q pour arrondir les pointes

Exercice 3 — Cheveux de Sakura

  1. Reprends le path des cheveux de Sakura dans le cursor.js
  2. Colle-le dans le champ d="..." du Path Editor
  3. Observe comment les points et les courbes sont placés
  4. Essaie de modifier la forme en déplaçant un point de contrôle
  5. Copie le nouveau path modifié et remplace dans le cursor.js
