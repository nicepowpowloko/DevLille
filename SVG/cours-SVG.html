C'est quoi le SVG ?

SVG = Scalable Vector Graphics. C'est un format d'image qui se code en HTML. Contrairement aux PNG/JPG, il ne pixelise jamais, quelle que soit la taille.

// Pourquoi SVG ?

Vectoriel : parfait à toutes les tailles (favicon 16px → écran 4K)

Intégré dans le HTML : on peut le styler avec CSS et l'animer avec JS

Léger : juste du texte, pas de kilos d'image

Modifiable : couleurs, tailles, formes — tout en live

// Les 3 attributs essentiels du SVG

viewBox="0 0 200 200" → système de coordonnées interne (x y largeur hauteur). Pense-y comme une "grille" de dessin.

xmlns → obligatoire, indique que c'est du SVG

Path — la forme ultime

<path> permet de dessiner n'importe quelle forme. C'est la plus puissante des formes SVG. Elle utilise des commandes comme un stylo.

// Les commandes Path

M x y → Move to — déplace le stylo sans tracer

L x y → Line to — trace une ligne droite

Q cx cy x y → courbe Quadratique (1 point de contrôle)

C cx1 cy1 cx2 cy2 x y → courbe Cubique (2 points de contrôle)

Z → ferme le chemin (retour au point de départ)

Les lettres majuscules = coordonnées absolues. minuscules = relatives.

Animations CSS

Les éléments SVG se stylent avec CSS comme des éléments HTML. Tu peux les animer avec @keyframes — c'est comme ça qu'on a animé Sakura !

animations.html

// Transform-origin : LE piège

En SVG, transform-origin utilise les coordonnées du viewBox, pas le coin de l'élément. Pour faire tourner un élément autour de son centre, il faut mettre les coordonnées de son centre exact.

Exemple : rectangle à x=120, y=70, width=60, height=60 → centre = transform-origin: 150px 100px
