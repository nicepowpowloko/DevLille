Sessions
PHP

HTTP est sans etat : chaque requete est independante. Les sessions permettent de persister des donnees entre les pages pour un meme visiteur — connexion, panier, preferences.

Fondamentaux

Comment fonctionnent les sessions PHP

PHP stocke les donnees de session cote serveur dans des fichiers temporaires. Un identifiant unique (PHPSESSID) est transmis via un cookie pour reconnaitre le visiteur a chaque requete.

1. Visiteur arrive sur la page, PHP appelle session_start() 2. PHP cree un fichier : /tmp/sess_abc123xyz envoie au navigateur : Set-Cookie: PHPSESSID=abc123xyz 3. Page suivante navigateur envoie : Cookie: PHPSESSID=abc123xyz 4. PHP charge /tmp/sess_abc123xyz → $_SESSION disponible
i
Les donnees vivent cote serveur. Le navigateur ne recoit que l'identifiant (PHPSESSID). Le contenu de $_SESSION n'est jamais envoye au navigateur — l'utilisateur ne peut pas le modifier.

01
Etape 1

Demarrer une session — session_start()

session_start() — regles et verificationPHP
<?php
// REGLE ABSOLUE : session_start() en PREMIER
// Avant tout echo, tout espace, tout HTML
session_start();

// $_SESSION est maintenant disponible
$_SESSION['nom'] = 'Alice';

// Verifier l'etat de la session
if (session_status() === PHP_SESSION_NONE) {
    session_start();
}
// PHP_SESSION_NONE     = pas de session active
// PHP_SESSION_ACTIVE   = session deja demarree
// PHP_SESSION_DISABLED = sessions desactivees
!
"Headers already sent" — l'erreur la plus frequente. Elle survient quand du HTML ou un echo est envoye avant session_start(). Verifier : pas d'espace avant <?php, pas de BOM UTF-8, pas de contenu dans les fichiers inclus avant session_start().

Etape 2

Lire et ecrire dans $_SESSION

$_SESSION — toutes les operationsPHP
<?php
session_start();

// Ecrire
$_SESSION['user_id']   = 42;
$_SESSION['user_nom']  = 'Alice';
$_SESSION['user_role'] = 'admin';
$_SESSION['connecte']  = true;
$_SESSION['panier']    = [];   // les tableaux fonctionnent

// Lire
echo $_SESSION['user_nom'];
$id = $_SESSION['user_id'] ?? null;

// Verifier existence
if (isset($_SESSION['connecte'])) {
    echo 'Connecte : ' . $_SESSION['user_nom'];
}

// Modifier
$_SESSION['user_role'] = 'moderateur';

// Supprimer une cle
unset($_SESSION['cle_temp']);

// Debug
var_dump($_SESSION);

// ID de session courant
echo session_id();   // "a1b2c3..." (32 chars hex)

Systeme de connexion utilisateur

login.php — connexion complete avec sessionComplet
<?php
session_start();

// Si deja connecte, rediriger
if (isset($_SESSION['user_id'])) {
    header('Location: dashboard.php'); exit;
}

$erreur = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $email = trim($_POST['email']    ?? '');
    $mdp   = trim($_POST['password'] ?? '');

    // Chercher l'utilisateur en BDD (PDO)
    $user = trouverUserParEmail($email);

    if ($user && password_verify($mdp, $user['mot_de_passe'])) {
        // Securite : nouvel ID pour eviter la fixation
        session_regenerate_id(true);

        $_SESSION['user_id']    = $user['id'];
        $_SESSION['user_nom']   = $user['nom'];
        $_SESSION['user_role']  = $user['role'];
        $_SESSION['connecte_le'] = time();

        header('Location: dashboard.php'); exit;
    } else {
        $erreur = 'Email ou mot de passe incorrect.';
    }
}
?>

Etape 4

Deconnexion propre — les 3 etapes

logout.php — deconnexion completePHP
<?php
session_start();

// Etape 1 : vider le tableau $_SESSION
$_SESSION = [];

// Etape 2 : supprimer le cookie PHPSESSID
if (ini_get('session.use_cookies')) {
    $p = session_get_cookie_params();
    setcookie(
        session_name(), '', time() - 42000,
        $p['path'], $p['domain'], $p['secure'], $p['httponly']
    );
}

// Etape 3 : detruire le fichier session cote serveur
session_destroy();

header('Location: login.php');
exit;
!
Les 3 etapes sont toutes necessaires. Vider $_SESSION seul laisse le cookie valide. Supprimer le cookie seul laisse le fichier serveur accessible. session_destroy() seul laisse le cookie actif. Il faut les 3.

Etape 5 — Cas d'usage

Panier de commande en session

panier.php — gestion completeComplet
<?php
session_start();

// Initialiser si absent
if (!isset($_SESSION['panier'])) {
    $_SESSION['panier'] = [];
}

function ajouterAuPanier(int $id, int $qte = 1): void {
    if (isset($_SESSION['panier'][$id])) {
        $_SESSION['panier'][$id] += $qte;
    } else {
        $_SESSION['panier'][$id] = $qte;
    }
}

function supprimerDuPanier(int $id): void {
    unset($_SESSION['panier'][$id]);
}

function nbArticles(): int {
    return array_sum($_SESSION['panier'] ?? []);
}

function viderPanier(): void {
    $_SESSION['panier'] = [];
}

// Utilisation
ajouterAuPanier(5, 2);   // produit 5, qte 2
ajouterAuPanier(12);     // produit 12, qte 1
echo nbArticles();        // 3
// $_SESSION['panier'] = [5 => 2, 12 => 1]
OK
Le panier persiste entre toutes les pages tant que la session est active. Chaque page qui utilise le panier doit appeler session_start() en premier. Les donnees sont automatiquement sauvegardees entre les requetes.

Etape 6 — Securite

Securiser les sessions

Configuration securisee + timeout d'inactivitePHP
<?php
// Configurer AVANT session_start()
ini_set('session.cookie_httponly', 1);    // inaccessible en JS
ini_set('session.cookie_secure',   1);    // HTTPS seulement
ini_set('session.cookie_samesite', 'Strict'); // anti-CSRF
ini_set('session.gc_maxlifetime',  3600);  // expire apres 1h

session_start();

// Regenerer l'ID apres connexion (anti-fixation)
session_regenerate_id(true);

// Timeout d'inactivite
$timeout = 1800;   // 30 minutes
if (isset($_SESSION['last_activity']) &&
    (time() - $_SESSION['last_activity']) > $timeout) {
    session_destroy();
    header('Location: login.php?timeout=1'); exit;
}
$_SESSION['last_activity'] = time();
!
Ne jamais stocker de mot de passe en session. La session doit contenir l'ID, le nom, le role — jamais le mot de passe ni les donnees bancaires.
