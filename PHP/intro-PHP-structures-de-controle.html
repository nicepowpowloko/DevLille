Structures
de contrôle

Les structures de contrôle permettent de diriger l'exécution du code : prendre des décisions avec if/else et switch, et répéter des opérations avec les boucles for, while et foreach.

if / else switch / match for while / do-while foreach break / continue
00
Vue d'ensemble

Les deux familles de structures

Sans structures de contrôle, PHP exécute le code de haut en bas, ligne par ligne, sans jamais s'arrêter ni répéter. Les structures de contrôle permettent deux choses fondamentales : choisir quel code exécuter selon une condition, et répéter du code un certain nombre de fois.

FamilleStructuresUsage
Conditionsif, elseif, else, switch, matchExécuter du code selon une condition
Bouclesfor, while, do-while, foreachRépéter du code un certain nombre de fois
Contrôle de bouclebreak, continue, returnInterrompre ou sauter des itérations
01
Étape 1 — Conditions

if / elseif / else — prendre des décisions

Structure if complète — toutes les variantesPHP
<?php
$age = 17;

// if seul
if ($age >= 18) {
    echo "Majeur";
}

// if + else
if ($age >= 18) {
    echo "Majeur";
} else {
    echo "Mineur";
}

// if + elseif + else (plusieurs branches)
if ($age < 13) {
    echo "Enfant";
} elseif ($age < 18) {
    echo "Adolescent";
} elseif ($age < 65) {
    echo "Adulte";
} else {
    echo "Senior";
}

// Conditions multiples avec && et ||
$note = 14;
if ($note >= 10 && $note < 20) {
    echo "Admis";
}

// Syntaxe alternative (dans les templates HTML)
<?php if ($age >= 18): ?>
    <p>Contenu pour les majeurs</p>
<?php else: ?>
    <p>Contenu pour les mineurs</p>
<?php endif; ?>
!
La syntaxe alternative (if(): ... endif;) est plus lisible quand on mélange PHP et HTML dans les vues. Elle évite de perdre le fil des accolades dans du HTML dense. Choisissez-la systématiquement dans vos templates.

Étape 2 — Choix multiples

switch et match — comparer une valeur à plusieurs cas

switch — comparaison souplePHP
<?php
$jour = "lundi";

switch ($jour) {
    case "lundi":
    case "mardi":
    case "mercredi":
    case "jeudi":
    case "vendredi":
        echo "Jour de semaine";
        break;   // OBLIGATOIRE pour arrêter ici

    case "samedi":
    case "dimanche":
        echo "Week-end";
        break;

    default:            // aucun case ne correspond
        echo "Jour inconnu";
}
// switch utilise == (comparaison lâche)
match — comparaison stricte (PHP 8+)PHP 8
<?php
$statut = 2;

// match retourne une valeur, utilise === (strict)
$label = match($statut) {
    1       => "En attente",
    2, 3   => "En cours",     // plusieurs valeurs possibles
    4       => "Terminé",
    0       => "Annulé",
    default => "Inconnu",
};
echo $label;  // "En cours"

// Différences switch vs match :
// match utilise === (strict), switch utilise == (lâche)
// match retourne une valeur, switch exécute des instructions
// match lève une erreur si aucun cas ne correspond (sans default)
// match n'a pas besoin de break
Critèreswitchmatch (PHP 8+)

Étape 3 — Boucles

Boucle for — quand on connaît le nombre d'itérations

La boucle for s'utilise quand on connaît à l'avance le nombre de répétitions. Elle est composée de trois parties : initialisation, condition, incrément.

Boucle for — anatomie et exemplesBoucle
<?php
//    init   condition    incrément
for ($i=0; $i < 5;  $i++) {
    echo $i . " ";
}
// Affiche : 0 1 2 3 4

// Compter à rebours
for ($i = 5; $i > 0; $i--) {
    echo $i . " ";
}
// Affiche : 5 4 3 2 1

// Incrément par pas de 2
for ($i = 0; $i <= 10; $i += 2) {
    echo $i . " ";
}
// Affiche : 0 2 4 6 8 10

// Générer un tableau HTML
echo "<ul>";
for ($i = 1; $i <= 5; $i++) {
    echo "<li>Élément " . $i . "</li>";
}
echo "</ul>";
Exécution étape par étape
for ($i=0; $i < 5; $i++)

Tour 1 : init: $i=0 → condition: 0<5 = true → echo 0 → incrément: $i=1
Tour 2 : condition: 1<5 = true → echo 1 → $i=2
Tour 3 : condition: 2<5 = true → echo 2 → $i=3
Tour 4 : condition: 3<5 = true → echo 3 → $i=4
Tour 5 : condition: 4<5 = true → echo 4 → $i=5
Stop : condition: 5<5 = false → la boucle s'arrête
04
Étape 4 — Boucles conditionnelles

while et do-while — répéter tant que

while s'utilise quand on ne connaît pas le nombre de répétitions à l'avance. On répète tant qu'une condition est vraie. do-while garantit au moins une exécution.

while et do-whileBoucle
<?php

// while : condition vérifiée AVANT chaque tour
$compteur = 1;
while ($compteur <= 5) {
    echo $compteur . " ";
    $compteur++;
}
// Affiche : 1 2 3 4 5

// Exemple réel : lire des lignes d'un fichier
$fichier = fopen("data.txt", "r");
while (($ligne = fgets($fichier)) !== false) {
    echo $ligne;
}
fclose($fichier);

// do-while : condition vérifiée APRÈS chaque tour
// Garantit au moins 1 exécution
$n = 10;
do {
    echo $n;      // s'exécute même si $n = 10 > 5
    $n++;
} while ($n < 5);
// Affiche : 10 (une seule fois — puis la condition est false)

// Cas d'usage do-while : demander une saisie valide
do {
    $saisie = readline("Entrez un nombre positif : ");
} while (!is_numeric($saisie) || $saisie <= 0);
!
Boucle infinie — le danger du while. Si la condition de while reste toujours vraie, le script tourne indéfiniment et provoque un timeout. Toujours vérifier que la variable testée est bien modifiée à l'intérieur de la boucle.

Étape 5 — Parcourir des tableaux

foreach — la boucle des tableaux

foreach est conçu spécifiquement pour parcourir des tableaux. Il est plus simple que for car pas besoin de gérer l'index manuellement. C'est la boucle la plus utilisée en PHP sur des données.

foreach — toutes les formesBoucle
<?php

// Tableau indexé — accès à la valeur seule
$fruits = ["pomme", "banane", "cerise"];

foreach ($fruits as $fruit) {
    echo $fruit . "<br>";
}

// Tableau indexé — accès à l'index ET la valeur
foreach ($fruits as $index => $fruit) {
    echo $index . " : " . $fruit . "<br>";
}
// Affiche : 0 : pomme / 1 : banane / 2 : cerise

// Tableau associatif — clé => valeur
$utilisateur = [
    "nom"    => "Dupont",
    "prenom" => "Alice",
    "age"    => 25,
];

foreach ($utilisateur as $cle => $valeur) {
    echo $cle . " : " . $valeur . "<br>";
}

// Tableau de tableaux — données BDD typiques
$produits = [
    ["nom" => "T-shirt", "prix" => 19.99],
    ["nom" => "Jean",    "prix" => 49.99],
    ["nom" => "Veste",   "prix" => 89.99],
];

echo "<table>";
foreach ($produits as $produit) {
    echo "<tr><td>" . $produit['nom'] . "</td>";
    echo "<td>" . $produit['prix'] . " €</td></tr>";
}
echo "</table>";
i
foreach travaille sur une copie. Par défaut, foreach copie le tableau — les modifications de $valeur n'affectent pas le tableau original. Pour modifier le tableau en place, utiliser une référence : foreach ($tab as &$val). Ne pas oublier unset($val) après la boucle pour éviter les effets de bord.

Étape 6 — Contrôle fin

break et continue — interrompre ou sauter

break et continuePHP
<?php

// break — sortir complètement de la boucle
for ($i = 0; $i < 10; $i++) {
    if ($i === 5) {
        break;      // sort de la boucle quand i = 5
    }
    echo $i . " ";
}
// Affiche : 0 1 2 3 4

// continue — passer à l'itération suivante
for ($i = 0; $i < 10; $i++) {
    if ($i % 2 === 0) {
        continue;   // saute les nombres pairs
    }
    echo $i . " ";
}
// Affiche : 1 3 5 7 9

// Cas réel : chercher un élément dans un tableau
$emails = ["a@ex.fr", "b@ex.fr", "c@ex.fr"];
$cible  = "b@ex.fr";
$trouve = false;

foreach ($emails as $email) {
    if ($email === $cible) {
        $trouve = true;
        break;  // inutile de continuer après avoir trouvé
    }
}
echo $trouve ? "Trouvé" : "Absent";
