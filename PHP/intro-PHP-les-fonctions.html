Les fonctions
en PHP

Une fonction est un bloc de code réutilisable avec un nom. On la définit une fois, on l'appelle autant de fois qu'on veut. Les fonctions sont le premier outil de lutte contre la duplication de code.

Déclaration Paramètres return Portée Closures
00
Concept fondamental

Pourquoi créer des fonctions — DRY

Le principe DRY (Don't Repeat Yourself) est la règle d'or du développement. Si vous écrivez le même code à deux endroits, créez une fonction. Les fonctions permettent aussi de nommer une intention : calculerTTC($prix) est plus lisible que les 3 lignes de calcul inline.

AVANT — code dupliqué : // Page 1 $prix_ttc = $prix * 1.20; $prix_ttc = round($prix_ttc, 2); // Page 2 — copié-collé $total_ttc = $total * 1.20; $total_ttc = round($total_ttc, 2); APRÈS — fonction : function calculerTTC($prix_ht) { return round($prix_ht * 1.20, 2); } calculerTTC($prix); // Page 1 calculerTTC($total); // Page 2

Étape 1 — Définition

Déclarer et appeler une fonction

Anatomie d'une fonction PHPPHP
<?php
//    mot-clé  nom          paramètre
function direBonjour($prenom) {
    echo "Bonjour, " . $prenom . " !";
}
//                   argument
direBonjour("Alice");   // Bonjour, Alice !
direBonjour("Bob");     // Bonjour, Bob !

// Fonction sans paramètre
function afficherDate() {
    echo date("d/m/Y");
}
afficherDate();   // 15/12/2024

// Les fonctions peuvent être déclarées APRÈS leur appel
// (hoisting en PHP — contrairement aux fonctions anonymes)
maSuperFonction();

function maSuperFonction() {
    echo "Ca fonctionne meme declarée après !";
}
i
Convention de nommage. En PHP, les fonctions utilisent le camelCase : calculerPrixTTC(), envoyerEmail(). Le nom doit décrire ce que fait la fonction — idéalement un verbe + complément. Évitez fonction1() ou traiter() qui ne décrivent rien.

Étape 2 — Données en entrée et en sortie

Paramètres et valeur de retour — return

return — renvoyer une valeurPHP
<?php

// Fonction qui retourne une valeur
function additionner($a, $b) {
    return $a + $b;   // arrête la fonction ET renvoie la valeur
}

$resultat = additionner(5, 3);
echo $resultat;   // 8

// On peut utiliser le retour directement
echo additionner(10, 20);         // 30
echo additionner(5, 3) * 2;        // 16

// return arrête l'exécution de la fonction
function verifierAge($age) {
    if ($age < 0) {
        return false;   // sort immédiatement
    }
    if ($age >= 18) {
        return "majeur";
    }
    return "mineur";
}

echo verifierAge(25);    // majeur
echo verifierAge(16);    // mineur
echo verifierAge(-5);    // (rien — retourne false)

// Fonction sans return — retourne null implicitement
function logMessage($msg) {
    echo "[LOG] " . $msg;
    // pas de return → retourne null
}
!
echo vs return — ne pas confondre. echo envoie directement au navigateur et ne peut pas être récupéré. return renvoie la valeur à l'appelant qui peut la stocker, la transformer, la comparer. Préférez return : ça rend les fonctions plus testables et réutilisables.

Étape 3 — Paramètres avancés

Valeurs par défaut, types, passage par référence

Valeurs par défaut et type hintsPHP 7+
<?php

// Paramètre avec valeur par défaut
function saluer($prenom, $formule = "Bonjour") {
    echo $formule . " " . $prenom;
}
saluer("Alice");              // Bonjour Alice
saluer("Alice", "Bonsoir");   // Bonsoir Alice

// Type hints (déclaration du type attendu — PHP 7+)
function calculerTTC(float $prix_ht, float $taux = 0.20): float {
    //            type param1       type param2     type retour
    return round($prix_ht * (1 + $taux), 2);
}

echo calculerTTC(100);          // 120.0
echo calculerTTC(100, 0.055);  // 105.5 (TVA 5.5%)
// calculerTTC("bonjour") → TypeError en mode strict

// Types disponibles pour les hints
// int, float, string, bool, array, object, null, mixed, void

// Type de retour void — ne retourne rien
function afficher(string $msg): void {
    echo $msg;
    // return; ou rien
}

// Passage par référence — modifie la variable d'origine
function doubler(&$valeur) {   // & = référence
    $valeur *= 2;
}
$n = 5;
doubler($n);
echo $n;   // 10 — $n a été modifié !

// Nombre variable de paramètres
function somme(...$nombres) {   // ... = variadic
    return array_sum($nombres);
}
echo somme(1, 2, 3, 4, 5);   // 15
+
Utilisez les type hints systématiquement. Ils documentent les paramètres attendus, permettent à votre IDE de vous aider, et font remonter les erreurs de type tôt. En ajoutant declare(strict_types=1); en début de fichier, les erreurs de type deviennent des exceptions plutôt que des conversions silencieuses.

Étape 4 — Scope

Portée des variables — local vs global

En PHP, les variables définies dans une fonction sont locales : elles n'existent que pendant l'exécution de la fonction. Les variables définies hors des fonctions sont globales : elles ne sont pas automatiquement accessibles dans les fonctions — il faut les demander explicitement.

Portée globale (hors fonction)
$config = "prod"
$nom = "Alice"
$total = 0

Variables accessibles partout dans le fichier, mais PAS dans les fonctions sans global.

Portée locale (dans la fonction)
$resultat = 42
$temp = []
$config via global $config

Variables créées dans la fonction. Détruites à la fin de la fonction.

Portée et mot-clé globalPHP
<?php
$compteur = 0;   // variable globale

function incrementer() {
    // $compteur n'est PAS accessible ici directement
    echo $compteur;  // Warning : variable non définie
}

function incrementerCorrect() {
    global $compteur;   // demander l'accès à la variable globale
    $compteur++;
}

incrementerCorrect();
incrementerCorrect();
echo $compteur;   // 2

// static — conserver la valeur entre les appels
function compter() {
    static $n = 0;  // initialisé une seule fois
    $n++;
    echo $n . " ";
}
compter();   // 1
compter();   // 2
compter();   // 3
!
Évitez global au maximum. global crée un couplage fort entre la fonction et l'état global. Passez plutôt la valeur en paramètre et retournez le résultat. C'est plus propre, plus testable, sans effets de bord. static est acceptable dans des cas précis (compteurs, caches légers).

Étape 5 — Fonctions modernes

Fonctions anonymes et fléchées

Closures et fonctions fléchéesPHP 7.4+
<?php

// Fonction anonyme (closure) — assignée à une variable
$multiplier = function($a, $b) {
    return $a * $b;
};
echo $multiplier(4, 5);   // 20

// Closure avec accès à une variable extérieure via use
$taux = 0.20;
$calculerTTC = function($prix) use ($taux) {
    return $prix * (1 + $taux);
};
echo $calculerTTC(100);   // 120

// Passage d'une fonction en argument (callback)
$nombres = [3, 1, 4, 1, 5, 9];
usort($nombres, function($a, $b) {
    return $a - $b;   // tri croissant
});

// Fonction fléchée — PHP 7.4+ (accès auto aux variables du scope parent)
$taux   = 0.20;
$calcul = fn($prix) => $prix * (1 + $taux);
// pas besoin de use — $taux est capturé automatiquement
echo $calcul(100);   // 120

// Utilisation typique avec array_map / array_filter
$prix = [10, 20, 30, 50];

$prix_ttc  = array_map(fn($p) => $p * 1.20, $prix);
$chers     = array_filter($prix, fn($p) => $p > 20);

Étape 6 — La bibliothèque PHP

Fonctions PHP natives — les incontournables

PHP embarque des milliers de fonctions natives. Voici les plus utilisées pour les chaînes, les nombres et les dates. PHP.net est la référence complète.

Fonctions sur les chaînesstring
<?php
$s = "  Bonjour le monde  ";

strlen($s)                    // longueur en octets : 20
mb_strlen($s)                 // longueur Unicode (accents) : 20
trim($s)                      // "Bonjour le monde" (espaces retirés)
strtolower($s)                // "  bonjour le monde  "
strtoupper($s)                // "  BONJOUR LE MONDE  "
ucfirst("bonjour")            // "Bonjour"
str_replace("monde", "PHP", $s) // "  Bonjour le PHP  "
strpos($s, "monde")            // 14 (position) ou false
substr($s, 2, 7)               // "Bonjour" (depuis pos 2, 7 chars)
explode(" ", trim($s))         // ["Bonjour", "le", "monde"]
implode(", ", ["a","b","c"])  // "a, b, c"
str_contains($s, "monde")     // true (PHP 8+)
str_starts_with($s, "  Bo")  // true (PHP 8+)
htmlspecialchars("<b>ok</b>") // "&lt;b&gt;ok" (sécurité XSS)
strip_tags("<b>ok</b>")      // "ok" (retire les balises)
sprintf("%.2f €", 12.3)       // "12.30 €"
Fonctions mathématiques et datesmath / date
<?php
// Maths
abs(-42)             // 42
round(3.567, 2)      // 3.57 (arrondi à 2 décimales)
floor(3.9)           // 3   (arrondi vers le bas)
ceil(3.1)            // 4   (arrondi vers le haut)
min(5, 3, 8)         // 3
max(5, 3, 8)         // 8
rand(1, 100)         // entier aléatoire entre 1 et 100
pow(2, 10)           // 1024
sqrt(16)             // 4

// Dates
date("d/m/Y")                    // "15/12/2024"
date("H:i:s")                    // "14:35:22"
date("Y-m-d H:i:s")              // "2024-12-15 14:35:22"
time()                           // timestamp Unix (secondes)
mktime(0,0,0, 12, 25, 2024)    // timestamp pour le 25/12/2024
strtotime("next monday")         // timestamp du prochain lundi
strtotime("+30 days")           // timestamp dans 30 jours
OK
Réflexe PHP.net : avant d'écrire une fonction soi-même, chercher si PHP en a déjà une. PHP a des centaines de fonctions natives pour les chaînes, tableaux, dates, fichiers, maths, regex. La documentation sur php.net est complète et inclut des exemples pour chaque fonction.
