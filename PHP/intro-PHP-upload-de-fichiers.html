PHP permet de recevoir des fichiers envoyes par un formulaire via la superglobale $_FILES. Ce support couvre la reception, la validation du type et de la taille, le deplacement securise, et les bonnes pratiques de securite.

00
Fondamentaux

$_FILES — la superglobale des fichiers

Quand un formulaire envoie un fichier, PHP le place dans un repertoire temporaire du serveur et remplit la superglobale $_FILES avec toutes les informations sur ce fichier.

Cle $_FILESContenuExemple
['name']Nom original du fichier (cote client)"photo.jpg"
['type']Type MIME declare par le navigateur"image/jpeg"
['size']Taille en octets204800 (200 Ko)
['tmp_name']Chemin du fichier temporaire sur le serveur"/tmp/phpXYZ123"
['error']Code d'erreur (0 = pas d'erreur)0
!
Ne jamais faire confiance a $_FILES['type']. Le type MIME dans $_FILES est envoye par le navigateur — il peut etre falsifie. Toujours verifier le type reel du fichier cote serveur avec finfo_file() ou mime_content_type().
01
Etape 1

Formulaire HTML pour l'upload

Formulaire upload — attributs obligatoiresHTML
<!-- IMPORTANT : enctype="multipart/form-data" est OBLIGATOIRE -->
<form method="post" action="upload.php"
      enctype="multipart/form-data">

  <!-- Champ fichier simple -->
  <input type="file" name="photo">

  <!-- Filtrer les types acceptes (cote client seulement) -->
  <input type="file" name="photo"
         accept="image/jpeg,image/png,image/webp">

  <!-- Plusieurs fichiers en meme temps -->
  <input type="file" name="documents[]" multiple>

  <button type="submit">Envoyer</button>
</form>
!
enctype="multipart/form-data" est obligatoire. Sans cet attribut, le fichier n'est pas envoye au serveur — seul le nom du fichier est transmis comme chaine de texte. C'est l'erreur la plus courante lors d'un premier upload.

Etape 2

Lire $_FILES — structure et codes d'erreur

Lire $_FILES et interpreter les erreursPHP
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {

    // Acceder au fichier (name="photo" dans le formulaire)
    $fichier = $_FILES["photo"];

    // Les 5 cles disponibles
    echo $fichier["name"];      // "photo.jpg"
    echo $fichier["type"];      // "image/jpeg" (non fiable !)
    echo $fichier["size"];      // 204800 (octets)
    echo $fichier["tmp_name"];  // "/tmp/phpABC123"
    echo $fichier["error"];     // 0 = OK

    // Verifier le code d'erreur en premier
    switch ($fichier["error"]) {
        case UPLOAD_ERR_OK:
            // 0 : aucune erreur, traiter le fichier
            break;
        case UPLOAD_ERR_INI_SIZE:   // 1 : depasse upload_max_filesize (php.ini)
        case UPLOAD_ERR_FORM_SIZE:  // 2 : depasse MAX_FILE_SIZE du formulaire
            echo "Fichier trop volumineux.";
            break;
        case UPLOAD_ERR_NO_FILE:    // 4 : aucun fichier envoye
            echo "Aucun fichier selectionne.";
            break;
        default:
            echo "Erreur upload : code " . $fichier["error"];
    }
}

Etape 3 — Securite

Valider le fichier — type, taille, extension

La validation d'un upload necessite plusieurs controles independants. Un seul ne suffit pas — ils se completent mutuellement.

Validation complete d'un fichier uploadeSecurite
<?php
function validerFichier(array $fichier): array {
    $erreurs = [];

    // 1. Verifier qu'un fichier a bien ete envoye
    if ($fichier["error"] !== UPLOAD_ERR_OK) {
        $erreurs[] = "Erreur lors de l'envoi (code " . $fichier["error"] . ").";
        return $erreurs;  // inutile de continuer
    }

    // 2. Verifier la taille (max 2 Mo)
    $tailleMax = 2 * 1024 * 1024;  // 2 Mo en octets
    if ($fichier["size"] > $tailleMax) {
        $erreurs[] = "Fichier trop volumineux (max 2 Mo).";
    }

    // 3. Verifier le type MIME REEL (pas celui du navigateur)
    $finfo = finfo_open(FILEINFO_MIME_TYPE);
    $typeMime = finfo_file($finfo, $fichier["tmp_name"]);
    finfo_close($finfo);

    $typesAutorises = ["image/jpeg", "image/png", "image/webp"];
    if (!in_array($typeMime, $typesAutorises)) {
        $erreurs[] = "Type de fichier non autorise : " . $typeMime;
    }

    // 4. Verifier l'extension du nom original
    $ext = strtolower(pathinfo($fichier["name"], PATHINFO_EXTENSION));
    $extsAutorisees = ["jpg", "jpeg", "png", "webp"];
    if (!in_array($ext, $extsAutorisees)) {
        $erreurs[] = "Extension non autorisee.";
    }

    return $erreurs;
}
VerificationPourquoiFonction PHP
Code erreurS'assurer que le fichier est arrive correctement$_FILES["error"] === UPLOAD_ERR_OK
TailleEviter de saturer le serveur$_FILES["size"]
Type MIME reelUn PNG peut etre renomme en .phpfinfo_file()
ExtensionDouble verification complementairepathinfo(..., PATHINFO_EXTENSION)

Etape 4

Deplacer le fichier — move_uploaded_file()

Apres validation, le fichier est dans un repertoire temporaire. Il faut le deplacer vers son emplacement definitif avec move_uploaded_file(). Cette fonction verifie que le fichier provient bien d'un upload PHP (securite).

move_uploaded_file() — deplacement securisePHP
<?php
$fichier = $_FILES["photo"];

// Dossier de destination
$dossier = __DIR__ . "/uploads/";

// Creer le dossier s'il n'existe pas
if (!is_dir($dossier)) {
    mkdir($dossier, 0755, true);
}

// Generer un nom unique pour eviter les collisions
$ext      = strtolower(pathinfo($fichier["name"], PATHINFO_EXTENSION));
$nomUnique = uniqid("img_", true) . "." . $ext;
// Resultat : "img_65abc123.456789.jpg"

// Chemin complet de destination
$destination = $dossier . $nomUnique;

// Deplacer le fichier temporaire vers sa destination
if (move_uploaded_file($fichier["tmp_name"], $destination)) {
    echo "Fichier enregistre : " . $nomUnique;
} else {
    echo "Erreur lors du deplacement du fichier.";
    // Causes : permissions insuffisantes, dossier inexistant
}
!
Toujours generer un nom de fichier aleatoire. Ne jamais utiliser le nom original fourni par l'utilisateur ($_FILES["name"]) comme nom de destination. Il peut contenir des caracteres dangereux, des slashes, ou ecraser un fichier existant. uniqid() garantit un nom unique.
!
Mettre le dossier uploads hors de la racine web OU bloquer l'execution PHP. Si un attaquant uploade un fichier PHP et que le dossier est accessible via URL, il peut l'executer. Solutions : placer uploads/ hors du document root, ou ajouter un .htaccess avec php_flag engine off dans le dossier.

Etape 5 — Complet

Script d'upload complet

upload.php — script complet et securiseComplet
<?php
$erreurs = [];
$succes  = false;
$nomFichier = "";

if ($_SERVER["REQUEST_METHOD"] === "POST" && isset($_FILES["photo"])) {

    $f        = $_FILES["photo"];
    $dossier  = __DIR__ . "/uploads/";
    $tailleMax = 2 * 1024 * 1024;

    // Verification code erreur
    if ($f["error"] !== UPLOAD_ERR_OK) {
        $erreurs[] = "Erreur upload (code " . $f["error"] . ").";
    } else {

        // Taille
        if ($f["size"] > $tailleMax)
            $erreurs[] = "Fichier trop volumineux (max 2 Mo).";

        // Type MIME reel
        $finfo   = finfo_open(FILEINFO_MIME_TYPE);
        $mime    = finfo_file($finfo, $f["tmp_name"]);
        finfo_close($finfo);
        $mimesOk = ["image/jpeg", "image/png", "image/webp"];
        if (!in_array($mime, $mimesOk))
            $erreurs[] = "Type non autorise : " . $mime;

        // Extension
        $ext    = strtolower(pathinfo($f["name"], PATHINFO_EXTENSION));
        $extsOk = ["jpg", "jpeg", "png", "webp"];
        if (!in_array($ext, $extsOk))
            $erreurs[] = "Extension non autorisee.";

        // Si tout OK, deplacer
        if (empty($erreurs)) {
            if (!is_dir($dossier)) mkdir($dossier, 0755, true);
            $nomFichier = uniqid("img_", true) . "." . $ext;
            if (move_uploaded_file($f["tmp_name"], $dossier . $nomFichier)) {
                $succes = true;
            } else {
                $erreurs[] = "Impossible de sauvegarder le fichier.";
            }
        }
    }
}
?>
<form method="post" enctype="multipart/form-data">
  <input type="file" name="photo" accept="image/*">
  <button type="submit">Uploader</button>
</form>
<?php if ($succes): ?>
  <p>Image enregistree : <?= htmlspecialchars($nomFichier) ?></p>
  <img src="uploads/<?= htmlspecialchars($nomFichier) ?>" style="max-width:300px">
<?php endif; ?>
<?php foreach ($erreurs as $e): ?>
  <p style="color:red"><?= htmlspecialchars($e) ?></p>
<?php endforeach; ?>
OK
Checklist upload : enctype multipart sur le form, verifier error=0, controler la taille, verifier le MIME reel avec finfo, nommer le fichier avec uniqid(), utiliser move_uploaded_file(), stocker hors racine web ou bloquer PHP dans uploads/.

Etape 6

Upload multiple — plusieurs fichiers

Upload de plusieurs fichiers simultanesPHP
<?php
// Formulaire : <input type="file" name="documents[]" multiple>
// $_FILES["documents"] est un tableau de tableaux

$resultats = [];
$nbFichiers = count($_FILES["documents"]["name"]);

for ($i = 0; $i < $nbFichiers; $i++) {

    // Reconstruire un tableau individuel pour chaque fichier
    $f = [
        "name"     => $_FILES["documents"]["name"][$i],
        "type"     => $_FILES["documents"]["type"][$i],
        "size"     => $_FILES["documents"]["size"][$i],
        "tmp_name" => $_FILES["documents"]["tmp_name"][$i],
        "error"    => $_FILES["documents"]["error"][$i],
    ];

    // Traiter chaque fichier individuellement
    if ($f["error"] === UPLOAD_ERR_OK) {
        $nom = uniqid() . "_" . basename($f["name"]);
        move_uploaded_file($f["tmp_name"], "uploads/" . $nom);
        $resultats[] = "OK : " . $f["name"];
    } else {
        $resultats[] = "Erreur : " . $f["name"];
    }
}

foreach ($resultats as $r) echo $r . "<br>";
i
Structure de $_FILES avec multiple. Avec name="fichiers[]", $_FILES ne regroupe pas les fichiers par fichier mais par propriete. $_FILES["fichiers"]["name"] est un tableau de tous les noms, $_FILES["fichiers"]["size"] un tableau de toutes les tailles, etc.
