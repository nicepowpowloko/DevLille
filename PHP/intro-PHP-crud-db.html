Architecture

Structure du projet

Ce projet suit une architecture simple en 3 couches : la base de donnees (MariaDB), le model (classe PHP qui encapsule les requetes PDO), et les pages (HTML + logique de formulaire). C'est la base du pattern MVC que vous verrez au Bloc 5.

projet-produits/ config/ database.php connexion PDO centralisee models/ ProduitModel.php toutes les requetes SQL pages/ liste.php READ — affichage + recherche + pagination ajouter.php CREATE — formulaire + traitement modifier.php UPDATE — formulaire pre-rempli + traitement supprimer.php DELETE — confirmation + suppression index.php routeur principal
i
Separation des responsabilites. Le model ne contient que des requetes SQL — pas d'HTML. Les pages ne contiennent pas de SQL — elles appellent le model. Cette separation rend le code testable et maintenable.

CREATE TABLE IF NOT EXISTS produits (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    nom          VARCHAR(200) NOT NULL,
    description  TEXT,
    prix         DECIMAL(10,2) NOT NULL,
    stock        INT DEFAULT 0,
    categorie_id INT,
    cree_le      DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (categorie_id) REFERENCES categories(id)
        ON DELETE SET NULL
);

function getDB(): PDO {
    static $pdo = null;

    if ($pdo === null) {
        $pdo = new PDO(
            "mysql:host=localhost;dbname=boutique;charset=utf8mb4",
            'appuser',
            'MotDePasse!',
            [
                PDO::ATTR_ERRMODE           => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,
            ]
        );
    }
    return $pdo;
}

Model

ProduitModel.php — couche d'acces aux donnees

models/ProduitModel.php — classe completeComplet
<?php
require_once __DIR__ . '/../config/database.php';

class ProduitModel {

    private PDO $pdo;

    public function __construct() {
        $this->pdo = getDB();
    }

    // READ — tous les produits (avec pagination)
    public function findAll(int $page = 1, int $perPage = 10): array {
        $offset = ($page - 1) * $perPage;
        $stmt = $this->pdo->prepare(
            "SELECT p.*, c.nom AS categorie_nom
             FROM produits p
             LEFT JOIN categories c ON p.categorie_id = c.id
             ORDER BY p.cree_le DESC
             LIMIT :limit OFFSET :offset"
        );
        $stmt->bindValue('limit',  $perPage, PDO::PARAM_INT);
        $stmt->bindValue('offset', $offset,  PDO::PARAM_INT);
        $stmt->execute();
        return $stmt->fetchAll();
    }

    // READ — un produit par ID
    public function findById(int $id): ?array {
        $stmt = $this->pdo->prepare(
            "SELECT * FROM produits WHERE id = :id"
        );
        $stmt->execute(['id' => $id]);
        $row = $stmt->fetch();
        return $row ?: null;
    }

    // READ — recherche par nom
    public function search(string $terme): array {
        $stmt = $this->pdo->prepare(
            "SELECT * FROM produits
             WHERE nom LIKE :terme OR description LIKE :terme
             ORDER BY nom ASC"
        );
        $stmt->execute(['terme' => '%' . $terme . '%']);
        return $stmt->fetchAll();
    }

    // READ — nombre total pour pagination
    public function count(): int {
        return (int) $this->pdo->query("SELECT COUNT(*) FROM produits")->fetchColumn();
    }

    // CREATE — ajouter un produit
    public function create(array $data): int {
        $stmt = $this->pdo->prepare(
            "INSERT INTO produits (nom, description, prix, stock, categorie_id)
             VALUES (:nom, :description, :prix, :stock, :categorie_id)"
        );
        $stmt->execute([
            'nom'          => $data['nom'],
            'description'  => $data['description'] ?? null,
            'prix'         => $data['prix'],
            'stock'        => $data['stock'] ?? 0,
            'categorie_id' => $data['categorie_id'] ?: null,
        ]);
        return (int) $this->pdo->lastInsertId();
    }

    // UPDATE — modifier un produit
    public function update(int $id, array $data): bool {
        $stmt = $this->pdo->prepare(
            "UPDATE produits
             SET nom = :nom, description = :description,
                 prix = :prix, stock = :stock, categorie_id = :categorie_id
             WHERE id = :id"
        );
        $stmt->execute([
            'nom'          => $data['nom'],
            'description'  => $data['description'] ?? null,
            'prix'         => $data['prix'],
            'stock'        => $data['stock'] ?? 0,
            'categorie_id' => $data['categorie_id'] ?: null,
            'id'           => $id,
        ]);
        return $stmt->rowCount() > 0;
    }

    // DELETE — supprimer un produit
    public function delete(int $id): bool {
        $stmt = $this->pdo->prepare("DELETE FROM produits WHERE id = :id");
        $stmt->execute(['id' => $id]);
        return $stmt->rowCount() > 0;
    }
}
+
bindValue vs execute([]) pour LIMIT/OFFSET. Avec execute([]), PDO transmet les valeurs comme des chaines. LIMIT et OFFSET attendent des entiers — certaines versions de MariaDB refusent les chaines. Utiliser bindValue() avec PDO::PARAM_INT pour les valeurs de pagination.

<?php
session_start();
require_once '../models/ProduitModel.php';

$model   = new ProduitModel();
$erreurs = [];
$nom = $prix = $stock = $description = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nom         = trim($_POST['nom']         ?? '');
    $prix        = $_POST['prix']        ?? '';
    $stock       = (int)($_POST['stock']       ?? 0);
    $description = trim($_POST['description'] ?? '');
    $cat_id      = (int)($_POST['categorie_id'] ?? 0);

    if (strlen($nom) < 2)
        $erreurs['nom'] = 'Nom obligatoire (2 car. min).';
    if (!is_numeric($prix) || (float)$prix <= 0)
        $erreurs['prix'] = 'Prix invalide.';
    if ($stock < 0)
        $erreurs['stock'] = 'Stock ne peut pas etre negatif.';

    if (empty($erreurs)) {
        try {
            $id = $model->create([
                'nom'          => $nom,
                'prix'         => (float)$prix,
                'stock'        => $stock,
                'description'  => $description,
                'categorie_id' => $cat_id,
            ]);
            $_SESSION['flash'] = 'Produit #' . $id . ' cree.';
            header('Location: liste.php'); exit;
        } catch (PDOException $e) {
            $erreurs['bdd'] = 'Erreur base de donnees.';
        }
    }
}
?>

+
Toujours supprimer via POST, jamais via GET. Un lien GET peut etre declenche par un navigateur, un bot, un prefetch. La page de confirmation avec formulaire POST est le minimum requis. En production, ajouter aussi un token CSRF pour empecher les requetes forgees depuis d'autres sites.

Recherche SQL — LIKE avec PDO

Recherche multi-colonnes dans ProduitModelPHP
<?php
// Dans ProduitModel — recherche avancee
public function search(string $terme, ?int $catId = null): array {
    // Construire la requete dynamiquement
    $sql = "SELECT p.*, c.nom AS categorie_nom
             FROM produits p
             LEFT JOIN categories c ON p.categorie_id = c.id
             WHERE (p.nom LIKE :terme OR p.description LIKE :terme)";

    $params = ['terme' => '%' . $terme . '%'];

    // Filtre categorie optionnel
    if ($catId !== null) {
        $sql .= " AND p.categorie_id = :cat";
        $params['cat'] = $catId;
    }

    $sql .= " ORDER BY p.nom ASC LIMIT 50";

    $stmt = $this->pdo->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}

// Dans liste.php — combiner recherche + filtre categorie
$q   = trim($_GET['q']   ?? '');
$cat = (int)($_GET['cat'] ?? 0);

if ($q) {
    $produits = $model->search($q, $cat > 0 ? $cat : null);
} else {
    $produits = $model->findAll($page, $perPage);
}
