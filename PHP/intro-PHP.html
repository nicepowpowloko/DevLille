Introduction
à PHP

PHP est un langage de programmation exécuté côté serveur. Le navigateur ne voit jamais le code PHP — il reçoit uniquement le HTML généré. Ce support explique comment PHP s'intègre dans une page web et les fondations du langage.

Fondamentaux

Comment PHP fonctionne — le modèle serveur

PHP est un langage côté serveur. Quand un visiteur demande une page .php, le serveur exécute le code PHP, génère du HTML, et envoie uniquement ce HTML au navigateur. Le navigateur ne voit jamais une ligne de PHP.

1. Navigateur→ demandeGET /index.php ↓ 2. Serveur→ lit le fichier, exécute PHP ↓ 3. PHP→ remplace le code par du HTML <?php echo "Bonjour"; ?> devient Bonjour ↓ 4. Navigateur ← reçoit du HTML pur, pas de PHP
i
HTML et PHP peuvent cohabiter dans le même fichier. Un fichier .php peut contenir du HTML ordinaire autour des blocs PHP. Tout ce qui est en dehors des balises <?php ?> est envoyé tel quel au navigateur.

01
Étape 1 — La syntaxe de base

Les balises PHP — délimiter le code

Le code PHP s'écrit entre des balises d'ouverture et de fermeture. Tout ce qui est dans ces balises est du PHP. Tout ce qui est en dehors est du HTML brut envoyé directement au navigateur.

index.php — HTML et PHP ensemblePHP
<!DOCTYPE html>
<html>
<body>

    <h1>Bienvenue</h1>  <!-- HTML pur, envoyé tel quel -->

    <?php
        // Ici c'est du PHP
        echo "Bonjour depuis le serveur !";
    ?>

    <p>Encore du HTML</p>

</body>
</html>
Ce que le navigateur reçoit
<!DOCTYPE html>
<html>
<body>
   <h1>Bienvenue</h1>
   Bonjour depuis le serveur !
   <p>Encore du HTML</p>
</body>
</html>

Le <?php ... ?> a été remplacé par son résultat.
Les 3 formes de balises PHPPHP
// Forme 1 : balise standard (recommandée — toujours disponible)
<?php
    echo "standard";
?>

// Forme 2 : balise courte echo (disponible en PHP 5.4+)
<?= "équivalent à <?php echo" ?>

// Forme 3 : fichier PHP pur (pas de balise de fermeture)
// Si le fichier est 100% PHP, omettre ?> en fin de fichier
// Évite les espaces parasites après ?>
<?php
    echo "fichier PHP pur";
// pas de ?> ici
!
Omettre la balise de fermeture ?> en fin de fichier PHP pur. Si un fichier ne contient que du PHP (pas de HTML), ne pas mettre ?> à la fin. Un espace ou un saut de ligne après ?> serait envoyé au navigateur avant les en-têtes HTTP — ce qui casse header(), setcookie() et les sessions.
!
Ne jamais utiliser <? sans le p. Les balises courtes <? dépendent d'une configuration serveur (short_open_tag) et peuvent ne pas fonctionner. Toujours utiliser <?php. Exception : <?= est toujours disponible depuis PHP 5.4.
02
Étape 2 — Afficher du contenu

echo et print — afficher du texte

echo est la construction la plus utilisée en PHP pour envoyer du contenu vers le navigateur. Ce n'est pas une fonction — c'est une construction du langage. On peut omettre les parenthèses.

echo — tout ce qu'on peut afficherPHP
<?php

// Afficher une chaîne
echo "Bonjour le monde";

// Afficher plusieurs valeurs (echo accepte une liste)
echo "Bonjour", " ", "Thomas";

// Afficher du HTML
echo "<h2>Titre généré en PHP</h2>";

// Guillemets doubles : les variables sont interprétées
$prenom = "Alice";
echo "Bonjour $prenom";// affiche : Bonjour Alice

// Guillemets simples : texte brut, variables NON interprétées
echo 'Bonjour $prenom';   // affiche : Bonjour $prenom

// Concaténation avec le point .
echo "Bonjour " . $prenom . " !";

// Afficher un nombre
echo 42;
echo 3.14;

// echo court dans du HTML
?>
<p>Bonjour <?= $prenom ?></p>
ConstructionSyntaxeDifférence
echoecho "texte";Peut afficher plusieurs valeurs séparées par virgule. Légèrement plus rapide.
printprint "texte";N'accepte qu'une valeur. Retourne toujours 1 (utilisable dans une expression).
<?=<?= $var ?>Raccourci pour echo dans du HTML. Identique à <?php echo.
i
Guillemets doubles vs simples — règle pratique. Utilisez des guillemets doubles "..." quand vous avez des variables à interpoler. Utilisez des guillemets simples '...' pour les chaînes fixes sans variable — c'est légèrement plus performant et évite les surprises.

Étape 3 — Documenter le code

Commentaires — les trois syntaxes

Les commentaires sont ignorés par PHP et n'apparaissent jamais dans le HTML envoyé au navigateur. Ils servent à documenter le code, expliquer une logique complexe, ou désactiver temporairement une ligne.

Les 3 types de commentaires PHPPHP
<?php

// Commentaire sur une ligne (style C++)
// Tout ce qui suit // jusqu'à la fin de ligne est ignoré
echo "visible"; // commentaire en fin de ligne

# Commentaire sur une ligne (style shell)
# Même comportement que // — moins courant en PHP

/*
 * Commentaire sur plusieurs lignes
 * Utile pour les blocs d'explication
 * ou pour désactiver du code temporairement
 */
echo "toujours visible";

/**
 * PHPDoc — commentaire de documentation
 * Utilisé avant les fonctions et classes
 *
 * @param string $prenom Le prénom de l'utilisateur
 * @return string        Le message de bienvenue
 */
function bienvenue($prenom) {
    return "Bonjour " . $prenom;
}
+
Bonne pratique : commenter le pourquoi, pas le quoi. // incrémente $i ne sert à rien — le code l'exprime déjà. En revanche // l'utilisateur doit exister avant d'incrémenter son score explique une règle métier invisible dans le code seul.

Étape 4 — Organisation des fichiers

Inclusion de fichiers — include et require

PHP permet d'inclure le contenu d'un fichier dans un autre. C'est le mécanisme fondamental pour éviter la répétition : un en-tête commun, un pied de page partagé, une configuration centralisée.

Les 4 fonctions d'inclusionPHP
<?php

// include : inclure un fichier — AVERTISSEMENT si absent
include 'header.php';         // warning, le script continue

// require : inclure un fichier — ERREUR FATALE si absent
require 'config.php';         // fatal error, le script s'arrête

// include_once / require_once : inclure UNE SEULE fois
// Si le fichier a déjà été inclus, PHP l'ignore
include_once 'fonctions.php';
require_once 'config.php';    // inclus une seule fois même si appelé 2x
Structure typique d'un projet PHP simpleProjet
// Structure des fichiers
// projet/
// ├── index.php         ← page d'accueil
// ├── config.php        ← configuration (BDD, constantes)
// └── includes/
//     ├── header.php    ← en-tête HTML commun
//     └── footer.php    ← pied de page commun

// --- config.php ---
<?php
define('NOM_SITE',  'Ma boutique');
define('VERSION',   '1.0');
// pas de ?> en fin de fichier PHP pur

// --- includes/header.php ---
<?php require_once '../config.php'; ?>
<!DOCTYPE html>
<html><head><title><?= NOM_SITE ?></title></head>
<body>

// --- index.php ---
<?php
require_once 'includes/header.php';
echo "<h1>Bienvenue sur " . NOM_SITE . "</h1>";
require_once 'includes/footer.php';
?>
FonctionFichier absentInclus deux foisUsage
includeWarning — continueInclus deux foisContenu optionnel (widget, pub)
requireFatal error — stopInclus deux foisFichier indispensable (config)
include_onceWarning — continueIgnoréFonctions incluses de partout
require_onceFatal error — stopIgnoréConfig, classes (usage standard)
!
require_once est votre choix par défaut. Pour les fichiers de configuration et de fonctions, préférez toujours require_once. Si le fichier est absent, le script s'arrête proprement avec un message d'erreur au lieu de continuer à produire un résultat incorrect.

Exercice — une mini page PHP complète

Créer une page PHP qui utilise tout ce qu'on vient de voir : balises, echo, variables, commentaires, et inclusion d'un header/footer.

config.php — à créer en premierfichier 1
<?php
// config.php — configuration globale du projet

define('NOM_SITE', 'Mon premier projet PHP');
define('AUTEUR',   'Thomas');

// Pas de balise de fermeture — fichier PHP pur
includes/header.phpfichier 2
<?php require_once __DIR__ . '/../config.php'; ?>
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title><?= NOM_SITE ?></title>
</head>
<body>
<header>
    <h1><?= NOM_SITE ?></h1>
</header>
<main>
index.php — page principalefichier 3
<?php
// Inclure l'en-tête (charge aussi config.php)
require_once 'includes/header.php';

// Contenu de la page
$heure    = date('H');   // heure actuelle (0-23)
$message  = "Bonjour";

echo "<p>Il est " . date('H:i') . "</p>";
echo "<p>" . $message . " depuis " . AUTEUR . "</p>";
echo "<p>PHP version : " . phpversion() . "</p>";

// Inclure le pied de page
require_once 'includes/footer.php';
?>
OK
Ce que cette mini page démontre : les balises <?php et <?=, echo avec concaténation, les commentaires, require_once, les constantes define(), et la séparation en plusieurs fichiers.
