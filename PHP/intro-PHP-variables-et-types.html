Variables et
types en PHP

Une variable est une boîte nommée qui stocke une valeur. PHP est un langage à typage dynamique : le type d'une variable est déterminé automatiquement selon la valeur qu'on lui assigne. Ce support couvre les 8 types fondamentaux et tous les opérateurs.

00
Concept fondamental

Les variables en PHP — stockage en mémoire

Une variable est un espace en mémoire avec un nom. En PHP, toutes les variables commencent par $. PHP est un langage à typage dynamique faible : pas besoin de déclarer le type, PHP le détermine tout seul selon la valeur assignée — et peut le changer automatiquement si nécessaire.

Les règles de nommage des variablesPHP
<?php

// Noms VALIDES
$prenom      = "Alice";   // lettres minuscules
$nom_complet = "Dupont";  // underscore autorisé
$age         = 25;
$_privee     = "ok";      // peut commencer par _
$var2        = "ok";      // chiffre (pas en premier)
$PrenomNom   = "ok";      // camelCase / PascalCase

// Noms INVALIDES
// $2var    → commence par un chiffre
// $mon-nom → tiret interdit (opérateur moins)
// $class   → mot réservé PHP

// PHP est sensible à la casse
$age  = 25;
$Age  = 30;   // variable DIFFÉRENTE de $age
$AGE  = 35;   // encore une autre variable
i
Convention de nommage PHP. Le standard PSR recommande le camelCase pour les variables ($nomComplet) et le snake_case pour les variables de configuration ($base_de_donnees). L'important est d'être cohérent dans tout le projet.
01
Étape 1 — Déclaration

Déclarer et assigner une variable

En PHP, il n'y a pas de mot-clé de déclaration comme var ou let en JavaScript. On crée directement la variable en lui assignant une valeur avec =.

Déclaration et manipulation de variablesPHP
<?php

// Assignation simple
$message = "Bonjour";

// Réassignation — la variable change de valeur
$message = "Au revoir";    // la valeur précédente est perdue

// Assignation multiple
$a = $b = $c = 0;           // les trois valent 0

// Assignation par valeur vs par référence
$x = 10;
$y = $x;      // copie de valeur — y est indépendant
$x = 20;
echo $y;     // affiche 10 — y n'a pas changé

$a = 10;
$b = &$a;    // référence — b pointe vers a
$a = 20;
echo $b;     // affiche 20 — b suit a

// Vérifier si une variable existe
if (isset($message)) {
    echo $message;
}

// Supprimer une variable
unset($message);
// isset($message) retourne maintenant false

Étape 2 — Les types de données

Les 8 types PHP

PHP possède 8 types de données, répartis en 3 catégories : scalaires (une seule valeur), composés (plusieurs valeurs) et spéciaux.

Les 8 types PHP avec exemplesPHP
<?php

// ── Types scalaires (une seule valeur) ──────────────────────────

// 1. int — entier
$age         = 25;
$negatif     = -10;
$hexadecimal = 0xFF;     // 255
$binaire     = 0b1010;   // 10

// 2. float — nombre à virgule flottante
$prix        = 19.99;
$pi          = 3.14159;
$scientifique= 1.5e3;    // 1500.0

// 3. string — chaîne de caractères
$prenom      = "Alice";
$vide        = "";
$multiline   = "ligne 1\nligne 2";  // \n = saut de ligne

// 4. bool — booléen
$actif       = true;
$desactive   = false;

// ── Types composés (plusieurs valeurs) ──────────────────────────

// 5. array — tableau (voir support 05)
$couleurs    = ["rouge", "vert", "bleu"];

// 6. object — objet (voir POO)
// $user = new User();

// ── Types spéciaux ───────────────────────────────────────────────

// 7. null — absence de valeur
$inconnu     = null;
$nonDefinie;                     // variable non initialisée = null

// 8. resource — référence vers une ressource externe
// $fichier = fopen("data.txt", "r");  ← type resource

// Vérifier le type d'une variable
echo gettype($age);      // integer
echo gettype($prix);     // double (float)
echo gettype($prenom);   // string
echo gettype($actif);    // boolean

// Fonctions de vérification de type (retournent bool)
is_int($age)       // true
is_float($prix)    // true
is_string($prenom) // true
is_bool($actif)    // true
is_null($inconnu)  // true
is_array($couleurs)// true

// var_dump() — type + valeur (idéal pour déboguer)
var_dump($age);    // int(25)
var_dump($prix);   // float(19.99)
var_dump($actif);  // bool(true)
!
var_dump() est votre meilleur outil de débogage. Contrairement à echo qui affiche juste la valeur, var_dump() affiche le type et la valeur. Sur un tableau, il montre toute la structure. Indispensable pour comprendre ce que contient une variable.
!
Les valeurs "falsy" en PHP. En PHP, ces valeurs sont considérées comme false dans un test booléen : false, 0, 0.0, "" (chaîne vide), "0", [] (tableau vide), null. Toute autre valeur est true.

Étape 3 — Les opérateurs

Opérateurs — arithmétiques, comparaison, logiques

Opérateurs arithmétiquesPHP
<?php
$a = 10;  $b = 3;

echo $a +  $b;   // 13   — addition
echo $a -  $b;   // 7    — soustraction
echo $a *  $b;   // 30   — multiplication
echo $a /  $b;   // 3.33 — division (retourne float si non entier)
echo $a %  $b;   // 1    — modulo (reste de la division entière)
echo $a ** $b;   // 1000 — puissance (10³)

// Opérateurs d'incrémentation/décrémentation
$i = 5;
$i++;          // $i vaut maintenant 6 (post-incrémentation)
$i--;          // $i vaut maintenant 5
++$i;          // pré-incrémentation (incrémente AVANT d'utiliser)

// Opérateurs d'assignation combinés
$total  = 100;
$total += 20;   // $total = $total + 20  → 120
$total -= 10;   // $total = $total - 10  → 110
$total *= 2;    // $total = $total * 2   → 220
$total /= 4;    // $total = $total / 4   → 55
$total %= 10;   // $total = $total % 10  → 5

// Concaténation de chaînes avec .
$texte  = "Bonjour";
$texte .= " monde";   // "Bonjour monde"
Opérateurs de comparaison — == vs ===Piège classique
<?php
// == égalité AVEC conversion de type (loose comparison)
var_dump(0   ==  "0");    // bool(true)  — PHP convertit "0" en 0
var_dump(1   ==  "1");    // bool(true)
var_dump(true == 1);     // bool(true)  — true converti en 1
var_dump(false == 0);    // bool(true)
var_dump(null  == false); // bool(true)  — DANGER !

// === égalité STRICTE (valeur ET type — recommandé)
var_dump(0   === "0");   // bool(false) — int ≠ string
var_dump(1   === "1");   // bool(false)
var_dump(true === 1);    // bool(false) — bool ≠ int

// Autres opérateurs de comparaison
$a = 5;  $b = 10;
$a !=  $b    // inégalité (avec conversion)
$a !== $b    // inégalité stricte
$a <   $b    // strictement inférieur → true
$a >   $b    // strictement supérieur → false
$a <=  $b    // inférieur ou égal     → true
$a >=  $b    // supérieur ou égal     → false
$a <=> $b   // spaceship : -1 si ab
!
Toujours préférer === à ==. L'opérateur == fait des conversions implicites qui créent des comportements inattendus. 0 == "bonjour" retourne true en PHP (PHP convertit "bonjour" en 0). L'opérateur === compare la valeur ET le type sans conversion — résultat toujours prévisible.
Opérateurs logiquesPHP
<?php
$connecte = true;
$admin    = false;

// && (et)  — les DEUX doivent être true
if ($connecte && $admin) {  // false
    echo "Accès admin";
}

// || (ou)  — AU MOINS UN doit être true
if ($connecte || $admin) {  // true
    echo "Accès utilisateur";
}

// ! (non)  — inverse la valeur
if (!$admin) {              // !false = true
    echo "Pas admin";
}

// Opérateur ternaire : condition ? valeur_si_vrai : valeur_si_faux
$role = $admin ? "admin" : "utilisateur";

// Opérateur null coalescing ?? (PHP 7+)
$nom = $_GET['nom'] ?? "inconnu";
// Si $_GET['nom'] n'existe pas ou est null → "inconnu"

// Opérateur d'assignation null coalescing ??= (PHP 7.4+)
$compteur ??= 0;   // si $compteur est null, l'assigner à 0

Étape 4 — Conversions

Conversions de types — casting et juggling

PHP fait des conversions automatiques (type juggling) dans certaines situations. On peut aussi forcer une conversion (type casting) explicitement.

Conversions explicites (casting)PHP
<?php

// Cast vers int
$a = (int) "42px";     // 42   — s'arrête au premier non-chiffre
$b = (int) "bonjour"; // 0    — pas de chiffre en début
$c = (int) 19.9;       // 19   — troncature (pas d'arrondi)
$d = (int) true;       // 1
$e = (int) false;      // 0
$f = (int) null;       // 0

// Cast vers float
$g = (float) "3.14px"; // 3.14

// Cast vers string
$h = (string) 42;      // "42"
$i = (string) true;    // "1"
$j = (string) false;   // ""   (chaîne vide !)
$k = (string) null;    // ""

// Cast vers bool
$l = (bool) 0;          // false
$m = (bool) 1;          // true
$n = (bool) "";         // false
$o = (bool) "bonjour"; // true

// Fonctions de conversion (plus explicites)
intval("42px")          // 42
floatval("3.14px")     // 3.14
strval(42)             // "42"
settype($var, "int")   // modifie $var en place

Étape 5 — Valeurs immuables

Constantes — define() et const

Une constante est une valeur nommée qui ne peut pas être modifiée après sa définition. Contrairement aux variables, pas de $ devant son nom. Par convention, les constantes s'écrivent en MAJUSCULES.

define() vs constPHP
<?php

// define() — peut être appelé n'importe où dans le code
define('TVA', 0.20);
define('NOM_SITE', 'Ma boutique');
define('MAX_CONNEXIONS', 100);

// const — doit être au niveau supérieur (hors fonction)
const VERSION = '2.1.0';
const DEBUG   = false;

// Utilisation — pas de $ !
$prix_ht = 100;
$prix_ttc = $prix_ht * (1 + TVA);
echo "Prix TTC : " . $prix_ttc;   // 120

// Vérifier si une constante existe
if (defined('TVA')) {
    echo TVA;
}

// Constantes prédéfinies PHP (très utiles)
echo PHP_VERSION;       // "8.2.0"
echo PHP_EOL;           // fin de ligne (\n sur Linux)
echo PHP_INT_MAX;       // entier maximum
echo __FILE__;          // chemin absolu du fichier courant
echo __DIR__;           // dossier du fichier courant
echo __LINE__;          // numéro de ligne courante
OK
A retenir : les constantes n'ont pas de $, s'écrivent en MAJUSCULES, et ne peuvent pas être modifiées. Utilisez-les pour les valeurs de configuration (TVA, URL, limites) partagées dans tout le projet.
