Module 10 : Les Sessions

Une session permet de stocker des informations sur le serveur pour un utilisateur spécifique pendant sa visite. Parfait pour gérer les connexions utilisateurs !

Démarrer une session

<?php // TOUJOURS démarrer la session en PREMIER // AVANT tout code HTML ou echo session_start(); // Maintenant on peut utiliser $_SESSION ?>

IMPORTANT :

session_start() doit être appelé avant tout affichage HTML, sinon vous aurez une erreur "headers already sent".

Stocker des données en session

<?php session_start(); // Stocker une variable $_SESSION['prenom'] = "Marie"; $_SESSION['user_id'] = 42; $_SESSION['connecte'] = true; // Stocker un tableau $_SESSION['panier'] = array( 'produit1' => 'Ordinateur', 'produit2' => 'Souris' ); echo "Session créée !"; ?>

Lire des données de session

<?php session_start(); // Vérifier si une variable existe if (isset($_SESSION['prenom'])) { echo "Bonjour " . $_SESSION['prenom']; } else { echo "Vous n'êtes pas connecté"; } // Afficher toutes les variables de session echo "<pre>"; print_r($_SESSION); echo "</pre>"; ?>

Supprimer des données de session

<?php session_start(); // Supprimer une variable spécifique unset($_SESSION['prenom']); // Supprimer TOUTES les variables session_unset(); // Détruire complètement la session session_destroy(); ?>

Exemple complet : Système de connexion

1. Page de connexion (login.php)
<?php session_start(); $erreur = ""; if ($_SERVER['REQUEST_METHOD'] === 'POST') { $email = $_POST['email']; $password = $_POST['password']; // Vérification simple (à remplacer par BDD) if ($email === "[email protected]" && $password === "123456") { // Connexion réussie $_SESSION['user_id'] = 1; $_SESSION['prenom'] = "Marie"; $_SESSION['email'] = $email; $_SESSION['connecte'] = true; // Redirection vers page protégée header("Location: dashboard.php"); exit(); } else { $erreur = "Email ou mot de passe incorrect"; } } ?> <!DOCTYPE html> <html> <head> <title>Connexion</title> </head> <body> <h1>Connexion</h1> <?php if ($erreur): ?> <div style="color: red;"><?php echo $erreur; ?></div> <?php endif; ?> <form method="POST"> <input type="email" name="email" placeholder="Email" required> <input type="password" name="password" placeholder="Mot de passe" required> <button type="submit">Se connecter</button> </form> </body> </html>
2. Page protégée (dashboard.php)
<?php session_start(); // Vérifier si l'utilisateur est connecté if (!isset($_SESSION['connecte']) || $_SESSION['connecte'] !== true) { // Rediriger vers la page de connexion header("Location: login.php"); exit(); } ?> <!DOCTYPE html> <html> <head> <title>Dashboard</title> </head> <body> <h1>Bienvenue <?php echo $_SESSION['prenom']; ?> !</h1> <p>Vous êtes connecté avec : <?php echo $_SESSION['email']; ?></p> <a href="logout.php">Se déconnecter</a> </body> </html>
3. Page de déconnexion (logout.php)
<?php session_start(); // Détruire toutes les variables de session session_unset(); // Détruire la session session_destroy(); // Rediriger vers la page de connexion header("Location: login.php"); exit(); ?>

Durée de vie d'une session

<?php // Définir la durée de vie du cookie de session (en secondes) // 3600 = 1 heure session_set_cookie_params(3600); session_start(); // Définir une expiration personnalisée $_SESSION['expire'] = time() + 1800; // 30 minutes // Vérifier l'expiration if (isset($_SESSION['expire']) && time() > $_SESSION['expire']) { session_destroy(); header("Location: login.php"); exit(); } ?>

Résumé des sessions :

  • session_start() - Démarre la session (TOUJOURS en premier)
  • $_SESSION['cle'] = valeur - Stocker une donnée
  • isset($_SESSION['cle']) - Vérifier si existe
  • unset($_SESSION['cle']) - Supprimer une variable
  • session_destroy() - Détruire la session complète

Module 11 : Les Cookies

Un cookie est un petit fichier texte stocké sur l'ordinateur de l'utilisateur. Parfait pour "se souvenir" de l'utilisateur entre plusieurs visites.

Créer un cookie

<?php // setcookie(nom, valeur, expiration, chemin, domaine, secure, httponly) // Cookie simple (expire dans 30 jours) setcookie("prenom", "Marie", time() + (30 * 24 * 3600)); // Cookie avec chemin setcookie("user_id", "42", time() + 86400, "/"); // Cookie sécurisé setcookie("token", "abc123", time() + 3600, "/", "", true, true); ?>

IMPORTANT :

setcookie() doit être appelé avant tout affichage HTML, comme pour les sessions.

Lire un cookie

<?php // Vérifier si le cookie existe if (isset($_COOKIE['prenom'])) { echo "Bonjour " . $_COOKIE['prenom']; } else { echo "Cookie non trouvé"; } // Afficher tous les cookies echo "<pre>"; print_r($_COOKIE); echo "</pre>"; ?>

Supprimer un cookie

<?php // Mettre une date d'expiration dans le passé setcookie("prenom", "", time() - 3600); // Ou setcookie("prenom", "", 1); ?>

Différences Sessions vs Cookies

Critère Sessions Cookies
Stockage Sur le serveur Sur l'ordinateur client
Sécurité Plus sécurisé Moins sécurisé
Taille Illimitée ~4 Ko maximum
Durée Jusqu'à fermeture navigateur Définie par le développeur
Usage Authentification, panier "Se souvenir de moi", préférences

Exemple : "Se souvenir de moi"

<?php // Page de connexion avec "Se souvenir de moi" if ($_SERVER['REQUEST_METHOD'] === 'POST') { $email = $_POST['email']; $password = $_POST['password']; $remember = isset($_POST['remember']); // Vérification (simplifiée) if ($email === "[email protected]" && $password === "123456") { session_start(); $_SESSION['user_id'] = 1; $_SESSION['connecte'] = true; // Si "Se souvenir de moi" est coché if ($remember) { // Cookie pour 30 jours setcookie("remember_email", $email, time() + (30 * 24 * 3600), "/"); setcookie("remember_token", "token_securise", time() + (30 * 24 * 3600), "/"); } header("Location: dashboard.php"); exit(); } } // Vérifier si l'utilisateur a un cookie "remember" if (isset($_COOKIE['remember_email']) && isset($_COOKIE['remember_token'])) { // Connecter automatiquement l'utilisateur session_start(); $_SESSION['user_id'] = 1; $_SESSION['connecte'] = true; header("Location: dashboard.php"); exit(); } ?> <form method="POST"> <input type="email" name="email" placeholder="Email"> <input type="password" name="password" placeholder="Mot de passe"> <label> <input type="checkbox" name="remember"> Se souvenir de moi </label> <button type="submit">Connexion</button> </form>

Module 12 : Upload de Fichiers

Formulaire d'upload

<!-- IMPORTANT : ajouter enctype="multipart/form-data" --> <form action="upload.php" method="POST" enctype="multipart/form-data"> <label>Choisir un fichier :</label> <input type="file" name="fichier"> <button type="submit">Envoyer</button> </form>

Traitement de l'upload

<?php // upload.php if ($_SERVER['REQUEST_METHOD'] === 'POST') { // Vérifier si un fichier a été uploadé if (isset($_FILES['fichier']) && $_FILES['fichier']['error'] === 0) { // Informations sur le fichier $nom_fichier = $_FILES['fichier']['name']; $type_fichier = $_FILES['fichier']['type']; $taille_fichier = $_FILES['fichier']['size']; $tmp_name = $_FILES['fichier']['tmp_name']; // Dossier de destination $dossier_uploads = "uploads/"; // Créer le dossier s'il n'existe pas if (!file_exists($dossier_uploads)) { mkdir($dossier_uploads, 0777, true); } // Chemin complet de destination $chemin_destination = $dossier_uploads . $nom_fichier; // Déplacer le fichier uploadé if (move_uploaded_file($tmp_name, $chemin_destination)) { echo " Fichier uploadé avec succès !"; } else { echo " Erreur lors de l'upload"; } } else { echo " Aucun fichier ou erreur d'upload"; } } ?>

Sécuriser l'upload

<?php if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_FILES['fichier'])) { $fichier = $_FILES['fichier']; // 1. Vérifier les erreurs if ($fichier['error'] !== UPLOAD_ERR_OK) { die("Erreur lors de l'upload"); } // 2. Vérifier la taille (max 5 Mo) $taille_max = 5 * 1024 * 1024; // 5 Mo en octets if ($fichier['size'] > $taille_max) { die("Le fichier est trop volumineux (max 5 Mo)"); } // 3. Vérifier le type de fichier $extensions_autorisees = ['jpg', 'jpeg', 'png', 'gif', 'pdf']; $extension = pathinfo($fichier['name'], PATHINFO_EXTENSION); if (!in_array(strtolower($extension), $extensions_autorisees)) { die("Extension non autorisée"); } // 4. Renommer le fichier pour éviter les conflits $nouveau_nom = uniqid() . '_' . time() . '.' . $extension; // 5. Déplacer le fichier $destination = "uploads/" . $nouveau_nom; if (move_uploaded_file($fichier['tmp_name'], $destination)) { echo " Fichier uploadé : " . $nouveau_nom; } else { echo " Erreur lors du déplacement"; } } ?>

Sécurité importante :

  • Toujours vérifier l'extension du fichier
  • Limiter la taille des fichiers
  • Renommer les fichiers uploadés
  • Ne jamais faire confiance au nom original
  • Stocker les uploads hors du dossier public si possible

Module 13 : Introduction à MySQL

MySQL est un système de gestion de bases de données relationnelles. Il permet de stocker et gérer des données de manière structurée.

Concepts de base

Structure hiérarchique

  1. Serveur MySQL : Le logiciel qui gère les bases de données
  2. Base de données : Contient plusieurs tables
  3. Table : Contient des colonnes et des lignes
  4. Colonne : Un champ (ex: nom, email)
  5. Ligne : Un enregistrement de données

Types de données courants

Type Description Exemple
INT Nombre entier 42
VARCHAR(n) Chaîne variable (max n caractères) VARCHAR(255)
TEXT Texte long Article de blog
DATE Date (YYYY-MM-DD) 2026-02-04
DATETIME Date et heure 2026-02-04 15:30:00
BOOLEAN Vrai/Faux (0 ou 1) 1
FLOAT / DECIMAL Nombre décimal 19.99

Requêtes SQL de base

Créer une base de données

-- Créer une base de données CREATE DATABASE ma_base; -- Utiliser une base de données USE ma_base;

Créer une table

-- Créer une table "utilisateurs" CREATE TABLE utilisateurs ( id INT PRIMARY KEY AUTO_INCREMENT, nom VARCHAR(100) NOT NULL, prenom VARCHAR(100) NOT NULL, email VARCHAR(255) UNIQUE NOT NULL, mot_de_passe VARCHAR(255) NOT NULL, date_inscription DATETIME DEFAULT CURRENT_TIMESTAMP );

INSERT - Ajouter des données

-- Insérer un utilisateur INSERT INTO utilisateurs (nom, prenom, email, mot_de_passe) VALUES ('Dupont', 'Marie', '[email protected]', 'motdepasse123'); -- Insérer plusieurs utilisateurs INSERT INTO utilisateurs (nom, prenom, email, mot_de_passe) VALUES ('Martin', 'Lucas', '[email protected]', 'pass123'), ('Bernard', 'Sophie', '[email protected]', 'pass456');

SELECT - Lire des données

-- Sélectionner tous les utilisateurs SELECT * FROM utilisateurs; -- Sélectionner des colonnes spécifiques SELECT nom, prenom, email FROM utilisateurs; -- Avec une condition WHERE SELECT * FROM utilisateurs WHERE nom = 'Dupont'; -- Avec plusieurs conditions SELECT * FROM utilisateurs WHERE nom = 'Dupont' AND prenom = 'Marie'; -- Avec LIKE (recherche partielle) SELECT * FROM utilisateurs WHERE email LIKE '%@example.com'; -- Trier les résultats SELECT * FROM utilisateurs ORDER BY nom ASC; SELECT * FROM utilisateurs ORDER BY date_inscription DESC; -- Limiter le nombre de résultats SELECT * FROM utilisateurs LIMIT 10; -- Compter les résultats SELECT COUNT(*) FROM utilisateurs;

UPDATE - Modifier des données

-- Modifier un utilisateur UPDATE utilisateurs SET email = '[email protected]' WHERE id = 1; -- Modifier plusieurs colonnes UPDATE utilisateurs SET nom = 'Martin', prenom = 'Luc' WHERE id = 2; -- Sans WHERE, tous les enregistrements sont modifiés ! UPDATE utilisateurs SET nom = 'Test'; -- DANGER !

DELETE - Supprimer des données

-- Supprimer un utilisateur DELETE FROM utilisateurs WHERE id = 3; -- Sans WHERE, TOUS les enregistrements sont supprimés ! DELETE FROM utilisateurs; -- DANGER !

ATTENTION :

Toujours utiliser WHERE avec UPDATE et DELETE, sinon vous modifierez/supprimerez TOUTES les lignes !

Module 14 : PDO - PHP Data Objects

PDO est la méthode moderne et sécurisée pour se connecter à une base de données MySQL en PHP. C'est celle que vous devez utiliser !

Connexion à la base de données

<?php // config.php - Fichier de configuration $host = 'localhost'; $dbname = 'ma_base'; $username = 'root'; $password = ''; // Vide par défaut sur WAMP/XAMPP try { // Créer la connexion PDO $pdo = new PDO("mysql:host=$host;dbname=$dbname;charset=utf8", $username, $password); // Configurer PDO pour afficher les erreurs $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION); // Mode de récupération par défaut : tableau associatif $pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC); echo "Connexion réussie !"; } catch (PDOException $e) { die("Erreur de connexion : " . $e->getMessage()); } ?>

Bonnes pratiques :

  • Créer un fichier config.php séparé pour la connexion
  • Ne jamais afficher les erreurs en production
  • Utiliser toujours charset=utf8 pour les accents

Requêtes préparées (ESSENTIEL pour la sécurité !)

SELECT avec requête préparée

<?php require 'config.php'; // Rechercher un utilisateur par email $email = "[email protected]"; // Préparer la requête $stmt = $pdo->prepare("SELECT * FROM utilisateurs WHERE email = :email"); // Exécuter avec les paramètres $stmt->execute(['email' => $email]); // Récupérer le résultat $utilisateur = $stmt->fetch(); if ($utilisateur) { echo "Bonjour " . $utilisateur['prenom']; } else { echo "Utilisateur non trouvé"; } ?>

INSERT avec requête préparée

<?php require 'config.php'; $nom = "Dupont"; $prenom = "Marie"; $email = "[email protected]"; $password = password_hash("motdepasse123", PASSWORD_DEFAULT); // Préparer la requête d'insertion $stmt = $pdo->prepare(" INSERT INTO utilisateurs (nom, prenom, email, mot_de_passe) VALUES (:nom, :prenom, :email, :password) "); // Exécuter $resultat = $stmt->execute([ 'nom' => $nom, 'prenom' => $prenom, 'email' => $email, 'password' => $password ]); if ($resultat) { echo "Utilisateur créé avec l'ID : " . $pdo->lastInsertId(); } ?>

UPDATE avec requête préparée

<?php require 'config.php'; $id = 1; $nouveau_email = "[email protected]"; $stmt = $pdo->prepare(" UPDATE utilisateurs SET email = :email WHERE id = :id "); $resultat = $stmt->execute([ 'email' => $nouveau_email, 'id' => $id ]); if ($resultat) { echo "Utilisateur modifié"; echo "Lignes affectées : " . $stmt->rowCount(); } ?>

DELETE avec requête préparée

<?php require 'config.php'; $id = 3; $stmt = $pdo->prepare("DELETE FROM utilisateurs WHERE id = :id"); $resultat = $stmt->execute(['id' => $id]); if ($resultat) { echo "Utilisateur supprimé"; } ?>

Récupérer plusieurs résultats

<?php require 'config.php'; // Récupérer tous les utilisateurs $stmt = $pdo->query("SELECT * FROM utilisateurs"); $utilisateurs = $stmt->fetchAll(); foreach ($utilisateurs as $user) { echo $user['prenom'] . " " . $user['nom'] . "<br>"; } // Avec une condition $stmt = $pdo->prepare("SELECT * FROM utilisateurs WHERE nom = :nom"); $stmt->execute(['nom' => 'Dupont']); $resultats = $stmt->fetchAll(); ?>

INJECTIONS SQL - DANGER !

N'utilisez JAMAIS cette méthode :

<?php // DANGEREUX - Injection SQL possible ! $email = $_GET['email']; $query = "SELECT * FROM utilisateurs WHERE email = '$email'"; $result = $pdo->query($query); // Un attaquant pourrait envoyer : // ?email=' OR '1'='1 // Et récupérer TOUS les utilisateurs ! ?>

Toujours utiliser les requêtes préparées :

<?php // SÉCURISÉ $email = $_GET['email']; $stmt = $pdo->prepare("SELECT * FROM utilisateurs WHERE email = :email"); $stmt->execute(['email' => $email]); $user = $stmt->fetch(); ?>

Module 16 : Sécurité

1. Hachage des mots de passe

<?php // TOUJOURS hacher les mots de passe ! // Inscription - Hacher le mot de passe $password = "motdepasse123"; $hash = password_hash($password, PASSWORD_DEFAULT); // Résultat : $2y$10$randomsaltandhashvalue... // Stocker $hash en BDD (PAS le mot de passe en clair !) // Connexion - Vérifier le mot de passe $password_saisli = "motdepasse123"; $hash_en_bdd = "$2y$10$..."; // Récupéré depuis la BDD if (password_verify($password_saisi, $hash_en_bdd)) { echo " Mot de passe correct !"; } else { echo " Mot de passe incorrect"; } ?>

2. Protection contre les injections SQL

<?php // DANGEREUX - Injection SQL $email = $_GET['email']; $query = "SELECT * FROM users WHERE email = '$email'"; // SÉCURISÉ - Requête préparée $email = $_GET['email']; $stmt = $pdo->prepare("SELECT * FROM users WHERE email = :email"); $stmt->execute(['email' => $email]); ?>

3. Protection XSS (Cross-Site Scripting)

<?php // Toujours échapper les données avant affichage $nom = $_POST['nom']; // DANGEREUX echo $nom; // SÉCURISÉ echo htmlspecialchars($nom, ENT_QUOTES, 'UTF-8'); ?>

4. Protection CSRF (Cross-Site Request Forgery)

<?php session_start(); // Générer un token CSRF if (!isset($_SESSION['csrf_token'])) { $_SESSION['csrf_token'] = bin2hex(random_bytes(32)); } // Dans le formulaire ?> <form method="POST"> <input type="hidden" name="csrf_token" value="<?php echo $_SESSION['csrf_token']; ?>"> <!-- autres champs --> </form> <?php // Vérifier le token if ($_SERVER['REQUEST_METHOD'] === 'POST') { if (!isset($_POST['csrf_token']) || $_POST['csrf_token'] !== $_SESSION['csrf_token']) { die("Token CSRF invalide"); } // Traiter le formulaire... } ?>

Règles de sécurité essentielles :

  1. Toujours utiliser des requêtes préparées (PDO)
  2. Hacher les mots de passe avec password_hash()
  3. Échapper les données avec htmlspecialchars()
  4. Valider toutes les entrées utilisateur
  5. Utiliser HTTPS en production
  6. Ne jamais afficher les erreurs en production
  7. Limiter les tentatives de connexion
