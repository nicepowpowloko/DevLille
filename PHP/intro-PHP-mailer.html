Module PHP — Envoi d'emails

PHP Mailer

Apprenez à envoyer des emails depuis PHP : fonction native mail(), bibliothèque PHPMailer, SMTP, emails HTML et pièces jointes.

Envoyer des emails en PHP Concepts

PHP propose deux approches pour envoyer des emails :

mail() natif

Fonction built-in de PHP. Simple, mais limitée : pas de SMTP, peu de contrôle sur les en-têtes, souvent bloquée par les hébergeurs modernes.

PHPMailer

Bibliothèque open-source (via Composer). Supporte SMTP, TLS, emails HTML, pièces jointes, envois multiples, etc. Standard de l'industrie.

Prérequis MAMP

Sous MAMP (port 8889), la fonction mail() native ne fonctionne pas sans configuration Sendmail. PHPMailer + SMTP est la solution recommandée. Vous pouvez utiliser un compte Gmail ou un service de test comme Mailtrap.

Fonction mail() native Built-in

La fonction mail() est disponible nativement en PHP. Elle est simple mais peu fiable en développement local.

Syntaxe

ParamètreTypeDescription
$tostringDestinataire(s)
$subjectstringObjet du message
$messagestringCorps du message
$headersstring|arrayEn-têtes optionnels (From, CC…)
PHP 
// Envoi simple avec mail()
$to      = 'destinataire@exemple.com';
$subject = 'Bonjour depuis PHP !';
$message = 'Ceci est un message de test.';
$headers = 'From: expediteur@monsite.com';

if (mail($to, $subject, $message, $headers)) {
    echo 'Email envoyé avec succès !';
} else {
    echo 'Échec de l\'envoi.';
}
Limites de mail()
  • Nécessite un serveur Sendmail/Postfix configuré sur le serveur
  • Emails souvent classés en spam (pas d'authentification SPF/DKIM)
  • Pas de support natif SMTP authentifié
  • Pas de prise en charge facile des emails HTML ou des pièces jointes

Premier email avec PHPMailer Exemple complet
PHP — send_email.php
// Chargement de l'autoloader Composer
require 'vendor/autoload.php';

use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\SMTP;
use PHPMailer\PHPMailer\Exception;

// Chargement de la config
$config = require 'config/mailer.php';

$mail = new PHPMailer(true); // true = exceptions activées

try {
    // ── Configuration SMTP ─
    $mail->isSMTP();
    $mail->Host       = $config['host'];
    $mail->SMTPAuth   = true;
    $mail->Username   = $config['username'];
    $mail->Password   = $config['password'];
    $mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
    $mail->Port       = $config['port'];
    $mail->CharSet    = 'UTF-8';

    // ── Expéditeur & destinataire ──
    $mail->setFrom($config['from'], $config['from_name']);
    $mail->addAddress('destinataire@exemple.com', 'Jean Dupont');
    $mail->addReplyTo($config['from'], $config['from_name']);

    // ── Contenu ──
    $mail->isHTML(false);
    $mail->Subject = 'Test PHPMailer';
    $mail->Body    = 'Bonjour ! Ceci est un email de test envoyé via PHPMailer.';

    $mail->send();
    echo 'Email envoyé avec succès !';

} catch (Exception $e) {
    echo "Erreur : {$mail->ErrorInfo}";
}

Formulaire de contact complet Cas pratique

Exemple complet : formulaire HTML → validation PHP → envoi par email.

contact.html

HTML
<form action="traitement_contact.php" method="post">
  <label>Nom</label>
  <input type="text" name="nom" required>

  <label>Email</label>
  <input type="email" name="email" required>

  <label>Message</label>
  <textarea name="message" required></textarea>

  <button type="submit">Envoyer</button>
</form>

traitement_contact.php

PHP
require 'vendor/autoload.php';

use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\Exception;

$config = require 'config/mailer.php';

// ── 1. Validation & nettoyage des données ──
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    header('Location: contact.html');
    exit;
}

$nom     = trim(htmlspecialchars($_POST['nom'] ?? ''));
$email   = filter_var($_POST['email'] ?? '', FILTER_VALIDATE_EMAIL);
$message = trim(htmlspecialchars($_POST['message'] ?? ''));

if (!$nom || !$email || !$message) {
    echo 'Données invalides.';
    exit;
}

// ── 2. Envoi de l'email ──
$mail = new PHPMailer(true);

try {
    $mail->isSMTP();
    $mail->Host       = $config['host'];
    $mail->SMTPAuth   = true;
    $mail->Username   = $config['username'];
    $mail->Password   = $config['password'];
    $mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
    $mail->Port       = $config['port'];
    $mail->CharSet    = 'UTF-8';

    $mail->setFrom($config['from'], $config['from_name']);
    $mail->addAddress('admin@monsite.com', 'Admin');
    $mail->addReplyTo($email, $nom); // Répondre directement à l'utilisateur

    $mail->isHTML(true);
    $mail->Subject = "Nouveau message de {$nom}";
    $mail->Body    = "
        <h2>Message de {$nom}</h2>
        <p><strong>Email :</strong> {$email}</p>
        <p><strong>Message :</strong></p>
        <blockquote>{$message}</blockquote>
    ";
    $mail->AltBody = "De: {$nom} ({$email})\n\n{$message}";

    $mail->send();

    // Rediriger avec confirmation
    header('Location: contact.html?statut=succes');

} catch (Exception $e) {
    header('Location: contact.html?statut=erreur');
}
exit;
Réinitialisation de mot de passe Cas pratique

Fonctionnement classique en 3 étapes :

  • 1
    Génération d'un token unique

    Créer un token aléatoire sécurisé, le stocker en BDD avec une expiration.

  • 2
    Envoi de l'email avec le lien

    Le lien contient le token : https://monsite.com/reset?token=XYZ

  • 3
    Validation du token et mise à jour du mot de passe

    Vérifier que le token existe et n'est pas expiré, puis permettre la saisie du nouveau mot de passe.

PHP — forgot_password.php
require 'vendor/autoload.php';
require 'config/database.php';  // connexion PDO dans $pdo

use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\Exception;

$email  = filter_var($_POST['email'] ?? '', FILTER_VALIDATE_EMAIL);
$config = require 'config/mailer.php';

if ($email) {
    // Vérifier si l'email existe
    $stmt = $pdo->prepare('SELECT id FROM users WHERE email = ?');
    $stmt->execute([$email]);
    $user = $stmt->fetch();

    if ($user) {
        // Générer un token sécurisé
        $token   = bin2hex(random_bytes(32));
        $expires = date('Y-m-d H:i:s', strtotime('+1 hour'));

        // Stocker en BDD
        $stmt = $pdo->prepare(
            'INSERT INTO password_resets (user_id, token, expires_at)
             VALUES (?, ?, ?)'
        );
        $stmt->execute([$user['id'], hash('sha256', $token), $expires]);

        // Construire le lien
        $lien = "https://monsite.com/reset_password.php?token={$token}";

        // Envoyer l'email
        $mail = new PHPMailer(true);
        try {
            // ... config SMTP ...
            $mail->addAddress($email);
            $mail->Subject = 'Réinitialisation de votre mot de passe';
            $mail->isHTML(true);
            $mail->Body = "
                <p>Vous avez demandé la réinitialisation de votre mot de passe.</p>
                <p>Cliquez sur ce lien (valable 1 heure) :</p>
                <a href='{$lien}'>Réinitialiser mon mot de passe</a>
                <p>Si vous n'êtes pas à l'origine de cette demande, ignorez cet email.</p>
            ";
            $mail->send();
        } catch (Exception $e) { /* log erreur */ }
    }

    // Toujours afficher le même message (sécurité)
    echo 'Si cet email existe, un lien de réinitialisation a été envoyé.';
}
🛡️ Sécurité & bonnes pratiques Important
À éviter
  • Mettre les credentials SMTP dans le code versionné
  • Afficher $mail->ErrorInfo à l'utilisateur final
  • Ne pas valider les données du formulaire avant envoi
  • Envoyer un email par utilisateur trouvé (confirmation de l'existence)
  • Utiliser des tokens prévisibles pour les réinitialisations
À faire
  • Stocker les credentials dans un fichier hors version (.gitignore) ou en variables d'environnement
  • Logger les erreurs côté serveur (error_log())
  • Valider et nettoyer toutes les données (filter_var, htmlspecialchars)
  • Utiliser random_bytes() pour les tokens
  • Hasher les tokens en BDD (hash('sha256', $token))
  • Limiter le taux d'envoi (anti-spam)

Exercice 3 — Email avec pièce jointe uploadée Avancé

Énoncé

Créez un formulaire permettant d'envoyer un CV par email. Le formulaire doit avoir :

  • Nom, Prénom, Email du candidat
  • Poste souhaité (select : Développeur Web, UX Designer, Chef de projet)
  • Un champ de téléversement pour le CV (PDF uniquement, max 2 Mo)
  • Validation du type MIME et de la taille côté PHP
  • Email HTML récapitulatif envoyé au RH avec le CV en pièce jointe
  • Email de confirmation envoyé au candidat
PHP — traitement_candidature.php
require 'vendor/autoload.php';
use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\Exception;

// Validation des champs texte
$nom    = trim(htmlspecialchars($_POST['nom'] ?? ''));
$prenom = trim(htmlspecialchars($_POST['prenom'] ?? ''));
$email  = filter_var($_POST['email'] ?? '', FILTER_VALIDATE_EMAIL);
$poste  = trim(htmlspecialchars($_POST['poste'] ?? ''));

// Validation du fichier
$cv = $_FILES['cv'] ?? null;
$erreurs = [];

if (!$nom || !$prenom || !$email || !$poste) {
    $erreurs[] = 'Champs obligatoires manquants.';
}

if (!$cv || $cv['error'] !== UPLOAD_ERR_OK) {
    $erreurs[] = 'Aucun fichier téléversé.';
} else {
    // Vérif type MIME réel
    $finfo = new finfo(FILEINFO_MIME_TYPE);
    $mime  = $finfo->file($cv['tmp_name']);

    if ($mime !== 'application/pdf') {
        $erreurs[] = 'Le fichier doit être un PDF.';
    }
    if ($cv['size'] > 2 * 1024 * 1024) {
        $erreurs[] = 'Le PDF ne doit pas dépasser 2 Mo.';
    }
}

if (!empty($erreurs)) {
    header('Location: candidature.php?statut=erreur'); exit;
}

// Envoi email RH avec pièce jointe
$mail = new PHPMailer(true);
try {
    // ... config SMTP ...
    $mail->addAddress('rh@monentreprise.com', 'RH');
    $mail->addAttachment($cv['tmp_name'], "CV_{$nom}_{$prenom}.pdf");
    $mail->isHTML(true);
    $mail->Subject = "Candidature {$poste} — {$prenom} {$nom}";
    $mail->Body    = "
        <h2>Nouvelle candidature</h2>
        <p><strong>Candidat :</strong> {$prenom} {$nom}</p>
        <p><strong>Email :</strong> {$email}</p>
        <p><strong>Poste :</strong> {$poste}</p>
        <p>Le CV est joint à cet email.</p>
    ";
    $mail->send();

    // Email de confirmation au candidat
    $mail->clearAddresses();
    $mail->clearAttachments();
    $mail->addAddress($email, "{$prenom} {$nom}");
    $mail->Subject = 'Votre candidature a bien été reçue';
    $mail->Body    = "
        <p>Bonjour {$prenom},</p>
        <p>Nous avons bien reçu votre candidature pour le poste de <strong>{$poste}</strong>.</p>
        <p>Notre équipe RH reviendra vers vous dans les meilleurs délais.</p>
        <p>Cordialement,</p>
    ";
    $mail->send();

    header('Location: candidature.php?statut=succes');
} catch (Exception $e) {
    error_log("Mailer: {$mail->ErrorInfo}");
    header('Location: candidature.php?statut=erreur');
}
exit;
