Formulaires
et validation

Les formulaires sont le principal point d'entrée des données utilisateur. Ce support couvre la récupération via $_GET et $_POST, la validation, et la protection contre les failles XSS.

GET vs POST — deux façons d'envoyer des données

Données dansL'URL (?nom=Alice)Le corps de la requête (invisible)

!
Ne jamais faire confiance aux données reçues. Toute donnée venant de $_GET, $_POST ou $_REQUEST est potentiellement malveillante. Toujours valider et assainir avant utilisation.
01
Étape 1

Créer un formulaire HTML

Formulaire HTML — champs courantsHTML
<form action="traitement.php" method="post">

  <!-- Texte, email, password, number -->
  <input type="text"     name="nom"     required maxlength="50">
  <input type="email"    name="email"   required>
  <input type="password" name="mdp"     minlength="8">
  <input type="number"   name="age"     min="0" max="120">

  <!-- Liste deroulante -->
  <select name="role">
    <option value="user">Utilisateur</option>
    <option value="admin">Administrateur</option>
  </select>

  <!-- Checkbox — absent de $_POST si non cochee -->
  <input type="checkbox" name="cgu" value="1">

  <!-- Boutons radio — meme name, values differentes -->
  <input type="radio" name="genre" value="h"> Homme
  <input type="radio" name="genre" value="f"> Femme

  <!-- Zone de texte -->
  <textarea name="message" rows="5"></textarea>

  <button type="submit">Envoyer</button>
</form>
i
L'attribut name est la clé PHP. C'est la valeur de name dans le HTML qui détermine la clé dans $_POST. Un champ sans name n'est pas envoyé au serveur.
02
Étape 2

$_POST et $_GET — lire les données

traitement.php — récupérer les donnéesPHP
<?php

// Vérifier si le formulaire a été soumis
if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    // Récupérer une valeur — ?? pour éviter les warnings
    $nom     = $_POST['nom']     ?? '';
    $email   = $_POST['email']   ?? '';
    $age     = $_POST['age']     ?? null;
    $message = $_POST['message'] ?? '';

    // Checkbox : n'existe pas si non cochée
    $cgu = isset($_POST['cgu']);   // true ou false

    // Radio : valeur de l'option choisie
    $genre = $_POST['genre'] ?? '';
}

// Données dans l'URL (?page=2&tri=nom)
$page = $_GET['page'] ?? 1;
$tri  = $_GET['tri']  ?? 'date';

// filter_input — récupérer ET valider en une ligne
$age_ok   = filter_input(INPUT_POST, 'age',   FILTER_VALIDATE_INT);
$email_ok = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL);
// Retourne la valeur si valide, false si invalide, null si absent
!
Toujours utiliser ?? pour les valeurs optionnelles. Accéder à $_POST['champ'] directement génère un Warning si le champ est absent. L'opérateur ?? retourne la valeur par défaut si la clé est absente ou null.
03
Étape 3

Valider les données — règles et messages d'erreur

Validation complète d'un formulaire d'inscriptionPHP
<?php
$erreurs = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    $nom     = trim($_POST['nom']     ?? '');
    $email   = trim($_POST['email']   ?? '');
    $age     = (int)($_POST['age']     ?? 0);

    // Nom : obligatoire, 2-50 caractères
    if (empty($nom)) {
        $erreurs['nom'] = "Nom obligatoire.";
    } elseif (strlen($nom) < 2 || strlen($nom) > 50) {
        $erreurs['nom'] = "Nom : entre 2 et 50 caractères.";
    }

    // Email : obligatoire, format valide
    if (empty($email)) {
        $erreurs['email'] = "Email obligatoire.";
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $erreurs['email'] = "Format d'email invalide.";
    }

    // Age : entre 18 et 120
    if ($age < 18 || $age > 120) {
        $erreurs['age'] = "Age doit etre entre 18 et 120.";
    }

    // Si aucune erreur → traitement
    if (empty($erreurs)) {
        // insertion BDD, email, etc.
        header('Location: confirmation.php');
        exit;
    }
}
+
Conserver les valeurs saisies après une erreur. Toujours repeupler les champs avec les valeurs postées : value="<?= htmlspecialchars($nom ?? '') ?>". L'utilisateur ne doit pas tout ressaisir pour une seule erreur.
04
Étape 4 — Sécurité

Assainir — se protéger des failles XSS

Une faille XSS (Cross-Site Scripting) survient quand des données utilisateur sont affichées telles quelles dans du HTML. Un attaquant injecte du JavaScript qui s'exécute dans le navigateur des visiteurs.

XSS — problème et solutionSécurité
<?php
// DANGEREUX — affichage direct
echo "Bonjour " . $_POST['nom'];
// Si nom = "<script>alert('XSS')</script>"
// → le script s'execute !

// CORRECT — htmlspecialchars() encode les caracteres dangereux
echo "Bonjour " . htmlspecialchars($_POST['nom'], ENT_QUOTES, 'UTF-8');
// < devient &lt;   > devient &gt;   ' et " aussi

// Raccourci recommande — creer une fonction e()
function e($val): string {
    return htmlspecialchars((string)$val, ENT_QUOTES, 'UTF-8');
}
?>

<!-- Utilisation dans les templates -->
<h1><?= e($titre) ?></h1>
<input value="<?= e($nom) ?>">

Étape 5 — Complet

Formulaire complet — page PHP autonome

contact.php — page complète avec gestion erreursComplet
<?php
function e($v): string { return htmlspecialchars((string)$v, ENT_QUOTES, 'UTF-8'); }

$erreurs = []; $succes = false;
$nom = $email = $message = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nom     = trim($_POST['nom']     ?? '');
    $email   = trim($_POST['email']   ?? '');
    $message = trim($_POST['message'] ?? '');

    if (empty($nom))
        $erreurs['nom'] = "Nom obligatoire.";
    if (!filter_var($email, FILTER_VALIDATE_EMAIL))
        $erreurs['email'] = "Email invalide.";
    if (strlen($message) < 10)
        $erreurs['message'] = "Message trop court (10 min).";

    if (empty($erreurs)) {
        $succes = true;
        $nom = $email = $message = '';
    }
}
?>
<!DOCTYPE html><html><body>
<?php if ($succes): ?>
  <p>Message envoyé avec succès !</p>
<?php endif; ?>

<form method="post">
  <input name="nom" value="<?= e($nom) ?>">
  <?php if (isset($erreurs['nom'])): ?>
    <span class="err"><?= e($erreurs['nom']) ?></span>
  <?php endif; ?>

  <input type="email" name="email" value="<?= e($email) ?>">
  <?php if (isset($erreurs['email'])): ?>
    <span class="err"><?= e($erreurs['email']) ?></span>
  <?php endif; ?>

  <textarea name="message"><?= e($message) ?></textarea>
  <?php if (isset($erreurs['message'])): ?>
    <span class="err"><?= e($erreurs['message']) ?></span>
  <?php endif; ?>

  <button type="submit">Envoyer</button>
</form>
</body></html>
OK
Pattern PRG (Post/Redirect/Get). Après un traitement POST réussi, faire une redirection header('Location: confirmation.php') pour éviter le double envoi au rechargement de page.
