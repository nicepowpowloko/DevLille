Les tableaux
PHP

Un tableau est une structure de données qui stocke plusieurs valeurs dans une seule variable. PHP les rend extrêmement flexibles : types mixtes, imbrication, et des dizaines de fonctions natives pour les manipuler.

Les 3 types de tableaux PHP

PHP ne distingue pas syntaxiquement les trois types — ce sont tous des array. La différence est dans la nature des clés utilisées.

TypeClésUsage typique
IndexéEntiers auto (0, 1, 2…)Liste de produits, de noms, résultats
AssociatifChaînes nomméesUn utilisateur (nom, email, age), une ligne BDD
MultidimensionnelTableaux imbriquésPlusieurs lignes SQL, catalogue de produits
01
Étape 1

Tableau indexé — accès par position

Tableau indexéPHP
<?php
// Création — syntaxe courte (recommandée)
$fruits = ["pomme", "banane", "cerise"];
//          index 0   index 1    index 2

// Accès par index
echo $fruits[0];   // pomme
echo $fruits[2];   // cerise

// Modifier une valeur
$fruits[1] = "mangue";

// Ajouter en fin — [] sans index
$fruits[] = "kiwi";   // index 3

// Nombre d'éléments
echo count($fruits);   // 4

// Dernier élément (PHP 8+)
echo $fruits[-1];   // kiwi

// Afficher tout (débogage)
print_r($fruits);
var_dump($fruits);
i
Les index commencent à 0. Le premier élément est à l'index 0. L'index du dernier élément est count($tab) - 1. Accéder à un index inexistant génère un Warning.

Étape 2

Tableau associatif — accès par clé

Tableau associatifPHP
<?php
$user = [
    "nom"    => "Dupont",
    "prenom" => "Alice",
    "age"    => 25,
    "email"  => "alice@example.com",
];

// Accès par clé
echo $user["nom"];    // Dupont

// Modifier / ajouter
$user["age"]   = 26;
$user["ville"] = "Paris";

// Vérifier si une clé existe
if (isset($user["email"])) { echo $user["email"]; }

// Supprimer une clé
unset($user["email"]);

// Toutes les clés / valeurs
$cles = array_keys($user);
$vals = array_values($user);

// Parcourir
foreach ($user as $cle => $valeur) {
    echo "<p><b>" . $cle . "</b> : " . $valeur . "</p>";
}

Étape 3

Tableau multidimensionnel — la structure BDD

Tableau de tableauxPHP
<?php
// Comme SELECT * FROM produits
$produits = [
    ["id" => 1, "nom" => "T-shirt", "prix" => 19.99, "stock" => 50],
    ["id" => 2, "nom" => "Jean",    "prix" => 49.99, "stock" => 30],
    ["id" => 3, "nom" => "Veste",   "prix" => 89.99, "stock" => 15],
];

// Accès double crochet
echo $produits[0]["nom"];   // T-shirt
echo $produits[1]["prix"];  // 49.99

// Affichage HTML en tableau
echo "<table><tr><th>Nom</th><th>Prix</th></tr>";
foreach ($produits as $p) {
    echo "<tr><td>" . htmlspecialchars($p["nom"]) . "</td>";
    echo "<td>" . $p["prix"] . " €</td></tr>";
}
echo "</table>";

// Modifier un élément imbriqué
$produits[0]["prix"] = 14.99;
$produits[2]["stock"]--;

Étape 4

Ajouter, supprimer, fusionner

Manipulation de tableauxPHP
<?php
$fruits = ["pomme", "banane", "cerise"];

// Ajouter en fin / début
array_push($fruits, "kiwi");       // ou $fruits[] = "kiwi"
array_unshift($fruits, "abricot"); // ajoute en début

// Retirer dernier / premier
$dernier = array_pop($fruits);    // retire et retourne "kiwi"
$premier = array_shift($fruits);  // retire et retourne "abricot"

// Supprimer par index (laisse un trou)
unset($fruits[1]);
$fruits = array_values($fruits);  // réindexer

// Extraire une portion
$portion = array_slice($fruits, 1, 2);

// Fusionner
$legumes = ["carotte", "courgette"];
$tout = array_merge($fruits, $legumes);

// Dédupliquer
$doublons = [1, 2, 2, 3, 3];
$unique = array_unique($doublons);  // [1, 2, 3]

Étape 5

Trier un tableau

Fonctions de triPHP
<?php
$notes = [14, 8, 17, 12, 5];

sort($notes);   // croissant : [5, 8, 12, 14, 17]
rsort($notes);  // décroissant : [17, 14, 12, 8, 5]

// Associatif — conserver les clés
$ages = ["Alice" => 25, "Bob" => 32, "Clara" => 19];
asort($ages);  // par valeur, clés conservées
ksort($ages);  // par clé alphabétique

// usort — tri personnalisé
$produits = [
    ["nom" => "Veste",   "prix" => 89],
    ["nom" => "T-shirt", "prix" => 19],
    ["nom" => "Jean",    "prix" => 49],
];
usort($produits, fn($a, $b) => $a["prix"] - $b["prix"]);
// Résultat trié par prix croissant

Étape 6

Chercher et filtrer

Recherche et filtrePHP
<?php
$roles = ["admin", "editor", "viewer"];

in_array("admin", $roles)         // true
in_array("admin", $roles, true)   // strict (===)
array_search("editor", $roles)    // 1 ou false

// array_filter — garder selon condition
$notes = [14, 8, 17, 5, 12];
$admis = array_filter($notes, fn($n) => $n >= 10);
// [14, 17, 12] — clés originales conservées
$admis = array_values($admis);   // réindexer

// Filtrer tableau de tableaux
$produits = [
    ["nom" => "T-shirt", "stock" => 0],
    ["nom" => "Jean",    "stock" => 30],
];
$dispos = array_filter($produits, fn($p) => $p["stock"] > 0);

Étape 7

array_map et array_reduce — transformer

map, reduce, columnPHP
<?php

// array_map — transformer chaque élément
$prix_ht  = [10, 20, 30, 50];
$prix_ttc = array_map(fn($p) => round($p * 1.20, 2), $prix_ht);
// [12.0, 24.0, 36.0, 60.0]

// array_reduce — réduire à une valeur
$notes  = [12, 15, 8, 17];
$somme  = array_reduce($notes, fn($carry, $n) => $carry + $n, 0);
$moyenne = $somme / count($notes);  // 13

// array_column — extraire une colonne d'un tableau 2D
$produits = [
    ["id" => 1, "nom" => "T-shirt", "prix" => 19],
    ["id" => 2, "nom" => "Jean",    "prix" => 49],
];
$noms  = array_column($produits, "nom");      // ["T-shirt", "Jean"]
$parId = array_column($produits, null, "id"); // indexé par id
OK
Le trio fondamental : array_map transforme, array_filter sélectionne, array_reduce agrège. Ces trois fonctions couvrent 90% des opérations sur des données.
