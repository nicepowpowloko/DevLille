Module 1 : Introduction à PHP

Qu'est-ce que PHP ?

PHP (Hypertext Preprocessor) est un langage de programmation côté serveur utilisé pour créer des sites web dynamiques.

  • Créé en 1994 par Rasmus Lerdorf
  • Utilisé par 77% des sites web (WordPress, Facebook, Wikipedia...)
  • Gratuit et open-source
  • Facile à apprendre et puissant

Client vs Serveur

Côté Client (Frontend) Côté Serveur (Backend)
HTML, CSS, JavaScript PHP, Python, Node.js
S'exécute dans le navigateur S'exécute sur le serveur
Visible par l'utilisateur Invisible, code caché
Interface visuelle Traitement des données

Installation de l'environnement

Windows : WAMP / XAMPP

  1. Télécharger WAMP : wampserver.com
  2. Installer WAMP
  3. Lancer WAMP (icône verte = serveur actif)
  4. Créer vos fichiers PHP dans : C:\wamp64\www\
  5. Accéder via : http://localhost/

Mac : MAMP

  1. Télécharger MAMP : mamp.info
  2. Installer et lancer MAMP
  3. Créer vos fichiers dans : /Applications/MAMP/htdocs/

Votre premier fichier PHP

<?php // Ceci est un commentaire echo "Bonjour le monde !"; ?>

Règles importantes :

  • Les fichiers PHP ont l'extension .php
  • Le code PHP commence par <?php et se termine par ?>
  • Chaque instruction se termine par un ;
  • PHP est sensible à la casse pour les variables

Module 2 : Syntaxe de base

Balises PHP

<?php // Balise standard (recommandée) echo "Hello"; ?> <?php // Balise courte (à éviter) echo "Hello"; ?> <?php // Une seule balise pour tout le fichier (le plus courant) echo "Hello"; // Pas de ?> à la fin si le fichier ne contient que du PHP

Afficher du contenu

<?php // echo - affiche du texte echo "Bonjour"; echo "Bonjour", " ", "le", " ", "monde"; // Plusieurs valeurs // print - similaire à echo print "Hello"; // var_dump() - affiche le type et la valeur (utile pour déboguer) var_dump("Hello"); var_dump(42); // print_r() - affiche les tableaux de façon lisible print_r(array(1, 2, 3)); ?>

Commentaires

<?php // Commentaire sur une ligne # Aussi un commentaire sur une ligne /* Commentaire sur plusieurs lignes */ /** * Commentaire de documentation * @param string $nom * @return string */ ?>

Mélanger HTML et PHP

<!DOCTYPE html> <html> <head> <title>Ma page PHP</title> </head> <body> <h1><?php echo "Titre dynamique"; ?></h1> <?php $prenom = "Thomas"; echo "<p>Bonjour $prenom</p>"; ?> <p>Nous sommes le <?php echo date("d/m/Y"); ?></p> </body> </html>

Module 3 : Les Variables

Déclaration et utilisation

<?php // Une variable commence TOUJOURS par $ $nom = "Thomas"; $age = 30; $estMajeur = true; $prix = 19.99; // Afficher une variable echo $nom; // Thomas echo "Je m'appelle $nom"; // Je m'appelle Thomas echo 'Je m\'appelle $nom'; // Je m'appelle $nom (pas d'interpolation avec '') // Concaténation avec . echo "Je m'appelle " . $nom . " et j'ai " . $age . " ans"; ?>

Types de données

Type Description Exemple
String Chaîne de caractères $nom = "Marie";
Integer Nombre entier $age = 25;
Float Nombre décimal $prix = 19.99;
Boolean Vrai ou Faux $actif = true;
Array Tableau $fruits = array("pomme", "banane");
NULL Aucune valeur $vide = null;

Vérifier le type d'une variable

<?php $age = 25; // var_dump() affiche le type ET la valeur var_dump($age); // int(25) // gettype() retourne le type echo gettype($age); // integer // is_*() vérifie le type if (is_int($age)) { echo "C'est un entier"; } if (is_string($nom)) { echo "C'est une chaîne"; } if (is_bool($actif)) { echo "C'est un booléen"; } ?>

Conversion de types (Casting)

<?php $nombre = "42"; // C'est une chaîne // Convertir en entier $entier = (int)$nombre; $entier = intval($nombre); // Convertir en float $decimal = (float)"19.99"; $decimal = floatval("19.99"); // Convertir en string $texte = (string)42; $texte = strval(42); // Convertir en booléen $bool = (bool)1; // true $bool = (bool)0; // false ?>

Constantes

<?php // Constante avec define() define("SITE_NAME", "Mon Site Web"); define("VERSION", "1.0"); echo SITE_NAME; // Mon Site Web // Constante avec const (depuis PHP 5.3) const DB_HOST = "localhost"; const DB_USER = "root"; echo DB_HOST; // localhost // Constantes prédéfinies PHP echo PHP_VERSION; // Version de PHP echo PHP_OS; // Système d'exploitation echo __FILE__; // Nom du fichier actuel echo __DIR__; // Répertoire du fichier actuel echo __LINE__; // Numéro de ligne actuelle ?>

Opérateurs

Arithmétiques

<?php $a = 10; $b = 3; echo $a + $b; // 13 (Addition) echo $a - $b; // 7 (Soustraction) echo $a * $b; // 30 (Multiplication) echo $a / $b; // 3.333... (Division) echo $a % $b; // 1 (Modulo - reste de la division) echo $a ** $b; // 1000 (Puissance) // Incrémentation / Décrémentation $count = 0; $count++; // $count = 1 $count--; // $count = 0 ?>

Comparaison

<?php $a = 5; $b = "5"; // Égalité (valeur) var_dump($a == $b); // true // Identité (valeur ET type) var_dump($a === $b); // false // Différent var_dump($a != $b); // false var_dump($a !== $b); // true // Comparaisons var_dump($a > 3); // true var_dump($a < 10); // true var_dump($a >= 5); // true var_dump($a <= 5); // true ?>

Logiques

<?php $age = 25; $majeur = true; // ET logique if ($age >= 18 && $majeur) { echo "Accès autorisé"; } // OU logique if ($age < 18 || !$majeur) { echo "Accès refusé"; } // NON logique if (!$majeur) { echo "Pas majeur"; } ?>

Module 4 : Les Structures Conditionnelles

if / else

<?php $age = 20; // if simple if ($age >= 18) { echo "Vous êtes majeur"; } // if / else if ($age >= 18) { echo "Majeur"; } else { echo "Mineur"; } // if / elseif / else if ($age < 12) { echo "Enfant"; } elseif ($age < 18) { echo "Adolescent"; } elseif ($age < 60) { echo "Adulte"; } else { echo "Senior"; } ?>

Opérateur ternaire

<?php $age = 20; // Syntaxe : condition ? si_vrai : si_faux $statut = ($age >= 18) ? "Majeur" : "Mineur"; echo $statut; // Majeur // Équivalent à : if ($age >= 18) { $statut = "Majeur"; } else { $statut = "Mineur"; } ?>

switch

<?php $jour = "lundi"; switch ($jour) { case "lundi": echo "Début de semaine"; break; case "mardi": case "mercredi": case "jeudi": echo "Milieu de semaine"; break; case "vendredi": echo "Bientôt le weekend !"; break; case "samedi": case "dimanche": echo "Weekend !"; break; default: echo "Jour non reconnu"; } ?>

match (PHP 8+)

<?php $statut = 200; $message = match($statut) { 200 => "OK", 404 => "Non trouvé", 500 => "Erreur serveur", default => "Statut inconnu" }; echo $message; // OK ?>

Bonnes pratiques :

  • Utilisez === (triple égal) au lieu de ==
  • Simplifiez avec l'opérateur ternaire pour les cas simples
  • Préférez match à switch si PHP 8+
  • N'oubliez pas le break dans les switch

Module 5 : Les Boucles

while

<?php // Tant que la condition est vraie, la boucle continue $i = 1; while ($i <= 5) { echo "Tour $i<br>"; $i++; } // Résultat : // Tour 1 // Tour 2 // Tour 3 // Tour 4 // Tour 5 ?>

do...while

<?php // Exécute AU MOINS une fois, puis vérifie la condition $i = 1; do { echo "Tour $i<br>"; $i++; } while ($i <= 5); ?>

for

<?php // for (initialisation; condition; incrémentation) for ($i = 1; $i <= 5; $i++) { echo "Tour $i<br>"; } // Compter à rebours for ($i = 10; $i >= 1; $i--) { echo "$i... "; } echo "Décollage !"; // Boucle de 2 en 2 for ($i = 0; $i <= 10; $i += 2) { echo "$i "; // 0 2 4 6 8 10 } ?>

foreach (pour les tableaux)

<?php $fruits = array("Pomme", "Banane", "Orange"); // Parcourir les valeurs foreach ($fruits as $fruit) { echo "$fruit<br>"; } // Parcourir les clés ET les valeurs $ages = array("Marie" => 25, "Lucas" => 30, "Sophie" => 28); foreach ($ages as $prenom => $age) { echo "$prenom a $age ans<br>"; } ?>

break et continue

<?php // break - sort de la boucle for ($i = 1; $i <= 10; $i++) { if ($i === 5) { break; // Sort à i=5 } echo "$i "; // 1 2 3 4 } // continue - passe à l'itération suivante for ($i = 1; $i <= 10; $i++) { if ($i % 2 === 0) { continue; // Saute les nombres pairs } echo "$i "; // 1 3 5 7 9 } ?>

Exemple pratique : Table de multiplication

<?php echo "<table border='1'>"; for ($i = 1; $i <= 10; $i++) { echo "<tr>"; for ($j = 1; $j <= 10; $j++) { echo "<td>" . ($i * $j) . "</td>"; } echo "</tr>"; } echo "</table>"; ?>

Module 6 : Les Fonctions

Créer une fonction

<?php // Fonction simple function direBonjour() { echo "Bonjour !"; } // Appeler la fonction direBonjour(); // Bonjour ! // Fonction avec paramètres function saluer($prenom) { echo "Bonjour $prenom !"; } saluer("Thomas"); // Bonjour Thomas ! // Fonction avec valeur de retour function additionner($a, $b) { return $a + $b; } $resultat = additionner(5, 3); echo $resultat; // 8 ?>

Paramètres par défaut

<?php function saluer($prenom, $formule = "Bonjour") { return "$formule $prenom !"; } echo saluer("Marie"); // Bonjour Marie ! echo saluer("Lucas", "Salut"); // Salut Lucas ! ?>

Typage des paramètres (PHP 7+)

<?php // Typage strict declare(strict_types=1); function additionner(int $a, int $b): int { return $a + $b; } echo additionner(5, 3); // 8 // echo additionner(5.5, 3); // Erreur si strict_types=1 function obtenirNom(string $prenom, string $nom): string { return "$prenom $nom"; } function estMajeur(int $age): bool { return $age >= 18; } ?>

Fonctions variables

<?php function crier($texte) { return strtoupper($texte); } $maFonction = "crier"; echo $maFonction("bonjour"); // BONJOUR ?>

Fonctions anonymes (lambda)

<?php // Fonction anonyme $dire = function($message) { echo $message; }; $dire("Hello"); // Hello // Fonction fléchée (PHP 7.4+) $multiplier = fn($x, $y) => $x * $y; echo $multiplier(5, 3); // 15 ?>

Fonctions utiles intégrées

Manipulation de chaînes

<?php $texte = "Bonjour le monde"; // Longueur echo strlen($texte); // 16 // Majuscules / Minuscules echo strtoupper($texte); // BONJOUR LE MONDE echo strtolower($texte); // bonjour le monde echo ucfirst($texte); // Bonjour le monde echo ucwords($texte); // Bonjour Le Monde // Remplacer echo str_replace("monde", "PHP", $texte); // Bonjour le PHP // Découper $mots = explode(" ", $texte); // ["Bonjour", "le", "monde"] // Joindre $phrase = implode(" - ", $mots); // Bonjour - le - monde // Extraire une partie echo substr($texte, 0, 7); // Bonjour // Position d'un caractère echo strpos($texte, "le"); // 8 ?>

Manipulation de nombres

<?php // Arrondir echo round(3.7); // 4 echo ceil(3.1); // 4 (arrondi supérieur) echo floor(3.9); // 3 (arrondi inférieur) // Valeur absolue echo abs(-10); // 10 // Maximum / Minimum echo max(5, 10, 3); // 10 echo min(5, 10, 3); // 3 // Nombre aléatoire echo rand(1, 100); // Nombre entre 1 et 100 // Puissance / Racine echo pow(2, 3); // 8 (2^3) echo sqrt(16); // 4 ?>

Fonctions de date

<?php // Date actuelle echo date("d/m/Y"); // 04/02/2026 echo date("H:i:s"); // 15:30:45 echo date("d/m/Y H:i:s"); // 04/02/2026 15:30:45 // Timestamp echo time(); // 1738681845 (secondes depuis 1970) // Créer une date $date = mktime(15, 30, 0, 2, 4, 2026); echo date("d/m/Y", $date); // Formater une date $dateObj = new DateTime("2026-02-04"); echo $dateObj->format("d/m/Y"); // 04/02/2026 ?>

Module 7 : Les Tableaux (Arrays)

Tableaux indexés

<?php // Créer un tableau $fruits = array("Pomme", "Banane", "Orange"); // Syntaxe courte (PHP 5.4+) $fruits = ["Pomme", "Banane", "Orange"]; // Accéder aux éléments (index commence à 0) echo $fruits[0]; // Pomme echo $fruits[1]; // Banane // Modifier un élément $fruits[1] = "Fraise"; // Ajouter un élément $fruits[] = "Kiwi"; // Ajoute à la fin array_push($fruits, "Mangue"); // Ajoute à la fin // Nombre d'éléments echo count($fruits); // 5 // Parcourir le tableau for ($i = 0; $i < count($fruits); $i++) { echo $fruits[$i] . "<br>"; } foreach ($fruits as $fruit) { echo "$fruit<br>"; } ?>

Tableaux associatifs

<?php // Tableau avec clés personnalisées $personne = array( "prenom" => "Marie", "nom" => "Dupont", "age" => 25, "ville" => "Lille" ); // Syntaxe courte $personne = [ "prenom" => "Marie", "nom" => "Dupont", "age" => 25, "ville" => "Lille" ]; // Accéder aux éléments echo $personne["prenom"]; // Marie echo $personne["age"]; // 25 // Ajouter une clé $personne["email"] = "[email protected]"; // Parcourir foreach ($personne as $cle => $valeur) { echo "$cle : $valeur<br>"; } ?>

Tableaux multidimensionnels

<?php $etudiants = [ [ "nom" => "Dupont", "prenom" => "Marie", "notes" => [15, 12, 18] ], [ "nom" => "Martin", "prenom" => "Lucas", "notes" => [14, 16, 13] ] ]; // Accéder aux éléments echo $etudiants[0]["prenom"]; // Marie echo $etudiants[0]["notes"][0]; // 15 // Parcourir foreach ($etudiants as $etudiant) { echo $etudiant["prenom"] . " " . $etudiant["nom"] . "<br>"; foreach ($etudiant["notes"] as $note) { echo "Note : $note<br>"; } } ?>

Fonctions de tableaux essentielles

<?php $nombres = [5, 2, 8, 1, 9]; // Trier sort($nombres); // Tri croissant : [1, 2, 5, 8, 9] rsort($nombres); // Tri décroissant : [9, 8, 5, 2, 1] // Tableaux associatifs $ages = ["Marie" => 25, "Lucas" => 30, "Sophie" => 28]; asort($ages); // Tri par valeur ksort($ages); // Tri par clé // Rechercher $fruits = ["Pomme", "Banane", "Orange"]; if (in_array("Banane", $fruits)) { echo "Banane trouvée !"; } $position = array_search("Orange", $fruits); // 2 // Ajouter / Retirer array_push($fruits, "Kiwi"); // Ajoute à la fin array_pop($fruits); // Retire le dernier array_unshift($fruits, "Fraise"); // Ajoute au début array_shift($fruits); // Retire le premier // Fusionner $tableau1 = [1, 2, 3]; $tableau2 = [4, 5, 6]; $fusion = array_merge($tableau1, $tableau2); // [1, 2, 3, 4, 5, 6] // Découper $portion = array_slice($fruits, 1, 2); // Extrait 2 éléments à partir de l'index 1 // Supprimer une clé unset($ages["Marie"]); // Obtenir les clés / valeurs $cles = array_keys($ages); $valeurs = array_values($ages); // Vérifier si une clé existe if (array_key_exists("Lucas", $ages)) { echo "Lucas existe"; } // Compter les occurrences $lettres = ['a', 'b', 'a', 'c', 'a']; $comptage = array_count_values($lettres); // ['a' => 3, 'b' => 1, 'c' => 1] ?>

Fonctions les plus utilisées :

  • count() - Nombre d'éléments
  • in_array() - Vérifier si existe
  • array_push() - Ajouter à la fin
  • sort() / asort() / ksort() - Trier
  • array_merge() - Fusionner
  • array_keys() / array_values() - Obtenir clés/valeurs

Module 8 : Les Superglobales

Les superglobales sont des variables PHP automatiquement disponibles partout dans le script.

$_SERVER

Contient des informations sur le serveur et l'environnement

<?php // Informations sur la requête echo $_SERVER['PHP_SELF']; // Nom du fichier actuel echo $_SERVER['SERVER_NAME']; // Nom du serveur echo $_SERVER['HTTP_HOST']; // En-tête Host echo $_SERVER['HTTP_USER_AGENT']; // Navigateur de l'utilisateur echo $_SERVER['SCRIPT_NAME']; // Chemin du script // Méthode HTTP echo $_SERVER['REQUEST_METHOD']; // GET, POST, etc. // Adresse IP echo $_SERVER['REMOTE_ADDR']; // IP du client echo $_SERVER['SERVER_ADDR']; // IP du serveur // URL echo $_SERVER['REQUEST_URI']; // URI demandée ?>

$GLOBALS

Accès aux variables globales

<?php $x = 10; function test() { // Accéder à $x depuis la fonction echo $GLOBALS['x']; // 10 } test(); ?>

Les autres superglobales

Superglobale Description
$_GET Données envoyées via URL (méthode GET)
$_POST Données envoyées via formulaire (méthode POST)
$_REQUEST Combine $_GET, $_POST et $_COOKIE
$_SESSION Variables de session
$_COOKIE Cookies du navigateur
$_FILES Fichiers uploadés
$_ENV Variables d'environnement

Sécurité importante :

Ne faites JAMAIS confiance aux données des superglobales ! Elles viennent de l'utilisateur et peuvent contenir du code malveillant. Toujours valider et nettoyer les données.

Module 9 : Méthodes GET et POST

Les méthodes GET et POST permettent d'envoyer des données d'un formulaire HTML vers PHP.

Méthode GET

Les données sont envoyées dans l'URL

Formulaire GET

<!-- formulaire.html --> <form action="traitement.php" method="GET"> <label>Prénom :</label> <input type="text" name="prenom"> <label>Âge :</label> <input type="number" name="age"> <button type="submit">Envoyer</button> </form>

Récupération en PHP

<?php // traitement.php // Vérifier si les données existent if (isset($_GET['prenom']) && isset($_GET['age'])) { $prenom = $_GET['prenom']; $age = $_GET['age']; echo "Bonjour $prenom, vous avez $age ans"; } // URL résultante : traitement.php?prenom=Marie&age=25 ?>

Avantages et inconvénients de GET

Avantages Inconvénients
• Possibilité de mettre en favoris • Données visibles dans l'URL
• Peut être partagé facilement • Limité à ~2000 caractères
• Bon pour les recherches • Non sécurisé pour mots de passe

Méthode POST

Les données sont envoyées de manière cachée

Formulaire POST

<!-- formulaire-post.html --> <form action="traitement-post.php" method="POST"> <label>Email :</label> <input type="email" name="email" required> <label>Mot de passe :</label> <input type="password" name="password" required> <label>Message :</label> <textarea name="message"></textarea> <button type="submit">Envoyer</button> </form>

Récupération en PHP

<?php // traitement-post.php if ($_SERVER['REQUEST_METHOD'] === 'POST') { // Récupérer les données $email = $_POST['email']; $password = $_POST['password']; $message = $_POST['message']; echo "Email : $email<br>"; echo "Message : $message"; // Les données ne sont PAS visibles dans l'URL } ?>

Avantages et inconvénients de POST

Avantages Inconvénients
• Données cachées (plus sécurisé) • Ne peut pas être mis en favoris
• Pas de limite de taille • Ne peut pas être partagé
• Parfait pour les formulaires • Rafraîchir = renvoyer les données

Validation des données

<?php // Vérifier si le formulaire a été soumis if ($_SERVER['REQUEST_METHOD'] === 'POST') { // Vérifier si les champs existent if (isset($_POST['prenom']) && isset($_POST['email'])) { $prenom = $_POST['prenom']; $email = $_POST['email']; // Vérifier que les champs ne sont pas vides if (empty($prenom)) { echo "Erreur : Le prénom est obligatoire"; } elseif (empty($email)) { echo "Erreur : L'email est obligatoire"; } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) { echo "Erreur : Email invalide"; } else { echo "Données valides !"; // Traiter les données... } } } ?>

Nettoyer les données (Sécurité)

<?php if ($_SERVER['REQUEST_METHOD'] === 'POST') { // Supprimer les espaces $prenom = trim($_POST['prenom']); // Supprimer les balises HTML $prenom = strip_tags($prenom); // Convertir les caractères spéciaux en HTML $prenom = htmlspecialchars($prenom, ENT_QUOTES, 'UTF-8'); // Ou tout en un avec filter_input() $prenom = filter_input(INPUT_POST, 'prenom', FILTER_SANITIZE_STRING); $email = filter_input(INPUT_POST, 'email', FILTER_SANITIZE_EMAIL); // Valider l'email if (filter_var($email, FILTER_VALIDATE_EMAIL)) { echo "Email valide : $email"; } } ?>

Exemple complet : Formulaire de contact

<!-- contact.php --> <?php $erreurs = []; $succes = false; if ($_SERVER['REQUEST_METHOD'] === 'POST') { // Récupération et nettoyage $nom = trim(htmlspecialchars($_POST['nom'])); $email = trim(htmlspecialchars($_POST['email'])); $message = trim(htmlspecialchars($_POST['message'])); // Validation if (empty($nom)) { $erreurs[] = "Le nom est obligatoire"; } if (empty($email)) { $erreurs[] = "L'email est obligatoire"; } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) { $erreurs[] = "L'email est invalide"; } if (empty($message)) { $erreurs[] = "Le message est obligatoire"; } elseif (strlen($message) < 10) { $erreurs[] = "Le message doit contenir au moins 10 caractères"; } // Si pas d'erreurs if (empty($erreurs)) { // Traiter le formulaire (envoyer email, enregistrer en BDD, etc.) $succes = true; } } ?> <!DOCTYPE html> <html> <head> <title>Formulaire de contact</title> </head> <body> <h1>Contactez-nous</h1> <?php if ($succes): ?> <div style="color: green; background: #d4edda; padding: 15px; margin: 10px 0;"> Message envoyé avec succès ! </div> <?php endif; ?> <?php if (!empty($erreurs)): ?> <div style="color: red; background: #f8d7da; padding: 15px; margin: 10px 0;"> <ul> <?php foreach ($erreurs as $erreur): ?> <li><?php echo $erreur; ?></li> <?php endforeach; ?> </ul> </div> <?php endif; ?> <form method="POST" action=""> <div> <label>Nom :</label> <input type="text" name="nom" value="<?php echo isset($nom) ? $nom : ''; ?>"> </div> <div> <label>Email :</label> <input type="email" name="email" value="<?php echo isset($email) ? $email : ''; ?>"> </div> <div> <label>Message :</label> <textarea name="message"><?php echo isset($message) ? $message : ''; ?></textarea> </div> <button type="submit">Envoyer</button> </form> </body> </html>

Récapitulatif GET vs POST :

Critère GET POST
Visibilité Données dans l'URL Données cachées
Sécurité Moins sécurisé Plus sécurisé
Taille ~2000 caractères max Illimité
Mise en cache Oui Non
Usage typique Recherche, filtres Formulaires, login
