Concept

Classe vs objet — le plan et la maison

Une classe est un modele qui definit la structure et le comportement. Un objet est une instance concrete creee a partir de cette classe. On peut creer autant d'objets qu'on veut depuis une seule classe.

Classe Produit ← plan, modele, definition Proprietes : nom, prix, stock Methodes : appliquerRemise(), estDisponible() $p1 = new Produit("T-shirt", 19.99, 50) ← instance 1 $p2 = new Produit("Jean", 49.99, 0) ← instance 2 $p3 = new Produit("Veste", 89.99, 15) ← instance 3 Chaque objet a ses propres valeurs de proprietes mais partage les memes methodes de la classe
i
Pourquoi la POO ? Elle permet de regrouper donnees et comportements dans une meme unite, de reutiliser du code par heritage, et de masquer la complexite derriere une interface simple. Le code devient plus facile a maintenir et a faire evoluer.
01
Etape 1

Declarer une classe et creer des objets

Syntaxe de base — classe et instanciationPHP
<?php
// Declaration d'une classe (dans un fichier Produit.php)
class Produit {
    // Contenu : proprietes + methodes
}

// Instanciation : creer un objet depuis la classe
$p = new Produit();

// Plusieurs objets depuis la meme classe
$p1 = new Produit();
$p2 = new Produit();
// $p1 et $p2 sont des objets independants

// Verifier si une variable est un objet
var_dump($p instanceof Produit);  // bool(true)

// Convention de nommage
// Classe    : PascalCase  ex: ProduitService, UserModel
// Methode   : camelCase   ex: calculerPrix(), getNom()
// Propriete : camelCase   ex: $prixHT, $nomComplet
// Fichier   : Produit.php (meme nom que la classe)

Etape 3

Methodes — les comportements de l'objet

Methodes — $this et retoursPHP
<?php
class Produit {

    public string $nom  = '';
    public float  $prix = 0.0;
    public int    $stock = 0;

    // $this designe l'objet courant
    public function calculerTTC(float $taux = 0.20): float {
        return round($this->prix * (1 + $taux), 2);
    }

    public function estDisponible(): bool {
        return $this->stock > 0;
    }

    public function appliquerRemise(float $pct): void {
        $this->prix = round($this->prix * (1 - $pct / 100), 2);
    }

    public function vendre(int $qte = 1): bool {
        if ($this->stock < $qte) return false;
        $this->stock -= $qte;
        return true;
    }

    // __toString : conversion automatique en chaine
    public function __toString(): string {
        return $this->nom . ' (' . $this->prix . ' EUR)';
    }
}

// Utilisation
$p = new Produit();
$p->nom  = 'T-shirt';
$p->prix = 19.99;
$p->stock = 5;

echo $p->calculerTTC();   // 23.99
echo $p->estDisponible() ? 'Dispo' : 'Rupture';
$p->appliquerRemise(10);  // -10% : prix = 17.99
echo $p;                   // T-shirt (17.99 EUR)
i
$this represente l'objet courant. A l'interieur d'une methode, $this pointe vers l'instance sur laquelle la methode est appelee. $p1->calculerTTC() utilise $this->prix qui est le prix de $p1. Chaque instance a ses propres valeurs.

Etape 4

Constructeur — __construct()

Le constructeur est une methode speciale appelee automatiquement lors de la creation d'un objet avec new. Il sert a initialiser les proprietes.

__construct() et promotion des proprietes (PHP 8)PHP
<?php
// Methode classique
class Produit {
    public string $nom;
    public float  $prix;
    public int    $stock;

    public function __construct(string $nom, float $prix, int $stock = 0) {
        $this->nom   = $nom;
        $this->prix  = $prix;
        $this->stock = $stock;
    }
}

// Promotion des proprietes (PHP 8+) — version courte
class Produit {
    public function __construct(
        public string $nom,
        public float  $prix,
        public int    $stock = 0,
    ) {}
    // PHP cree automatiquement les proprietes et les assigne
}

// Utilisation identique dans les deux cas
$p1 = new Produit('T-shirt', 19.99, 50);
$p2 = new Produit('Jean',    49.99);      // stock = 0

echo $p1->nom;   // T-shirt
echo $p2->prix;  // 49.99
+
La promotion des proprietes (PHP 8) est la syntaxe recommandee. Elle est plus concise et evite la repetition : on ne declare pas les proprietes en haut puis on les assigne dans le constructeur. Tout se fait en une seule ligne dans la signature du constructeur.

Encapsulation — getters et settersPHP
<?php
class CompteBancaire {

    private float $solde;
    private array $historique = [];

    public function __construct(float $soldeInitial = 0) {
        $this->solde = $soldeInitial;
    }

    // Getter : lire une propriete privee
    public function getSolde(): float {
        return $this->solde;
    }

    // Methode publique qui modifie le solde de facon controlee
    public function crediter(float $montant): void {
        if ($montant <= 0) throw new InvalidArgumentException('Montant invalide');
        $this->solde += $montant;
        $this->logOperation('credit', $montant);
    }

    public function debiter(float $montant): bool {
        if ($montant > $this->solde) return false;
        $this->solde -= $montant;
        $this->logOperation('debit', $montant);
        return true;
    }

    // Methode privee : detail d'implementation
    private function logOperation(string $type, float $montant): void {
        $this->historique[] = date('H:i') . ' ' . $type . ' ' . $montant;
    }
}

$compte = new CompteBancaire(1000);
$compte->crediter(500);
$compte->debiter(200);
echo $compte->getSolde();      // 1300
// $compte->solde = 9999;  ← ERREUR : private
!
Principe d'encapsulation. Rendre les proprietes private et exposer uniquement des methodes publiques contrôlees permet de garantir la coherence de l'objet. On ne peut pas mettre un solde negatif en ecrivant directement $compte->solde = -500. La classe protege ses invariants.

Etape 6

Static — proprietes et methodes de classe

static — sans instanciationPHP
<?php
class Produit {
    // Propriete statique : partagee entre toutes les instances
    private static int $nbCrees = 0;
    public  static float $tauxTVA = 0.20;

    public function __construct(
        public string $nom,
        public float  $prix
    ) {
        self::$nbCrees++;   // self:: pour acceder aux membres statiques
    }

    // Methode statique : appel sans objet
    public static function getNbCrees(): int {
        return self::$nbCrees;
    }

    public static function calculerTTC(float $prix): float {
        return round($prix * (1 + self::$tauxTVA), 2);
    }
}

// Acces statique sans new : ClassName::membre
echo Produit::calculerTTC(100);  // 120
echo Produit::$tauxTVA;          // 0.20

$p1 = new Produit('T-shirt', 19);
$p2 = new Produit('Jean', 49);
echo Produit::getNbCrees();      // 2

Synthese

Classe Produit complete

Produit.php — classe complete et documenteeComplet
<?php
/**
 * Represente un produit du catalogue.
 */
class Produit {

    public function __construct(
        private string $nom,
        private float  $prix,
        private int    $stock        = 0,
        private ?string $description = null,
    ) {
        if ($prix < 0) throw new InvalidArgumentException('Prix negatif interdit');
    }

    // Getters
    public function getNom():    string  { return $this->nom;   }
    public function getPrix():   float   { return $this->prix;  }
    public function getStock():  int     { return $this->stock; }

    // Setters avec validation
    public function setPrix(float $prix): void {
        if ($prix < 0) throw new InvalidArgumentException('Prix negatif');
        $this->prix = $prix;
    }

    // Logique metier
    public function calculerTTC(float $taux = 0.20): float {
        return round($this->prix * (1 + $taux), 2);
    }

    public function estDisponible(): bool {
        return $this->stock > 0;
    }

    public function vendre(int $qte = 1): bool {
        if ($qte > $this->stock) return false;
        $this->stock -= $qte;
        return true;
    }

    public function appliquerRemise(float $pct): static {
        $this->prix = round($this->prix * (1 - $pct / 100), 2);
        return $this;   // fluent interface
    }

    public function __toString(): string {
        return '[' . $this->nom . '] ' . $this->prix . ' EUR | stock: ' . $this->stock;
    }
}

// Usage
$p = new Produit('T-shirt', 20.00, 10);
$p->appliquerRemise(10)->appliquerRemise(5);  // chaining
echo $p;   // [T-shirt] 17.1 EUR | stock: 10
OK
A retenir : classe = plan, objet = instance. $this = l'objet courant. __construct() initialise. Proprietes privees + methodes publiques = encapsulation. self:: pour les membres statiques.
