CSS

Cascading Style Sheets

Module 1 : Introduction au CSS

1.1 Qu'est-ce que le CSS ?

CSS (Cascading Style Sheets) est le langage utilisé pour styliser et mettre en page les documents HTML. Il permet de séparer le contenu (HTML) de la présentation (CSS).

Les trois façons d'intégrer du CSS :

<!-- 1. CSS Inline (dans l'élément HTML) --> <p style="color: blue; font-size: 16px;">Texte en bleu</p> <!-- 2. CSS Interne (dans la balise <style>) --> <head> <style> p { color: blue; font-size: 16px; } </style> </head> <!-- 3. CSS Externe (fichier séparé - RECOMMANDÉ) --> <head> <link rel="stylesheet" href="styles.css"> </head>

1.2 Structure d'une règle CSS

sélecteur { propriété: valeur; autre-propriété: autre-valeur; } /* Exemple */ h1 { color: red; font-size: 32px; text-align: center; }
Important : Chaque déclaration CSS se termine par un point-virgule (;). Les accolades {} délimitent le bloc de déclarations.

1.3 Les commentaires CSS

/* Ceci est un commentaire sur une ligne */ /* Ceci est un commentaire sur plusieurs lignes */ h1 { color: blue; /* Commentaire en fin de ligne */ }

Exemple pratique : Premier fichier CSS

/* styles.css */ body { font-family: Arial, sans-serif; margin: 0; padding: 20px; background-color: #f0f0f0; } h1 { color: #333; text-align: center; } p { color: #666; line-height: 1.6; }

Module 2 : Les Sélecteurs CSS

2.1 Sélecteurs de base

Sélecteur d'élément (type)

/* Sélectionne tous les paragraphes */ p { color: blue; } /* Sélectionne tous les titres h1 */ h1 { font-size: 32px; }

Sélecteur de classe (.)

/* HTML */ <p class="important">Texte important</p> /* CSS */ .important { color: red; font-weight: bold; }

Sélecteur d'identifiant (#)

/* HTML */ <div id="header">En-tête</div> /* CSS */ #header { background-color: navy; color: white; padding: 20px; }
Important : Un ID doit être unique sur la page. Utilisez les classes pour les styles réutilisables.

2.2 Sélecteurs combinés

/* Sélecteur descendant (espace) */ div p { color: blue; } /* Sélecteur enfant direct (>) */ ul > li { list-style: none; } /* Sélecteur de frère adjacent (+) */ h1 + p { font-weight: bold; } /* Sélecteur de frères généraux (~) */ h1 ~ p { margin-top: 10px; }
Astuce : Utilisez des sélecteurs spécifiques mais pas trop complexes pour une meilleure maintenabilité.

Module 3 : Couleurs et Texte

3.1 Les couleurs en CSS

/* Hexadécimal */ h1 { color: #FF0000; } /* RGB */ div { color: rgb(255, 0, 0); } /* RGBA (avec transparence) */ .overlay { background-color: rgba(0, 0, 0, 0.5); } /* HSL */ button { background-color: hsl(200, 100%, 50%); }

3.2 Propriétés de texte

/* Famille de police */ body { font-family: Arial, sans-serif; } /* Taille */ p { font-size: 16px; } /* Graisse */ p { font-weight: bold; } /* Alignement */ h1 { text-align: center; } /* Hauteur de ligne */ p { line-height: 1.6; } /* Ombre portée */ h1 { text-shadow: 2px 2px 4px rgba(0,0,0,0.5); }
Astuce : Pour une meilleure lisibilité, utilisez line-height entre 1.4 et 1.8 pour les paragraphes.

Module 4 : Le Box Model

4.1 Comprendre le Box Model

Chaque élément HTML est une boîte rectangulaire composée de :

  • Content : Le contenu
  • Padding : Espacement intérieur
  • Border : La bordure
  • Margin : Espacement extérieur

4.2 Padding, Border, Margin

/* Padding */ div { padding: 20px; } /* Border */ div { border: 2px solid black; border-radius: 10px; } /* Margin */ div { margin: 20px; } /* Centrer horizontalement */ .center { width: 800px; margin: 0 auto; }

4.3 Box-sizing

/* Recommandé pour tous les éléments */ * { box-sizing: border-box; } /* La largeur inclut padding et border */ .box { box-sizing: border-box; width: 300px; padding: 20px; border: 5px solid black; }
Astuce : Utilisez toujours box-sizing: border-box pour un calcul intuitif des dimensions.

Module 5 : Positionnement

5.1 Display

/* Block */ div { display: block; } /* Inline */ span { display: inline; } /* Inline-block */ button { display: inline-block; } /* None */ .hidden { display: none; }

5.2 Position

/* Relative */ .box { position: relative; top: 20px; left: 30px; } /* Absolute */ .overlay { position: absolute; top: 0; right: 0; } /* Fixed */ .navbar { position: fixed; top: 0; left: 0; right: 0; } /* Sticky */ .sticky-header { position: sticky; top: 0; }

5.3 Z-index

/* Superposition */ .layer-1 { position: relative; z-index: 1; } .layer-2 { position: relative; z-index: 2; }
Important : Pour utiliser z-index, l'élément doit avoir une position autre que static.

Module 6 : Flexbox

6.1 Créer un conteneur Flex

.container { display: flex; }

6.2 Propriétés du conteneur

/* Direction */ .container { flex-direction: row; /* ou column */ } /* Retour à la ligne */ .container { flex-wrap: wrap; } /* Alignement horizontal */ .container { justify-content: center; /* flex-start, flex-end, space-between, space-around */ } /* Alignement vertical */ .container { align-items: center; /* flex-start, flex-end, stretch, baseline */ }

6.3 Propriétés des enfants

/* Flex */ .item { flex: 1; /* flex-grow, flex-shrink, flex-basis */ } /* Alignement individuel */ .item { align-self: flex-start; }
Astuce : Pour centrer parfaitement : display: flex + justify-content: center + align-items: center.

Module 7 : CSS Grid

7.1 Créer une grille

.container { display: grid; }

7.2 Définir les colonnes et lignes

/* Colonnes */ .grid { grid-template-columns: 1fr 1fr 1fr; /* ou repeat(3, 1fr) */ } /* Responsive */ .grid { grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); } /* Espacement */ .grid { gap: 20px; }

7.3 Placement des éléments

/* Grid-column */ .item { grid-column: 1 / 3; grid-row: span 2; } /* Grid-area */ .container { grid-template-areas: "header header" "sidebar content" "footer footer"; } .header { grid-area: header; }
Différence : Flexbox = 1D (ligne OU colonne), Grid = 2D (lignes ET colonnes).

Module 8 : Responsive Design

8.1 Meta Viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">

8.2 Media Queries

/* Mobile First */ .container { width: 100%; } /* Tablette */ @media (min-width: 768px) { .container { width: 750px; } } /* Desktop */ @media (min-width: 1024px) { .container { width: 960px; } }

8.3 Images responsive

img { max-width: 100%; height: auto; }
Astuce : Mobile First recommandé : commencez par mobile, puis ajoutez pour écrans plus grands.

Module 9 : Transitions CSS

9.1 Syntaxe de base

/* Transition simple */ button { background-color: blue; transition: background-color 0.3s ease; } button:hover { background-color: red; } /* Plusieurs propriétés */ .card { transition: transform 0.3s, box-shadow 0.3s; } .card:hover { transform: translateY(-10px); box-shadow: 0 10px 30px rgba(0,0,0,0.2); }
Performance : Privilégiez transform et opacity pour de meilleures performances.

Module 10 : Animations CSS

10.1 Keyframes

/* Définir l'animation */ @keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } } /* Appliquer */ .element { animation: fadeIn 1s ease-in-out; }

10.2 Animations courantes

/* Rotation infinie */ @keyframes rotate { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } .spinner { animation: rotate 1s linear infinite; } /* Bounce */ @keyframes bounce { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-20px); } }
Astuce : Utilisez animation-fill-mode: forwards pour garder le dernier état.

Module 11 : Transformations CSS

11.1 Transformations 2D

/* Translate (déplacement) */ .element { transform: translate(50px, 100px); } /* Scale (mise à l'échelle) */ .element { transform: scale(1.5); } /* Rotate (rotation) */ .element { transform: rotate(45deg); } /* Skew (inclinaison) */ .element { transform: skew(20deg, 10deg); } /* Combinaison */ .element { transform: translate(50px, 0) rotate(45deg) scale(1.2); }

11.2 Centrage parfait

.center { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
Performance : Transform est très performant, utilisez-le plutôt que top/left/margin.

Module 12 : Pseudo-classes et Pseudo-éléments

12.1 Pseudo-classes

/* Interaction */ a:hover { color: red; } button:active { transform: scale(0.95); } input:focus { border-color: blue; } /* Structure */ li:first-child { font-weight: bold; } li:last-child { margin-bottom: 0; } tr:nth-child(odd) { background: #f0f0f0; } /* État */ input:checked { border-color: green; } input:disabled { opacity: 0.5; } input:valid { border-color: green; } input:invalid { border-color: red; }

12.2 Pseudo-éléments

/* ::before et ::after */ .element::before { content: "→ "; color: blue; } .element::after { content: " ←"; color: red; } /* ::first-letter */ p::first-letter { font-size: 2em; font-weight: bold; } /* ::selection */ ::selection { background-color: yellow; color: black; }
Astuce : Les pseudo-éléments ::before et ::after nécessitent toujours la propriété content.

Module 13 : Variables CSS

13.1 Déclarer et utiliser

/* Déclarer */ :root { --primary-color: #3498db; --spacing: 20px; --border-radius: 10px; } /* Utiliser */ button { background-color: var(--primary-color); padding: var(--spacing); border-radius: var(--border-radius); } /* Fallback */ .element { color: var(--text-color, #333); }

13.2 Thème sombre/clair

/* Thème clair */ :root { --bg-color: #ffffff; --text-color: #333333; } /* Thème sombre */ [data-theme="dark"] { --bg-color: #1a1a1a; --text-color: #ffffff; } body { background-color: var(--bg-color); color: var(--text-color); }
Astuce : Les variables CSS facilitent la création de systèmes de design cohérents.

Module 14 : Optimisation et Bonnes Pratiques

14.1 Nomenclature BEM

/* Block Element Modifier */ .card { } .card__header { } .card__title { } .card--featured { } .card__title--centered { }

14.2 Sélecteurs performants

/* ÉVITER */ div.container div.content ul li a { color: blue; } /* MIEUX */ .nav-link { color: blue; }

14.3 Checklist

  • Sélecteurs simples et efficaces
  • Éviter !important
  • Transform et opacity pour animations
  • Variables CSS pour cohérence
  • Approche Mobile First
  • Minifier en production
  • Commenter le code complexe
Règle d'or : Code simple, maintenable et performant avant tout.
