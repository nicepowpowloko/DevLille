La Destructuration

Tableaux · Objets · Renommage · Valeurs par defaut · Imbriquee

01

Pourquoi ca existe

La destructuration est une syntaxe qui permet d'extraire des valeurs d'un tableau ou d'un objet et de les affecter directement a des variables, en une seule ligne.

C'est fondamental en JS moderne : React, les APIs, Node.js — tu la retrouves partout. Sans elle, le code devient verbeux et difficile a lire.

02

Avant / Apres

Avant — sans destructuration

avant.js 
const user = {
  nom: "Alice",
  age: 28,
  ville: "Lyon"
};

// Recuperer chaque propriete separement
const nom   = user.nom;
const age   = user.age;
const ville = user.ville;

console.log(nom, age, ville);
// "Alice" 28 "Lyon"

Apres — avec destructuration

apres.js 
const user = {
  nom: "Alice",
  age: 28,
  ville: "Lyon"
};

// Tout en une seule ligne
const { nom, age, ville } = user;

console.log(nom, age, ville);
// "Alice" 28 "Lyon"
03

Les deux formes

Destructuration d'objet

Utilise des accolades { }. On extrait par le nom des proprietes.

Destructuration de tableau

Utilise des crochets [ ]. On extrait par la position (index).

01

Principe de base

Avec un tableau, la destructuration extrait les valeurs selon leur position. Le premier crochet = index 0, le deuxieme = index 1, etc.

tableau-base.js 
const couleurs = ["rouge", "vert", "bleu"];

// Sans destructuration
const c1 = couleurs[0]; // "rouge"
const c2 = couleurs[1]; // "vert"

// Avec destructuration — tu choisis le nom librement
const [premiere, deuxieme, troisieme] = couleurs;

console.log(premiere);  // "rouge"
console.log(deuxieme);  // "vert"
console.log(troisieme); // "bleu"
02

Ignorer des elements

ignorer.js 
const scores = [100, 85, 70, 60, 45];

// On ne recupere que le 1er et le 3eme
// Une virgule vide = on saute cet element
const [premier, , troisieme] = scores;

console.log(premier);   // 100
console.log(troisieme); // 70
03

Le rest operator — ...rest

Le ... (spread/rest) permet de capturer tous les elements restants dans un nouveau tableau. Il doit toujours etre en dernier.

rest-tableau.js 
const equipe = ["Alice", "Bob", "Clara", "David", "Eve"];

// Premier = capitaine, le reste = membres
const [capitaine, adjoint, ...membres] = equipe;

console.log(capitaine); // "Alice"
console.log(adjoint);   // "Bob"
console.log(membres);   // ["Clara", "David", "Eve"]
04

Valeur par defaut dans un tableau

defaut-tableau.js 
const coords = [48.85, 2.35];

// altitude n'existe pas dans le tableau → on lui donne 0 par defaut
const [lat, lng, altitude = 0] = coords;

console.log(lat);      // 48.85
console.log(lng);      // 2.35
console.log(altitude); // 0 (valeur par defaut)
Bon a savoir
La valeur par defaut ne s'applique que si la valeur est undefined. Si la valeur est null ou 0, la valeur par defaut n'est PAS utilisee.
05

Echanger deux variables

L'un des cas d'usage les plus elegants : permuter deux variables sans variable temporaire.

swap.js 
let a = 1;
let b = 2;

// Avant : besoin d'une variable temporaire
let temp = a;
a = b;
b = temp;

// Apres : une seule ligne avec la destructuration
[a, b] = [b, a];

console.log(a); // 2
console.log(b); // 1
01

Principe de base

Avec un objet, la destructuration extrait par le nom de la propriete. L'ordre n'a aucune importance — contrairement aux tableaux.

objet-base.js 
const produit = {
  nom:       "Clavier Razer",
  prix:      149,
  categorie: "peripherique",
  stock:     42
};

// On extrait seulement ce dont on a besoin
const { nom, prix } = produit;

console.log(nom);  // "Clavier Razer"
console.log(prix); // 149

// L'ordre n'a pas d'importance
const { stock, categorie, nom: n } = produit;
02

Destructuration dans les parametres de fonction

L'un des usages les plus courants en pratique : destructurer directement dans la signature de la fonction. Ca evite d'ecrire user.nom, user.age... partout dans le corps.

param-fonction.js 
// Avant — on recoit l'objet entier et on accede aux props
function afficherUser(user) {
  console.log(user.nom, user.age, user.email);
}

// Apres — on destructure directement dans les parametres
function afficherUser({ nom, age, email }) {
  console.log(nom, age, email);
}

const user = { nom: "Bob", age: 32, email: "bob@mail.fr" };
afficherUser(user); // "Bob" 32 "bob@mail.fr"

// Tres courant en React pour les props de composant
function Bouton({ label, onClick, disabled = false }) {
  // label, onClick et disabled sont directement accessibles
}
Contexte React
En React, toutes les props arrivent dans un objet. Destructurer dans les parametres est la convention standard : function Card({ title, content, isActive })
03

Le rest operator avec un objet

rest-objet.js 
const config = {
  host:     "localhost",
  port:     3000,
  debug:    true,
  timeout:  5000,
  retries:  3
};

// On extrait host et port, le reste va dans "options"
const { host, port, ...options } = config;

console.log(host);    // "localhost"
console.log(port);    // 3000
console.log(options); // { debug: true, timeout: 5000, retries: 3 }
01

Renommer une variable

Par defaut, la variable cree porte le meme nom que la propriete. Mais on peut renommer avec les deux-points : pour eviter les conflits ou pour plus de clarte.

renommage.js 
const apiResponse = {
  user_name:   "alice_dev",
  user_email:  "alice@dev.fr",
  created_at:  "2024-01-15"
};

// Syntaxe : propriete: nouveauNom
const {
  user_name:  username,
  user_email: email,
  created_at: dateCreation
} = apiResponse;

// Les variables s'appellent username, email, dateCreation
// user_name, user_email, created_at n'existent PAS
console.log(username);     // "alice_dev"
console.log(email);        // "alice@dev.fr"
console.log(dateCreation); // "2024-01-15"
Piege classique
Apres un renommage, la variable originale (user_name) n'existe pas. Seul le nouveau nom (username) est accessible. Essayer d'utiliser l'ancien nom provoque une ReferenceError.
02

Valeurs par defaut

On peut definir une valeur de secours avec = qui s'applique uniquement si la propriete est undefined. Tres utile pour rendre le code robuste face a des donnees incompletes.

valeur-defaut.js 
const settings = {
  theme: "dark",
  lang:  "fr"
  // fontSize n'est pas presente dans l'objet
};

const {
  theme    = "light",   // existe → "dark" (pas la valeur par defaut)
  lang     = "en",     // existe → "fr" (pas la valeur par defaut)
  fontSize = 16        // absent → 16 (valeur par defaut utilisee)
} = settings;

console.log(theme);    // "dark"
console.log(lang);     // "fr"
console.log(fontSize); // 16
03

Renommage + Valeur par defaut combine

On peut combiner les deux : renommer ET donner une valeur par defaut en meme temps. La syntaxe : propriete: nouveauNom = valeurDefaut

combo.js 
const data = {
  user_id: 42
  // user_role absent
};

const {
  user_id:   id             = 0,
  user_role: role           = "visiteur",
  user_name: nom            = "Anonyme"
} = data;

console.log(id);   // 42
console.log(role); // "visiteur"  (absent → valeur par defaut)
console.log(nom);  // "Anonyme"   (absent → valeur par defaut)
Recap syntaxe
{ prop } — extraction simple
{ prop: nouveauNom } — renommage
{ prop = defaut } — valeur par defaut
{ prop: nouveauNom = defaut } — les deux combines
01

Destructuration imbriquee d'objet

Quand une propriete contient elle-meme un objet, on peut descendre dans la structure en imbriquant les accolades. Tres courant avec les reponses d'API.

imbrique-objet.js 
// Structure typique d'une reponse API
const utilisateur = {
  id:   1,
  nom:  "Alice",
  adresse: {
    ville:       "Lyon",
    codePostal:  "69001",
    pays:        "France"
  },
  preferences: {
    theme:       "dark",
    notifications: true
  }
};

// On destructure en une seule expression
const {
  nom,
  adresse: { ville, codePostal },
  preferences: { theme }
} = utilisateur;

console.log(nom);         // "Alice"
console.log(ville);       // "Lyon"
console.log(codePostal);  // "69001"
console.log(theme);       // "dark"

// Attention : "adresse" et "preferences" ne sont PAS des variables
// On n'a extrait que ce qui est entre les accolades imbriquees
Piege important
Apres une destructuration imbriquee { adresse: { ville } }, la variable adresse n'existe PAS. Seul ville existe. Si tu veux aussi garder l'objet complet, il faut le declarer separement.

Objets dans un tableau

objets-dans-tableau.js 
const users = [
  { id: 1, nom: "Alice", role: "admin" },
  { id: 2, nom: "Bob",   role: "user"  }
];

// Destructuration du premier element du tableau
const [{ nom: premierNom, role: premierRole }] = users;

console.log(premierNom);  // "Alice"
console.log(premierRole); // "admin"

// Dans un .map() → tres courant avec les donnees d'API
users.map(({ id, nom }) => {
  console.log(`User #${id} : ${nom}`);
});
01

Avec fetch et une API

La destructuration prend tout son sens quand on recoit des donnees d'une API. On extrait exactement ce dont on a besoin, en renommant si necesaire, et on garde le reste accessible.

fetch-destructure.js 
async function afficherProfil(username) {
  const response = await fetch(`https://api.github.com/users/${username}`);
  const data     = await response.json();

  // Sans destructuration — verbeux
  // console.log(data.name, data.bio, data.public_repos, data.followers)

  // Avec destructuration + renommage + valeur par defaut
  const {
    name:         nom,
    bio           = "Pas de bio renseignee",
    public_repos: nbRepos,
    followers,
    company       = "Independant",
    location      = "Localisation inconnue"
  } = data;

  console.log("Nom      :", nom);
  console.log("Bio      :", bio);
  console.log("Repos    :", nbRepos);
  console.log("Followers:", followers);
  console.log("Societe  :", company);
  console.log("Lieu     :", location);
}

afficherProfil("torvalds");
02

Dans un .map() — pattern tres courant

map-destructure.js 
const produits = [
  { id: 1, nom: "Souris",  prix: 59,  stock: 12 },
  { id: 2, nom: "Clavier", prix: 149, stock: 0  },
  { id: 3, nom: "Casque",  prix: 99,  stock: 5  }
];

// On destructure directement dans le callback du .map()
const labels = produits.map(({ nom, prix, stock }) => {
  const dispo = stock > 0 ? "disponible" : "rupture";
  return `${nom} — ${prix}EUR (${dispo})`;
});

console.log(labels);
// ["Souris — 59EUR (disponible)", "Clavier — 149EUR (rupture)", ...]

// Meme chose avec .filter()
const enStock = produits.filter(({ stock }) => stock > 0);
console.log(enStock); // Souris et Casque
03

Retourner plusieurs valeurs d'une fonction

retour-multiple.js 
// Une fonction ne peut retourner qu'une valeur
// Astuce : retourner un objet ou un tableau et le destructurer

function calculerStats(notes) {
  const total   = notes.reduce((acc, n) => acc + n, 0);
  const moyenne = total / notes.length;
  const min     = Math.min(...notes);
  const max     = Math.max(...notes);

  return { total, moyenne, min, max };
}

// On recoit les 4 valeurs en une ligne
const { moyenne, min, max } = calculerStats([14, 17, 9, 12, 18]);

console.log("Moyenne :", moyenne); // 14
console.log("Min :", min);         // 9
console.log("Max :", max);         // 18

Correction

A lire seulement apres avoir essaye
Essaie d'abord par toi-meme. Les erreurs que tu vas faire sont plus instructives que la correction elle-meme.
correction.js 
async function getProfilComplet(userId) {
  try {

    // BONUS : les deux fetch en parallele avec Promise.all
    const [userRes, postsRes] = await Promise.all([
      fetch(`https://jsonplaceholder.typicode.com/users/${userId}`),
      fetch(`https://jsonplaceholder.typicode.com/posts?userId=${userId}`)
    ]);

    // Conversion JSON en parallele aussi
    const [userData, postsData] = await Promise.all([
      userRes.json(),
      postsRes.json()
    ]);

    // Destructuration avec renommage + imbriquee + valeur par defaut
    const {
      name:    nomComplet,
      email,
      phone,
      website = "non renseigne",
      address: { city: ville }
    } = userData;

    // Destructuration dans le .map()
    const posts = postsData.map(({ title, body }) => ({ title, body }));

    // Affichage
    console.log("Nom     :", nomComplet);
    console.log("Email   :", email);
    console.log("Ville   :", ville);
    console.log("Site    :", website);
    console.log("Posts   :", posts.length, "articles");
    console.log("Titre 1 :", posts[0].title);

  } catch (err) {
    console.error("Erreur :", err.message);
  }
}

getProfilComplet(1);
