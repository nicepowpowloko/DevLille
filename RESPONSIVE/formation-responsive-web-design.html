Introduction au Responsive Web Design

Qu'est-ce que le Responsive Web Design ?

Le Responsive Web Design (RWD) est une approche de conception web qui permet à un site de s'adapter automatiquement à différentes tailles d'écran et résolutions. L'objectif est d'offrir une expérience utilisateur optimale sur tous les appareils : ordinateurs de bureau, tablettes et smartphones.

Statistiques importantes

  • Plus de 60% du trafic web provient d'appareils mobiles
  • Google privilégie les sites mobile-first dans son indexation
  • 75% des utilisateurs jugent la crédibilité d'une entreprise sur la qualité de son site mobile

Les trois piliers du Responsive Design

  1. Grilles fluides (Fluid Grids) : Utilisation de pourcentages plutôt que de pixels fixes
  2. Images flexibles (Flexible Images) : Images qui s'adaptent à leur conteneur
  3. Media Queries : Règles CSS conditionnelles selon les caractéristiques de l'appareil

Approches du design responsive

Mobile First

Conception en partant des petits écrans vers les grands écrans. C'est l'approche recommandée aujourd'hui.

Avantages :
  • Meilleure performance sur mobile
  • Priorisation du contenu essentiel
  • Meilleur pour le SEO

Desktop First

Conception en partant des grands écrans vers les petits écrans (approche traditionnelle).

Concepts Fondamentaux

Unités relatives vs absolues

Unités absolues (à éviter pour le responsive)

/* Unités fixes - NON responsive */ .container { width: 960px; /* Pixels fixes */ height: 500px; font-size: 16px; }

Unités relatives (recommandées)

/* Unités relatives - RESPONSIVE */ .container { width: 80%; /* Pourcentage du parent */ max-width: 1200px; /* Limite maximale */ font-size: 1rem; /* Relatif à la taille de police racine */ padding: 2em; /* Relatif à la taille de police de l'élément */ margin: 5vw; /* 5% de la largeur du viewport */ }

Tableau des unités CSS

Unité Description Utilisation
% Pourcentage du parent Largeurs, hauteurs, marges
em Relatif à la taille de police de l'élément Paddings, marges, espacements
rem Relatif à la taille de police racine (html) Tailles de police, espacements globaux
vw 1% de la largeur du viewport Largeurs fluides, typographie responsive
vh 1% de la hauteur du viewport Sections pleine hauteur
vmin 1% de la plus petite dimension du viewport Éléments proportionnels
vmax 1% de la plus grande dimension du viewport Éléments proportionnels

Exemple pratique : Comparaison des unités

/* html { font-size: 16px; } par défaut */ .element1 { font-size: 16px; /* Toujours 16px */ } .element2 { font-size: 1rem; /* 16px (relatif à html) */ } .element3 { font-size: 1em; /* 16px si le parent = 16px */ } /* 32px si le parent = 32px */ .element4 { font-size: 2vw; /* Sur écran 1920px = 38.4px */ } /* Sur écran 375px = 7.5px */

Le Viewport et la Meta Tag

Qu'est-ce que le viewport ?

Le viewport est la zone visible de la page web dans le navigateur. Sans configuration appropriée, les sites s'affichent mal sur mobile.

Important !

Sans la balise viewport, les navigateurs mobiles affichent la page comme sur un écran de bureau (généralement 980px) et la réduisent pour qu'elle tienne dans l'écran.

La balise meta viewport (OBLIGATOIRE)

<!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mon site responsive</title> </head>

Attributs de la meta viewport

Attribut Description Valeurs
width Largeur du viewport device-width (recommandé) ou valeur en pixels
initial-scale Niveau de zoom initial 1.0 (recommandé, pas de zoom)
minimum-scale Zoom minimum autorisé 0.5 à 1.0
maximum-scale Zoom maximum autorisé 1.0 à 10.0
user-scalable Autoriser le zoom utilisateur yes (recommandé) ou no

Accessibilité

N'utilisez JAMAIS user-scalable=no ou maximum-scale=1.0 car cela empêche les utilisateurs malvoyants de zoomer sur votre contenu.

Les Media Queries

Qu'est-ce qu'une Media Query ?

Les Media Queries permettent d'appliquer des styles CSS spécifiques selon les caractéristiques de l'appareil (taille d'écran, orientation, résolution, etc.).

Syntaxe de base

/* Syntaxe générale */ @media type-de-media and (caractéristique: valeur) { /* Règles CSS */ }

Types de media

  • screen : Écrans (ordinateurs, tablettes, smartphones) - Le plus utilisé
  • print : Impression
  • all : Tous les types (valeur par défaut)

Caractéristiques principales

Caractéristique Description Exemple
width Largeur exacte du viewport width: 768px
min-width Largeur minimale min-width: 768px
max-width Largeur maximale max-width: 767px
height Hauteur du viewport height: 600px
orientation Portrait ou paysage orientation: landscape
aspect-ratio Ratio largeur/hauteur aspect-ratio: 16/9

Breakpoints standards

Points de rupture recommandés

  • Mobile : 320px à 480px
  • Tablette portrait : 481px à 768px
  • Tablette paysage : 769px à 1024px
  • Desktop : 1025px à 1200px
  • Large desktop : 1201px et plus

Approche Mobile First (Recommandée)

/* Mobile First : on part du mobile vers le desktop */ /* Styles de base pour mobile (320px et plus) */ .container { width: 100%; padding: 15px; font-size: 14px; } .menu { display: none; /* Menu caché par défaut sur mobile */ } .menu-button { display: block; /* Bouton burger visible */ } /* Tablette (768px et plus) */ @media screen and (min-width: 768px) { .container { width: 90%; padding: 20px; font-size: 16px; } .menu { display: flex; /* Menu visible */ } .menu-button { display: none; /* Bouton burger caché */ } } /* Desktop (1024px et plus) */ @media screen and (min-width: 1024px) { .container { width: 80%; max-width: 1200px; padding: 30px; font-size: 18px; } } /* Large Desktop (1440px et plus) */ @media screen and (min-width: 1440px) { .container { max-width: 1400px; } }

Approche Desktop First

/* Desktop First : on part du desktop vers le mobile */ /* Styles de base pour desktop */ .container { width: 80%; max-width: 1200px; padding: 30px; font-size: 18px; } .menu { display: flex; } .menu-button { display: none; } /* Tablette (max 1023px) */ @media screen and (max-width: 1023px) { .container { width: 90%; padding: 20px; font-size: 16px; } } /* Mobile (max 767px) */ @media screen and (max-width: 767px) { .container { width: 100%; padding: 15px; font-size: 14px; } .menu { display: none; } .menu-button { display: block; } }

Opérateurs logiques

/* AND : Combine plusieurs conditions */ @media screen and (min-width: 768px) and (max-width: 1024px) { /* Styles pour tablettes uniquement */ } /* OR : Avec une virgule */ @media screen and (max-width: 480px), screen and (orientation: portrait) { /* Mobile OU orientation portrait */ } /* NOT : Inverse la condition */ @media not screen and (min-width: 1024px) { /* Tous les appareils SAUF desktop */ }

Exemples pratiques

Exemple 1 : Grille responsive

/* Grille qui s'adapte */ .grid { display: grid; grid-template-columns: 1fr; /* 1 colonne sur mobile */ gap: 20px; } /* 2 colonnes sur tablette */ @media screen and (min-width: 768px) { .grid { grid-template-columns: repeat(2, 1fr); } } /* 3 colonnes sur desktop */ @media screen and (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } } /* 4 colonnes sur grand écran */ @media screen and (min-width: 1440px) { .grid { grid-template-columns: repeat(4, 1fr); } }

Exemple 2 : Orientation

/* Mode portrait (hauteur > largeur) */ @media screen and (orientation: portrait) { .hero { height: 50vh; } .sidebar { display: none; } } /* Mode paysage (largeur > hauteur) */ @media screen and (orientation: landscape) { .hero { height: 80vh; } .sidebar { display: block; } }

Exemple 3 : Navigation responsive

/* Navigation mobile */ .nav { display: flex; flex-direction: column; position: fixed; top: 0; left: -100%; width: 80%; height: 100vh; background: #333; transition: left 0.3s; } .nav.active { left: 0; } .nav-toggle { display: block; font-size: 24px; } /* Navigation desktop */ @media screen and (min-width: 768px) { .nav { position: static; flex-direction: row; width: auto; height: auto; left: 0; } .nav-toggle { display: none; } }

Layouts Responsive

1. Flexbox pour le responsive

Flexbox est parfait pour créer des layouts adaptatifs en une dimension (ligne ou colonne).

/* Container flexible */ .flex-container { display: flex; flex-wrap: wrap; /* Permet le retour à la ligne */ gap: 20px; } /* Items flexibles */ .flex-item { flex: 1 1 300px; /* grow shrink basis */ /* L'item grandit, rétrécit, et a une base de 300px */ } /* Exemple : 3 colonnes qui deviennent 1 colonne sur mobile */ @media screen and (max-width: 768px) { .flex-item { flex: 1 1 100%; /* Prend toute la largeur */ } }

2. CSS Grid pour le responsive

CSS Grid est idéal pour les layouts complexes en deux dimensions.

/* Grid responsive avec auto-fit */ .grid-container { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; } /* Grid avec zones nommées */ .layout { display: grid; grid-template-areas: "header header" "sidebar main" "footer footer"; gap: 20px; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .footer { grid-area: footer; } /* Sur mobile : tout en colonne */ @media screen and (max-width: 768px) { .layout { grid-template-areas: "header" "main" "sidebar" "footer"; } }

3. Layout classique responsive

Template complet mobile-first

/* Structure HTML suggérée : <div class="page-container"> <header class="header">...</header> <nav class="nav">...</nav> <main class="main-content">...</main> <aside class="sidebar">...</aside> <footer class="footer">...</footer> </div> */ /* Mobile First */ .page-container { display: grid; grid-template-areas: "header" "nav" "main" "sidebar" "footer"; min-height: 100vh; } .header { grid-area: header; padding: 20px; } .nav { grid-area: nav; padding: 10px; } .main-content { grid-area: main; padding: 20px; } .sidebar { grid-area: sidebar; padding: 20px; } .footer { grid-area: footer; padding: 20px; } /* Tablette : sidebar à côté du contenu */ @media screen and (min-width: 768px) { .page-container { grid-template-areas: "header header" "nav nav" "main sidebar" "footer footer"; grid-template-columns: 2fr 1fr; } } /* Desktop : nav horizontale */ @media screen and (min-width: 1024px) { .page-container { grid-template-areas: "header header header" "nav nav nav" "main main sidebar" "footer footer footer"; grid-template-columns: 1fr 1fr 300px; max-width: 1400px; margin: 0 auto; } }

4. Container queries (Moderne)

Les container queries permettent de styler un élément en fonction de la taille de son conteneur parent (et non du viewport).

/* Définir un container */ .card-container { container-type: inline-size; container-name: card; } /* Query sur le container */ @container card (min-width: 400px) { .card { display: flex; flex-direction: row; } } @container card (max-width: 399px) { .card { display: flex; flex-direction: column; } }

Compatibilité

Les container queries sont supportées par les navigateurs modernes (Chrome 105+, Firefox 110+, Safari 16+). Vérifiez la compatibilité sur caniuse.com

Images Responsive

1. Images fluides de base

/* Rendre toutes les images fluides */ img { max-width: 100%; height: auto; display: block; } /* Alternative avec object-fit */ img { width: 100%; height: 300px; object-fit: cover; /* ou contain, fill, none, scale-down */ }

2. L'élément <picture>

L'élément <picture> permet de fournir différentes versions d'une image selon la taille d'écran ou la résolution.

<picture> <!-- Image pour grand écran --> <source media="(min-width: 1024px)" srcset="image-large.jpg"> <!-- Image pour tablette --> <source media="(min-width: 768px)" srcset="image-medium.jpg"> <!-- Image par défaut (mobile) --> <img src="image-small.jpg" alt="Description"> </picture>

3. L'attribut srcset

L'attribut srcset permet au navigateur de choisir l'image la plus appropriée selon la résolution de l'écran.

<!-- Selon la largeur --> <img src="image-400.jpg" srcset="image-400.jpg 400w, image-800.jpg 800w, image-1200.jpg 1200w" sizes="(max-width: 600px) 100vw, (max-width: 1000px) 50vw, 33vw" alt="Description"> <!-- Selon la densité de pixels --> <img src="image.jpg" srcset="image.jpg 1x, image@2x.jpg 2x, image@3x.jpg 3x" alt="Description">

4. Images d'arrière-plan responsive

/* CSS pour images d'arrière-plan adaptatives */ .hero { background-image: url('hero-mobile.jpg'); background-size: cover; background-position: center; height: 50vh; } @media screen and (min-width: 768px) { .hero { background-image: url('hero-tablet.jpg'); height: 60vh; } } @media screen and (min-width: 1024px) { .hero { background-image: url('hero-desktop.jpg'); height: 70vh; } } @media screen and (min-width: 1440px) { .hero { background-image: url('hero-large.jpg'); height: 80vh; } }

5. Format WebP moderne

<picture> <!-- Format moderne WebP --> <source type="image/webp" srcset="image.webp"> <!-- Format de secours --> <img src="image.jpg" alt="Description"> </picture>

6. Lazy Loading

Le lazy loading permet de charger les images uniquement quand elles sont visibles, améliorant les performances.

<!-- Lazy loading natif --> <img src="image.jpg" alt="Description" loading="lazy"> <!-- Pour les iframes aussi --> <iframe src="video.html" loading="lazy"></iframe>

Bonnes pratiques pour les images

  • Toujours définir max-width: 100% sur les images
  • Utiliser height: auto pour conserver les proportions
  • Optimiser les images avant de les uploader (compression)
  • Fournir plusieurs tailles avec srcset
  • Utiliser le format WebP quand c'est possible
  • Toujours inclure un attribut alt descriptif
  • Utiliser lazy loading pour les images en dessous de la ligne de flottaison

Typographie Responsive

1. Tailles de police fluides

Méthode avec rem

/* Définir la base dans html */ html { font-size: 16px; /* Taille de base */ } /* Mobile */ body { font-size: 1rem; /* 16px */ line-height: 1.6; } h1 { font-size: 2rem; } /* 32px */ h2 { font-size: 1.75rem; } /* 28px */ h3 { font-size: 1.5rem; } /* 24px */ /* Tablette */ @media screen and (min-width: 768px) { html { font-size: 18px; /* Toutes les valeurs en rem augmentent */ } } /* Desktop */ @media screen and (min-width: 1024px) { html { font-size: 20px; } }

Méthode avec vw (viewport width)

/* Taille fluide basée sur la largeur du viewport */ h1 { font-size: calc(1.5rem + 2vw); /* Sur mobile 375px : ~24px */ /* Sur desktop 1920px : ~62px */ } /* Avec limites min et max */ h1 { font-size: clamp(1.5rem, 2vw + 1rem, 3rem); /* Minimum : 24px */ /* Fluide : 2vw + 16px */ /* Maximum : 48px */ }

2. La fonction clamp() (Moderne et recommandée)

La fonction clamp() permet de définir une taille fluide avec des limites minimales et maximales.

/* Syntaxe : clamp(MIN, PRÉFÉRÉ, MAX) */ body { font-size: clamp(1rem, 0.9rem + 0.5vw, 1.25rem); /* Min: 16px, Fluide, Max: 20px */ } h1 { font-size: clamp(2rem, 1.5rem + 2vw, 4rem); /* Min: 32px, Fluide, Max: 64px */ } h2 { font-size: clamp(1.5rem, 1.2rem + 1.5vw, 3rem); /* Min: 24px, Fluide, Max: 48px */ } h3 { font-size: clamp(1.25rem, 1rem + 1vw, 2rem); /* Min: 20px, Fluide, Max: 32px */ }

3. Échelle typographique complète

/* Système typographique responsive complet */ :root { --font-size-base: clamp(1rem, 0.9rem + 0.5vw, 1.125rem); --font-size-small: clamp(0.875rem, 0.8rem + 0.3vw, 1rem); --font-size-h1: clamp(2rem, 1.5rem + 2vw, 3.5rem); --font-size-h2: clamp(1.75rem, 1.3rem + 1.5vw, 2.75rem); --font-size-h3: clamp(1.5rem, 1.2rem + 1vw, 2.25rem); --font-size-h4: clamp(1.25rem, 1.1rem + 0.5vw, 1.75rem); } body { font-size: var(--font-size-base); line-height: 1.6; } small, .small { font-size: var(--font-size-small); } h1 { font-size: var(--font-size-h1); } h2 { font-size: var(--font-size-h2); } h3 { font-size: var(--font-size-h3); } h4 { font-size: var(--font-size-h4); }

4. Line-height responsive

/* Line-height adaptatif */ body { line-height: 1.6; /* Mobile : plus compact */ } @media screen and (min-width: 768px) { body { line-height: 1.7; /* Tablette : plus aéré */ } } @media screen and (min-width: 1024px) { body { line-height: 1.8; /* Desktop : maximum lisibilité */ } } /* Ou avec clamp */ p { line-height: clamp(1.5, 1.4 + 0.2vw, 1.8); }

5. Largeur de ligne optimale

Pour une lecture confortable, une ligne devrait contenir entre 50 et 75 caractères.

/* Limiter la largeur du texte */ .content p { max-width: 65ch; /* 65 caractères max */ margin-left: auto; margin-right: auto; } /* Ou avec une valeur en pixels */ .content { max-width: 750px; margin: 0 auto; padding: 0 20px; }

6. Espacements fluides

/* Espacements adaptatifs */ section { padding: clamp(2rem, 5vw, 5rem) clamp(1rem, 3vw, 3rem); margin-bottom: clamp(2rem, 4vw, 4rem); } .card { padding: clamp(1rem, 2vw, 2rem); gap: clamp(0.5rem, 1vw, 1.5rem); }

Bonnes pratiques typographiques

  • Utiliser clamp() pour des tailles fluides avec limites
  • Taille de base minimum : 16px pour le body
  • Contraste minimum : 4.5:1 pour le texte normal
  • Line-height entre 1.5 et 1.8 pour la lisibilité
  • Largeur de ligne maximum : 65-75 caractères
  • Utiliser des polices web-safe ou des Google Fonts

Exercices Pratiques

Exercice 1 : Page d'accueil responsive (Niveau Débutant)

Objectif

Créer une page d'accueil simple qui s'adapte du mobile au desktop.

Consignes

  1. Créer une structure HTML avec :
    • Un header avec logo et navigation
    • Une section hero avec titre et bouton
    • Une section "Services" avec 3 cartes
    • Un footer
  2. Appliquer les styles CSS en Mobile First
  3. Ajouter les breakpoints pour tablette (768px) et desktop (1024px)
  4. Les 3 cartes doivent être :
    • En colonne sur mobile
    • Sur 2 lignes sur tablette
    • Sur une ligne sur desktop

Critères de réussite

  • Meta viewport présente
  • Images fluides (max-width: 100%)
  • Au moins 2 media queries
  • Navigation qui s'adapte
  • Pas de scroll horizontal sur mobile

Exercice 2 : Grille de produits (Niveau Intermédiaire)

Objectif

Créer une grille de produits e-commerce responsive avec CSS Grid.

Consignes

  1. Créer 12 cartes produit avec :
    • Image
    • Titre
    • Prix
    • Bouton "Ajouter au panier"
  2. Utiliser CSS Grid avec auto-fit
  3. Affichage :
    • Mobile (< 768px) : 1 colonne
    • Tablette (768-1023px) : 2 colonnes
    • Desktop (1024-1439px) : 3 colonnes
    • Large (≥ 1440px) : 4 colonnes
  4. Ajouter une barre de recherche responsive

Bonus

  • Ajouter des filtres dans une sidebar qui disparaît sur mobile
  • Effet hover sur les cartes
  • Animation au survol

Exercice 3 : Dashboard responsive (Niveau Avancé)

Objectif

Créer un tableau de bord d'administration avec layouts complexes.

Consignes

  1. Structure :
    • Sidebar de navigation
    • Header avec profil utilisateur
    • Contenu principal avec widgets (stats, graphiques, tableaux)
  2. Comportement :
    • Mobile : Sidebar cachée, menu burger, widgets empilés
    • Tablette : Sidebar réduite (icônes seuls), widgets sur 2 colonnes
    • Desktop : Sidebar complète, widgets sur 3-4 colonnes
  3. Utiliser CSS Grid pour le layout principal
  4. Utiliser Flexbox pour les widgets
  5. Implémenter un menu burger fonctionnel (JavaScript)

Fonctionnalités JavaScript requises

  • Toggle du menu burger
  • Gestion de la sidebar (ouvrir/fermer)
  • Responsive navbar avec dropdown

Exercice 4 : Blog responsive (Niveau Intermédiaire)

Objectif

Créer une page de blog avec articles et sidebar responsive.

Consignes

  1. Layout :
    • Header avec navigation
    • Zone principale pour les articles
    • Sidebar avec catégories et articles populaires
    • Footer avec liens
  2. Articles avec :
    • Image responsive
    • Titre, date, auteur
    • Extrait du texte
    • Bouton "Lire la suite"
  3. Comportement responsive :
    • Mobile : Sidebar en dessous du contenu
    • Tablette : Sidebar à côté (30% de largeur)
    • Desktop : Layout fixe avec max-width
  4. Typographie responsive avec clamp()

Exercice 5 : Galerie d'images (Niveau Débutant)

Objectif

Créer une galerie photo responsive avec lightbox.

Consignes

  1. Créer 16 images dans une grille
  2. Utiliser CSS Grid avec auto-fit
  3. Images :
    • Ratio carré (aspect-ratio: 1/1)
    • Object-fit: cover
    • Transition au survol
  4. Grille responsive :
    • Mobile : 2 colonnes
    • Tablette : 3 colonnes
    • Desktop : 4 colonnes

Bonus

  • Effet de zoom au survol
  • Overlay avec titre au survol
  • Système de filtres par catégorie

Projet Final : Site vitrine complet (Niveau Expert)

Objectif

Créer un site vitrine professionnel multi-pages entièrement responsive.

Pages à créer

  1. Accueil : Hero, services, témoignages, CTA
  2. À propos : Timeline, équipe, valeurs
  3. Services : Grille de services détaillés
  4. Portfolio : Galerie filtrée de projets
  5. Blog : Liste d'articles avec pagination
  6. Contact : Formulaire + carte Google Maps

Contraintes techniques

  • Mobile First obligatoire
  • Au moins 4 breakpoints différents
  • Navigation responsive avec menu burger
  • Images optimisées avec srcset et formats WebP
  • Typographie fluide avec clamp()
  • Formulaire de contact validé
  • Animations CSS (transitions, transforms)
  • Performance : Lighthouse score > 90
  • Accessibilité : Validation WCAG niveau AA

Checklist responsive

Avant de livrer un projet responsive

  1. Meta viewport présente et correcte
  2. Aucun scroll horizontal sur mobile
  3. Images optimisées et fluides
  4. Tailles de police lisibles (min 16px)
  5. Zones cliquables suffisamment grandes (min 44x44px)
  6. Navigation utilisable sur mobile
  7. Formulaires ergonomiques sur mobile
  8. Test sur Chrome, Firefox, Safari
  9. Test sur vraies appareils si possible
  10. Validation W3C HTML et CSS
  11. Score Lighthouse > 90
  12. Accessibilité vérifiée (contraste, focus)

Pièges courants à éviter

Erreurs fréquentes

  • Oublier la meta viewport
  • Utiliser des largeurs fixes en pixels
  • Ne pas tester sur de vrais appareils
  • Tailles de police trop petites sur mobile
  • Boutons/liens trop petits pour être cliqués
  • Images non optimisées (poids trop lourd)
  • Utiliser max-width au lieu de min-width en mobile-first
  • Négliger l'accessibilité
