00
Préparation

Le plan — ce qu'on va construire

Avant de coder, on réfléchit à l'architecture. Un Whack-a-Mole c'est une grille 3×3 de trous où des taupes apparaissent aléatoirement. On clique dessus pour marquer des points. On a 30 secondes. On découpe ça en 4 composants :

App ← STATE : grille, score, temps, enCours, meilleurScore │ ← REFS : intervalMole, intervalTimer ├── StatusBar ← affiche score / timer / record │ props: score, temps, meilleurScore │ ├── Grid ← la grille 3×3 │ props: grille[], onFrappe │ └── Taupe × 9 ← chaque trou (vide ou taupe) │ props: active, onFrappe │ └── BoutonStart ← démarrer / abandonner props: enCours, onToggle
ℹ️
useRef pour les intervals. Les IDs de setInterval doivent survivre aux re-renders sans en déclencher de nouveaux. C'est exactement le rôle de useRef : stocker une valeur mutable sans provoquer de re-render quand elle change.

La grille c'est un tableau de 9 booléens :

Structure des données
// La grille = tableau de 9 booléens
// false = trou vide, true = taupe visible
const grille = [
    false, false, true,   // ligne du haut   → index 0, 1, 2
    false, false, false,  // ligne du milieu → index 3, 4, 5
    false, true,  false,  // ligne du bas    → index 6, 7, 8
]

// À tout moment, UNE SEULE taupe est visible
// Visuellement dans la grille :
// [ ][ ][🐭]
// [ ][ ][ ]
// [ ][🐭][ ]
💡
Règle : une seule taupe à la fois. Quand une nouvelle taupe apparaît, on remet toute la grille à false d'abord, puis on active une seule case. C'est simple et ça évite d'avoir à chercher l'ancienne.
01
Étape 1 — Premier composant

La Taupe — un seul trou

On commence par le plus petit composant : un trou. Il reçoit active (booléen — y a-t-il une taupe ?) et onFrappe (la fonction à appeler quand on clique). Le composant est désactivé si le trou est vide.

Taupe.jsxnouveau
// Taupe.jsx
// Props reçues :
//   active   → boolean — taupe visible ou trou vide
//   onFrappe → fonction à appeler au clic

function Taupe({ active, onFrappe }) {
    return (
        <button
            className={`taupe ${active ? 'active' : ''}`}
            onClick={active ? onFrappe : undefined}
            disabled={!active}
        >
            {active ? '🐭' : ''}
        </button>
    )
}

export default Taupe
Ce que ce composant rend
Un <button> circulaire. S'il est active, il affiche 🐭 et répond au clic. Sinon, il est vide et disabled — impossible de "frauder" en cliquant dans le vide.
onClick conditionnel. On écrit onClick={active ? onFrappe : undefined}. On aurait pu aussi utiliser simplement disabled={!active}, mais le onClick conditionnel est un pattern React courant à connaître.
▶
À ce stade : on a un bouton qui affiche une taupe ou rien. Il ne sait pas encore qu'il fait partie d'une grille — c'est le rôle du composant suivant.
02
Étape 2 — Assemblage

La Grille — 9 trous en 3×3

Grid reçoit le tableau de 9 booléens et la fonction onFrappe. Il mappe le tableau pour créer 9 composants Taupe. Il ne contient aucune logique — juste de l'affichage.

Grid.jsxnouveau
// Grid.jsx
// Props reçues :
//   grille   → boolean[] — tableau de 9 cases
//   onFrappe → fonction(index) appelée quand on frappe une taupe

function Grid({ grille, onFrappe }) {
    return (
        <div className="grid">
            {grille.map((active, i) => (
                <Taupe
                    key={i}
                    active={active}
                    onFrappe={() => onFrappe(i)}
                />
            ))}
        </div>
    )
}

export default Grid
ℹ️
() => onFrappe(i) — on encapsule l'appel dans une arrow function pour passer i (l'index de la case). Sans ça, onFrappe serait appelé immédiatement au render sans argument.

Le CSS de la grille utilise grid-template-columns: repeat(3, 1fr) pour créer 3 colonnes égales automatiquement :

App.css — grille 3×3
/* La grille */

}

/* Chaque trou */

    border-radius: 50%;
    background: rgba(255,255,255,.04);
    border: 2px solid #1e2d3d;

}

/* Taupe visible — surbrillance verte */
.taupe.active {

}
▶
À ce stade : la grille 3×3 s'affiche. On peut passer n'importe quel tableau de booléens en prop pour tester l'affichage. Les taupes actives se distinguent visuellement des trous vides.
03
Étape 3 — Le cerveau

Le State dans App — useState et useRef

C'est ici que tout le state du jeu est initialisé. On a besoin de useState pour tout ce qui doit provoquer un re-render à chaque changement, et de useRef pour stocker les IDs des intervals sans déclencher de re-render.

Pourquoi useRef pour les intervals ? Si on stockait l'ID de setInterval dans un useState, chaque mise à jour du state provoquerait un re-render — qui recréerait de nouveaux intervals à l'infini. useRef donne une boîte mutable qui ne déclenche pas de re-render.
App.jsx — état initialnouveau
import { useState, useRef } from 'react'
import Grid from './Grid'

// Fonction utilitaire : crée une grille vide
function grilleVide() {
    return Array(9).fill(false)
}

function App() {
    // ── STATE — déclenche des re-renders ──
    const [grille,        setGrille]        = useState(grilleVide())
    const [score,         setScore]         = useState(0)
    const [temps,         setTemps]         = useState(30)  // 30 secondes
    const [enCours,       setEnCours]       = useState(false)
    const [meilleurScore, setMeilleurScore] = useState(0)

    // ── REFS — muables sans re-render ──
    const intervalMole  = useRef(null)  // ID setInterval des taupes
    const intervalTimer = useRef(null)  // ID setInterval du countdown

    // Pour l'instant — juste afficher
    function frapper(index) {
        console.log('Frappe case :', index)
        // Logique complète à l'étape 4
    }

    return (
        <div className="app">
            <h1>Whack-a-Mole</h1>
            <p>Score : {score} — Temps : {temps}s</p>
            <Grid grille={grille} onFrappe={frapper} />
        </div>
    )
}

export default App
Différence useState / useRef
useState → déclenche un re-render à chaque changement → pour : score, temps, grille, enCours
useRef → boîte mutable silencieuse → pour : IDs d'intervals, valeurs "techniques" dont l'affichage ne dépend pas
▶
À ce stade : la grille s'affiche (vide), le score et le timer sont initialisés. Un clic sur une taupe affiche l'index dans la console. Il n'y a pas encore de logique de jeu.
04
Étape 4 — La mécanique

La logique de jeu

On complète les fonctions démarrer, apparitionTaupe, frapper et arrêter. C'est le cœur du jeu — tout tient dans ces quatre fonctions.

Fonction apparitionTaupe — la mécanique aléatoire
// Fait apparaître une taupe dans un trou aléatoire
function apparitionTaupe() {
    const index = Math.floor(Math.random() * 9)

    setGrille(() => {
        const g = Array(9).fill(false)  // reset tout
        g[index] = true                   // activer une seule case
        return g
    })
}
Fonctions démarrer et arrêter
function démarrer() {
    // 1. Réinitialiser le state
    setScore(0)
    setTemps(30)
    setEnCours(true)
    setGrille(grilleVide())

    // 2. Faire apparaître une taupe toutes les 800ms
    intervalMole.current = setInterval(apparitionTaupe, 800)

    // 3. Décrémenter le timer toutes les secondes
    intervalTimer.current = setInterval(() => {
        setTemps(t => {
            if (t <= 1) {
                arrêter()      // temps écoulé → stop !
                return 0
            }
            return t - 1
        })
    }, 1000)
}

function arrêter() {
    // Stopper les deux intervals
    clearInterval(intervalMole.current)
    clearInterval(intervalTimer.current)

    // Remettre l'interface à l'état initial
    setEnCours(false)
    setGrille(grilleVide())

    // Mettre à jour le meilleur score si battu
    setScore(s => {
        setMeilleurScore(best => Math.max(best, s))
        return s
    })
}
Fonction frapper
function frapper(index) {
    setGrille(prev => {
        // 1. La taupe a peut-être déjà disparu (cas rare mais possible)
        if (!prev[index]) return prev

        // 2. Cacher la taupe frappée
        const g = [...prev]
        g[index] = false
        return g
    })

    // 3. Incrémenter le score
    setScore(s => s + 1)
}
setTemps(t => t - 1) et non setTemps(temps - 1). Dans une closure de setInterval, la variable temps est capturée à sa valeur initiale et ne se met jamais à jour. La forme fonctionnelle t => t - 1 lit toujours la valeur la plus récente — c'est obligatoire ici.
ℹ️
Mise à jour du meilleur score. On utilise setScore(s => { setMeilleurScore(...) ; return s }) pour lire le score final exact au moment où la partie s'arrête — évite le problème de closure stale avec la valeur de score.
🎮
À ce stade : le jeu fonctionne ! Les taupes apparaissent, le timer défile, le score s'incrémente au clic. Il manque juste l'affichage structuré du statut et le bouton start/stop.

Étape 5 — Finitions

StatusBar & Contrôles

On crée le composant StatusBar qui affiche score, temps et record de façon structurée. On ajoute aussi le bouton Démarrer / Abandonner dans App.

StatusBar.jsxnouveau
// StatusBar.jsx
// Props : score (number), temps (number), meilleurScore (number)

function StatusBar({ score, temps, meilleurScore }) {
    // Timer rouge quand il reste 5 secondes ou moins
    const couleurTemps = temps <= 5 ? '#ff7b72' : '#ffa657'

    return (
        <div className="status-bar">

            <div className="stat">
                <span className="stat-label">Score</span>
                <span className="stat-val" style={{ color: '#f7df1e' }}>
                    {score}
                </span>
            </div>

            <div className="stat">
                <span className="stat-label">Temps</span>
                <span className="stat-val" style={{ color: couleurTemps }}>
                    {temps}s
                </span>
            </div>

            <div className="stat">
                <span className="stat-label">Record</span>
                <span className="stat-val" style={{ color: '#44D62C' }}>
                    {meilleurScore}
                </span>
            </div>

        </div>
    )
}

export default StatusBar
App.jsx — avec StatusBar et bouton togglemodifier
import StatusBar from './StatusBar'

function App() {
    // ... (state et refs identiques à l'étape 3)
    // ... (fonctions démarrer, arrêter, frapper de l'étape 4)

    return (
        <div className="app">
            <h1>Whack-a-Mole</h1>

            <StatusBar
                score={score}
                temps={temps}
                meilleurScore={meilleurScore}
            />

            <Grid
                grille={grille}
                onFrappe={frapper}
            />

            {/* Un seul bouton qui change de rôle selon l'état */}
            <button
                className={enCours ? 'btn-stop' : 'btn-start'}
                onClick={enCours ? arrêter : démarrer}
            >
                {enCours ? 'Abandonner' : score > 0 ? 'Rejouer' : 'Démarrer'}
            </button>
        </div>
    )
}
Le jeu est complet ! Les taupes apparaissent aléatoirement, le score monte, le timer se réduit et vire au rouge à 5s, la partie s'arrête automatiquement, le record est conservé en session.

Étape 6 — Bonus avancé

Niveaux de difficulté

Fonctionnalité avancée : ajouter trois niveaux de difficulté qui changent la vitesse d'apparition des taupes. On crée un objet de configuration NIVEAUX et un state niveau.

App.jsx — configuration et sélecteur de niveauversion avancée
// Configuration des niveaux — HORS du composant
const NIVEAUX = {
    facile:    { intervalle: 1200, label: 'Facile '  },
    normal:    { intervalle: 800,  label: 'Normal '  },
    difficile: { intervalle: 500,  label: 'Difficile ' },
}

function App() {
    // ... (autres states)
    const [niveau, setNiveau] = useState('normal')

    function démarrer() {
        const { intervalle } = NIVEAUX[niveau]  // lire la config du niveau actif
        // ... reset state
        intervalMole.current = setInterval(apparitionTaupe, intervalle)
        // ... timer identique
    }

    return (
        <div className="app">
            {/* Sélecteur de niveau — désactivé en cours de partie */}
            <div className="niveau-selector">
                {Object.entries(NIVEAUX).map(([key, { label }]) => (
                    <button
                        key={key}
                        className={`btn-niveau ${niveau === key ? 'actif' : ''}`}
                        onClick={() => setNiveau(key)}
                        disabled={enCours}
                    >
                        {label}
                    </button>
                ))}
            </div>

            {/* ... StatusBar, Grid, bouton Start identiques */}
        </div>
    )
}
Pattern : configuration externe. Externaliser la config dans un objet NIVEAUX hors du composant est une bonne pratique. Ça centralise les valeurs, facilite la maintenance, et évite de recréer l'objet à chaque render.
disabled={enCours} sur les boutons de niveau. On empêche de changer le niveau pendant une partie — ce serait incohérent. Désactiver les boutons avec disabled est plus simple que de gérer ça avec du state ou des conditions.

Version finale — un seul fichier simplifié

Voici le code complet du jeu en un seul fichier React, avec tous les styles en inline. Version condensée pour avoir une vision globale de la structure complète.

WhackAMole.jsx — code complet, un fichier
import { useState, useRef } from 'react'

// ─ Niveaux de difficulté ─/span>
const NIVEAUX = {
    facile:    { intervalle: 1200, label: 'Facile '  },
    normal:    { intervalle: 800,  label: 'Normal '  },
    difficile: { intervalle: 500,  label: 'Difficile ' },
}

// ─ Composant Taupe ─
function Taupe({ active, onFrappe }) {
    return (
        <button
            onClick={active ? onFrappe : undefined}
            style={{
                width: '90px', height: '90px', borderRadius: '50%',
                background: active ? 'rgba(68,214,44,.14)' : 'rgba(255,255,255,.04)',
                border: active ? '2px solid #44D62C' : '2px solid #1e2d3d',
                fontSize: '2.2rem', cursor: active ? 'pointer' : 'default',
                transition: 'all .15s',
                transform: active ? 'scale(1.1)' : 'scale(1)',
                boxShadow: active ? '0 0 16px rgba(68,214,44,.25)' : 'none',
            }}
        >
            {active ? '🐭' : ''}
        </button>
    )
}

// ─ Composant principal ─
export default function WhackAMole() {
    const [grille,        setGrille]        = useState(Array(9).fill(false))
    const [score,setScore]         = useState(0)
    const [temps,setTemps]         = useState(30)
    const [enCours,setEnCours]       = useState(false)
    const [meilleurScore, setMeilleurScore] = useState(0)
    const [niveau,setNiveau]        = useState('normal')

    const intervalMole  = useRef(null)
    const intervalTimer = useRef(null)

    function apparitionTaupe() {
        const i = Math.floor(Math.random() * 9)
        setGrille(() => { const g = Array(9).fill(false); g[i] = true; return g })
    }

    function démarrer() {
        setScore(0); setTemps(30); setEnCours(true)
        setGrille(Array(9).fill(false))
        intervalMole.current  = setInterval(apparitionTaupe, NIVEAUX[niveau].intervalle)
        intervalTimer.current = setInterval(() => {
            setTemps(t => { if (t <= 1) { arrêter(); return 0 }; return t - 1 })
        }, 1000)
    }

    function arrêter() {
        clearInterval(intervalMole.current)
        clearInterval(intervalTimer.current)
        setEnCours(false)
        setGrille(Array(9).fill(false))
        setScore(s => { setMeilleurScore(b => Math.max(b, s)); return s })
    }

    function frapper(index) {
        setGrille(prev => {
            if (!prev[index]) return prev
            const g = [...prev]; g[index] = false; return g
        })
        setScore(s => s + 1)
    }

    const couleurTemps = temps <= 5 ? '#ff7b72' : '#ffa657'

    return (
        <div style={{ minHeight:'100vh', background:'#080b0f', display:'flex', flexDirection:'column', alignItems:'center', justifyContent:'center', gap:'24px', fontFamily:'system-ui' }}>

            <h1 style={{ color:'#44D62C', fontSize:'2.2rem', fontWeight:900 }}>Whack-a-Mole</h1>

            {/* Stats */}
            <div style={{ display:'flex', gap:'36px' }}>
                {[
                    ['Score',  score,         '#f7df1e'  ],
                    ['Temps',  temps + 's',  couleurTemps],
                    ['Record', meilleurScore, '#44D62C'  ],
                ].map(([label, val, color]) => (
                    <div key={label} style={{ textAlign:'center' }}>
                        <div style={{ color:'#7d8590', fontSize:'.65rem', textTransform:'uppercase', letterSpacing:'.1em' }}>{label}</div>
                        <div style={{ color, fontSize:'1.8rem', fontWeight:900 }}>{val}</div>
                    </div>
                ))}
            </div>

            {/* Sélecteur de niveau */}
            <div style={{ display:'flex', gap:'8px' }}>
                {Object.entries(NIVEAUX).map(([key, { label }]) => (
                    <button key={key}
                        onClick={() => setNiveau(key)}
                        disabled={enCours}
                        style={{ padding:'5px 14px', borderRadius:'6px', cursor: enCours ? 'default' : 'pointer', border: niveau===key ? '1px solid rgba(68,214,44,.4)' : '1px solid #1e2d3d', background: niveau===key ? 'rgba(68,214,44,.1)' : 'transparent', color: niveau===key ? '#44D62C' : '#7d8590', fontSize:'.78rem' }}
                    >{label}</button>
                ))}
            </div>

            {/* Grille */}
            <div style={{ display:'grid', gridTemplateColumns:'repeat(3,1fr)', gap:'12px' }}>
                {grille.map((active, i) => (
                    <Taupe key={i} active={active} onFrappe={() => frapper(i)} />
                ))}
            </div>

            {/* Bouton */}
            <button
                onClick={enCours ? arrêter : démarrer}
                style={{ padding:'10px 32px', background: enCours ? 'rgba(255,123,114,.08)' : 'rgba(68,214,44,.1)', border: enCours ? '1px solid rgba(255,123,114,.3)' : '1px solid rgba(68,214,44,.3)', color: enCours ? '#ff7b72' : '#44D62C', borderRadius:'8px', cursor:'pointer', fontWeight:700, fontSize:'.9rem' }}
            >
                {enCours ? 'Abandonner' : score > 0 ? 'Rejouer' : 'Démarrer'}
            </button>

        </div>
    )
}
