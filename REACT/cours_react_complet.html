MODULE 1 : INTRODUCTION À REACT

1.1 Qu'est-ce que React ?

React est une bibliothèque JavaScript développée par Facebook pour la création d'interfaces utilisateur. Elle permet de construire des applications web modernes de manière efficace et structurée.

Caractéristiques principales

  • Bibliothèque déclarative : vous décrivez à quoi doit ressembler l'interface, React se charge du reste
  • Basée sur des composants : construction modulaire et réutilisable de l'interface
  • Virtual DOM : optimisation automatique des performances
  • JSX : syntaxe mélangeant HTML et JavaScript pour plus de lisibilité
  • Unidirectionnalité des données : flux de données prévisible et facile à déboguer

1.2 Installation et configuration

Prérequis

  • Node.js (version 14 ou supérieure)
  • npm ou yarn (gestionnaire de paquets)
  • Un éditeur de code (VS Code recommandé)

Création d'un projet avec Create React App

npx create-react-app mon-app
cd mon-app
npm start

Ces commandes créent un nouveau projet React avec toute la configuration nécessaire et lancent le serveur de développement. Votre application sera accessible à l'adresse http://localhost:3000.

Structure du projet

  • node_modules/ : dépendances du projet
  • public/ : fichiers statiques (HTML, images, etc.)
  • src/ : code source de l'application
  • package.json : configuration et dépendances du projet
Important : La commande npm start lance le serveur de développement avec rechargement automatique. Toute modification dans le code sera immédiatement visible dans le navigateur.

MODULE 2 : JSX (JAVASCRIPT XML)

2.1 Comprendre JSX

JSX est une extension syntaxique de JavaScript qui ressemble à du HTML. Il permet d'écrire des structures d'interface directement dans le code JavaScript, ce qui rend le code plus lisible et intuitif.

Exemple basique

const element = <h1>Bonjour, monde!</h1>;

JSX avec expressions JavaScript

const nom = 'Thomas';
const element = <h1>Bonjour, {nom}!</h1>;

Les accolades {} permettent d'insérer des expressions JavaScript dans le JSX. Vous pouvez y placer n'importe quelle expression JavaScript valide.

2.2 Règles importantes du JSX

  • Un seul élément racine : tout JSX doit avoir un élément parent unique. Si vous avez plusieurs éléments, enveloppez-les dans une <div> ou un Fragment <>
  • Fermeture des balises : toutes les balises doivent être fermées, même les balises auto-fermantes comme <img /> ou <br />
  • className au lieu de class : utilisez className pour définir des classes CSS car class est un mot réservé en JavaScript
  • Expressions entre accolades : utilisez {expression} pour insérer du JavaScript dynamique

Exemple complet

function Accueil() {
  const titre = 'Bienvenue';
  const actif = true;
  
  return (
    <div className={actif ? 'actif' : 'inactif'}>
      <h1>{titre}</h1>
      <p>Application React</p>
    </div>
  );
}
Attention : JSX n'est pas du HTML, mais du JavaScript. Il est transpilé en appels de fonctions JavaScript par Babel avant d'être exécuté dans le navigateur.

MODULE 3 : LES COMPOSANTS

3.1 Qu'est-ce qu'un composant ?

Un composant est une fonction JavaScript qui retourne du JSX. Les composants permettent de découper l'interface en morceaux indépendants et réutilisables, facilitant ainsi la maintenance et l'organisation du code.

Composant fonctionnel simple

function Bouton() {
  return <button>Cliquez-moi</button>;
}

3.2 Les Props (Propriétés)

Les props permettent de passer des données d'un composant parent vers un composant enfant. Elles sont en lecture seule, ce qui signifie qu'un composant ne peut pas modifier ses propres props.

Utilisation des props

// Définition du composant
function Salutation(props) {
  return <h1>Bonjour, {props.nom}!</h1>;
}

// Utilisation
<Salutation nom='Thomas' />

Destructuration des props

Pour améliorer la lisibilité, on peut destructurer les props directement dans les paramètres de la fonction :

function Carte({ titre, description, image }) {
  return (
    <div className='carte'>
      <img src={image} alt={titre} />
      <h2>{titre}</h2>
      <p>{description}</p>
    </div>
  );
}

3.3 Composition de composants

Les composants peuvent contenir d'autres composants. C'est le principe de composition qui permet de construire des interfaces complexes à partir de composants simples.

function App() {
  return (
    <div>
      <Header />
      <Main />
      <Footer />
    </div>
  );
}
Bonne pratique : Créez des composants petits et réutilisables. Chaque composant devrait avoir une responsabilité unique et claire.

MODULE 4 : STATE ET HOOKS

4.1 Le Hook useState

Le hook useState permet d'ajouter un état local à un composant fonctionnel. L'état représente les données qui peuvent changer au cours du temps et déclencher un nouveau rendu du composant.

Syntaxe de base

import { useState } from 'react';

function Compteur() {
  const [count, setCount] = useState(0);
  
  return (
    <div>
      <p>Vous avez cliqué {count} fois</p>
      <button onClick={() => setCount(count + 1)}>
        Incrémenter
      </button>
    </div>
  );
}

Explications :

  • count : variable d'état qui contient la valeur actuelle
  • setCount : fonction pour modifier l'état
  • useState(0) : initialise l'état à 0

État avec objet

function Formulaire() {
  const [utilisateur, setUtilisateur] = useState({
    nom: '',
    email: ''
  });
  
  const handleChange = (e) => {
    setUtilisateur({
      ...utilisateur,
      [e.target.name]: e.target.value
    });
  };
}

4.2 Le Hook useEffect

Le hook useEffect permet d'exécuter des effets de bord : récupération de données, souscriptions, modifications du DOM, etc. Il s'exécute après le rendu du composant.

Syntaxe de base

import { useState, useEffect } from 'react';

function Titre() {
  const [count, setCount] = useState(0);
  
  useEffect(() => {
    document.title = `Clics : ${count}`;
  }, [count]); // Se déclenche quand count change
}

Tableau de dépendances

  • [] (vide) : s'exécute une seule fois au montage du composant
  • [variable] : s'exécute quand la variable change
  • Pas de tableau : s'exécute à chaque rendu

Nettoyage avec useEffect

useEffect(() => {
  const timer = setInterval(() => {
    console.log('Tick');
  }, 1000);
  
  return () => clearInterval(timer); // Nettoyage
}, []);
Important : Toujours retourner une fonction de nettoyage dans useEffect si vous créez des timers, souscriptions ou écouteurs d'événements pour éviter les fuites mémoire.

MODULE 5 : GESTION DES ÉVÉNEMENTS

5.1 Événements en React

React utilise la syntaxe camelCase pour les événements (onClick au lieu de onclick). Les gestionnaires d'événements sont des fonctions passées directement au JSX.

Événement onClick

function Bouton() {
  const handleClick = () => {
    alert('Bouton cliqué!');
  };
  
  return <button onClick={handleClick}>Cliquez</button>;
}

Événement onChange

function Input() {
  const [texte, setTexte] = useState('');
  
  return (
    <input
      value={texte}
      onChange={(e) => setTexte(e.target.value)}
    />
  );
}

5.2 Événements de formulaire

function Formulaire() {
  const [nom, setNom] = useState('');
  
  const handleSubmit = (e) => {
    e.preventDefault(); // Empêche le rechargement
    console.log('Nom soumis :', nom);
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input value={nom} onChange={(e) => setNom(e.target.value)} />
      <button type='submit'>Envoyer</button>
    </form>
  );
}

Événements courants

Événement Utilisation
onClick Clic sur un élément
onChange Changement de valeur d'un input
onSubmit Soumission d'un formulaire
onMouseEnter Survol de la souris
onKeyDown Touche du clavier enfoncée
Attention : Ne jamais appeler directement une fonction dans un événement comme onClick={handleClick()}. Cela exécuterait la fonction immédiatement. Utilisez onClick={handleClick} ou onClick={() => handleClick()}.

MODULE 6 : RENDU CONDITIONNEL ET LISTES

6.1 Rendu conditionnel

Le rendu conditionnel permet d'afficher différents éléments selon des conditions.

Avec if/else

function Connexion({ estConnecte }) {
  if (estConnecte) {
    return <p>Bienvenue!</p>;
  } else {
    return <p>Veuillez vous connecter</p>;
  }
}

Avec opérateur ternaire

function Message({ estConnecte }) {
  return (
    <p>
      {estConnecte ? 'Bienvenue!' : 'Connectez-vous'}
    </p>
  );
}

Avec opérateur &&

function Alerte({ afficher, message }) {
  return (
    <div>
      {afficher && <p className='alerte'>{message}</p>}
    </div>
  );
}

6.2 Rendu de listes

Pour afficher des listes, on utilise la méthode .map() sur un tableau. Chaque élément doit avoir une prop 'key' unique.

Liste simple

function ListeFruits() {
  const fruits = ['Pomme', 'Banane', 'Orange'];
  
  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={index}>{fruit}</li>
      ))}
    </ul>
  );
}

Liste avec objets

function ListeUtilisateurs() {
  const utilisateurs = [
    { id: 1, nom: 'Alice', age: 25 },
    { id: 2, nom: 'Bob', age: 30 },
    { id: 3, nom: 'Charlie', age: 35 }
  ];
  
  return (
    <div>
      {utilisateurs.map(user => (
        <div key={user.id}>
          <h3>{user.nom}</h3>
          <p>Age: {user.age}</p>
        </div>
      ))}
    </div>
  );
}
Important : La prop 'key' doit être unique pour chaque élément. Évitez d'utiliser l'index si l'ordre peut changer, car cela peut causer des problèmes de performance et de comportement.

MODULE 7 : REQUÊTES HTTP ET API

7.1 Récupération de données avec fetch

Pour récupérer des données depuis une API, on utilise fetch() dans un useEffect.

Exemple avec fetch

import { useState, useEffect } from 'react';

function Utilisateurs() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  
  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(response => response.json())
      .then(data => {
        setUsers(data);
        setLoading(false);
      })
      .catch(error => console.error(error));
  }, []);
  
  if (loading) return <p>Chargement...</p>;
  
  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

7.2 Gestion des erreurs

function Donnees() {
  const [data, setData] = useState(null);
  const [error, setError] = useState(null);
  const [loading, setLoading] = useState(false);
  
  useEffect(() => {
    setLoading(true);
    fetch('https://api.example.com/data')
      .then(res => {
        if (!res.ok) throw new Error('Erreur réseau');
        return res.json();
      })
      .then(data => setData(data))
      .catch(err => setError(err.message))
      .finally(() => setLoading(false));
  }, []);
  
  if (loading) return <p>Chargement...</p>;
  if (error) return <p>Erreur : {error}</p>;
  
  return <div>{JSON.stringify(data)}</div>;
}
Bonne pratique : Toujours gérer les trois états : chargement (loading), erreur (error) et succès (data). Cela améliore l'expérience utilisateur en fournissant un feedback clair.

MODULE 9 : CONTEXT API (GESTION D'ÉTAT GLOBALE)

9.1 Qu'est-ce que le Context ?

Le Context permet de partager des données entre composants sans passer les props manuellement à chaque niveau. C'est idéal pour des données globales comme le thème, l'utilisateur connecté, la langue, etc.

9.2 Création d'un Context

import { createContext, useState, useContext } from 'react';

// Créer le Context
const ThemeContext = createContext();

// Provider
function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('clair');
  
  const toggleTheme = () => {
    setTheme(theme === 'clair' ? 'sombre' : 'clair');
  };
  
  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

9.3 Utilisation du Context

// Hook personnalisé
function useTheme() {
  return useContext(ThemeContext);
}

// Dans App.js
function App() {
  return (
    <ThemeProvider>
      <Header />
      <Main />
    </ThemeProvider>
  );
}

// Dans un composant enfant
function BoutonTheme() {
  const { theme, toggleTheme } = useTheme();
  
  return (
    <button onClick={toggleTheme}>
      Thème actuel : {theme}
    </button>
  );
}
Conseil : Créez toujours un hook personnalisé (comme useTheme) pour accéder au Context. Cela rend le code plus propre et facilite la maintenance.

MODULE 10 : HOOKS AVANCÉS

10.1 useReducer

useReducer est une alternative à useState pour gérer un état complexe avec plusieurs sous-valeurs ou lorsque la logique de mise à jour est complexe.

import { useReducer } from 'react';

function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 };
    case 'decrement':
      return { count: state.count - 1 };
    default:
      return state;
  }
}

function Compteur() {
  const [state, dispatch] = useReducer(reducer, { count: 0 });
  
  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
    </div>
  );
}

10.2 useMemo

useMemo mémorise le résultat d'un calcul coûteux pour éviter de le recalculer à chaque rendu.

import { useMemo, useState } from 'react';

function CalculCouteux({ nombres }) {
  const [count, setCount] = useState(0);
  
  const total = useMemo(() => {
    console.log('Calcul du total...');
    return nombres.reduce((acc, n) => acc + n, 0);
  }, [nombres]); // Recalculé uniquement si nombres change
  
  return (
    <div>
      <p>Total : {total}</p>
      <button onClick={() => setCount(count + 1)}>Count: {count}</button>
    </div>
  );
}

10.3 useCallback

useCallback mémorise une fonction pour éviter de la recréer à chaque rendu.

import { useCallback, useState } from 'react';

function Parent() {
  const [count, setCount] = useState(0);
  
  const handleClick = useCallback(() => {
    console.log('Bouton cliqué');
  }, []); // Fonction mémorisée
  
  return <Enfant onClick={handleClick} />;
}

10.4 useRef

useRef permet d'accéder directement à un élément DOM ou de conserver une valeur mutable qui ne déclenche pas de rendu.

import { useRef } from 'react';

function FocusInput() {
  const inputRef = useRef(null);
  
  const handleFocus = () => {
    inputRef.current.focus();
  };
  
  return (
    <div>
      <input ref={inputRef} type='text' />
      <button onClick={handleFocus}>Focus sur l'input</button>
    </div>
  );
}

MODULE 11 : BONNES PRATIQUES REACT

11.1 Structure de projet

  • src/components/ : composants réutilisables
  • src/pages/ : composants de page
  • src/hooks/ : hooks personnalisés
  • src/context/ : contexts
  • src/utils/ : fonctions utilitaires
  • src/services/ : appels API

11.2 Règles de nommage

  • Composants : PascalCase (UserProfile.jsx)
  • Fonctions : camelCase (getUserData)
  • Constantes : UPPER_SNAKE_CASE (API_URL)
  • Hooks personnalisés : use + PascalCase (useAuth)

11.3 Optimisation des performances

  • Utiliser React.memo pour éviter les rendus inutiles
  • Utiliser useMemo pour les calculs coûteux
  • Utiliser useCallback pour mémoriser les fonctions
  • Lazy loading avec React.lazy() et Suspense
  • Éviter les fonctions anonymes dans le JSX

Exemple React.memo

import React from 'react';

const Enfant = React.memo(({ nom }) => {
  console.log('Rendu Enfant');
  return <p>{nom}</p>;
});
