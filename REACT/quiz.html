Quiz Interactif en React

On va construire un quiz complet pas à pas : données en JSON, composants réutilisables, gestion du state, timer avec useEffect, et écran de résultats. Chaque composant a une responsabilité unique.

00
Préparation

Le plan — ce qu'on va construire

Un quiz c'est une suite de questions, chacune avec plusieurs options. L'utilisateur choisit une réponse, reçoit un feedback, puis passe à la suivante. À la fin, on affiche le score. On découpe en 5 composants :

App ← STATE : index, reponse, score, termine, temps │ ← EFFECT : timer par question │ ├── ProgressBar ← barre de progression + compteur │ props: actuelle, total │ ├── QuestionCard ← la question en cours │ props: question, reponse, temps, onReponse │ ├── Timer ← barre de temps visuelle │ │ props: temps, duree │ └── OptionButton x N ← chaque choix (composant réutilisable) │ props: texte, etat, onClick │ └── ResultScreen ← ecran final score + replay props: score, total, details[], onReplay
i
Separation of concerns. Chaque composant a une seule raison d'exister : ProgressBar ne sait pas ce qu'est un quiz, il affiche juste une fraction. OptionButton ne sait pas si la réponse est bonne, il affiche juste un état. C'est App qui possède la logique.

Les états possibles d'une option sont le coeur du composant OptionButton :

Etats d'un OptionButton
null — état initial, aucune réponse donnée — cliquable
"selectionne" — l'utilisateur a cliqué cette option, en attente — non cliquable
"correct" — cette option est la bonne réponse — surlignée en vert
"incorrect" — cette option était sélectionnée mais c'est la mauvaise — surlignée en rouge

Étape 2 — Composant réutilisable

ProgressBar — un composant sans état

ProgressBar est le plus simple des composants : il reçoit deux chiffres et affiche une barre. Aucun state, aucune logique. C'est un composant purement présentationnel — il ne fait que transformer des props en JSX. Ce pattern est très courant en React.

ProgressBar.jsxnouveau
// ProgressBar.jsx
// Props : actuelle (number), total (number)
// Exemple : actuelle=3, total=8 → barre à 37.5%

function ProgressBar({ actuelle, total }) {
    const pct = (actuelle / total) * 100

    return (
        <div className="progress-wrap">

            <span className="progress-label">
                Question {actuelle} / {total}
            </span>

            <div className="progress-track">
                <div
                    className="progress-bar"
                    style={{ width: `${pct}%` }}
                />
            </div>

        </div>
    )
}

export default ProgressBar
+
Réutilisabilité. Ce composant peut servir dans n'importe quel contexte : upload de fichier, étapes d'un formulaire, chargement. Il ne sait pas ce qu'est un quiz. Ses props sont génériques (actuelle, total) et non spécifiques (questionActuelle). C'est ça un bon composant réutilisable.
OptionButton.jsx — autre composant réutilisablenouveau
// OptionButton.jsx
// Props :
//   texte   → string  — le libellé de l'option
//   etat    → null | "selectionne" | "correct" | "incorrect"
//   onClick → function — appelée au clic

function OptionButton({ texte, etat, onClick }) {
    return (
        <button
            className={`option-btn ${etat ?? ''}`}
            onClick={onClick}
            disabled={etat !== null}
        >
            {texte}
        </button>
    )
}

export default OptionButton
?
disabled={etat !== null} — le bouton est désactivé dès qu'un état est défini, c'est-à-dire dès que l'utilisateur a répondu. Une seule condition couvre les trois états post-réponse ("selectionne", "correct", "incorrect"). Plus besoin de etat === "selectionne" || etat === "correct" || ....
>
A ce stade : deux composants réutilisables sans état, prêts à recevoir leurs props. On peut les tester en isolation en leur passant des valeurs en dur. La vraie logique viendra d'App.
03
Étape 3 — Assemblage

QuestionCard — assembler les sous-composants

QuestionCard assemble le texte de la question, les options via map(), le timer visuel et le feedback. Il reçoit la question courante (objet JSON) et la réponse donnée, et calcule l'état de chaque option.

QuestionCard.jsxnouveau
// QuestionCard.jsx
// Props :
//   question  → { id, question, options[], correct, explication }
//   reponse   → number | null — index de l'option choisie
//   temps     → number — secondes restantes
//   duree     → number — durée totale (pour la barre de timer)
//   onReponse → function(index) — appelée au clic sur une option

function QuestionCard({ question, reponse, temps, duree, onReponse }) {

    // Calcule l'état de chaque option depuis reponse + question.correct
    function getEtat(index) {
        if (reponse === null) return null            // pas encore répondu
        if (index === question.correct) return 'correct'  // toujours verte
        if (index === reponse) return 'incorrect'      // rouge si c'était celle choisie
        return 'selectionne'                            // autres → désactivées
    }

    const aRepondu = reponse !== null
    const correct  = reponse === question.correct

    return (
        <div className="question-card">

            {/* Barre de timer */}
            <Timer temps={temps} duree={duree} />

            {/* Texte de la question */}
            <p className="question-texte">{question.question}</p>

            {/* Options — map() sur le tableau JSON */}
            <div className="options">
                {question.options.map((texte, i) => (
                    <OptionButton
                        key={i}
                        texte={texte}
                        etat={getEtat(i)}
                        onClick={() => onReponse(i)}
                    />
                ))}
            </div>

            {/* Feedback — affiché seulement après réponse */}
            {aRepondu && (
                <div className={`feedback ${correct ? 'ok' : 'ko'}`}>
                    {question.explication}
                </div>
            )}

        </div>
    )
}

export default QuestionCard
!
getEtat() : le seul endroit où on décide de la couleur. La logique d'affichage est centralisée dans cette fonction locale. OptionButton ne sait pas si c'est une bonne ou mauvaise réponse — il affiche juste l'état qu'on lui passe. Si demain les règles d'affichage changent, on ne modifie que getEtat.

Le composant Timer est minimal — juste une barre CSS dont la largeur dépend du temps restant :

Timer.jsxnouveau
// Timer.jsx
// Props : temps (secondes restantes), duree (durée totale)

function Timer({ temps, duree }) {
    const pct     = (temps / duree) * 100
    const urgent  = temps <= 5
    const couleur = urgent ? '#ff7b72' : '#61dafb'

    return (
        <div className="timer-wrap">
            <div className="timer-track">
                <div
                    className="timer-bar"
                    style={{ width: `${pct}%`, background: couleur }}
                />
            </div>
            <span className={`timer-val ${urgent ? 'urgent' : ''}`}>
                {temps}s
            </span>
        </div>
    )
}

export default Timer
>
A ce stade : QuestionCard affiche une question complète avec ses options et son timer. On peut le tester en lui passant une question JSON en dur et reponse={null}. Les options sont cliquables mais rien ne se passe encore — la logique est dans App.

Étape 4 — Le state central

Le State dans App

App est le chef d'orchestre. Il détient tout le state et distribue les props. On a besoin de 5 useState pour couvrir l'ensemble du jeu.

App.jsx — état initialnouveau
import { useState, useEffect } from 'react'
import questions from './questions.json'
import ProgressBar   from './ProgressBar'
import QuestionCard  from './QuestionCard'
import ResultScreen  from './ResultScreen'

const DUREE = 20  // secondes par question

function App() {
    // Index de la question affichée (0 à questions.length - 1)
    const [index,    setIndex]    = useState(0)

    // Réponse donnée pour la question courante (null = pas encore répondu)
    const [reponse,  setReponse]  = useState(null)

    // Nombre de bonnes réponses
    const [score,    setScore]    = useState(0)

    // Résultats détaillés pour l'écran final
    const [details,  setDetails]  = useState([])

    // Secondes restantes pour la question en cours
    const [temps,    setTemps]    = useState(DUREE)

    // Valeurs dérivées — calculées depuis le state existant
    const questionCourante = questions[index]
    const termine          = index >= questions.length

    return (
        <div className="app">
            {termine ? (
                <ResultScreen
                    score={score}
                    total={questions.length}
                    details={details}
                    onReplay={replay}
                />
            ) : (
                <>
                    <ProgressBar
                        actuelle={index + 1}
                        total={questions.length}
                    />
                    <QuestionCard
                        question={questionCourante}
                        reponse={reponse}
                        temps={temps}
                        duree={DUREE}
                        onReponse={repondre}
                    />
                </>
            )}
        </div>
    )
}

export default App
Rôle de chaque state
index — la question affichée. Incrémenté à chaque "Suivant".
reponse — l'option choisie pour la question courante. Remise à null à chaque nouvelle question.
score — compteur de bonnes réponses. Incrémenté uniquement si reponse === question.correct.
details — tableau accumulé pour l'écran final : chaque question + réponse donnée.
temps — secondes restantes. Géré par useEffect (étape 6).

Étape 5 — Les actions

Logique de réponse et navigation

Trois fonctions couvrent toute la logique du jeu : repondre quand on clique une option, suivant pour passer à la question suivante, et replay pour tout remettre à zéro.

App.jsx — fonctions repondre, suivant, replaymodifier
function repondre(indexOption) {
    // 1. Ignorer si déjà répondu
    if (reponse !== null) return

    // 2. Enregistrer la réponse
    setReponse(indexOption)

    // 3. Mettre à jour le score si correct
    if (indexOption === questionCourante.correct) {
        setScore(s => s + 1)
    }

    // 4. Stocker dans les détails pour l'écran final
    setDetails(d => [...d, {
        question:    questionCourante.question,
        donnee:      indexOption,
        correcte:    questionCourante.correct,
        ok:          indexOption === questionCourante.correct,
    }])
}

function suivant() {
    setIndex(i => i + 1)   // avancer à la question suivante
    setReponse(null)         // réinitialiser la réponse
    setTemps(DUREE)          // remettre le timer à zéro
}

function replay() {
    setIndex(0)
    setReponse(null)
    setScore(0)
    setDetails([])
    setTemps(DUREE)
}
i
setScore(s => s + 1) — forme fonctionnelle. On utilise la forme avec callback plutôt que setScore(score + 1) pour éviter les closures stales : la callback reçoit toujours la valeur la plus récente de score, même si plusieurs mises à jour sont en file.
!
details[] = source de vérité de l'écran final. On accumule dans details tout ce dont ResultScreen aura besoin : question posée, réponse donnée, bonne réponse, résultat. Aucun recalcul à faire dans ResultScreen — il reçoit tout prêt.
>
A ce stade : le quiz est jouable. On répond, le feedback s'affiche, on passe à la suivante. Le timer s'affiche mais ne défile pas encore — c'est l'étape suivante.

Étape 6 — useEffect

useEffect — le timer et ses effets de bord

Le timer est l'exemple parfait d'un effet de bord : il utilise setInterval qui existe en dehors du cycle React. On a besoin d'un effect pour le lancer et d'une fonction de nettoyage pour l'arrêter. Deux cas doivent arrêter le timer : l'utilisateur répond, ou le temps est écoulé.

?
Rappel useEffect. useEffect(fn, [deps]) exécute fn après chaque render où deps a changé. Si fn retourne une fonction, React l'appelle avant le prochain déclenchement de l'effet ou au démontage. Ce return () => ... est la fonction de nettoyage — indispensable pour les intervals.
App.jsx — useEffect du timernouveau
useEffect(() => {
    // Pas de timer si la partie est terminée
    if (termine) return

    // Pas de timer si l'utilisateur a déjà répondu
    if (reponse !== null) return

    // Décrémenter chaque seconde
    const id = setInterval(() => {
        setTemps(t => {
            if (t <= 1) {
                // Temps écoulé → forcer une réponse incorrecte (-1 = timeout)
                repondre(-1)
                return 0
            }
            return t - 1
        })
    }, 1000)

    // Nettoyage — stopper l'interval quand :
    // - l'utilisateur répond (reponse change)
    // - on passe à la question suivante (index change)
    // - la partie se termine (termine change)
    return () => clearInterval(id)

}, [index, reponse, termine])  // redémarre à chaque nouvelle question
!
repondre(-1) pour le timeout. Quand le temps est écoulé, on appelle repondre(-1) : -1 n'est jamais un index valide donc la réponse sera toujours incorrecte, le feedback s'affiche, et la logique de question répond reste identique. Pas besoin d'un cas spécial "timeout" dans le reste du code.
!
[index, reponse, termine] comme dépendances. Le tableau de dépendances inclut index pour redémarrer le timer à chaque nouvelle question, reponse pour stopper le timer dès qu'on répond, et termine pour ne pas démarrer de timer sur l'écran final.
>
Le quiz est complet. Le timer défile, se fige quand on répond, se remet à zéro pour la suivante. Si le temps est écoulé, la question est comptée comme incorrecte.

Étape 7 — Ecran final

ResultScreen — afficher les résultats

ResultScreen est un composant purement présentationnel qui reçoit tout ce dont il a besoin depuis App. Il utilise map() sur le tableau details pour afficher le récapitulatif question par question.

ResultScreen.jsxnouveau
// ResultScreen.jsx
// Props :
//   score    → number — nombre de bonnes réponses
//   total    → number — nombre total de questions
//   details  → { question, donnee, correcte, ok }[]
//   onReplay → function — appelée au clic sur Rejouer

function ResultScreen({ score, total, details, onReplay }) {
    const pct     = Math.round((score / total) * 100)
    const message = pct === 100 ? 'Score parfait !'
                  : pct >= 75  ? 'Bonne maitrise du sujet.'
                  : pct >= 50  ? 'Encore un peu de travail.'
                  :                'Reprends le cours depuis le début.'

    return (
        <div className="result-screen">

            <div className="result-score">
                {score}<span>/{total}</span>
            </div>

            <p className="result-msg">{message}</p>

            {/* Récapitulatif — map() sur le tableau details */}
            <ul className="detail-list">
                {details.map((d, i) => (
                    <li key={i} className={`detail-item ${d.ok ? 'ok' : 'ko'}`}>
                        <span className="detail-icon">{d.ok ? 'V' : 'X'}</span>
                        {d.question}
                    </li>
                ))}
            </ul>

            <button className="btn-replay" onClick={onReplay}>
                Rejouer
            </button>

        </div>
    )
}

export default ResultScreen
+
ResultScreen ne recalcule rien. Tout a été préparé par App lors du remplissage de details. ResultScreen fait du rendu pur. C'est le principe Single Responsibility : chaque composant a un seul rôle. App calcule, les composants affichent.

                <div style={{ flex:1, height:'5px', background:'#1e2d3d', borderRadius:'3px', overflow:'hidden' }}>
                    <div style={{ height:'100%', width:`${(temps/DUREE)*100}%`, background: urgent ? '#ff7b72' : '#61dafb', transition:'width 1s linear, background .3s' }} />
                </div>
                <span style={{ fontFamily:'monospace', fontSize:'.85rem', color: urgent ? '#ff7b72' : '#ffa657', minWidth:'32px' }}>{temps}s</span>
            </div>
            {/* Question */}
            <p style={{ fontSize:'1rem', fontWeight:700, color:'#e6edf3', marginBottom:'18px', lineHeight:'1.55' }}>{q.question}</p>
            {/* Options */}
            <div style={{ display:'flex', flexDirection:'column', gap:'8px', marginBottom:'16px' }}>
                {q.options.map((txt, i) => {
                    let etat = null
                    if (reponse !== null) {
                        if (i === q.correct) etat = 'correct'
                        else if (i === reponse) etat = 'incorrect'
                        else etat = 'selectionne'
                    }
                    return <OptionButton key={i} texte={txt} etat={etat} onClick={() => repondre(i)} />
                })}
            </div>
            {/* Feedback */}
            {reponse !== null && (
                <div style={{ padding:'10px 14px', borderRadius:'7px', fontSize:'.82rem', marginBottom:'16px', background: reponse===q.correct ? 'rgba(68,214,44,.07)' : 'rgba(255,123,114,.06)', border: `1px solid ${reponse===q.correct ? 'rgba(68,214,44,.2)' : 'rgba(255,123,114,.2)'}`, color: reponse===q.correct ? '#9fdb8a' : '#ff7b72' }}>
                    {q.explication}
                </div>
            )}
            {/* Navigation */}
            <div style={{ display:'flex', justifyContent:'flex-end' }}>
                <button onClick={suivant} disabled={reponse === null}
                    style={{ padding:'9px 24px', background: reponse !== null ? 'rgba(97,218,251,.1)' : 'transparent', border:'1px solid rgba(97,218,251,.3)', color: reponse !== null ? '#61dafb' : '#3d444d', borderRadius:'7px', cursor: reponse !== null ? 'pointer' : 'default', fontWeight:700, fontFamily:'monospace', fontSize:'.8rem' }}
                >
                    {index === QUESTIONS.length - 1 ? 'Voir le score' : 'Suivant'}
                </button>
            </div>
        </div></div>
    )
}
