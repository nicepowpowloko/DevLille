00
Préparation

Le plan — ce qu'on va construire

Avant de coder, on réfléchit aux composants dont on a besoin. Un morpion c'est une grille 3×3 avec des cases. On va découper ça en 3 composants :

App ← STATE : plateau, joueur actif, gagnant ├── StatusBar ← affiche "Tour de X" ou "X a gagné !" │ props: statut, joueur │ ├── Board ← la grille 3×3 │ props: plateau[], onClic │ └── Cellule × 9 ← chaque case │ props: valeur, onClick, gagnante │ └── BoutonReset ← recommencer props: onReset
Le STATE est toujours au plus haut niveau commun. Le plateau est utilisé par Board ET StatusBar → le state est dans App. C'est la règle du "lift state up".

Le plateau c'est un tableau de 9 cases :

Structure des données
// Le plateau = tableau de 9 éléments
// null = case vide, 'X' ou 'O' = jouée
const plateau = [
    null, 'X', null,   // ligne du haut  → index 0, 1, 2
    'O',  'X', null,   // ligne du milieu → index 3, 4, 5
    null, null, 'X',   // ligne du bas    → index 6, 7, 8
]

// Visuellement dans la grille :
// [0][1][2]
// [3][4][5]
// [6][7][8]
01
Étape 1 — Premier composant

La Cellule — une seule case

On commence par le plus petit composant : une case. Elle reçoit une valeur (null, 'X' ou 'O') et une fonction à appeler quand on clique dessus.

Cellule.jsxnouveau
// Cellule.jsx
// Props reçues :
//   valeur   → null | 'X' | 'O'
//   onClick  → fonction à appeler au clic
//   gagnante → boolean — mettre en surbrillance ?

function Cellule({ valeur, onClick, gagnante }) {
    return (
        <button
            className={`cellule ${gagnante ? 'cellule-gagnante' : ''} ${valeur ? 'cellule-jouee' : ''}`}
            onClick={onClick}
            disabled={!!valeur}   {/* désactivée si déjà jouée */}
        >
            {valeur}
        </button>
    )
}

export default Cellule
disabled={!!valeur} — le !! convertit la valeur en booléen. !!null = false, !!'X' = true. La case est donc désactivée dès qu'elle est jouée.
Résultat étape 1
Une case qui affiche X, O ou rien. Elle peut être cliquée si vide, désactivée si jouée, et mise en surbrillance si elle fait partie de la combinaison gagnante.
02
Étape 2 — Assembler les cases

Le Board — la grille 3×3

Le Board reçoit le tableau plateau (9 cases) et génère les 9 Cellule avec .map(). Il reçoit aussi la fonction onClic qu'il transmet à chaque cellule.

Board.jsxnouveau
// Board.jsx
import Cellule from './Cellule'

// Props reçues :
//   plateau    → tableau de 9 valeurs
//   onClic     → fonction(index) — appelée au clic
//   casesGagnantes → tableau d'index [0,4,8] ou null

function Board({ plateau, onClic, casesGagnantes }) {
    return (
        <div className="board">
            {plateau.map((valeur, index) => (
                <Cellule
                    key={index}
                    valeur={valeur}
                    onClick={() => onClic(index)}
                    gagnante={casesGagnantes?.includes(index) ?? false}
                />
            ))}
        </div>
    )
}

export default Board
onClic(index) — on passe l'index de la case cliquée au parent. C'est le parent (App) qui décide quoi faire avec cet index. Le Board ne sait pas s'il peut jouer ou non — il délègue.
Résultat étape 2
Une grille 3×3 de boutons. Elle affiche le plateau mais ne gère pas encore la logique — c'est le rôle de App.
2 composants créés. On a les briques visuelles. Maintenant on ajoute le cerveau : le STATE dans App.
03
Étape 3 — La mémoire du jeu

Le State dans App

App gère trois informations : le plateau (9 cases), le joueur actif (X ou O), et le gagnant (null tant que personne n'a gagné).

App.jsx — le statenouveau
import { useState } from 'react'
import Board from './Board'

// Plateau vide au départ = 9 cases à null
const plateauVide = () => Array(9).fill(null)

function App() {
    // ── STATE ──
    const [plateau,  setPlateau]  = useState(plateauVide)
    const [joueur,   setJoueur]   = useState('X')    // X commence
    const [gagnant,  setGagnant]  = useState(null)   // null = personne

    // ── Pour l'instant : juste afficher ──
    function handleClic(index) {
        console.log('Case cliquée :', index)
        // On va compléter ça à l'étape 4
    }

    return (
        <div className="app">
            <h1>Morpion</h1>
            <p>Tour de : {joueur}</p>
            <Board
                plateau={plateau}
                onClic={handleClic}
                casesGagnantes={null}
            />
        </div>
    )
}

export default App
Array(9).fill(null) crée un tableau de 9 cases toutes à null. C'est notre plateau vide de départ.
▶
À ce stade : la grille s'affiche, on peut cliquer sur les cases, la console affiche l'index. Mais le jeu ne joue pas encore. C'est normal — on ajoute la logique à l'étape 4.
04
Étape 4 — Le cerveau

La logique de jeu

On complète handleClic pour qu'il joue réellement la case, et on ajoute la fonction calculerGagnant qui vérifie si quelqu'un a gagné après chaque coup.

Fonction calculerGagnant — à mettre HORS du composant
// Les 8 combinaisons gagnantes possibles
const COMBINAISONS = [
    [0, 1, 2], // ligne haut
    [3, 4, 5], // ligne milieu
    [6, 7, 8], // ligne bas
    [0, 3, 6], // colonne gauche
    [1, 4, 7], // colonne milieu
    [2, 5, 8], // colonne droite
    [0, 4, 8], // diagonale
    [2, 4, 6], // diagonale inverse
]

// Retourne { gagnant: 'X'|'O', cases: [i,j,k] } ou null
function calculerGagnant(plateau) {
    for (const [a, b, c] of COMBINAISONS) {
        if (
            plateau[a] &&
            plateau[a] === plateau[b] &&
            plateau[a] === plateau[c]
        ) {
            return { gagnant: plateau[a], cases: [a, b, c] }
        }
    }
    return null
}
App.jsx — handleClic complétémodifier
function handleClic(index) {
    // 1. Ignorer si case déjà jouée ou partie terminée
    if (plateau[index] || gagnant) return

    // 2. Copier le plateau (ne jamais muter le state directement)
    const nouveauPlateau = [...plateau]

    // 3. Jouer la case
    nouveauPlateau[index] = joueur

    // 4. Vérifier si quelqu'un a gagné
    const resultat = calculerGagnant(nouveauPlateau)
    if (resultat) {
        setGagnant(resultat)  // { gagnant: 'X', cases: [0,4,8] }
    }

    // 5. Mettre à jour le plateau et changer de joueur
    setPlateau(nouveauPlateau)
    setJoueur(joueur === 'X' ? 'O' : 'X')
}
Ne jamais faire plateau[index] = joueur directement ! On copie d'abord avec [...plateau]. Si on mute le tableau original, React ne détecte pas le changement et ne re-rend pas.
À ce stade : le jeu fonctionne ! X et O s'alternent, les cases jouées sont désactivées. Il manque juste l'affichage du gagnant et le bouton reset.

Étape 5 — Finitions

Status & Reset

On ajoute l'affichage du statut de la partie et le bouton pour recommencer. On crée aussi un composant StatusBar pour garder App propre.

StatusBar.jsxnouveau
// StatusBar.jsx
// Props : gagnant (objet|null), joueur ('X'|'O'), egalite (bool)

function StatusBar({ gagnant, joueur, egalite }) {
    let message
    let couleur

    if (gagnant) {
        message = ` ${gagnant.gagnant} a gagné !`
        couleur = '#44D62C'
    } else if (egalite) {
        message = ' Égalité !'
        couleur = '#f7df1e'
    } else {
        message = `Tour de ${joueur}`
        couleur = joueur === 'X' ? '#61dafb' : '#ff7b72'
    }

    return (
        <div className="status-bar" style={{ color: couleur }}>
            {message}
        </div>
    )
}

export default StatusBar
App.jsx — reset + égalité + StatusBarmodifier
import StatusBar from './StatusBar'

function App() {
    const [plateau,  setPlateau]  = useState(plateauVide)
    const [joueur,   setJoueur]   = useState('X')
    const [gagnant,  setGagnant]  = useState(null)

    // Égalité = toutes les cases jouées et pas de gagnant
    const egalite = !gagnant && plateau.every(c => c !== null)

    // Reset — tout remettre à zéro
    function reset() {
        setPlateau(plateauVide())
        setJoueur('X')
        setGagnant(null)
    }

    return (
        <div className="app">
            <h1>Morpion</h1>

            <StatusBar
                gagnant={gagnant}
                joueur={joueur}
                egalite={egalite}
            />

            <Board
                plateau={plateau}
                onClic={handleClic}
                casesGagnantes={gagnant?.cases ?? null}
            />

            <button className="btn-reset" onClick={reset}>
                Nouvelle partie
            </button>
        </div>
    )
}
Le jeu est complet ! X et O jouent, le gagnant s'affiche, les cases gagnantes sont surlignées, l'égalité est détectée, et on peut recommencer.
06
Étape 6 — Bonus avancé

Historique des coups — revenir en arrière

Fonctionnalité avancée : garder l'historique de chaque coup pour pouvoir remonter dans le temps. Au lieu de stocker plateau, on stocke un tableau de plateaux.

App.jsx — avec historiqueversion avancée
function App() {
    // Historique = tableau de plateaux
    // Ex: [ [null×9], ['X',null×8], ['X','O',null×7], ... ]
    const [historique, setHistorique] = useState([plateauVide()])
    const [etape,      setEtape]      = useState(0)

    // Le plateau actuel = l'historique à l'étape courante
    const plateau = historique[etape]
    const joueur  = etape % 2 === 0 ? 'X' : 'O' // pair=X, impair=O

    function handleClic(index) {
        if (plateau[index] || calculerGagnant(plateau)) return

        const nouveauPlateau = [...plateau]
        nouveauPlateau[index] = joueur

        // Couper l'historique à l'étape courante + ajouter
        setHistorique([...historique.slice(0, etape + 1), nouveauPlateau])
        setEtape(etape + 1)
    }

    return (
        <div className="app">
            {/* ... Board, StatusBar ... */}

            {/* Liste des coups passés */}
            <div className="historique">
                {historique.map((_, i) => (
                    <button key={i} onClick={() => setEtape(i)}>
                        {i === 0 ? 'Début' : `Coup ${i}`}
                    </button>
                ))}
            </div>
        </div>
    )
}
Le joueur actif sans state ! On calcule le joueur avec etape % 2 — si l'étape est paire c'est X, impaire c'est O. On n'a pas besoin d'un state séparé pour ça — c'est une valeur dérivée.

Code final

Morpion complet en un seul fichier

Pour une version simple utilisable directement dans ton projet, voici tout en un seul composant. Copie dans src/components/Morpion.jsx.

Morpion.jsx — tout-en-uncomplet
import { useState } from 'react'

// ── Combinaisons gagnantes ──
const COMBINAISONS = [
    [0,1,2],[3,4,5],[6,7,8],
    [0,3,6],[1,4,7],[2,5,8],
    [0,4,8],[2,4,6],
]

function calculerGagnant(p) {
    for (const [a,b,c] of COMBINAISONS)
        if (p[a] && p[a] === p[b] && p[a] === p[c])
            return { gagnant: p[a], cases: [a,b,c] }
    return null
}

// ── Composant Cellule ──
function Cellule({ valeur, onClick, gagnante }) {
    return (
        <button
            onClick={onClick}
            disabled={!!valeur}
            style={{
                width: '90px', height: '90px',
                fontSize: '2.4rem', fontWeight: 900,
                background: gagnante ? 'rgba(68,214,44,.15)' : '#0d1117',
                border: gagnante ? '2px solid #44D62C' : '2px solid #1e2d3d',
                borderRadius: '10px', cursor: valeur ? 'default' : 'pointer',
                color: valeur === 'X' ? '#61dafb' : '#ff7b72',
                transition: 'all .15s',
            }}
        >
            {valeur}
        </button>
    )
}

// ── Composant principal ──
export default function Morpion() {
    const [plateau, setPlateau]  = useState(Array(9).fill(null))
    const [joueur,  setJoueur]   = useState('X')
    const [gagnant, setGagnant]  = useState(null)

    const egalite = !gagnant && plateau.every(c => c !== null)

    function jouer(i) {
        if (plateau[i] || gagnant) return
        const p = [...plateau]
        p[i] = joueur
        const r = calculerGagnant(p)
        if (r) setGagnant(r)
        setPlateau(p)
        setJoueur(joueur === 'X' ? 'O' : 'X')
    }

    function reset() {
        setPlateau(Array(9).fill(null))
        setJoueur('X')
        setGagnant(null)
    }

    const statut = gagnant
        ? ` ${gagnant.gagnant} a gagné !`
        : egalite ? ' Égalité !'
        : `Tour de ${joueur}`

    const couleurStatut = gagnant ? '#44D62C'
        : egalite ? '#f7df1e'
        : joueur === 'X' ? '#61dafb' : '#ff7b72'

    return (
        <div style={{ minHeight:'100vh', background:'#080b0f', display:'flex', flexDirection:'column', alignItems:'center', justifyContent:'center', gap:'20px', fontFamily:'system-ui' }}>

            <h1 style={{ color:'#61dafb', fontSize:'2rem', fontWeight:900 }}>Morpion</h1>

            <p style={{ color: couleurStatut, fontWeight:700, fontSize:'1.1rem' }}>
                {statut}
            </p>

            <div style={{ display:'grid', gridTemplateColumns:'repeat(3,1fr)', gap:'8px' }}>
                {plateau.map((val, i) => (
                    <Cellule
                        key={i}
                        valeur={val}
                        onClick={() => jouer(i)}
                        gagnante={gagnant?.cases.includes(i) ?? false}
                    />
                ))}
            </div>

            <button
                onClick={reset}
                style={{ padding:'10px 28px', background:'rgba(97,218,251,.1)', border:'1px solid rgba(97,218,251,.3)', color:'#61dafb', borderRadius:'8px', cursor:'pointer', fontWeight:700, fontSize:'.9rem' }}
            >
                Nouvelle partie
            </button>
        </div>
    )
}
