JSX
JavaScript + XML

Comprendre la syntaxe JSX, ses règles, et comment React transforme ce code en vrai HTML.

JSX React Babel Composants
Étape 1

C'est quoi JSX ?

JSX c'est du HTML écrit dans du JavaScript. Ce n'est pas du vrai HTML — c'est une extension de syntaxe que Babel transforme en appels React.createElement() avant que le navigateur l'exécute.

Sans JSX (verbeux)
React.createElement(
  'h1',
  { className: 'title' },
  'Bonjour'
)
Avec JSX (lisible)
<h1 className="title">
  Bonjour
</h1>

← même résultat, bien plus clair
JSX n'est pas obligatoire en React, mais tout le monde l'utilise. C'est tellement plus lisible que d'écrire React.createElement à la main que c'est devenu le standard.
Étape 2

Les règles JSX à connaître

1 — Un seul élément racine
Le return ne peut retourner qu'un seul élément. Utilise <div> ou <></> (Fragment) pour en envelopper plusieurs.
2 — Toutes les balises fermées
En HTML <br> est valide. En JSX il faut <br />. Toutes les balises doivent être explicitement fermées.
3 — className, pas class
class est un mot réservé en JS. En JSX on écrit className. Pareil pour for → htmlFor.
4 — {} pour le JavaScript
Les accolades {} permettent d'insérer n'importe quelle expression JS dans le JSX : variable, fonction, calcul…
5 — camelCase pour les attributs
onclick → onClick, onchange → onChange, tabindex → tabIndex…
6 — Les composants en majuscule
<div> = balise HTML native. <Button> = composant React. La majuscule initiale est obligatoire.
Étape 3

La syntaxe en pratique

// Un composant React = une fonction qui retourne du JSX
function Carte() {
    return (
        // Parenthèses pour le multi-ligne
        <div className="carte">
            <h2>Titre</h2>
            <p>Description</p>
            <img src="photo.jpg" alt="photo" />  // balise auto-fermante
            <br />// pas <br> tout seul !
        </div>
    );
}

// Fragment — évite un div inutile dans le DOM
function Duo() {
    return (
        <>
            <h1>Titre</h1>
            <p>Paragraphe</p>
        </>
    );
}
// {} = "sortir du HTML, entrer en JS"
const prenom = "Alice";
const age    = 28;

function Profil() {
    return (
        <div>
            {/* Afficher une variable */}
            <h2>{prenom}</h2>

            {/* Expression JS dans {} */}
            <p>Elle a {age} ans ({2024 - age} de naissance)</p>

            {/* Dans un attribut aussi */}
            <img src={`/avatars/${prenom.toLowerCase()}.jpg`} alt={prenom} />

            {/* Appel de fonction */}
            <span>{prenom.toUpperCase()}</span>
        </div>
    );
}
const estConnecté = true;
const score      = 42;

function Dashboard() {
    return (
        <div>

            {/* Ternaire — si/sinon */}
            {estConnecté
                ? <p>Bienvenue !</p>
                : <p>Connecte-toi</p>
            }

            {/* && — afficher seulement si vrai */}
            {score > 40 && <span className="badge">Champion !</span>}

            {/* Variable JSX — calculer avant le return */}
            {(() => {
                if (score >= 90) return <span>Expert</span>;
                if (score >= 50) return <span>Intermédiaire</span>;
                return <span>Débutant</span>;
            })()}

        </div>
    );
}
const fruits = ["Pomme", "Banane", "Cerise"];

const devs = [
    { id: 1, nom: "Alice",  poste: "Frontend" },
    { id: 2, nom: "Bob",    poste: "Backend"  },
    { id: 3, nom: "Chloé",  poste: "Fullstack"},
];

function Liste() {
    return (
        <div>
            {/* .map() pour générer une liste */}
            <ul>
                {fruits.map(fruit => (
                    <li key={fruit}>{fruit}</li>
                ))}
            </ul>

            {/* Objets — key sur l'id unique */}
            <ul>
                {devs.map(dev => (
                    <li key={dev.id}>
                        {dev.nom} — {dev.poste}
                    </li>
                ))}
            </ul>
        </div>
    );
}
La prop key est obligatoire dans les listes. React l'utilise pour identifier chaque élément et optimiser les mises à jour du DOM. Utilise toujours un id unique — jamais l'index du tableau si la liste peut changer.
Étape 4

Passer des données avec les Props

Les props sont les attributs des composants React. C'est comme ça qu'on passe des données d'un composant parent à un composant enfant.

Props — passer et recevoir
// ── Définir le composant avec des props ──
function CarteDevs(props) {
    return (
        <div className="carte">
            <h2>{props.nom}</h2>
            <p>{props.poste}</p>
            <span>{props.salaire.toLocaleString('fr-FR')} €</span>
        </div>
    );
}

// ── Déstructuration (plus propre) ──
function CarteDevs({ nom, poste, salaire, remote = false }) {
    return (
        <div className="carte">
            <h2>{nom}</h2>
            <p>{poste}</p>
            {remote && <span>Remote</span>}
        </div>
    );
}

// ── Utiliser le composant ──
function App() {
    return (
        <div>
            <CarteDevs nom="Alice"  poste="Frontend"  salaire={38000} remote />
            <CarteDevs nom="Bob"    poste="Backend"   salaire={44000}       />
            <CarteDevs nom="Chloé"  poste="Fullstack" salaire={52000} remote />
        </div>
    );
}
Valeur par défaut : dans la déstructuration {"{ remote = false }"}, si la prop n'est pas passée, elle vaut false. Écrire remote tout seul dans JSX équivaut à remote={"{true}"}.
Étape 5

Erreurs fréquentes à éviter

Erreurs communes JSX
// Plusieurs éléments racine — ERREUR
return (
    <h1>Titre</h1>
    <p>Paragraphe</p>   // ← Erreur : 2 éléments racine
);

// Solution : Fragment
return (
    <>
        <h1>Titre</h1>
        <p>Paragraphe</p>
    </>
);

// class au lieu de className
<div class="carte">...  // ← Warning React
<div className="carte">... // 

// Balise non fermée
<input type="text">        // ← Erreur JSX
<input type="text" />      // 

// if dans le return JSX
return (
    <div>
        {if (ok) { ... }}  // ← Erreur : if n'est pas une expression
        {ok && <span>OK</span>}  // opérateur logique
        {ok ? <span>Oui</span> : <span>Non</span>}  // ternaire
    </div>
);
Dans les {} JSX, uniquement des expressions — pas d'instructions (if, for, while…). Une expression retourne une valeur. Une instruction ne retourne rien. Utilise le ternaire ou && à la place.
