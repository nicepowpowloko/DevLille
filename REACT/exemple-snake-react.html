// Étape 01

Les constantes — les règles du jeu

1
Définir les paramètres fixes du jeu

Avant de coder, on définit les valeurs qui ne changeront jamais : la taille de la grille, la vitesse... Ce sont des constantes (pas des états React).

// ─── CONSTANTES ─── // Ces valeurs ne changent JAMAIS → pas de useState // On les définit EN DEHORS du composant const LARGEUR = 20; // nombre de cases en largeur const HAUTEUR = 20; // nombre de cases en hauteur const VITESSE = 150; // millisecondes entre chaque mouvement // Position de départ du serpent (milieu de la grille) const DEPART = [ { x: 10, y: 10 }, // tête { x: 9, y: 10 }, // segment 2 { x: 8, y: 10 }, // queue ];
Pourquoi EN DEHORS du composant ?

Les constantes n'ont pas besoin d'être "réactives". Les mettre en dehors du composant évite de les recréer à chaque re-render. Bonne habitude !

// Étape 02

Les états — ce qui peut changer

2
Identifier et créer les useState

On se pose la question : qu'est-ce qui peut changer pendant la partie ? Chaque réponse = un useState.

function Snake() { // ─── LES ÉTATS (ce qui change = re-render) ──────── // 1) Le serpent : un tableau de segments {x, y} // Valeur initiale = position de départ définie plus haut const [serpent, setSerpent] = useState(DEPART); // 2) La direction : où va la tête ? {x, y} // {x:1, y:0} = droite | {x:-1, y:0} = gauche // {x:0, y:1} = bas | {x:0, y:-1} = haut const [direction, setDirection] = useState({ x: 1, y: 0 }); // 3) La nourriture : une seule case {x, y} const [nourriture, setNourriture] = useState({ x: 15, y: 10 }); // 4) Le score : un nombre entier const [score, setScore] = useState(0); // 5) Game over : vrai ou faux const [gameOver, setGameOver] = useState(false); // 6) En jeu ou non (pour la pause et l'écran d'accueil) const [enJeu, setEnJeu] = useState(false);
Règle d'or

Si une valeur doit changer ET que ce changement doit mettre à jour l'affichage → useState. Sinon → variable simple ou useRef.

// Étape 03

La boucle de jeu — useEffect + setInterval

3
Faire bouger le serpent automatiquement

Le cœur du jeu : toutes les X millisecondes, on calcule la nouvelle position de la tête et on vérifie si on a mangé ou si on est mort.

// ─── BOUCLE DE JEU ── useEffect(() => { // Si pas en jeu ou game over → on ne lance rien if (!enJeu || gameOver) return; const timer = setInterval(() => { // On met à jour le serpent avec la forme fonctionnelle // "ancienSerpent" = valeur GARANTIE à jour (important !) setSerpent(ancienSerpent => { // 1) Calculer où va la nouvelle tête const tete = ancienSerpent[0]; // segment [0] = tête const nouvelleTete = { x: tete.x + direction.x, y: tete.y + direction.y, }; // 2) Vérifier collision avec les murs const horsMur = nouvelleTete.x < 0 || nouvelleTete.x >= LARGEUR || nouvelleTete.y < 0 || nouvelleTete.y >= HAUTEUR; // 3) Vérifier collision avec son propre corps const toucheCorps = ancienSerpent.some( seg => seg.x === nouvelleTete.x && seg.y === nouvelleTete.y ); // 4) Si collision → Game Over if (horsMur || toucheCorps) { setGameOver(true); return ancienSerpent; // on ne bouge plus } // 5) A-t-on mangé la nourriture ? const aMange = nouvelleTete.x === nourriture.x && nouvelleTete.y === nourriture.y; // 6) Construire le nouveau serpent const nouveauCorps = [nouvelleTete, ...ancienSerpent]; // On ajoute la tête AU DÉBUT du tableau (spread) if (aMange) { setScore(s => s + 10); // +10 points placerNourriture(); // nouvelle pomme return nouveauCorps; // le serpent GRANDIT } else { return nouveauCorps.slice(0, -1); // .slice(0, -1) = on retire le DERNIER segment // → le serpent avance sans grandir } }); }, VITESSE); // ← se répète toutes les 150ms // IMPORTANT : nettoyage quand le composant se démonte // ou quand les dépendances changent return () => clearInterval(timer); }, [enJeu, gameOver, direction, nourriture]); // ↑ Le tableau de dépendances : useEffect se relance // si l'une de ces valeurs change
Pourquoi la forme fonctionnelle ?

setSerpent(ancien => ...) garantit qu'on lit la dernière version du serpent, même si plusieurs updates ont eu lieu. C'est crucial dans un setInterval !

// Étape 04

Le clavier — écouter les touches

4
Changer la direction avec les flèches

Un deuxième useEffect s'occupe uniquement d'écouter les touches du clavier. On utilise addEventListener et on le nettoie proprement.

// ─── ÉCOUTE DU CLAVIER ── useEffect(() => { const gererTouche = (e) => { // e.key contient le nom de la touche pressée if (e.key === 'ArrowUp') setDirection(d => { if (d.y === 1) return d; // interdit de faire demi-tour ↓→↑ return { x: 0, y: -1 }; }); else if (e.key === 'ArrowDown') setDirection(d => { if (d.y === -1) return d; // interdit demi-tour ↑→↓ return { x: 0, y: 1 }; }); else if (e.key === 'ArrowLeft') setDirection(d => { if (d.x === 1) return d; // interdit demi-tour →← return { x: -1, y: 0 }; }); else if (e.key === 'ArrowRight') setDirection(d => { if (d.x === -1) return d; // interdit demi-tour ←→ return { x: 1, y: 0 }; }); }; // On "branche" l'écoute sur la fenêtre window.addEventListener('keydown', gererTouche); // On "débranche" quand le composant se démonte return () => window.removeEventListener('keydown', gererTouche); }, []); // [] → s'exécute une seule fois
Demi-tour interdit !

Si le serpent va à droite (x: 1), appuyer sur ← déclencherait une collision immédiate avec son propre corps. On bloque ce cas avec une condition if (d.x === -1) return d.

// Étape 05

La nourriture — position aléatoire

5
Placer la pomme sur une case libre

Quand le serpent mange la pomme, on en place une nouvelle au hasard — mais pas sur le serpent !

// ─── FONCTION : placer la nourriture ── const placerNourriture = () => { // On génère des positions aléatoires jusqu'à // en trouver une qui n'est pas sur le serpent let pos; do { pos = { x: Math.floor(Math.random() * LARGEUR), y: Math.floor(Math.random() * HAUTEUR), }; // .some() = "au moins un segment est à cette position ?" } while (serpent.some(s => s.x === pos.x && s.y === pos.y)); setNourriture(pos); // mise à jour de l'état → re-render }; // ─── FONCTION : (re)démarrer le jeu ── const demarrer = () => { setSerpent(DEPART); // remet le serpent au départ setDirection({ x: 1, y: 0 }); // direction : droite setNourriture({ x: 15, y: 10 }); // pomme initiale setScore(0); // score à 0 setGameOver(false); // reset game over setEnJeu(true); // lance la boucle ! };
// Étape 06

L'affichage — JSX et .map()

6
Dessiner la grille avec .map()

On génère toutes les cases de la grille avec .map(). Pour chaque case, on vérifie si c'est la tête, le corps ou la nourriture pour lui donner la bonne couleur.

// ─── AFFICHAGE (le return du composant) ─── return ( <div> {/* ── Écran d'accueil ── */} {!enJeu && !gameOver && ( <div className="ecran"> <h2>🐍 Snake</h2> <button onClick={demarrer}>Jouer</button> </div> )} {/* ── Écran Game Over ── */} {gameOver && ( <div className="ecran"> <h2>Game Over</h2> <p>Score final : {score}</p> <button onClick={demarrer}>Rejouer</button> </div> )} {/* ── La grille ── */} <div className="grille"> {/* On crée un tableau [0,1,2,...,19] pour les lignes */} {[...Array(HAUTEUR)].map((_, y) => {/* Pour chaque ligne, on crée les colonnes */} [...Array(LARGEUR)].map((_, x) => { // Quelle est cette case ? const estTete = serpent[0].x === x && serpent[0].y === y; const estCorps = serpent.some(s => s.x === x && s.y === y); const estPomme = nourriture.x === x && nourriture.y === y; return ( <div key={`{x}-{y}`} // ← clé unique obligatoire className={ estTete ? 'case tete' : estCorps ? 'case corps' : estPomme ? 'case pomme' : 'case' } /> ); }) )} </div> </div> );
Astuce : générer un tableau de N éléments

[...Array(20)] crée un tableau de 20 cases vides. Combiné à .map((_, index) => ...), c'est la façon la plus propre de boucler N fois en JSX.

// Code complet

Le fichier App.jsx — tout assemblé

Comment utiliser ce code

Créez un projet Vite (npm create vite@latest mon-snake -- --template react), remplacez le contenu de src/App.jsx par le code ci-dessous, et remplacez src/App.css par les styles. C'est tout !

// src/App.jsx — Snake complet en React // Formation DWWM — Real Conseil import { useState, useEffect } from 'react'; import './App.css'; // ─── CONSTANTES (en dehors du composant) ── const LARGEUR = 20; const HAUTEUR = 20; const VITESSE = 150; const DEPART = [ { x: 10, y: 10 }, { x: 9, y: 10 }, { x: 8, y: 10 }, ]; // ─── COMPOSANT PRINCIPAL ── function App() { // États const [serpent, setSerpent] = useState(DEPART); const [direction, setDirection] = useState({ x: 1, y: 0 }); const [nourriture, setNourriture] = useState({ x: 15, y: 10 }); const [score, setScore] = useState(0); const [gameOver, setGameOver] = useState(false); const [enJeu, setEnJeu] = useState(false); // ── Boucle de jeu ── useEffect(() => { if (!enJeu || gameOver) return; const timer = setInterval(() => { setSerpent(ancien => { const nouvelleTete = { x: ancien[0].x + direction.x, y: ancien[0].y + direction.y, }; const horsMur = nouvelleTete.x < 0 || nouvelleTete.x >= LARGEUR || nouvelleTete.y < 0 || nouvelleTete.y >= HAUTEUR; const toucheCorps = ancien.some( s => s.x === nouvelleTete.x && s.y === nouvelleTete.y ); if (horsMur || toucheCorps) { setGameOver(true); return ancien; } const aMange = nouvelleTete.x === nourriture.x && nouvelleTete.y === nourriture.y; const nouveau = [nouvelleTete, ...ancien]; if (aMange) { setScore(s => s + 10); placerNourriture(); return nouveau; } return nouveau.slice(0, -1); }); }, VITESSE); return () => clearInterval(timer); }, [enJeu, gameOver, direction, nourriture]); // ── Clavier ── useEffect(() => { const gererTouche = (e) => { if (e.key === 'ArrowUp') setDirection(d => d.y===1 ? d : { x:0, y:-1 }); else if (e.key === 'ArrowDown') setDirection(d => d.y===-1 ? d : { x:0, y: 1 }); else if (e.key === 'ArrowLeft') setDirection(d => d.x===1 ? d : { x:-1, y: 0 }); else if (e.key === 'ArrowRight') setDirection(d => d.x===-1 ? d : { x: 1, y: 0 }); }; window.addEventListener('keydown', gererTouche); return () => window.removeEventListener('keydown', gererTouche); }, []); // ── Fonctions utilitaires ── const placerNourriture = () => { let pos; do { pos = { x: Math.floor(Math.random() * LARGEUR), y: Math.floor(Math.random() * HAUTEUR), }; } while (serpent.some(s => s.x === pos.x && s.y === pos.y)); setNourriture(pos); }; const demarrer = () => { setSerpent(DEPART); setDirection({ x: 1, y: 0 }); setNourriture({ x: 15, y: 10 }); setScore(0); setGameOver(false); setEnJeu(true); }; // ── Rendu ── return ( <div className="app"> <h1>🐍 Snake</h1> <p className="score">Score : {score}</p> <div className="conteneur"> {!enJeu && !gameOver && ( <div className="ecran"> <p>Utilisez les flèches du clavier</p> <button onClick={demarrer}>▶ Jouer</button> </div> )} {gameOver && ( <div className="ecran"> <h2>Game Over</h2> <p>Score final : {score}</p> <button onClick={demarrer}>↺ Rejouer</button> </div> )} <div className="grille"> {[...Array(HAUTEUR)].map((_, y) => [...Array(LARGEUR)].map((_, x) => { const estTete = serpent[0].x===x && serpent[0].y===y; const estCorps = serpent.some(s => s.x===x && s.y===y); const estPomme = nourriture.x===x && nourriture.y===y; return ( <div key={`{x}-{y}`} className={ estTete ? 'case tete' : estCorps ? 'case corps' : estPomme ? 'case pomme' : 'case' } /> ); }) )} </div> </div> </div> ); } export default App;
