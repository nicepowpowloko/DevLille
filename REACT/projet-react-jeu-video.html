Travail en binôme — Choisissez votre jeu !

Vous travaillez par groupe de 2. Chaque binôme choisit un jeu parmi les propositions ci-dessous et le réalise entièrement en React. L'objectif est de mettre en pratique les concepts vus en cours : composants, useState, useEffect, props et gestion d'état. Un binôme = un jeu. Pas deux groupes sur le même jeu si possible.

morpion.jsx
⭕
Morpion (Tic-Tac-Toe)
⬤ Débutant ⏱ 2–3 jours

Le grand classique. Deux joueurs s'affrontent en local sur la même machine. Gérer les tours, détecter le gagnant et afficher le score. Idéal pour bien maîtriser useState.

Concepts React pratiqués
useState props composants logique conditionnelle
Fonctionnalités attendues
Plateau 3×3 cliquable, alternance des joueurs X / O
Détection automatique du gagnant ou match nul
Bouton "Rejouer" et affichage du score cumulé
Bonus : historique des coups + retour arrière
memory-game.jsx
🃏
Jeu de Memory
⬤ Débutant ⏱ 2–3 jours

Retournez les cartes et retrouvez les paires identiques. Excellent pour pratiquer la gestion d'état d'un tableau, les délais avec useEffect et le mélange de tableaux.

Concepts React pratiqués

Fonctionnalités attendues
Grille de cartes mélangées (emojis ou images)
Retournement animé, vérification des paires
Compteur de tentatives et timer
Bonus : meilleur score sauvegardé (localStorage)
quiz-app.jsx
🧠
Quiz interactif
⬤ Intermédiaire ⏱ 3–4 jours

Un quiz avec 10 questions, chronomètre par question et score final. Thème libre (culture générale, React lui-même, cinéma…). Parfait pour structurer des composants réutilisables.

Concepts React pratiqués
useState useEffect composants réutilisables données JSON
Fonctionnalités attendues
Minimum 10 questions avec 4 choix chacune
Barre de progression et chronomètre par question
Écran de résultats avec score et récapitulatif
Bonus : questions chargées depuis une API (Open Trivia DB)

🐍
Snake
⬤ Intermédiaire ⏱ 3–5 jours

Le serpent qui grandit en mangeant des fruits. Gérer le mouvement automatique avec un intervalle, les collisions et les touches du clavier. Bonne introduction aux boucles de jeu en React.

Concepts React pratiqués

Fonctionnalités attendues
Serpent contrôlable aux touches directionnelles

whack-a-mole.jsx
🐹
Whack-a-Mole
⬤ Intermédiaire ⏱ 2–4 jours

Des taupes apparaissent aléatoirement dans des trous — cliquez dessus avant qu'elles disparaissent ! Un classique des jeux de réaction, très ludique à coder et excellent pour setTimeout.

Concepts React pratiqués

Fonctionnalités attendues

wordle-fr.jsx
🟩
Wordle français
⬤ Avancé ⏱ 4–6 jours

Devinez le mot en 6 tentatives. Chaque lettre indique si elle est bien placée (🟩), présente (🟨) ou absente (⬜). Gestion d'un clavier virtuel, d'un tableau 2D et de la validation de mots.

useState useEffect tableau 2D clavier virtuel validation complexe
Fonctionnalités attendues
Grille 6×5 avec coloration des lettres
Clavier virtuel + saisie physique au clavier
Liste de mots valides (dictionnaire JS intégré)
Bonus : animations d'entrée des lettres + mode sombre/clair

Placez des tours sur une grille pour stopper les ennemis qui avancent sur un chemin. Version simplifiée mais réelle. Apprendre à gérer une boucle de jeu complexe et des données imbriquées.

Étapes de travail

Comment s'organiser en binôme

1
Choisissez votre jeu et signalez votre choix
Discutez avec votre binôme du jeu qui vous correspond. Un jeu = un binôme. Signalez votre choix au formateur pour éviter les doublons.
2
Créez un repo GitHub commun dès le début
Un membre crée le repo, l'autre est ajouté en collaborateur. Travaillez avec des branches et faites des commits réguliers avec des messages clairs.
3
Décomposez en composants avant de coder
Faites un schéma (papier ou Figma) de vos composants React avant de commencer. Qui gère quel état ? Quelles props passe-t-on ?
4
Répartissez les tâches équitablement
Exemple : l'un gère la logique de jeu (state, fonctions), l'autre le rendu et le style. Changez les rôles à mi-parcours pour que chacun touche à tout.
5
Préparez une présentation de 5 minutes
Montrez le jeu en action, expliquez votre architecture de composants, parlez des difficultés rencontrées et de ce que vous avez appris.

Évaluation

Critères d'évaluation

Utilisation de React Hooks utilisés correctement (useState, useEffect), composants bien séparés, pas de code spaghetti.
Le jeu fonctionne Le jeu est jouable du début à la fin, sans bug bloquant. La logique est correcte.
Qualité du code Code lisible, bien commenté, noms de variables explicites. Pas de code mort.
Interface & design L'interface est propre et utilisable. Pas besoin d'être parfait, mais soigné.
GitHub & organisation Repo public, commits réguliers des deux membres, README expliquant le projet.
Présentation orale Chaque membre parle. Vous expliquez vos choix techniques et ce que vous avez appris.
