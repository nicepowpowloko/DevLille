Objectifs pédagogiques

Ce que vous allez pratiquer

À travers ce projet, vous allez mobiliser toutes les notions vues en cours sur React dans un contexte réel et ludique. L'idée est de créer un mini-jeu interactif entièrement en React, de A à Z, en binôme.

Travailler en duo

Répartissez-vous les tâches dès le départ : qui fait quoi ? Utilisez GitHub (si possible) ou échangez vos fichiers. Discutez, débugguez ensemble, c'est comme ça qu'on progresse le plus vite !

Composants

useState

Gérer l'état du jeu : score, tour, niveau, vie du joueur…

Événements

Étapes du projet

01

Choisir le jeu & se répartir les rôles

Discutez en binôme, choisissez votre jeu, puis listez les fonctionnalités à implémenter. Définissez clairement : qui gère l'interface ? qui gère la logique ? Écrivez ça sur papier ou dans un fichier README.md.

02

Créer le projet avec Vite

Dans votre terminal : npm create vite@latest mon-jeu -- --template react puis cd mon-jeu, npm install, npm run dev. Supprimez le contenu inutile du fichier App.jsx et partez de zéro !

03

Identifier et créer vos composants

Avant de coder, faites un schéma de votre interface sur papier. Quels sont les "blocs" indépendants ? Exemple pour le Morpion : <Plateau />, <Case />, <Score />, <BoutonRejouer />. Créez un dossier src/components/.

04

Gérer l'état avec useState

Identifiez ce qui doit "changer" dans votre jeu : le score, le tour en cours, l'état gagné/perdu, les cases jouées… Chaque valeur qui change = un useState. Placez les états dans le composant parent qui en a besoin.

05

Connecter la logique aux événements

Ajoutez les onClick, onKeyDown, etc. Écrivez les fonctions qui modifient l'état : vérifier une victoire, augmenter le score, passer au tour suivant… Testez chaque fonctionnalité une par une.

06

Ajouter le rendu conditionnel

Gérez les écrans : écran d'accueil, jeu en cours, victoire, défaite. Utilisez des conditions dans le JSX : {gameState === 'playing' && <Plateau />} ou un opérateur ternaire.

07

Styliser et améliorer

Ajoutez du CSS (fichiers .css, classes CSS ou style inline). Rendez le jeu agréable à utiliser. Bonus : ajoutez des animations CSS, un son, un meilleur score sauvegardé avec localStorage.

08

Présentation au groupe

Préparez une démo de 5 minutes : montrez le jeu en action, expliquez votre découpage en composants, parlez d'une difficulté rencontrée et comment vous l'avez résolue. Montrez votre code !

Mémo React

Une référence rapide des notions essentielles utilisées dans ce projet. Consultez cette section si vous avez un trou de mémoire !

1 — Créer un composant

Un composant React est une fonction JavaScript qui retourne du JSX. Son nom commence toujours par une majuscule.

// src/components/Score.jsx function Score({ points, joueur }) { return ( <div className="score"> <h2>{joueur}</h2> <p>Score : {points}</p> </div> ); } export default Score; // Utilisation dans le parent : <Score joueur="Alice" points=42 />
À retenir
  • Les props sont des paramètres en lecture seule : le composant enfant ne peut pas les modifier.
  • On destructure les props directement dans les paramètres : ({ points, joueur })

2 — useState : gérer un état local

Chaque fois qu'une valeur doit changer et provoquer un rafraîchissement de l'affichage, on utilise useState.

import { useState } from 'react'; function Compteur() { // [valeurActuelle, fonctionPourChanger] = useState(valeurInitiale) const [score, setScore] = useState(0); const [gameOver, setGameOver] = useState(false); const marquerPoint = () => { setScore(score + 1); // ← provoque un re-render }; return ( <div> <p>Score : {score}</p> <button onClick={marquerPoint}>+1</button> </div> ); }
Piège classique

On ne modifie jamais la valeur directement : score = score + 1. On utilise toujours la fonction setter : setScore(score + 1). Sans ça, l'affichage ne se met pas à jour !

3 — État avec un tableau ou un objet

Pour gérer un plateau de jeu, une liste de cartes ou l'historique des coups, on stocke un tableau dans l'état.

const [cases, setCases] = useState(Array(9).fill(null)); // cases = [null, null, null, null, null, null, null, null, null] const jouerCase = (index) => { const nouvellesCases = [...cases]; // ← copie du tableau ! nouvellesCases[index] = 'X'; setCases(nouvellesCases); // ← nouveau tableau = re-render };
Ne jamais muter l'état directement

Toujours créer une copie avec le spread operator [...cases] ou {...objet} avant de modifier, puis passer la copie à la fonction setter.

4 — useEffect : effets de bord

Utilisez useEffect pour déclencher du code après le rendu : minuteurs, décomptes automatiques, chargement de données…

import { useState, useEffect } from 'react'; function Minuteur() { const [temps, setTemps] = useState(30); useEffect(() => { const intervalle = setInterval(() => { setTemps(t => t - 1); // forme fonctionnelle recommandée }, 1000); // ← La fonction de nettoyage : TRÈS IMPORTANTE ! return () => clearInterval(intervalle); }, []); // [] = s'exécute UNE SEULE FOIS au montage return <p>Temps restant : {temps}s</p>; }
Les dépendances de useEffect
  • useEffect(fn, []) → s'exécute une seule fois au démarrage
  • useEffect(fn, [score]) → s'exécute à chaque fois que score change
  • useEffect(fn) → s'exécute à chaque re-render (rarement souhaité)

5 — Rendu conditionnel

Afficher différents écrans selon l'état du jeu : menu d'accueil, partie en cours, victoire, défaite…

function App() { const [ecran, setEcran] = useState('accueil'); // ecran peut valoir : 'accueil' | 'jeu' | 'victoire' | 'defaite' return ( <div> {/* Méthode 1 : opérateur ternaire */} {ecran === 'accueil' ? <Accueil onStart={() => setEcran('jeu')} /> : <Jeu onVictoire={() => setEcran('victoire')} /> } {/* Méthode 2 : && (si seulement dans un cas) */} {ecran === 'victoire' && <Victoire />} </div> ); }

6 — Afficher une liste avec .map()

Pour afficher un tableau de données (cases du plateau, cartes, questions…), on utilise la méthode .map() dans le JSX.

function Plateau({ cases, onClic }) { return ( <div className="plateau"> {cases.map((valeur, index) => ( <Case key={index} // ← OBLIGATOIRE avec .map() valeur={valeur} onClick={() => onClic(index)} /> ))} </div> ); }
La prop key est obligatoire !

React a besoin d'une key unique pour chaque élément dans un .map(). Utilisez un identifiant unique (id, index en dernier recours). Sans elle : warning dans la console et bugs potentiels !

Erreurs fréquentes & solutions

Voici les problèmes les plus souvent rencontrés lors d'un premier projet React. Si vous êtes bloqués, commencez par vérifier ici !

L'affichage ne se met pas à jour quand je change une valeur

Cause : vous modifiez la variable directement au lieu d'utiliser la fonction setter.
Solution : remplacez score = score + 1 par setScore(score + 1). React ne peut détecter les changements que via la fonction setter.

"Cannot read properties of undefined" sur mes props

Cause : le composant parent n'envoie pas la prop, ou le nom est différent.
Solution : vérifiez le nom dans le parent <MonComposant score={score} /> et dans l'enfant function MonComposant({ score }). Les noms doivent être identiques.

Warning "Each child in a list should have a unique key prop"

Cause : vous utilisez .map() sans la prop key.
Solution : ajoutez key={index} ou mieux key={item.id} sur chaque élément retourné dans le .map().

Le minuteur ne s'arrête jamais (ou tourne en double)

Cause : vous avez oublié la fonction de nettoyage dans useEffect.
Solution : retournez toujours return () => clearInterval(monIntervalle); dans votre useEffect pour nettoyer le minuteur quand le composant se démonte.

Ma fonction dans onClick déclenche immédiatement sans cliquer

Cause : vous appelez la fonction au lieu de la passer en référence.
onClick={jouer()} — s'exécute au rendu !
onClick={jouer} — s'exécute au clic.
onClick={() => jouer(index)} — avec un argument.

Je dois modifier l'état mais je lis l'ancienne valeur

Cause : plusieurs mises à jour d'état dans la même fonction.
Solution : utilisez la forme fonctionnelle du setter : setScore(s => s + 1). React garantit alors que s est la dernière valeur à jour.

Réflexe de débogage
  • Ouvrez la console (F12) : les erreurs React sont très explicites !
  • Installez l'extension React Developer Tools (Chrome/Firefox) pour inspecter vos composants et leurs états en temps réel.
  • Ajoutez des console.log(etat) dans vos fonctions pour suivre les valeurs.

Idées

localStorage

Sauvegardez le meilleur score même après fermeture du navigateur avec localStorage.setItem('meilleurScore', score) et rechargez-le avec useEffect au démarrage.

Sons & effets

Ajoutez des sons avec l'API Audio du navigateur : new Audio('son.mp3').play(). Un son de victoire, un son d'erreur, ça change tout !

Données externes

Pour un quiz, récupérez vos questions depuis une API publique comme Open Trivia DB avec fetch() dans un useEffect.
