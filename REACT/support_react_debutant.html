1. Pourquoi apprendre React ?

1.1 Qu'est-ce que React ?

React est une bibliothèque JavaScript créée par Facebook en 2013. Elle permet de construire des interfaces utilisateur (UI) modernes et dynamiques en découpant l'interface en petits blocs réutilisables appelés composants.

[ ]

Composants

L'interface est découpée en blocs réutilisables. Chaque bouton, formulaire, carte est un composant.

~

Réactif

L'interface se met à jour automatiquement quand les données changent, sans recharger la page.

#

Populaire

React est utilisé par Facebook, Netflix, Airbnb, Uber, Instagram. C'est la lib JS la plus demandée en emploi.

1.2 Pourquoi React plutôt que du JavaScript natif ?

JavaScript natif (Vanilla JS)
// Afficher et mettre à jour un compteur
let count = 0;
const btn = document.getElementById('btn');
const display = document.getElementById('count');

btn.addEventListener('click', () => {
    count++;
    display.textContent = count;
    // Mise à jour manuelle du DOM
});
React
// Même chose en React
function Compteur() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>
        Incrementer
      </button>
    </div>
  );
}

1.3 Où utilise-t-on React ?

Cas d'usage de React
Applications SPA : Single Page Application - une seule page HTML, navigation sans rechargement (comme Gmail, Twitter)
Tableaux de bord : Dashboard avec graphiques, données en temps réel, filtres interactifs
E-commerce : Panier en temps réel, filtres produits, pages dynamiques
Applications mobiles : React Native permet de créer des apps iOS et Android avec React
Sites avec beaucoup d'interactions : Formulaires multi-étapes, filtres en temps réel, notifications live
Prérequis avant React :
  • HTML / CSS bases
  • JavaScript : variables, fonctions, tableaux, objets
  • JavaScript moderne : arrow functions, destructuring, spread operator, modules (import/export)
  • Notions de fetch() et async/await (optionnel mais utile)

3. Le JSX

Le JSX (JavaScript XML) est une syntaxe spéciale qui permet d'écrire du HTML directement dans JavaScript. C'est la base de React.

JSX basique
// JSX : HTML dans JavaScript
const element = (
  <div className="carte">
    <h1>Bonjour React !</h1>
    <p>Mon premier composant</p>
  </div>
);

3.1 Différences JSX vs HTML

HTML classique JSX (React) Raison
class="..." className="..." class est un mot reservé en JS
for="..." htmlFor="..." for est un mot reservé en JS
onclick="..." onClick={...} camelCase + accolades pour JS
<input> <input /> Tags auto-fermants obligatoires
style="color: red" style={{'{{'}}color: 'red'{{'}}'}} style est un objet JS

3.2 Expressions JavaScript dans le JSX

On peut insérer n'importe quelle expression JavaScript dans le JSX en utilisant des accolades { }.

JSX + JavaScript
function Bonjour() {
  const prenom = "Thomas";
  const age = 30;
  const estMajeur = age >= 18;

  return (
    <div>
      <h1>Bonjour {prenom} !</h1>
      <p>Tu as {age} ans.</p>
      <p>2 + 2 = {2 + 2}</p>
      <p>{estMajeur ? "Majeur" : "Mineur"}</p>
    </div>
  );
}
Rendu dans le navigateur

Bonjour Thomas !

Tu as 30 ans.

2 + 2 = 4

Majeur

Règle importante : Un composant React ne peut retourner qu'un seul élément racine. Si tu as plusieurs éléments, les entoure avec une <div> ou un <></> (Fragment React).
Fragment React
// Utiliser un Fragment pour éviter une div inutile
return (
  <>
    <h1>Titre</h1>
    <p>Paragraphe</p>
  </>
);

4. Les Composants

Un composant est un bloc de code réutilisable qui retourne du JSX. C'est le concept central de React. Pense-y comme à une brique LEGO : on assemble des petits composants pour créer une interface complète.

4.1 Créer un composant

MonComposant.jsx
// 1. Un composant = une fonction qui retourne du JSX
// 2. Le nom commence TOUJOURS par une majuscule
// 3. Un seul export par fichier (bonne pratique)

function Carte() {
  return (
    <div className="carte">
      <h2>Thomas Dupont</h2>
      <p>Développeur Web</p>
    </div>
  );
}

export default Carte;

4.2 Utiliser un composant dans un autre

App.jsx
// Importer le composant
import Carte from './components/Carte';

function App() {
  return (
    <div>
      <h1>Mon équipe</h1>

      // Utiliser le composant comme une balise HTML
      <Carte />
      <Carte />
      <Carte />
    </div>
  );
}

export default App;

5. Les Props

Les props (propriétés) permettent de passer des données d'un composant parent à un composant enfant. Elles rendent les composants dynamiques et réutilisables.

5.1 Passer des props

App.jsx - Passer des props
// On passe les props comme des attributs HTML
function App() {
  return (
    <div>
      <Carte
        nom="Thomas"
        metier="Formateur"
        age={35}
      />
      <Carte
        nom="Alice"
        metier="Développeuse"
        age={28}
      />
    </div>
  );
}
Carte.jsx - Recevoir des props
// Les props arrivent comme un objet dans la fonction
function Carte(props) {
  return (
    <div className="carte">
      <h2>{props.nom}</h2>
      <p>{props.metier}</p>
      <p>{props.age} ans</p>
    </div>
  );
}

// Version avec destructuring (recommandée)
function Carte({ nom, metier, age }) {
  return (
    <div className="carte">
      <h2>{nom}</h2>
      <p>{metier}</p>
      <p>{age} ans</p>
    </div>
  );
}

export default Carte;
Règle fondamentale : Les props sont en lecture seule. Un composant ne peut jamais modifier ses propres props. Les données vont toujours du parent vers l'enfant (sens unique).

Valeurs par défaut

      {texte}
    </button>
  );

// Utilisation

<Bouton texte="Valider" couleur="vert" />  ← "Valider" en vert

6. Le State avec useState

Le state (état) permet à un composant de stocker et gérer ses propres données. Quand le state change, React re-rend automatiquement le composant.

Hook : useState
Syntaxe
import { useState } from 'react';

// const [valeur, modifieur] = useState(valeurInitiale)
const [compteur, setCompteur] = useState(0);
const [nom, setNom] = useState("");
const [afficher, setAfficher] = useState(false);
const [liste, setListe] = useState([]);

6.1 Exemple : Compteur

Compteur.jsx
import { useState } from 'react';

function Compteur() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Compteur : {count}</h2>
      <button onClick={() => setCount(count + 1)}>
        Incrementer
      </button>
      <button onClick={() => setCount(count - 1)}>
        Decrementer
      </button>
      <button onClick={() => setCount(0)}>
        Reset
      </button>
    </div>
  );
}

export default Compteur;

6.2 Exemple : Formulaire contrôlé

Formulaire.jsx
import { useState } from 'react';

function Formulaire() {
  const [nom, setNom] = useState("");
  const [email, setEmail] = useState("");
  const [message, setMessage] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log({ nom, email });
    setMessage(`Bonjour ${nom}, votre email est ${email}`);
  };

  return (
    <div>
      <form onSubmit={handleSubmit}>
        <input
          type="text"
          value={nom}
          onChange={(e) => setNom(e.target.value)}
          placeholder="Votre nom"
        />
        <input
          type="email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          placeholder="Votre email"
        />
        <button type="submit">Envoyer</button>
      </form>

      {message && <p>{message}</p>}
    </div>
  );
}

export default Formulaire;

7. useEffect

useEffect permet d'exécuter du code quand le composant s'affiche ou quand une donnée change. C'est ici qu'on met les appels API, les timers, etc.

Hook : useEffect
Syntaxe
import { useEffect } from 'react';

// Tableau de dépendances [] = exécuté UNE SEULE FOIS au chargement
useEffect(() => {
  console.log("Composant monté !");
}, []);

// Exécuté à chaque fois que 'valeur' change
useEffect(() => {
  console.log("valeur a changé :", valeur);
}, [valeur]);

// Sans tableau : exécuté à CHAQUE rendu (déconseillé)
useEffect(() => {
  console.log("Re-rendu !");
});

7.1 Exemple : Chargement au démarrage

ChargementData.jsx
import { useState, useEffect } from 'react';

function ListeUtilisateurs() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [erreur, setErreur] = useState(null);

  // Charger les données au montage du composant
  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const response = await fetch('https://jsonplaceholder.typicode.com/users');
        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setErreur("Erreur lors du chargement");
      } finally {
        setLoading(false);
      }
    };

    fetchUsers();
  }, []); ← tableau vide = une seule fois au chargement

  if (loading) return <p>Chargement...</p>;
  if (erreur) return <p>{erreur}</p>;

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

export default ListeUtilisateurs;

9. Consommer une API REST avec React

Voici un exemple complet qui combine useState, useEffect et fetch() pour afficher des données depuis une API.

AppPokemon.jsx - Exemple complet
import { useState, useEffect } from 'react';

// Composant carte Pokemon
function CartePokemon({ pokemon }) {
  return (
    <div className="carte">
      <img src={pokemon.sprites.front_default} alt={pokemon.name} />
      <h3>{pokemon.name}</h3>
      <p>HP : {pokemon.stats[0].base_stat}</p>
    </div>
  );
}

// Composant principal avec recherche
function AppPokemon() {
  const [recherche, setRecherche] = useState("pikachu");
  const [pokemon, setPokemon] = useState(null);
  const [loading, setLoading] = useState(false);
  const [erreur, setErreur] = useState("");

  const chercher = async () => {
    setLoading(true);
    setErreur("");

    try {
      const res = await fetch(
        `https://pokeapi.co/api/v2/pokemon/${recherche.toLowerCase()}`
      );
      if (!res.ok) throw new Error("Pokemon non trouvé");
      const data = await res.json();
      setPokemon(data);
    } catch (err) {
      setErreur(err.message);
      setPokemon(null);
    } finally {
      setLoading(false);
    }
  };

  // Charger Pikachu au démarrage
  useEffect(() => { chercher(); }, []);

  return (
    <div>
      <h1>Recherche Pokemon</h1>

      <input
        value={recherche}
        onChange={(e) => setRecherche(e.target.value)}
        placeholder="Nom du Pokemon"
      />
      <button onClick={chercher}>Rechercher</button>

      {loading && <p>Chargement...</p>}
      {erreur && <p style={{'{{'}}color: 'red'{{'}}'}}>{erreur}</p>}
      {pokemon && <CartePokemon pokemon={pokemon} />}
    </div>
  );
}

export default AppPokemon;
Flux de données dans ce composant
1. Montage : useEffect déclenche chercher() → appel API PokéAPI
2. Loading : setLoading(true) → affiche "Chargement..."
3. Réponse API : setPokemon(data) → React re-rend le composant
4. Affichage : CartePokemon reçoit pokemon en prop → affiche les données
5. Nouvelle recherche : L'utilisateur tape un nom → clique "Rechercher" → chercher() relancé

11. React Router - Navigation entre pages

React Router est la bibliothèque standard pour gérer la navigation entre pages dans une application React. Sans React Router, on ne peut pas avoir plusieurs pages dans une SPA.

11.1 Installation

Terminal
# Installer React Router
npm install react-router-dom

11.2 Concepts essentiels

Les 4 composants principaux de React Router
BrowserRouter : Enveloppe toute l'application - active le système de routing (dans main.jsx)
Routes : Conteneur de toutes les routes - remplace l'ancien Switch
Route : Associe une URL (/accueil, /contact) à un composant page
Link : Remplace les balises <a href> - navigation sans rechargement de page

11.3 Mise en place

main.jsx - Activer le Router
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
)
App.jsx - Définir les routes
import { Routes, Route } from 'react-router-dom'
import Header from './components/Header'
import Accueil from './pages/Accueil'
import Produits from './pages/Produits'
import Contact from './pages/Contact'
import PageNotFound from './pages/PageNotFound'

function App() {
  return (
    <>
      <Header />  ← toujours visible sur toutes les pages

      <Routes>
        <Route path="/"          element={<Accueil />}      />
        <Route path="/produits"  element={<Produits />}     />
        <Route path="/contact"   element={<Contact />}      />
        <Route path="*"          element={<PageNotFound />}  />
      </Routes>
    </>
  )
}

export default App
Header.jsx - Navigation avec Link
import { Link, NavLink } from 'react-router-dom'

function Header() {
  return (
    <nav>
      // Link : navigation simple sans rechargement
      <Link to="/">Accueil</Link>
      <Link to="/produits">Produits</Link>

      // NavLink : ajoute automatiquement la class "active"
      // sur le lien de la page actuelle
      <NavLink
        to="/contact"
        className={({ isActive }) => isActive ? 'lien-actif' : 'lien'}
      >
        Contact
      </NavLink>
    </nav>
  )
}

export default Header

11.4 Routes dynamiques avec paramètres

Une route dynamique permet d'afficher un produit, un utilisateur, un article selon son ID dans l'URL.

App.jsx - Route avec paramètre :id
// Définir la route avec un paramètre :id
<Route path="/produits/:id" element={<DetailProduit />} />

// URL résultante : /produits/1, /produits/42, /produits/abc
DetailProduit.jsx - Récupérer le paramètre
import { useParams } from 'react-router-dom'
import { useState, useEffect } from 'react'

function DetailProduit() {
  // useParams récupère les paramètres de l'URL
  const { id } = useParams()
  const [produit, setProduit] = useState(null)

  useEffect(() => {
    fetch(`https://fakestoreapi.com/products/${id}`)
      .then(res => res.json())
      .then(data => setProduit(data))
  }, [id]) ← se relance si l'id change dans l'URL

  if (!produit) return <p>Chargement...</p>

  return (
    <div>
      <h1>{produit.title}</h1>
      <p>{produit.price} euros</p>
      <img src={produit.image} alt={produit.title} />
    </div>
  )
}

export default DetailProduit

  const handleLogin = () => {

    navigate('/')

    // Revenir en arrière
    navigate(-1)

    // Rediriger sans pouvoir revenir en arrière
    navigate('/dashboard', { replace: true })
  }

  return <button onClick={handleLogin}>Se connecter</button>
}

12.2 Le state du panier dans App.jsx

App.jsx - State central du panier
import { useState } from 'react'
import { Routes, Route } from 'react-router-dom'
import Header from './components/Header'
import Boutique from './pages/Boutique'
import MonPanier from './pages/MonPanier'

function App() {
  // Le panier est un tableau d'objets { ...produit, quantite }
  const [panier, setPanier] = useState([])

  // Ajouter un produit au panier
  const ajouterAuPanier = (produit) => {
    setPanier(panierActuel => {
      // Le produit est déjà dans le panier ?
      const existe = panierActuel.find(item => item.id === produit.id)

      if (existe) {
        // Oui → augmenter la quantité
        return panierActuel.map(item =>
          item.id === produit.id
            ? { ...item, quantite: item.quantite + 1 }
            : item
        )
      } else {
        // Non → l'ajouter avec quantite = 1
        return [...panierActuel, { ...produit, quantite: 1 }]
      }
    })
  }

  // Retirer un produit du panier
  const retirerDuPanier = (id) => {
    setPanier(panierActuel =>
      panierActuel.filter(item => item.id !== id)
    )
  }

  // Modifier la quantité d'un article
  const modifierQuantite = (id, quantite) => {
    if (quantite <= 0) {
      retirerDuPanier(id)
      return
    }
    setPanier(panierActuel =>
      panierActuel.map(item =>
        item.id === id ? { ...item, quantite } : item
      )
    )
  }

  // Vider le panier
  const viderPanier = () => setPanier([])

  // Nombre total d'articles
  const nbArticles = panier.reduce((total, item) => total + item.quantite, 0)

  // Total du panier
  const totalPanier = panier.reduce(
    (total, item) => total + item.prix * item.quantite, 0
  )

  return (
    <>
      <Header nbArticles={nbArticles} />
      <Routes>
        <Route path="/"       element={<Boutique ajouterAuPanier={ajouterAuPanier} />} />
        <Route path="/panier" element={
          <MonPanier
            panier={panier}
            retirerDuPanier={retirerDuPanier}
            modifierQuantite={modifierQuantite}
            viderPanier={viderPanier}
            total={totalPanier}
          />
        } />
      </Routes>
    </>
  )
}

export default App

Concept important - Remontée d'état (Lifting State Up) :

Le panier est géré dans App.jsx et non dans le composant Panier. Pourquoi ? Parce que plusieurs composants ont besoin d'y accéder : le Header (affiche le nombre d'articles), la Boutique (ajouter), le Panier (lire et modifier). On place toujours le state dans le composant parent commun le plus proche.

App.jsx
import { useState } from 'react'
import { Routes, Route } from 'react-router-dom'
import Header from './components/Header'
import ListeTaches from './pages/ListeTaches'
import DetailTache from './pages/DetailTache'

function App() {
  const [taches, setTaches] = useState([
    { id: 1, titre: "Apprendre React", description: "Étudier les hooks", priorite: "haute", terminee: false },
    { id: 2, titre: "Faire le TP", description: "Exercice Todo List", priorite: "normale", terminee: false },
    { id: 3, titre: "Réviser JS", description: "Arrow functions, map, filter", priorite: "faible", terminee: true },
  ])

  // Ajouter une tâche
  const ajouterTache = (nouvelleTache) => {
    const tacheAvecId = {
      ...nouvelleTache,
      id: Date.now(), ← ID unique basé sur timestamp
      terminee: false
    }
    setTaches([...taches, tacheAvecId])
  }

  // Basculer terminée / en cours
  const toggleTerminee = (id) => {
    setTaches(taches.map(t =>
      t.id === id ? { ...t, terminee: !t.terminee } : t
    ))
  }

  // Supprimer une tâche
  const supprimerTache = (id) => {
    if (confirm("Supprimer cette tâche ?")) {
      setTaches(taches.filter(t => t.id !== id))
    }
  }

  return (
    <>
      <Header />
      <Routes>
        <Route path="/" element={
          <ListeTaches
            taches={taches}
            ajouterTache={ajouterTache}
            toggleTerminee={toggleTerminee}
            supprimerTache={supprimerTache}
          />
        } />
        <Route path="/taches/:id" element={<DetailTache taches={taches} />} />
      </Routes>
    </>
  )
}

export default App

import { useState } from 'react'
import CarteTache from '../components/CarteTache'

function ListeTaches({ taches, ajouterTache, toggleTerminee, supprimerTache }) {
  const [filtre, setFiltre] = useState('toutes')

  const tachesFiltrees = taches.filter(t => {

import { useState } from 'react'

function FormulaireAjout({ ajouterTache }) {
  const [form, setForm] = useState({
    titre: '',
    description: '',
    priorite: 'normale'
  })

  const handleChange = (e) => {
    setForm({ ...form, [e.target.name]: e.target.value })
  }

  const handleSubmit = (e) => {
    e.preventDefault()
    if (!form.titre.trim()) return
    ajouterTache(form)
    setForm({ titre: '', description: '', priorite: 'normale' })
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        name="titre"
        value={form.titre}
        onChange={handleChange}
        placeholder="Titre de la tache"
        required
      />
      <textarea
        name="description"
        value={form.description}
        onChange={handleChange}
        placeholder="Description (optionnel)"
      />
      <select name="priorite" value={form.priorite} onChange={handleChange}>
        <option value="faible">Faible</option>
        <option value="normale">Normale</option>
        <option value="haute">Haute</option>
      </select>
      <button type="submit">Ajouter la tache</button>
    </form>
  )
}

import { useParams, Link } from 'react-router-dom'

function DetailTache({ taches }) {
  const { id } = useParams()

  // Trouver la tâche dont l'id correspond à l'URL
  const tache = taches.find(t => t.id === Number(id))

  if (!tache) return <p>Tache introuvable.</p>

  const couleurPriorite = {
    faible: 'green',
    normale: 'orange',
    haute: 'red'
  }

  return (
    <div>
      <Link to="/">← Retour a la liste</Link>

      <h1>{tache.titre}</h1>
      <p>{tache.description}</p>

      <span style={{'{{'} color: couleurPriorite[tache.priorite] {'}}'}}}>
        Priorite : {tache.priorite}
      </span>

      <p>Statut : {tache.terminee ? "Terminee" : "En cours"}</p>
    </div>
  )
}
