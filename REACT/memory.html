00
Préparation

Le plan — ce qu'on va construire

Avant de coder, on réfléchit à l'architecture. Un Memory c'est une grille 4×4 de cartes retournées face cachée. On clique sur deux cartes — si elles ont le même symbole, elles restent visibles. Sinon elles se retournent. On cherche les 8 paires. On décompose en 3 composants :

App ← STATE : cartes[], selection[], trouvees[], tentatives │ ← EFFECT : compare les 2 cartes sélectionnées ├── StatusBar ← affiche paires trouvées / tentatives / temps │ props: paires, tentatives, temps │ ├── Grid ← la grille 4×4 │ props: cartes[], selection[], trouvees[], onClic │ └── Carte × 16 ← chaque carte (dos / face) │ props: carte, retournee, trouvee, onClick │ └── BoutonReset ← recommencer / mélanger props: onReset
💡
Le tableau de données est la clé. On part d'un tableau de 8 symboles, on le double pour créer 16 cartes, puis on mélange. C'est map() qui transforme chaque élément du tableau en composant Carte. Le STATE en lui-même est très simple — c'est la structure des données qui fait le jeu.

Les données c'est un tableau d'objets, chacun avec un id unique et un symbole :

Structure des donnéesdonnées
// 8 symboles de base
const SYMBOLES = ['🦊', '🐬', '🌵', '🎸', '🍕', '🚀', '🎯', '🦋']

// Après doublement + mélange → tableau de 16 cartes
// Chaque carte = { id: unique, symbole: '🦊' }
[
    { id: 0, symbole: '🚀' },   // index 0 — position dans la grille
    { id: 1, symbole: '🦊' },   // index 1
    { id: 2, symbole: '🎸' },   // index 2
    // ... 13 autres
    { id: 15, symbole: '🚀' },  // le doublon de id 0 — même symbole !
]

// Les IDs sont UNIQUES — c'est grâce à eux qu'on identifie
// chaque carte individuellement dans la grille.
// Les SYMBOLES sont en double — c'est ce qu'on compare pour les paires.
ℹ️
id ≠ symbole. L'id est unique pour chaque carte (0 à 15) — c'est pour React et la sélection. Le symbole est en double (2 cartes par symbole) — c'est ce qu'on compare pour trouver une paire. Sans cette distinction, impossible de savoir quelle carte précise a été cliquée.

La fonction mélanger : on double le tableau, on donne un id unique à chaque carte, on mélange avec sort :

Fonction créerJeu() — hors du composant
const SYMBOLES = ['🦊', '🐬', '🌵', '🎸', '🍕', '🚀', '🎯', '🦋']

function créerJeu() {
    return [...SYMBOLES, ...SYMBOLES]   // doubler : 8 → 16 cartes
        .map((symbole, i) => ({ id: i, symbole }))  // ajouter un id unique
        .sort(() => Math.random() - 0.5)              // mélanger aléatoirement
}

// Exemple de résultat :
// créerJeu() → [ {id:12, symbole:'🦋'}, {id:3, symbole:'🎸'}, ... ]
// À chaque appel, ordre différent — c'est le mélange !
💡
.sort(() => Math.random() - 0.5) — cette technique mélange un tableau en triant de façon aléatoire (le comparateur renvoie un nombre positif ou négatif au hasard). Ce n'est pas le mélange le plus uniforme (Fisher-Yates est mieux), mais c'est court et suffisant pour un jeu.

Étape 1 — Premier composant

La Carte — dos et face

Le composant Carte est le plus visuel du projet. Il reçoit 4 props : carte (l'objet données), retournee (sélectionnée en ce moment), trouvee (paire validée), et onClick. L'effet de retournement 3D est en CSS pur.

Carte.jsxnouveau
// Carte.jsx
// Props reçues :
//   carte     → { id, symbole }  — les données de la carte
//   retournee → boolean — sélectionnée (temporairement visible)
//   trouvee   → boolean — paire validée (reste visible)
//   onClick   → fonction à appeler au clic

function Carte({ carte, retournee, trouvee, onClick }) {
    // La carte est visible si elle est retournée OU trouvée
    const visible = retournee || trouvee

    return (
        <div
            className={`carte ${visible ? 'retournee' : ''} ${trouvee ? 'trouvee' : ''}`}
            onClick={!visible ? onClick : undefined}
        >
            {/* Le conteneur qui se retourne en 3D */}
            <div className="carte-inner">

                {/* Le dos — visible par défaut */}
                <div className="carte-dos">?</div>

                {/* La face — visible après retournement */}
                <div className="carte-face">
                    {carte.symbole}
                </div>

            </div>
        </div>
    )
}

export default Carte

🔄
backface-visibility: hidden — la clé du retournement. Sans ça, les deux faces seraient visibles en même temps. Cette propriété dit au navigateur : "cache cette face quand elle est tournée vers l'arrière". Combinée avec transform: rotateY(180deg) sur la face avant, on obtient l'effet de carte qui se retourne.
▶
À ce stade : on a une carte qui affiche "?" et qui se retourne en 3D quand on ajoute la classe retournee. Elle ne sait pas encore qu'elle fait partie d'un jeu — c'est App qui gérera ça.
02
Étape 2 — map() en action

La Grille — map() transforme les données en composants

C'est ici que map() prend tout son sens. Le composant Grid reçoit un tableau de 16 objets et les transforme en 16 composants Carte. Zéro logique — pur affichage dirigé par les données.

Grid.jsxnouveau
// Grid.jsx
// Props reçues :
//   cartes    → { id, symbole }[] — les 16 cartes mélangées
//   selection → number[]          — IDs des 1 ou 2 cartes sélectionnées
//   trouvees  → number[]          — IDs de toutes les paires validées
//   onClic    → fonction(id)      — appelée au clic sur une carte

function Grid({ cartes, selection, trouvees, onClic }) {
    return (
        <div className="grid">
            {cartes.map(carte => (
                <Carte
                    key={carte.id}
                    carte={carte}
                    retournee={selection.includes(carte.id)}
                    trouvee={trouvees.includes(carte.id)}
                    onClick={() => onClic(carte.id)}
                />
            ))}
        </div>
    )
}

export default Grid
Comment map() connecte données et affichage
Données → cartes[] = tableau de 16 objets {id, symbole}
map() → transforme chaque objet en composant <Carte />
selection.includes(id) → calcule automatiquement si la carte est visible
trouvees.includes(id) → calcule automatiquement si la paire est validée

Grid ne stocke rien. Toute la logique est dans les props qu'App lui passe.
key={carte.id} et non key={index}. React utilise la key pour identifier chaque élément d'une liste. Utiliser l'index du tableau comme key peut créer des bugs visuels quand l'ordre change (ex: après un nouveau mélange). L'id unique de chaque carte est une clé stable et fiable.
▶
À ce stade : la grille 4×4 s'affiche. On peut passer n'importe quels tableaux selection et trouvees en props pour tester visuellement les états. Le map() fait tout le travail de rendu.
03
Étape 3 — Organiser le state

Le State dans App

On initialise tout le state dans App. La structure est simple : 4 useState qui couvrent l'ensemble du jeu. Chaque state a un rôle précis et distinct.

App.jsx — état initialnouveau
import { useState, useEffect } from 'react'
import Grid from './Grid'

// ... (SYMBOLES et créerJeu définis plus haut)

function App() {
    // Les 16 cartes mélangées — la source de vérité du plateau
    const [cartes,     setCartes]     = useState(créerJeu())

    // IDs des cartes actuellement sélectionnées (max 2)
    const [selection,  setSelection]  = useState([])

    // IDs de toutes les cartes dont la paire a été trouvée
    const [trouvees,   setTrouvees]   = useState([])

    // Nombre de tentatives (chaque fois qu'on retourne 2 cartes)
    const [tentatives, setTentatives] = useState(0)

    // Valeur dérivée — pas besoin d'un state séparé
    const paires = trouvees.length / 2    // 2 IDs par paire
    const victoire = paires === 8         // 8 paires = partie gagnée

    return (
        <div className="app">
            <h1>Memory</h1>
            <p>Paires : {paires}/8 — Tentatives : {tentatives}</p>
            <Grid
                cartes={cartes}
                selection={selection}
                trouvees={trouvees}
                onClic={id => console.log('clic', id)}
            />
        </div>
    )
}

export default App
Rôle de chaque state
cartes[] — le plateau fixe une fois mélangé. Ne change qu'au reset.
selection[] — les IDs des cartes temporairement retournées (0, 1 ou 2 éléments).
trouvees[] — liste cumulative des IDs des paires validées. Grandit jusqu'à 16.
tentatives — compteur simple, incrémenté à chaque deuxième carte retournée.
paires et victoire sont des valeurs dérivées. Pas besoin de useState pour elles — elles se calculent instantanément depuis trouvees. En React, une règle simple : si une valeur peut être calculée depuis le state existant, ne la mets pas dans le state.
▶
À ce stade : la grille s'affiche avec 16 cartes mélangées face cachée. Les clics sont loggués dans la console. Aucune carte ne se retourne encore — c'est l'étape suivante.
04
Étape 4 — La logique de clic

Gérer le clic — retourner une carte

La fonction cliquer gère le retournement d'une carte. Elle doit vérifier plusieurs conditions avant d'agir, puis mettre à jour la sélection. La détection de paire sera gérée séparément par useEffect à l'étape 5.

App.jsx — fonction cliquermodifier
function cliquer(id) {
    // 1. Ignorer si déjà 2 cartes retournées (en cours de comparaison)
    if (selection.length === 2) return

    // 2. Ignorer si la carte est déjà dans la sélection (double-clic)
    if (selection.includes(id)) return

    // 3. Ignorer si la carte fait partie d'une paire déjà trouvée
    if (trouvees.includes(id)) return

    // 4. Ajouter la carte à la sélection
    const nouvelleSel = [...selection, id]
    setSelection(nouvelleSel)

    // 5. Si c'est la 2ème carte → incrémenter les tentatives
    if (nouvelleSel.length === 2) {
        setTentatives(t => t + 1)
    }
    // La comparaison des 2 cartes est gérée par useEffect (étape 5)
}
ℹ️
Pourquoi séparer cliquer et la comparaison ? On aurait pu tout mettre dans cliquer, mais setSelection est asynchrone — la valeur de selection ne se met pas à jour instantanément après l'appel. useEffect s'exécute après que React ait mis à jour le state et re-rendu, donc il voit toujours les valeurs correctes.
▶
À ce stade : les cartes se retournent au clic. On peut en retourner 2 puis plus rien — la garde selection.length === 2 bloque les clics suivants. Mais elles restent retournées indéfiniment car la comparaison n'est pas encore implémentée.
05
Étape 5 — Le cœur de la logique

useEffect — surveiller la sélection et détecter les paires

useEffect permet de réagir à un changement de state. Ici, on veut : "à chaque fois que selection change et contient exactement 2 cartes, compare-les". C'est exactement le cas d'usage de useEffect avec un tableau de dépendances.

🎯
useEffect — rappel du principe. useEffect(callback, [deps]) exécute callback après chaque render où deps a changé. Le tableau [selection] dit à React : "surveille selection — si sa valeur change, lance la callback". C'est un observateur de state.
App.jsx — useEffect de comparaisonnouveau
useEffect(() => {
    // Ne rien faire si on n'a pas encore 2 cartes retournées
    if (selection.length !== 2) return

    const [id1, id2] = selection

    // Retrouver les objets carte depuis les IDs
    const carte1 = cartes.find(c => c.id === id1)
    const carte2 = cartes.find(c => c.id === id2)

    if (carte1.symbole === carte2.symbole) {
        // Paire trouvée — ajouter les 2 IDs aux trouvées
        setTrouvees(prev => [...prev, id1, id2])
        setSelection([])  // vider la sélection immédiatement
    } else {
        //  Pas une paire — attendre 900ms puis retourner les cartes
        const timer = setTimeout(() => {
            setSelection([])
        }, 900)
        // Nettoyage : annuler le timer si le composant est démonté
        return () => clearTimeout(timer)
    }

}, [selection])  // ← se déclenche à chaque changement de selection
Le return dans useEffect = fonction de nettoyage. Quand on retourne une fonction depuis useEffect, React l'appelle avant de re-lancer l'effet ou de démonter le composant. Ici, si la sélection change avant les 900ms (reset par exemple), le clearTimeout annule le timer fantôme.
find() pour retrouver une carte depuis son ID. On stocke uniquement les IDs dans selection (léger), puis on retrouve les objets complets avec cartes.find(c => c.id === id) au moment de la comparaison. C'est plus propre que de stocker les objets entiers dans la sélection.
Le jeu est fonctionnel ! Les cartes se retournent, les paires validées restent visibles (fond vert), les non-paires se retournent après 900ms. Le compteur de tentatives s'incrémente. Il manque le reset et les finitions.

Étape 6 — Bonus avancé

Timer et meilleur score avec useEffect

On ajoute un chronomètre qui démarre au premier clic et s'arrête à la victoire. C'est un deuxième useEffect — on voit ici qu'on peut en avoir plusieurs dans un même composant, chacun surveillant des dépendances différentes.

App.jsx — timer avec useEffectversion avancée
const [secondes,     setSecondes]     = useState(0)
const [enCours,      setEnCours]      = useState(false)
const [meilleurTemps, setMeilleurTemps] = useState(null)

// Effect 1 — démarrer le timer au premier clic
useEffect(() => {
    if (tentatives === 1 && !enCours) {
        setEnCours(true)   // déclenche le 2ème effect
    }
}, [tentatives])

// Effect 2 — le chronomètre (surveille enCours)
useEffect(() => {
    if (!enCours) return

    const id = setInterval(() => setSecondes(s => s + 1), 1000)
    return () => clearInterval(id)  // nettoyage à l'arrêt
}, [enCours])

// Effect 3 — détecter la victoire (surveille trouvees)
useEffect(() => {
    if (trouvees.length !== 16) return

    setEnCours(false)  // stoppe le chrono
    if (meilleurTemps === null || secondes < meilleurTemps) {
        setMeilleurTemps(secondes)
    }
}, [trouvees])
Plusieurs useEffect = séparation des responsabilités. Chaque useEffect a une responsabilité unique : démarrer le timer, faire tourner le chrono, détecter la victoire. C'est plus lisible et plus maintenable qu'un seul gros effet qui fait tout. C'est la philosophie React des "hooks composables".
La fonction reset — on remet tout à zéro :
App.jsx — fonction reset
function reset() {
    setCartes(créerJeu())  // nouveau mélange
    setSelection([])
    setTrouvees([])
    setTentatives(0)
    setSecondes(0)
    setEnCours(false)
}

Code complet

Version finale — un seul fichier simplifié

Voici le code complet du jeu en un seul fichier React, avec tous les styles en inline. Version condensée pour avoir une vision globale de toute la structure.

Memory.jsx — code complet, un fichier
import { useState, useEffect } from 'react'

// ── Données ─
const SYMBOLES = ['🦊', '🐬', '🌵', '🎸', '🍕', '🚀', '🎯', '🦋']

function créerJeu() {
    return [...SYMBOLES, ...SYMBOLES]
        .map((symbole, i) => ({ id: i, symbole }))
        .sort(() => Math.random() - 0.5)
}

// ── Composant Carte ─
function Carte({ carte, retournee, trouvee, onClick }) {
    const visible = retournee || trouvee
    return (
        <div
            onClick={!visible ? onClick : undefined}
            style={{ width:'80px', height:'80px', cursor: visible ? 'default' : 'pointer', perspective:'600px' }}
        >
            <div style={{
                width:'100%', height:'100%', position:'relative',
                transformStyle:'preserve-3d',
                transition:'transform .45s ease',
                transform: visible ? 'rotateY(180deg)' : 'rotateY(0deg)',
            }}>
                {/* Dos */}
                <div style={{ position:'absolute', inset:0, borderRadius:'10px', display:'flex', alignItems:'center', justifyContent:'center', backfaceVisibility:'hidden', background:'#111820', border:'2px solid #1e2d3d', fontSize:'1.4rem', color:'#3d444d' }}>?</div>
                {/* Face */}
                <div style={{ position:'absolute', inset:0, borderRadius:'10px', display:'flex', alignItems:'center', justifyContent:'center', backfaceVisibility:'hidden', transform:'rotateY(180deg)', background: trouvee ? 'rgba(68,214,44,.1)' : 'rgba(192,132,252,.12)', border: trouvee ? '2px solid rgba(68,214,44,.4)' : '2px solid rgba(192,132,252,.3)', fontSize:'2rem' }}>{carte.symbole}</div>
            </div>
        </div>
    )
}

// ── Composant principal ─
export default function Memory() {
    const [cartes,      setCartes]      = useState(créerJeu())
    const [selection,   setSelection]   = useState([])
    const [trouvees,    setTrouvees]    = useState([])
    const [tentatives,  setTentatives]  = useState(0)
    const [secondes,    setSecondes]    = useState(0)
    const [enCours,     setEnCours]     = useState(false)
    const [meilleur,    setMeilleur]    = useState(null)

    const paires   = trouvees.length / 2
    const victoire = paires === 8

    // ── Effect : comparaison des 2 cartes ──
    useEffect(() => {
        if (selection.length !== 2) return
        const [id1, id2] = selection
        const c1 = cartes.find(c => c.id === id1)
        const c2 = cartes.find(c => c.id === id2)
        if (c1.symbole === c2.symbole) {
            setTrouvees(p => [...p, id1, id2])
            setSelection([])
        } else {
            const t = setTimeout(() => setSelection([]), 900)
            return () => clearTimeout(t)
        }
    }, [selection])

    // ── Effect : chronomètre ──
    useEffect(() => {
        if (!enCours) return
        const id = setInterval(() => setSecondes(s => s + 1), 1000)
        return () => clearInterval(id)
    }, [enCours])

    // ── Effect : démarrer au 1er clic ──
    useEffect(() => {
        if (tentatives === 1 && !enCours) setEnCours(true)
    }, [tentatives])

    // ── Effect : victoire ──
    useEffect(() => {
        if (!victoire) return
        setEnCours(false)
        if (meilleur === null || secondes < meilleur) setMeilleur(secondes)
    }, [victoire])

    function cliquer(id) {
        if (selection.length === 2 || selection.includes(id) || trouvees.includes(id)) return
        const s = [...selection, id]
        setSelection(s)
        if (s.length === 2) setTentatives(t => t + 1)
    }

    function reset() {
        setCartes(créerJeu()); setSelection([]); setTrouvees([])
        setTentatives(0); setSecondes(0); setEnCours(false)
    }

    return (
        <div style={{ minHeight:'100vh', background:'#080b0f', display:'flex', flexDirection:'column', alignItems:'center', justifyContent:'center', gap:'24px', fontFamily:'system-ui' }}>

            <h1 style={{ color:'#c084fc', fontSize:'2.2rem', fontWeight:900 }}>Memory</h1>

            {/* Stats */}
            <div style={{ display:'flex', gap:'36px' }}>
                {[
                    ['Paires',   `${paires}/8`,      '#c084fc'],
                    ['Essais',   tentatives,        '#f7df1e'],
                    ['Temps',    secondes + 's',    '#ffa657'],
                    ['Record',   meilleur !== null ? meilleur + 's' : '—', '#44D62C'],
                ].map(([label, val, color]) => (
                    <div key={label} style={{ textAlign:'center' }}>
                        <div style={{ color:'#7d8590', fontSize:'.6rem', textTransform:'uppercase', letterSpacing:'.1em' }}>{label}</div>
                        <div style={{ color, fontSize:'1.8rem', fontWeight:900 }}>{val}</div>
                    </div>
                ))}
            </div>

            {/* Grille */}
            <div style={{ display:'grid', gridTemplateColumns:'repeat(4,1fr)', gap:'10px' }}>
                {cartes.map(carte => (
                    <Carte
                        key={carte.id}
                        carte={carte}
                        retournee={selection.includes(carte.id)}
                        trouvee={trouvees.includes(carte.id)}
                        onClick={() => cliquer(carte.id)}
                    />
                ))}
            </div>

            {/* Victoire */}
            {victoire && (
                <div style={{ color:'#9fdb8a', fontFamily:'monospace', padding:'10px 24px', background:'rgba(68,214,44,.07)', border:'1px solid rgba(68,214,44,.2)', borderRadius:'8px' }}>
                    Gagné en {secondes}s et {tentatives} essais !
                </div>
            )}

            {/* Bouton reset */}
            <button
                onClick={reset}
                style={{ padding:'10px 32px', background:'rgba(192,132,252,.1)', border:'1px solid rgba(192,132,252,.3)', color:'#c084fc', borderRadius:'8px', cursor:'pointer', fontWeight:700, fontSize:'.9rem' }}
            >
                {victoire ? 'Rejouer' : tentatives > 0 ? 'Recommencer' : 'Mélanger'}
            </button>

        </div>
    )
}
