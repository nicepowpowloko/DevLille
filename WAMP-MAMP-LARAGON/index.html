Comparatif

WAMP vs MAMP vs Laragon

Les trois environnements installent le meme trio : Apache (serveur web), MySQL/MariaDB (base de donnees) et PHP. Ils different par leur interface et leur plateforme.

WAMP

Windows uniquement

WampServer installe Apache, MySQL et PHP. Interface en icone dans la barre des taches. Le plus repandu en formation francophone.

URL : wampserver.com

MAMP

Mac + Windows

MAMP est le choix naturel sur Mac. Existe aussi en version Windows. Interface graphique simple. Version gratuite suffisante pour nos TPs.

URL : mamp.info

Laragon

Windows (leger)

Laragon est plus moderne et leger. Portable, pas d'installation systeme. Demarre tres rapidement. Prefere par beaucoup de devs Windows.

URL : laragon.org

Linux (LAMP)

Ubuntu / Debian

Apache + MySQL + PHP installes via apt. Pas d'interface graphique : tout se gere en terminal. Standard pour la production.

Doc : ubuntu.com + packages apt

WAMP

Installation et demarrage

WAMP — Windows
1
Telecharger WampServer sur wampserver.com. Choisir la version 64-bit correspondant a votre Windows.
2
Lancer l'installateur en tant qu'administrateur (clic droit → "Executer en tant qu'administrateur"). Accepter toutes les options par defaut.
3
A la fin de l'installation, WAMP demande le navigateur par defaut et l'editeur de texte. Valider avec les chemins proposes.
4
Lancer WampServer depuis le bureau. L'icone W apparait dans la barre des taches en bas a droite.
5
Attendre que l'icone devienne verte. Rouge = erreur, Orange = en cours, Vert = tout fonctionne.
6
Ouvrir le navigateur et aller sur http://localhost. La page d'accueil de WampServer doit s'afficher.
!
Icone reste orange ou rouge ? Souvent un conflit de port 80 avec Skype ou IIS. Clic droit sur l'icone WAMP → Tools → Test Port 80. Ou changer le port Apache dans la configuration.

Ouvrir phpMyAdmin : clic gauche sur l'icone verte → "phpMyAdmin". Ou directement dans le navigateur : http://localhost/phpmyadmin.

Connexion par defaut : identifiant root, mot de passe vide (ne rien saisir).

!
Dossier des projets WAMP. Vos fichiers PHP doivent etre places dans C:\wamp64\www\nom-projet\. Ensuite accessible sur http://localhost/nom-projet.

Creer la base de donnees et les tables

WAMP — Creer une base de donnees

Deux methodes : via phpMyAdmin (interface graphique) ou via le terminal MySQL. Les deux aboutissent au meme resultat.

Methode 1 — phpMyAdmin

1
Ouvrir http://localhost/phpmyadmin. Se connecter avec root / mot de passe vide.
2
Dans le panneau gauche, cliquer sur "Nouveau" (ou "New" en anglais) tout en haut de la liste des bases.
3
Saisir le nom de la base de donnees : boutique. Choisir l'interclassement utf8mb4_unicode_ci. Cliquer "Creer".
4
La base boutique apparait dans le panneau gauche. Cliquer dessus pour la selectionner.
5
Cliquer sur l'onglet "SQL" en haut. Coller le script de creation de tables (voir section 07). Cliquer "Executer".
6
Les tables apparaissent dans le panneau gauche. Cliquer sur une table pour voir sa structure.
+
Raccourci WAMP phpMyAdmin. Clic gauche sur l'icone verte dans la barre des taches → phpMyAdmin. Plus rapide que taper l'URL.

MAMP

Installation et demarrage

MAMP — Mac & Windows
1
Telecharger MAMP (version gratuite) sur mamp.info. Sur Mac : fichier .pkg. Sur Windows : installateur .exe.
2
Mac : ouvrir le .pkg et suivre l'assistant. MAMP s'installe dans /Applications/MAMP/. Windows : lancer l'installateur, chemin par defaut C:\MAMP.
3
Lancer l'application MAMP (pas MAMP Pro). L'interface avec deux boutons apparait.
4
Cliquer sur "Start Servers". Les deux voyants Apache et MySQL passent au vert.
5
Cliquer sur "Open WebStart page" ou ouvrir http://localhost:8888 dans le navigateur.
6
La page de demarrage MAMP s'affiche avec les liens vers phpMyAdmin et les infos PHP.
!
Port specifique de MAMP. MAMP utilise par defaut le port 8888 pour Apache et 8889 pour MySQL (version gratuite). Votre URL sera http://localhost:8888/nom-projet. Dans votre connexion PDO, le port MySQL sera 8889.

Acces phpMyAdmin sur Mac : http://localhost:8888/phpMyAdmin/ ou clic sur le lien dans la page de demarrage. Identifiant : root, mot de passe : root.

!
Dossier des projets MAMP. Mac : /Applications/MAMP/htdocs/nom-projet/. Windows : C:\MAMP\htdocs\nom-projet\. Accessible sur http://localhost:8888/nom-projet.

Laragon

Installation et demarrage

Laragon — Windows
1
Telecharger Laragon Full sur laragon.org. La version "Full" inclut PHP, MySQL, phpMyAdmin, Composer et Node.js.
2
Lancer l'installateur. Laragon propose de s'installer dans C:\laragon. Ne pas changer le dossier pour eviter les problemes de chemin.
3
Lancer Laragon. L'interface epuree avec les boutons "Start All" et "Stop All" apparait.
4
Cliquer sur "Start All". Apache et MySQL demarrent. Les indicateurs passent au vert.
5
Cliquer sur "Web" pour ouvrir le navigateur sur http://localhost. La page de demarrage Laragon s'affiche.
6
Menu "Database" dans Laragon ouvre directement HeidiSQL, ou cliquer sur "phpMyAdmin" dans la page web.
+
Laragon cree des virtual hosts automatiquement. Chaque dossier cree dans C:\laragon\www\ devient accessible sur http://nom-dossier.test. Tres pratique pour avoir plusieurs projets distincts.

Acces phpMyAdmin : dans l'interface Laragon, menu "Database" → "phpMyAdmin". Ou http://localhost/phpmyadmin. Identifiant : root, mot de passe : vide.

!
Dossier des projets Laragon. C:\laragon\www\nom-projet\. Accessible sur http://localhost/nom-projet ou http://nom-projet.test (virtual host auto).

Laragon

Creer la base de donnees et les tables

Laragon — Creer une base de donnees

Laragon propose deux outils pour gerer MySQL : phpMyAdmin (navigateur) et HeidiSQL (client lourd integre, plus complet).

Via HeidiSQL (recommande Laragon)

1
Dans l'interface Laragon, clic sur "Database" → "HeidiSQL". HeidiSQL s'ouvre connecte automatiquement.
2
Dans le panneau gauche, clic droit sur la connexion → "Creer nouveau" → "Base de donnees".
3
Saisir le nom boutique, interclassement utf8mb4_unicode_ci. Valider.
4
Double-cliquer sur la base boutique pour la selectionner. Cliquer sur "Requete" (onglet en haut).
5
Coller le script SQL de creation de tables (section 07). Cliquer "Executer (F9)".

Via phpMyAdmin

1
Depuis la page http://localhost/phpmyadmin. Login : root / vide.
2
Meme procedure que WAMP : "Nouveau" → nom boutique → utf8mb4_unicode_ci → "Creer" → onglet SQL → coller et executer.

Linux

Installation LAMP sur Ubuntu/Debian

Linux (Ubuntu/Debian) — LAMP

Sur Linux, pas d'installateur graphique : on installe Apache, MySQL et PHP directement via le gestionnaire de paquets. La distribution Ubuntu/Debian est la plus courante en formation.

1
Ouvrir un terminal. Mettre a jour les paquets : sudo apt update && sudo apt upgrade -y.
2
Installer Apache + MySQL + PHP en une commande (voir bloc ci-dessous).
3
Demarrer et activer les services : sudo systemctl start apache2 mysql.
4
Tester dans le navigateur : http://localhost. La page Apache par defaut s'affiche.
5
Securiser MySQL avec : sudo mysql_secure_installation (definir un mot de passe root, retirer les utilisateurs anonymes).
Installation LAMP — Ubuntu/DebianTerminal
# Ubuntu / Debian — tout en une commande
sudo apt update && sudo apt upgrade -y

# Installer Apache, MySQL et PHP + extensions courantes
sudo apt install -y apache2 mysql-server php libapache2-mod-php
sudo apt install -y php-mysql php-mbstring php-xml php-curl php-zip php-gd

# Verifier les versions installees
apache2 -v
mysql --version
php -v

# Demarrer les services et les activer au boot
sudo systemctl start apache2 mysql
sudo systemctl enable apache2 mysql

# Verifier que les services tournent
sudo systemctl status apache2
sudo systemctl status mysql

# Ouvrir http://localhost dans le navigateur
# La page "Apache2 Ubuntu Default Page" doit s'afficher
!
Dossier des projets Linux. Le dossier racine web d'Apache est /var/www/html/. Creer un sous-dossier sudo mkdir /var/www/html/mon-projet. Pour eviter de toujours utiliser sudo, changer le proprietaire : sudo chown -R $USER:$USER /var/www/html/.

Linux

phpMyAdmin et creation de la BDD

Linux — phpMyAdmin et BDD
1
Installer phpMyAdmin : sudo apt install -y phpmyadmin. Choisir apache2 quand demande.
2
Redemarrer Apache : sudo systemctl restart apache2.
3
Ouvrir http://localhost/phpmyadmin. Login : root avec le mot de passe MySQL.
4
Cliquer "Nouveau" dans le panneau gauche. Nommer la base boutique, interclassement utf8mb4_unicode_ci.
5
Onglet SQL, coller le script de la section 07, cliquer "Executer".
phpMyAdmin — installationTerminal
# Installer phpMyAdmin
sudo apt install -y phpmyadmin

# Pendant l'installation :
# - Choisir "apache2" comme serveur web (espace pour selectionner, entree)
# - "Configure database for phpmyadmin with dbconfig-common" : Oui
# - Definir un mot de passe pour phpMyAdmin

# Activer l'extension mbstring si pas deja fait
sudo phpenmod mbstring
sudo systemctl restart apache2

# Si phpMyAdmin n'est pas accessible apres installation
sudo ln -s /usr/share/phpmyadmin /var/www/html/phpmyadmin

# Acces : http://localhost/phpmyadmin
# Identifiant : root | Mot de passe : celui defini lors de mysql_secure_installation
Creer BDD et utilisateur MySQL — ligne de commandeSQL
# Connexion MySQL en tant que root (Linux)
sudo mysql
# Ou si un mot de passe root a ete defini :
mysql -u root -p

# Creer un utilisateur dedie (recommande en production)
CREATE USER 'appuser'@'localhost' IDENTIFIED BY 'motdepasse';
CREATE DATABASE boutique CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
GRANT ALL PRIVILEGES ON boutique.* TO 'appuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# Importer le script SQL
mysql -u appuser -p boutique < boutique.sql
i
Sur Linux, on peut se connecter a MySQL sans mot de passe avec sudo. La commande sudo mysql connecte directement en root via le socket Unix. C'est le comportement par defaut sur Ubuntu. Apres mysql_secure_installation, un mot de passe est requis.

SQL

Script de creation complet

Ce script SQL cree trois tables liees : categories, produits (avec cle etrangere) et utilisateurs. Il insere des donnees de test et termine par un SELECT de verification. A coller dans l'onglet SQL de phpMyAdmin ou HeidiSQL.

boutique.sql — script complet a executer dans phpMyAdminSQL
-- Selectionner la base de donnees
USE boutique;

-- Table categories
CREATE TABLE IF NOT EXISTS categories (
    id         INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nom        VARCHAR(100) NOT NULL,
    slug       VARCHAR(120) NOT NULL UNIQUE,
    cree_le    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Table produits
CREATE TABLE IF NOT EXISTS produits (
    id           INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    categorie_id INT UNSIGNED NULL,
    nom          VARCHAR(200) NOT NULL,
    description  TEXT,
    prix         DECIMAL(10,2) NOT NULL DEFAULT 0.00,
    stock        INT UNSIGNED NOT NULL DEFAULT 0,
    image        VARCHAR(255),
    actif        TINYINT(1) NOT NULL DEFAULT 1,
    cree_le      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    modifie_le   TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (categorie_id) REFERENCES categories(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Table utilisateurs
CREATE TABLE IF NOT EXISTS utilisateurs (
    id         INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nom        VARCHAR(100) NOT NULL,
    email      VARCHAR(180) NOT NULL UNIQUE,
    mot_de_passe VARCHAR(255) NOT NULL,
    role       ENUM('user','admin') NOT NULL DEFAULT 'user',
    cree_le    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Donnees de test
INSERT INTO categories (nom, slug) VALUES
    ('Vetements', 'vetements'),
    ('Accessoires', 'accessoires'),
    ('Chaussures', 'chaussures');

INSERT INTO produits (categorie_id, nom, prix, stock) VALUES
    (1, 'T-shirt blanc',    19.99, 50),
    (1, 'Jean slim bleu',   49.99, 30),
    (2, 'Ceinture cuir',   25.00, 20),
    (3, 'Baskets running', 79.90,  0);

-- Verification
SELECT p.nom, p.prix, c.nom AS categorie
FROM produits p
JOIN categories c ON p.categorie_id = c.id;
!
Toujours commencer par USE. L'instruction USE boutique; selectionne la base. Sans elle, les CREATE TABLE echoueraient avec "No database selected". Dans phpMyAdmin, si vous avez deja selectionne la base dans le panneau gauche, le USE est optionnel.

CLI

Ligne de commande MySQL

La ligne de commande MySQL permet de travailler sans interface graphique. Utile pour importer des fichiers SQL volumineux, scripter des operations, ou travailler sur un serveur distant.

Ouvrir le terminal MySQL — selon l'environnementTerminal
# WAMP : ouvrir le terminal MySQL
# Clic gauche icone WAMP → MySQL → MySQL Console
# Ou depuis le terminal Windows :
C:\wamp64\bin\mysql\mysql8.0.x\bin\mysql.exe -u root

# Connexion (pas de mot de passe)
mysql -u root

# MAMP Mac : chemin specifique
/Applications/MAMP/Library/bin/mysql -u root -p
# Mot de passe MAMP : root

# Laragon : MySQL accessible dans le PATH
mysql -u root
# Ou clic bouton "Terminal" dans l'interface Laragon
Commandes MySQL essentiellesSQL
-- Une fois connecte au prompt mysql>

-- Lister les bases de donnees
SHOW DATABASES;

-- Creer une base
CREATE DATABASE boutique CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Selectionner une base
USE boutique;

-- Lister les tables
SHOW TABLES;

-- Structure d'une table
DESCRIBE produits;

-- Importer un fichier SQL
mysql -u root boutique < boutique.sql

-- Quitter
EXIT;
i
Importer un fichier SQL depuis le terminal. Pour les gros fichiers, phpMyAdmin a une limite de taille. La commande mysql -u root boutique < boutique.sql n'a pas cette limitation et est beaucoup plus rapide.

PDO

Connexion PDO selon l'environnement

Recapitulatif des parametres de connexion PDO selon l'environnement. Attention au port MySQL qui differe entre MAMP Mac (8889) et les autres (3306).

config/database.php — connexions selon l'environnementPHP
<?php
// config/database.php

return [

    // WAMP (Windows) — port par defaut 3306
    'wamp' => [
        'dsn'      => 'mysql:host=localhost;port=3306;dbname=boutique;charset=utf8mb4',
        'user'     => 'root',
        'password' => '',  // vide par defaut
    ],

    // MAMP (Mac) — port 8889 obligatoire
    'mamp_mac' => [
        'dsn'      => 'mysql:host=localhost;port=8889;dbname=boutique;charset=utf8mb4',
        'user'     => 'root',
        'password' => 'root',
    ],

    // MAMP (Windows) — port par defaut 3306
    'mamp_win' => [
        'dsn'      => 'mysql:host=localhost;port=3306;dbname=boutique;charset=utf8mb4',
        'user'     => 'root',
        'password' => 'root',
    ],

    // Laragon (Windows) — port par defaut 3306
    'laragon' => [
        'dsn'      => 'mysql:host=localhost;port=3306;dbname=boutique;charset=utf8mb4',
        'user'     => 'root',
        'password' => '',
    ],
];
.env + connexion PDO universellePHP
<?php
// Recommande : utiliser .env pour ne pas hardcoder les credentials

// .env
DB_HOST=localhost
DB_PORT=3306
# MAMP Mac : DB_PORT=8889
DB_NAME=boutique
DB_USER=root
DB_PASS=

// Connexion PDO universelle depuis les variables .env
function getConnection(): PDO {
    $dsn = 'mysql:host=' . getenv('DB_HOST')
         . ';port='    . getenv('DB_PORT')
         . ';dbname='  . getenv('DB_NAME')
         . ';charset=utf8mb4';

    return new PDO($dsn, getenv('DB_USER'), getenv('DB_PASS'), [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE  => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES   => false,
    ]);
}

// Test rapide
try {
    $pdo = getConnection();
    echo 'Connexion OK : ' . $pdo->getAttribute(PDO::ATTR_SERVER_VERSION);
} catch (PDOException $e) {
    echo 'Erreur : ' . $e->getMessage();
}
