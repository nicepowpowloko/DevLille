Set & Map

Structures de donnees modernes · Cas d'usage · Methodes

01

Pourquoi ces structures existent

JS dispose de deux structures de donnees classiques : les tableaux (Array) et les objets (Object). Elles couvrent 90% des cas, mais elles ont des limites precises.

Set et Map ont ete introduits en ES6 pour resoudre ces limites de facon native, propre et performante. Ce ne sont pas des remplacants — ce sont des complements pour des cas d'usage specifiques.

Set

Une collection de valeurs uniques. Comme un tableau, mais il refuse automatiquement les doublons. Ideal pour stocker des identifiants, des tags, des elements selectionnes.

Map

Une collection de paires cle → valeur. Comme un objet, mais les cles peuvent etre de n'importe quel type, pas seulement des chaines. Ideal pour des associations, des caches, des compteurs.

02

Vue d'ensemble rapide

Structure Stocke Doublons Type des cles Ordre garanti Quand l'utiliser
Array valeurs indexees Oui index numerique Oui listes ordonnees
Object paires cle/valeur Oui string / Symbol Partiel config, entites
Set valeurs uniques Non — Oui (insertion) unicite, dedup
Map paires cle/valeur Oui n'importe quel type Oui (insertion) association, cache
01

Creer un Set

Un Set s'instancie avec new Set(). On peut lui passer un iterable (tableau, chaine...) en argument. Tous les doublons sont automatiquement supprimes a la creation.

set-creation.js 
// Set vide
const monSet = new Set();

// Set a partir d'un tableau — les doublons sont vires d'office
const nombres = new Set([1, 2, 3, 2, 1, 4, 3]);
console.log(nombres); // Set(4) { 1, 2, 3, 4 }

// Set a partir d'une chaine — chaque caractere unique
const lettres = new Set("javascript");
console.log(lettres); // Set(9) { 'j', 'a', 'v', 's', 'c', 'r', 'i', 'p', 't' }

// La propriete .size (pas .length !)
console.log(nombres.size); // 4
Attention
Un Set utilise .size et non .length comme les tableaux. C'est un piege classique a l'entretien.
02

Iterer sur un Set

set-iteration.js 
const tags = new Set(["js", "react", "css", "html"]);

// for...of — la facon la plus courante
for (const tag of tags) {
  console.log(tag); // "js", "react", "css", "html"
}

// .forEach()
tags.forEach((valeur) => {
  console.log(valeur);
});

// Convertir en tableau pour utiliser .map(), .filter(), etc.
const tableau = [...tags];      // spread operator
const tableau2 = Array.from(tags); // Array.from()

// Les deux sont equivalents
console.log(tableau);  // ["js", "react", "css", "html"]
03

Cas d'usage classique — dedoublonner un tableau

C'est probablement la chose pour laquelle on utilise le plus Set en pratique : supprimer les doublons d'un tableau en une ligne. Propre, lisible, natif.

dedup.js 
const ids = [1, 2, 3, 2, 1, 4, 5, 3, 5];

// Avant — verbose et lent
const unique1 = ids.filter((val, idx, arr) => arr.indexOf(val) === idx);

// Apres — une ligne avec Set
const unique2 = [...new Set(ids)];
console.log(unique2); // [1, 2, 3, 4, 5]

// Meme chose avec des chaines
const mots   = ["js", "react", "js", "vue", "react"];
const uniques = [...new Set(mots)];
console.log(uniques); // ["js", "react", "vue"]
01

Toutes les methodes

.add(val) Ajoute une valeur. Si elle existe deja, rien ne se passe. Retourne le Set (chainable).
.has(val) Verifie si une valeur existe. Retourne true ou false. Tres rapide (O(1)).
.delete(val) Supprime une valeur. Retourne true si elle existait, false sinon.
.clear() Vide completement le Set. Aucun retour utile.
.size Propriete (pas methode) — nombre d'elements dans le Set.
.forEach(fn) Itere sur chaque valeur et appelle la fonction.
.values() Retourne un iterateur sur les valeurs. Utilisable avec for...of.
[...set] Spread pour convertir en tableau et acceder aux methodes Array.
02

Exemples detailles

set-methodes.js 
const competences = new Set(["js", "html", "css"]);

// .add() — chainable
competences.add("react").add("node");
console.log(competences); // Set(5) { 'js', 'html', 'css', 'react', 'node' }

// .add() ignore les doublons silencieusement
competences.add("js");
console.log(competences.size); // 5, pas 6

// .has() — verification rapide O(1)
competences.has("react");  // true
competences.has("python"); // false

// .delete() — retourne true si la valeur existait
const supprime = competences.delete("html");
console.log(supprime);     // true
console.log(competences.size); // 4

// Convertir + filtrer — Set n'a pas .filter() nativement
const courtes = [...competences].filter(c => c.length <= 3);
console.log(courtes); // ["js", "css"]

// .clear()
competences.clear();
console.log(competences.size); // 0
03

Operations ensemblistes

Set n'a pas de methodes natives pour l'union, l'intersection ou la difference, mais elles s'implementent facilement en une ligne avec le spread et les methodes de tableaux.

set-operations.js 
const setA = new Set([1, 2, 3, 4]);
const setB = new Set([3, 4, 5, 6]);

// Union — tous les elements des deux
const union        = new Set([...setA, ...setB]);
console.log(union); // Set { 1, 2, 3, 4, 5, 6 }

// Intersection — elements presents dans les deux
const inter        = new Set([...setA].filter(x => setB.has(x)));
console.log(inter); // Set { 3, 4 }

// Difference — elements de A absents de B
const diff         = new Set([...setA].filter(x => !setB.has(x)));
console.log(diff);  // Set { 1, 2 }
01

Creer une Map

Une Map s'instancie avec new Map(). On peut lui passer un tableau de paires [cle, valeur]. Contrairement a un objet, les cles peuvent etre de n'importe quel type : string, number, objet, fonction...

map-creation.js 
// Map vide puis remplissage
const maMap = new Map();
maMap.set("nom",    "Alice");
maMap.set("age",    28);
maMap.set("actif",  true);

// Map a partir d'un tableau de paires [cle, valeur]
const scores = new Map([
  ["Alice", 95],
  ["Bob",   87],
  ["Clara", 91]
]);

// .size — nombre de paires
console.log(scores.size); // 3

// Cles de n'importe quel type — IMPOSSIBLE avec un objet !
const objKey  = { id: 1 };
const fnKey   = () => {};
const mapAvec = new Map();

mapAvec.set(objKey, "un objet comme cle");
mapAvec.set(fnKey,  "une fonction comme cle");
mapAvec.set(42,     "un nombre comme cle");

console.log(mapAvec.get(objKey)); // "un objet comme cle"
02

Iterer sur une Map

map-iteration.js 
const scores = new Map([
  ["Alice", 95], ["Bob", 87], ["Clara", 91]
]);

// for...of avec destructuration [cle, valeur]
for (const [nom, score] of scores) {
  console.log(`${nom} : ${score}`);
}
// "Alice : 95"  "Bob : 87"  "Clara : 91"

// .forEach(valeur, cle) — ATTENTION : valeur avant cle !
scores.forEach((score, nom) => {
  console.log(nom, "->", score);
});

// Iterer sur les cles ou valeurs separement
for (const cle    of scores.keys())   { console.log(cle); }
for (const valeur of scores.values()) { console.log(valeur); }

// Convertir en tableau de paires
const paires = [...scores];
// [ ["Alice", 95], ["Bob", 87], ["Clara", 91] ]
Piege classique
Dans .forEach(), l'ordre des parametres est (valeur, cle) et non (cle, valeur). C'est l'inverse de ce qu'on attendrait intuitivement.
01

Toutes les methodes

.set(k, v) Ajoute ou met a jour une paire cle/valeur. Retourne la Map (chainable).
.get(k) Recupere la valeur associee a la cle. Retourne undefined si la cle n'existe pas.
.has(k) Verifie si une cle existe. Retourne true ou false. Complexite O(1).
.delete(k) Supprime la paire associee a la cle. Retourne true si la cle existait.
.clear() Vide completement la Map.
.size Propriete — nombre de paires cle/valeur.
.keys() Iterateur sur les cles dans l'ordre d'insertion.
.values() Iterateur sur les valeurs dans l'ordre d'insertion.
.entries() Iterateur sur les paires [cle, valeur]. Equivalent de boucler sur la Map.
.forEach(fn) Itere avec un callback. Ordre des params : (valeur, cle, map).
02

Exemples detailles

map-methodes.js 
const cache = new Map();

// .set() — chainable
cache
  .set("user:1", { nom: "Alice", age: 28 })
  .set("user:2", { nom: "Bob",   age: 32 });

// .get() — recuperer une valeur
const alice = cache.get("user:1");
console.log(alice); // { nom: "Alice", age: 28 }

// .get() sur une cle inexistante → undefined, pas d'erreur
cache.get("user:999"); // undefined

// .has() — verifier avant de lire pour eviter undefined
if (cache.has("user:1")) {
  console.log("En cache !", cache.get("user:1"));
}

// .set() met a jour si la cle existe deja
cache.set("user:1", { nom: "Alice", age: 29 }); // mise a jour
console.log(cache.size); // 2, pas 3

// .delete()
cache.delete("user:2");
console.log(cache.size); // 1
03

Map vers Object et Object vers Map

conversion.js 
// Object → Map
const config = { host: "localhost", port: 3000, debug: true };
const configMap = new Map(Object.entries(config));
console.log(configMap); // Map { 'host' => 'localhost', 'port' => 3000, ... }

// Map → Object
const maMap   = new Map([[ "a", 1], ["b", 2]]);
const monObjet = Object.fromEntries(maMap);
console.log(monObjet); // { a: 1, b: 2 }

// Map → Array de paires
const paires = [...maMap]; // ou Array.from(maMap)
// [ ['a', 1], ['b', 2] ]
01

Set vs Array

Operation Array Set
Verifier l'existence d'une valeur .includes(v) — O(n) lent sur grands tableaux .has(v) — O(1) toujours rapide
Ajouter une valeur unique Verifier + push — 2 etapes .add(v) — 1 etape, gere les doublons
Supprimer une valeur .filter() — cree un nouveau tableau .delete(v) — en place, direct
Acces par index arr[2] — oui Non — Set n'a pas d'index
Doublons Oui — gestion manuelle Non — automatique
.map() .filter() .reduce() Oui — natif Non — convertir en tableau d'abord
Quand choisir Set
Quand tu as besoin d'unicite et/ou de verifications rapides d'existence. Autrement, garde un tableau.
02

Map vs Object

Caracteristique Object Map
Type des cles String ou Symbol uniquement N'importe quel type
Ordre des cles Partiel (strings numeriques d'abord) Ordre d'insertion garanti
Compter les entrees Object.keys(o).length — verbose map.size — direct
Cles heritees Oui — heritage du prototype Non — seulement les cles definies
Performances (lectures/ecritures frequentes) Correct Meilleur sur de nombreuses ops
Serialisation JSON JSON.stringify() natif Pas natif — convertir d'abord
Quand choisir Map
Quand les cles ne sont pas des strings, quand tu fais de nombreuses ajouts/suppressions, ou quand tu as besoin d'ordre d'insertion garanti. Pour des donnees statiques, garde un objet.
01

Set — gestion d'elements selectionnes

selection-set.js 
// Panier de produits — chaque produit ne peut etre qu'une fois
const panier = new Set();

function toggleProduit(id) {
  if (panier.has(id)) {
    panier.delete(id);
    console.log(`Produit ${id} retire du panier`);
  } else {
    panier.add(id);
    console.log(`Produit ${id} ajoute au panier`);
  }
}

toggleProduit("prod-1"); // ajoute
toggleProduit("prod-2"); // ajoute
toggleProduit("prod-1"); // retire

console.log("Panier :", [...panier]); // ["prod-2"]
console.log("Total :", panier.size);    // 1
02

Map — cache de resultats API

cache-map.js 
// Cache pour eviter des appels API redondants
const userCache = new Map();

async function getUser(id) {

  // Verifier si deja en cache
  if (userCache.has(id)) {
    console.log(`Cache hit pour id=${id}`);
    return userCache.get(id);
  }

  // Sinon, appel API
  const res  = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
  const data = await res.json();

  // Stocker en cache pour la prochaine fois
  userCache.set(id, data);
  console.log(`Fetch API pour id=${id}`);

  return data;
}

await getUser(1); // Fetch API
await getUser(1); // Cache hit — pas de requete reseau
await getUser(2); // Fetch API
03

Map — compteur de frequences

compteur-map.js 
// Compter la frequence de chaque valeur dans un tableau
const langues = ["js", "php", "js", "python", "js", "php", "rust"];

const compteur = new Map();

for (const lang of langues) {
  // .get() retourne undefined si absent → ?? 0 pour initialiser
  const actuel = compteur.get(lang) ?? 0;
  compteur.set(lang, actuel + 1);
}

console.log(compteur);
// Map { 'js' => 3, 'php' => 2, 'python' => 1, 'rust' => 1 }

// Trouver la langue la plus utilisee
let max = "", maxVal = 0;
for (const [lang, nb] of compteur) {
  if (nb > maxVal) { max = lang; maxVal = nb; }
}
console.log(`Plus populaire : ${max} (${maxVal} fois)`); // js (3 fois)

correction.js 
async function analyserPosts() {
  try {
    const res   = await fetch("https://jsonplaceholder.typicode.com/posts");
    const posts = await res.json();

    // 1. Set des userIds uniques
    const userIds = new Set(posts.map((p) => p?.userId ?? 0));
    console.log("Utilisateurs uniques :", userIds.size); // 10

    // 2. Map userId → tableau de posts
    const postsByUser = new Map();

    for (const post of posts) {
      const uid     = post?.userId ?? 0;
      const existant = postsByUser.get(uid) ?? [];
      postsByUser.set(uid, [...existant, post]);
    }

    // 3. Afficher les stats
    for (const [userId, userPosts] of postsByUser) {
      console.log(`User ${userId} : ${userPosts.length} posts`);
    }

    // BONUS — utilisateur avec le plus de posts
    let topUser = null, topCount = 0;

    for (const [userId, userPosts] of postsByUser) {
      if (userPosts.length > topCount) {
        topUser  = userId;
        topCount = userPosts.length;
      }
    }

    console.log(`Top auteur : User ${topUser} avec ${topCount} posts`);

  } catch (err) {
    console.error("Erreur :", err?.message ?? "inconnue");
  }
}
