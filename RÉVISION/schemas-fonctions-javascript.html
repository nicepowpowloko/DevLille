Révision : créer une FONCTION en JavaScript

0
Comprendre le concept
Une fonction, c'est comme une MACHINE
ENTRÉE
(Paramètres / Ingrédients)
↓
TRAITEMENT
(Instructions / Recette)
↓
SORTIE
(Return / Résultat)
ANALOGIE : Une fonction, c'est comme une recette de cuisine !
On donne des ingrédients (paramètres) → On suit la recette (code) → On obtient un plat (résultat)
Pourquoi utiliser des fonctions ?
Pour ne pas répéter le même code plusieurs fois
Pour organiser et structurer son code
Pour pouvoir réutiliser facilement du code
Pour rendre le code plus lisible
1
L'anatomie d'une fonction
Décomposition visuelle
function nomDeLaFonction(parametre1, parametre2) { // Instructions à exécuter return resultat; }
Élément Rôle Obligatoire ?
function Mot-clé pour déclarer une fonction OUI
nomDeLaFonction Le nom que vous donnez à votre fonction OUI
() Parenthèses pour les paramètres OUI (même vides)
parametre1, parametre2 Données que la fonction peut recevoir NON (optionnel)
{} Accolades contenant le code OUI
return Renvoyer un résultat NON (optionnel)
2
Créer une fonction SIMPLE (sans paramètre)
Objectif : Afficher "Bonjour !"

ÉTAPE A : Déclarer la fonction

function direBonjour() { console.log("Bonjour !"); }
Explication :
• function = je crée une fonction
• direBonjour = son nom
• () = pas de paramètre
• {...} = le code à exécuter

ÉTAPE B : Appeler la fonction

direBonjour(); // Résultat dans la console : // Bonjour !
Explication :
• Pour utiliser la fonction, on écrit son nom
• Suivi de ()
• C'est ce qu'on appelle "appeler" une fonction
ATTENTION : Déclarer une fonction NE l'exécute PAS !
Il faut l'appeler avec nomDeLaFonction() pour qu'elle s'exécute.
MAUVAIS
// La fonction est déclarée mais jamais appelée function direBonjour() { console.log("Bonjour !"); } // Rien ne s'affiche !
BON
// 1. On déclare la fonction function direBonjour() { console.log("Bonjour !"); } // 2. On l'appelle ! direBonjour();
3
Ajouter des PARAMÈTRES
Objectif : Dire bonjour à une personne spécifique
PARAMÈTRE : "Alice"
(Donnée entrante)
↓
FONCTION : direBonjour(prenom)
Créer le message "Bonjour Alice !"
↓
RÉSULTAT : Affiche "Bonjour Alice !"
Le code
// DÉCLARATION avec un paramètre function direBonjour(prenom) { console.log("Bonjour " + prenom + " !"); } // APPELS avec différents arguments direBonjour("Alice"); // Affiche : Bonjour Alice ! direBonjour("Bob"); // Affiche : Bonjour Bob ! direBonjour("Charlie"); // Affiche : Bonjour Charlie !
Vocabulaire important :
• PARAMÈTRE = Variable dans la déclaration (prenom dans l'exemple)
• ARGUMENT = Valeur passée lors de l'appel ("Alice", "Bob"...)
Plusieurs paramètres
// Fonction avec 2 paramètres function saluer(prenom, age) { console.log("Bonjour " + prenom + ", tu as " + age + " ans."); } // Appel avec 2 arguments saluer("Marie", 25); // Affiche : Bonjour Marie, tu as 25 ans.
ASTUCE : Les paramètres sont séparés par des virgules
L'ordre est important : 1er argument → 1er paramètre, 2ème argument → 2ème paramètre
4
Utiliser RETURN pour renvoyer un résultat
Objectif : Calculer et réutiliser le résultat

SANS return

function additionner(a, b) { let resultat = a + b; console.log(resultat); } let total = additionner(5, 3); // Affiche : 8 console.log(total); // Affiche : undefined console.log(total + 10); // Affiche : NaN (impossible !)

AVEC return

function additionner(a, b) { let resultat = a + b; return resultat; } let total = additionner(5, 3); // total vaut 8 console.log(total); // Affiche : 8 console.log(total + 10); // Affiche : 18
RETURN = DONNER UN CADEAU
Sans return, la fonction fait son travail mais ne vous donne rien !
Avec return, elle vous rend un résultat que vous pouvez réutiliser.
RÈGLE IMPORTANTE :
Une fois que return est exécuté, la fonction s'arrête immédiatement.
Tout le code après return ne sera JAMAIS exécuté !
function exemple() { console.log("Ligne 1"); // S'exécute console.log("Ligne 2"); // S'exécute return "Résultat"; // S'exécute et STOP console.log("Ligne 3"); // NE S'EXÉCUTE JAMAIS console.log("Ligne 4"); // NE S'EXÉCUTE JAMAIS }

Connecter la fonction au HTML
Créer un bouton qui utilise une fonction

HTML

<button id="monBouton"> Cliquez-moi ! </button> <p id="resultat"></p>

JavaScript

// 1. Créer la fonction function afficherMessage() { let element = document.querySelector("#resultat"); element.textContent = "Bouton cliqué !"; } // 2. Connecter au bouton let bouton = document.querySelector("#monBouton"); bouton.addEventListener("click", afficherMessage);

↓
L'événement "click" est détecté
↓
La fonction afficherMessage() s'exécute
↓
Le texte "Bouton cliqué !" s'affiche
